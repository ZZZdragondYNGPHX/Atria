### 轮次精确顺序与覆盖

1. R1：「选择方案 B：完整规划 Hybrid Cognitive Memory 2.0，分阶段实现」。
2. R2：「B 作为系统默认，A 与 C 作为作品层面的可选策略」——**所指为旁白叙述知识边界**。
3. R3：先「第三轮选择方案 B」，后「第三轮选择方案 D」——**D 覆盖 B**，此处所指为认知更新方式。
4. R4：「第四轮选择方案 A：游戏时间驱动」——**所指为自主 NPC 模拟时间**。
5. R5：「第五轮选择方案 D」——**所指为角色遗忘**。
6. R6：用户要求立即建文档，每轮先落盘；同时开始讨论统一检索。**第六轮算法方案当前尚未选定。**

不得只把字母方案记成一组全局 A/B/C/D：它们分别属于不同问题。

## 2. 明确表达过的需求/约束

- 拟删除对外分立 LLM / RAG 召回并全面使用统一混合记忆，但保留所需的内部算法能力。
- 希望面向前沿 Agent RP、长篇故事、人物自主权、角色视角防全知、人格/文风自然、长期连续与稀疏调用。
- 先多轮架构讨论，**再**正式交付研究/规划让 Codex 融入当前开发分支的正式 Plan。
- 现阶段用户明确要求文档**立即创建并持续更新**；因此先保存研究讨论，后完成正式集成。

## 3. 研究建议 — 尚未构成用户批准

- T0 确定性、T1 重大事件按需共享 cognition pass、T2 自主模拟；具体触发阈值、频率、费用和失败降级未定。
- 记忆语义七类（Episodic / Semantic / Perspective / Social / Affective / Personality / Narrative）是逻辑分类，不是七个新存储服务。
- 统一入口内的可选词项/向量/图扩展/RRF/重排/LLM、多跳路径、角色感知先验过滤、独立评分通道。
- 原 Event / World authority、Actor cognition、Context、Commitment、TaskScheduler、费用记账沿用现有权威而不新增第二套真相。
- 轻度遗忘的数学衰减模型、保护清单、作者参数和情绪/记忆重构规则、Narrator 信息揭示默认均需设计与评测。
- 默认普通 RP 一次主要正文调用的质量—成本目标、离线整理与跨 Revision 缓存重验的精确实现细节待定。
- 老配置/索引删除、原始记忆持久化以及硬切换的数据迁移和清理细则还未批准。

## 4. 后续讨论的开放问题

- R6：统一 Hybrid 的核心检索算法、候选召回策略、分数与约束顺序、多跳推理触发、MemoryPacket 结构、缓存和失效。
- R7 候选：记忆抽取/写入的可验证协议、增量更新、矛盾消解、叙事与角色两类使用者的质量评测。
- R8 候选：完整阶段拆分、旧模式删除与数据边界、部署依赖、性能成本验收与 Codex 企划整合。
- 未来各轮以用户进一步授权为准，不预先将 R7/R8 等同实际定稿轮数。

## 5. 决策维护规范

用户某轮答复后，先将选项对应完整语义写入此文件；如覆盖旧选择，显式标注覆盖关系，不擦掉历史；随后更新具体领域模块，并在远端提交成功后回答该轮讨论。不把模型的默认推荐偷换为用户选择。
