# Hybrid Cognitive Memory 2.0 — 已确认产品决策

> **状态：R1–R5 已确认，R6 算法尚待讨论。**
> **任务：** `hybrid-cognitive-memory-2-0`；**入口：** [index.md](index.md)。
> 本文件只保存**最终生效的产品语义**。中间对话、选择按钮和助手建议不视作设计依据。后续讨论只能新增或显式修改下列决策；具体算法由 [R6 研究](retrieval-design.md) 比较，不在这里预设结论。

| 决策 ID | 已确认内容 | 实施边界 |
| --- | --- | --- |
| HCM-01 · 总范围 | **完整规划 Hybrid Cognitive Memory 2.0，分阶段实现。** 逐步删去对外独立 LLM Recall / RAG Recall 模式，只保留统一 Hybrid Recall。 | 不排除内部按需的词项、Embedding、重排、图推理和 LLM 组件；本轮不授权直接删除代码。 |
| HCM-02 · 叙事权限 | **B 系统默认：旁白与 NPC 认知分离。** 作品可选 A 严格限知、C 作者自定义。 | 旁白“可知”与“允许提前揭示”不同；NPC 不自动取得旁白信息。 |
| HCM-03 · 认知更新 | **D：默认事件驱动混合认知（B）；高度自主认知模拟（C）作为作品可选。** | 不默认让所有 NPC 持续调用模型；认知变化须来源可追溯。 |
| HCM-04 · 自主模拟时间 | **A：仅按正式游戏世界时间推进自主 NPC 模拟。** | 不把用户在线等待或离线真实时间直接等同世界时间。 |
| HCM-05 · 角色遗忘 | **D：默认轻度自然遗忘（B）；作品可选深度认知遗忘（C）。** | 检索衰减/摘要压缩不等于 NPC 真正遗忘；关键历史、承诺、关系保护；不清除 World Truth。 |

## 未冻结事项

第六轮需要确定：Hybrid 内部统一检索路线、授权过滤点、查询理解、图扩展与多跳升级、评分/多样性/预算、上下文编译、缓存、成本与验收。**在完成讨论前，参数、默认阈值、存储迁移、R6 的技术路线都只是候选**。

## 保持的系统权威

- World/Session 是事实与正式事件权威；Actor Cognition 是角色动态心理状态的所属域；Memory 负责历史证据与索引，不新造 World Truth。
- 与 [Agent Intelligence Runtime 正式企划](../agent-intelligence-runtime/index.md) 的 M1/M2/M3/M4/M8 协调，但不修改既有验收和授权。
- 认知建议不是提交结果；来源、角色可见性、分支版本、回滚与费用不能为省调用而跳过。
