## 已确认的第六轮最终架构选择

| 决策 ID | 已确认内容 | 实施边界 |
| --- | --- | --- |
| HCM-06 · 统一检索算法 | **采用 Constraint-first Adaptive Hybrid（强约束优先、自适应混合检索）。** 先依 Authority / Information 核对来源、Actor 视角、时间与 Branch，构建合法候选域；优先廉价词项及有界图检索，Embedding 可选；复杂查询按需使用 PPR、Rerank 或 LLM 辅助。 | 统一的产品召回接口，不是每轮全部算法并行运行；具体排名公式、请求/图预算和触发阈值由真实案例实测；关联推断不能提升为正式真相。 |
| HCM-07 · 硬切换与数据边界 | **删除旧独立 LLM/RAG Recall 的 UI、配置和执行路径，不做双读双写、模式别名或旧算法兼容。** 保留有来源且仍有效的 Atria 原生 Timeline/World、故事历史与可验证的用户记忆；派生索引重新构建。 | 不迁移 SillyTavern 旧数据；旧设置与索引明确清理；无来源或不可验证的旧衍生内容不得自动晋升为可信事实；实施前明确删除/保留清单与数据保护测试。 |
| HCM-08 · 正确性与交互时延 | **普通回合以零额外认知 LLM 调用为目标；当前正文依赖的来源、知识边界与权威状态必须同步核验；非关键反思、整理、压缩在后台有界执行。** 缺必要证据时明确未知或拒绝相关操作，不能以猜测换取低时延。 | “零额外”不代表检索/Embedding 免费，也不是所有任务硬性仅一次 LLM；必要阻塞与额外调用需来源、预算和效益；不许因性能指标弱化安全/权限/事实基线。 |

## 保持的系统权威

- World/Session 是事实与正式事件权威；Actor Cognition 是角色动态心理状态的所属域；Memory 负责历史证据与索引，不新造 World Truth。
- 与 [Agent Intelligence Runtime 正式企划](../agent-intelligence-runtime/index.md) 的 M1/M2/M3/M4/M8 协调，但不修改既有验收和授权。
- 认知建议不是提交结果；来源、角色可见性、分支版本、回滚与费用不能为省调用而跳过。
