# S24：有界候选比较与正式结果绑定

状态：2026-10-13 Native与Project有限工程消费者及双域确定性实际对照完成。依赖 [S22](s22-hypothetical-preview.md)、[S23](s23-model-prediction.md)、S19及 [architecture §8](architecture.md#8-counterfactual-与-metacognition)。双域同目标的两种合法方案均经原authority提交，比较方案各减少一处改动，同时增加本地比较开销。此有限结果不代表独立Agent决策质量、语义预测收益或一般高影响任务收益，细项与费用见同一Record。

首批比较是服务器自己准备的有界声明action与 exact Player projection。用户显式指定已有公开item/data field的期望值；固定规则先匹配目标，再选公开delta最小的候选，无法满足则不选择。不以未校准confidence当客观成功概率，不推导未声明的价值标准或玩家动作。可选模型预测沿原PredictionService逐候选执行，不信任客户端上传prediction artifact的producer身份。

`current=true`只说明源新鲜，不能证明客户端body曾由Host产生。所有候选仍是假设，不写World、Memory、Task结果、用户偏好或正式Experience outcome。选择只返回action proposal，真实操作需再次经原authority/Session CAS；预演不携带publication proof。

不接受caller自报receipt/actual值。只比较当前仍获准Player字段与所选S22预测，未选未来不参与误差或Outcome标签。S23自由文本没有机械可测claims时，modelPredictionError保持not_measurable，不能用text judge冒充事实误差。该typed comparison observation只引用原receipt，不另建事实/偏好writer。

模型发送继续同一bank，失败/取消/晚到费用保持。临时comparison不能声称跨restart durable恢复；丢失来源时保持unavailable，不从客户端字段重建producer证明。

Project独立消费者复用原planning Task、localWork与Workspace串行evaluate/review/commit，最多8候选、每个32操作，只接受source/project/frontend操作，不接受无法按原源快照恢复的Library资源操作。原Task计划、Review及commit仍须执行。evaluateWorkspace实际临时应用并finally恢复文件及preview handle，不能称为纯内存隔离，也不宣称所有并发reader均隔离。正式outcome从原completed Task及Studio Git changeSet receipt取得，质量和模型误差保持not_measurable。

中断后修复成功仍报告失败并保留费用，持续失败阻止原Task及Git同步。Git恢复marker与原Task.recovery中的服务器源identity共同保证重建Studio不自动把临时候选提交成用户修改；双marker写入失败时依赖原Task CAS持久化，连Task持久化失败也明确报错，不承诺不存在的durability。精确原HEAD/源恢复后只清活动阻断identity，原blocked状态、费用及历史保留供显式Task控制。ProjectStore拒绝大小写变体.git路径。临时comparison按原storage authority及owner隔离；丢失token不可从caller重建。

实际双域对照复用同任务/配置/质量底线；预先声明的宽改动基线不是独立抽样的Agent决策，不能将确定性最少改动选择推导为模型收益。
