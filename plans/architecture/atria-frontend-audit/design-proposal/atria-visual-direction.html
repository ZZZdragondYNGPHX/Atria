故事是光，
界面是建筑。An atrium for stories — quiet architecture, lit only where the story lives.

Atria 同时是长篇阅读的舞台、作者的精密工作台，也是版本、权限与恢复的可信账本。这套方向把三者放进同一座「中庭」：结构安静克制，光只落在故事上；每一种真相状态——草稿、已提交、历史、原件、精确引用、未知——都有自己不会被误读的形状。

Principles

六条设计原则

i.

光只给故事

金色（Lumen）只用于故事之光与每屏唯一的主意图。工作台保持中性墨色，让作品与作者的文字成为画面里最亮的东西。

ii.

真相有形状

草稿是虚线，已提交是实心，历史是斜纹，原件带锁，精确引用带准星，未知是点线。灰度、色盲、forced-colors 下依然可辨。

draftrev 8b21rev 7f3aUNKNOWN
iii.

同等能力，不同姿态

手机不是只读版。编辑、Review、审批、恢复都以 Sheet、列表和坐标替代手势完成；布局可以不同，能做的事必须相同。

iv.

作品接管舞台，宿主永远留门

Work 可以在 hybrid / full 模式改写舞台，但「退出作品界面 · 停止 · 保存 · Persona · 诊断 · 重载表现」始终可达，且不受作品样式影响。

v.

按后果命名操作

「预览历史」≠「切换分支」，「移入回收站」≠「永久删除」，「停止」≠「撤销」。按钮文字描述它真正改变了什么，而不是笼统的「确定」。

vi.

不画假的绿灯

NOT_RUN、UNKNOWN、source_unready、BLOCKED 是一等视觉公民。没有证据就不显示成功，没有来源就不显示数值，宁可诚实地留白。

性质：讨论输入 · 非产品合同 · 非冻结设计 · 非实施授权 数据：本地演示 · 不发模型请求 · 不连接第三方 · 不读写真实账户 运行验收：全部 NOT_RUN

✦
雾港十三夜 · 入口「第三夜：自由探索」· 以 沈砚 参与
T38 · 23:02 · rev 3c9e

雾是从傍晚开始漫上来的。先吞掉了海关钟楼的尖顶，接着是一排排停泊的驳船，最后连码头上那盏孤零零的煤气灯，也只剩下一团昏黄、湿漉漉的光晕，像谁在水里化开了一滴蜜。

你把领口竖起来，站在第七号仓库的檐下。信上只写了一句话——「子夜之前，灯下等我」——没有落款，字迹却熟悉得叫人心慌。三年前，同样的笔迹在你的书店里留下过一册《海错图》残卷，此后再没有人来取。

潮水一下一下拍着木桩，声音闷而远。远处汽笛响了一声，又很快被雾咽了回去。

「沈先生倒是守时。」

声音从灯影的另一侧传来，不高，带着一点刚唱完夜场的沙哑。她披一件旧呢子大衣，伞没有撑开，只垂在手里，伞尖在石板上点出一小圈水痕。「我以为您会带巡捕房的人来。三年前那样的事，换了谁都该多留个心眼。」

T41 · 23:11 · rev 5b8a

柳絮的目光在残卷上停了很久。煤气灯的火苗忽然矮了一下，光晕缩回灯罩里，又慢慢涨开，照见扉页角落一枚褪了色的朱印——不是藏书印，是一枚船印，印文只剩半个「渡」字。

「渡口的渡。」她低声说，像是怕惊动了什么，「您父亲那条船，就叫这个名字。」

04.6动效：沉降、退出、回弹

动效只表达因果与层级：东西从哪来、到哪去。进入用「沉降」（浮起 6px 后落定），退出更快，回弹只给手势。减少动态效果开启后全部变为即时，流式文本不闪烁光标。

04.7层级与 Escape / Back

所有临时层共用一个层栈：Escape / Android Back 每次只关最上一层并归还焦点；输入法组合中的 Escape 不关层。作品界面永远在宿主「门」之下。

04.8图标：1.6px 线描，24 网格

单色描边、圆头圆角、无填充，随文字颜色变化。图标永远配文字或 aria-label；纯装饰图标 aria-hidden。

04.9断点与密度

Compact ≤ 719底部五域栏 + 全局菜单；Inspector → 三档 Sheet；Studio 五段式；对话框 → 全屏层
Medium 720–1179图标导航轨；Inspector 叠加在内容上（可固定）；Studio 两栏 + 侧抽屉
Expanded ≥ 1180导航轨 + 主区 + 固定 Inspector；Studio 树 / 编辑 / AI 三栏

数值沿用现有 atria-shell/constants.js，不是新冻结。密度两档：舒适（默认，触屏与阅读）与紧凑（专业编辑）；密度只改间距与字号阶梯，不隐藏任何控件。
