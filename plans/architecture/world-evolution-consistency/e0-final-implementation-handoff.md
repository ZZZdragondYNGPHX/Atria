# ARCH-DWE-01 · 功能实施入口与恢复范围

[唯一入口](index.md) · [实现分工](e0-preflight-execution.md) · [同一 Record](../../../records/architecture/world-evolution-consistency.md)。**Draft / Paused**。W1-B～W22-B 的已确认架构方向保持。

## 已确定的实现方向

- P2 优先：原 SessionRevision 中受保护的最小 Subject identity/origin/scope/admission；原领域继续持有事实值，HCM/Context 只作合法派生。
- 新主体承担持续后果时，与正式效果经原 Native Domain 发布；World reducer、Authority Turn 与 Narrator 沿各自原入口协调结果，不能把两个不同提交说成同一事务。
- 读取按 Session/Branch/Revision，再按可用领域 Clock 的有效时间与合法 Perspective；Source Claim、私人 Belief 与客观事实区分。
- Timeline/Play/媒体消费真实 Participant 与独立表达模板；Library/Studio 提供正文、关键绑定和起点预览，不只增加后台 schema。

## 恢复后直接落实的接口

| 接口工作 | 对应功能 |
| --- | --- |
| 原受保护 Namespace 与 Typed admission、Revision/Receipt | 主体登记与持续世界效果 |
| Domain Fact 来源／有效期／纠错读取，Save/Branch/GC 引用 | 当前／历史世界、存读档 |
| 动态 Perspective 与 Subject/LocalRef 映射 | NPC 认知、记忆、有限自主行动 |
| Effective World／Source Claim→ContextPort | 正确当前事实、史料、传闻与个人所知进入 Prompt |
| Participant／Expression／展示投影 | 动态对话人物、档案、语音与插图 |
| 作者定义／EntryPoint／预览／冻结及旧调用替换 | 世界创作器、Studio 装配与 Play 可见世界 |

具体字段、ID 名称、函数签名与原服务整合由执行者按原实现落实；只有改变已确认产品语义或超出用户范围的取舍才需再讨论。执行方式见[入口：实施时的连续推进](index.md#实施时的连续推进)。
