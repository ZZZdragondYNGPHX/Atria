# 世界状态、历史和存储

## 读取与声明

- observe 只加载一次确定 Revision；将已取得快照交给内部加载路径。
- 不可变包声明以包内容身份和入口缓存编译结果；解析 Data 与比较源码不应成为热缓存命中的前置工作。缓存有明确容量与生命周期。
- 生命周期记录按 ID 建立可复用索引。按 ID 查询计入实际访问量，集合筛选仅对扫描过的记录计量；修改记录集合时同步失效。
- 校验按不变声明、未变记录与修改记录区分。避免对调用方可变对象做身份信任；复用只限真正不可变对象或由写入者维护的版本。
- 内部读取共享宿主接纳并深冻结的记录值，公共可变读取返回隔离副本；记录信封和可写状态容器仍独立。类型校验复用同一不可变值的成功结果。

## 候选与模拟

- 逐步以局部复制替换整个 base 深复制；只读 timeline/manifest/knowledge 共享，写入 namespace 和被修改的记录复制。先核对所有写入点，防止候选污染基底。
- 模拟到期调度只在依赖变化时重新评估。声明无法给出完整依赖时保留正确的重新评估，不能因优化改变游戏因果与顺序。
- 状态增量仍由既有存储保存；执行侧保留变更身份，减少全树 diff 和 hash。内容寻址和新提交的身份计算保留。
- 无损历史保留：读取窗口/索引与当前行动所需数据分离。现有明确要求完整历史的消费者必须保持语义，不以偷偷裁剪数组实现优化。
- 追加发布复用相同且宿主接纳的不可变历史前缀及已写入的新条目，保留全部变体；改写、分支切换和检查点仍重建。冷完整加载仍是完整历史读取。

## 事务与查询

- Session 操作顺序由现有资源锁负责；计算不占用账号级存储事务。最终出版继续使用 expected revision CAS 和耐久事务。
- SQL Native 查询把条件、排序与 limit 下推；检查 key 表达式与索引可用性，参数化绑定，不拼接用户 SQL。
- 文件存储保持现有 journal 权威，不把异步文件读取当 CPU 并行。可按 key 已知前缀缩小目录枚举；没有索引的集合查询诚实记录扫描成本。
- 文件文档缓存按完整 FD stamp 校验并限制条数/驻留字节，写入更新 stamp，变更时同步撤销解码状态身份。journal 压缩/解压异步化，保持字节格式和恢复权威。
- 不引入跨 mutable HEAD 的快照缓存；资源删除、恢复和 GC 仍由现有权威协调。

## 证据

以大记录集合单 ID 读取、局部更新、重复观察、长历史和两个会话竞争为场景。核对状态与历史不丢失、基底不被候选修改、冲突失败不发布、计算期间无关存储访问可完成。

## P7：完整读取、摘要和集合查询

- 完整历史保留所有消息与变体，通过既有存储的有界批量读取消除逐条请求；FS 使用有界并发，SQL 使用精确 key 集合。窗口读取复用同一路径；不得扫描同会话无关分支替代精确读取。
- 保持现有内容寻址的字节和 SHA256 语义，对宿主拥有的不可变子树复用规范序列化结果/摘要及逻辑字节数；已提交回执共享只读内容，候选和公开可变读取仍隔离。可变对象绝不按引用缓存。缓存限制驻留字节，避免以额外常驻全世界副本换时间；改变后的 namespace 根仍对完整规范字节计算 SHA256。
- 扩展现有记录索引支持实际使用的字段相等查询及 ID/字段并集；写入/成员变化准确失效，计量实际扫描与读取工作。优先消除重复扫描，不提高 maxItems 或工作预算。
- 使用原封不动的现有游戏规则、自然新局及连续世界推进，在相同持久化起点比较主线基线和改造版。保留分支、历史、世界事实和确定性输出的等价性；长历史补充样本明确标注，不能当作自然玩法证据。
