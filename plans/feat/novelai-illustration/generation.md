# S3 — 提示词生成

以现有模型路线与生成调度为基础增加正式绘图提示词用途，允许插件指定独立路线。每个标注独立提交；创建标注不请求模型，生成提示词不调用 NovelAI。

请求采用标注所对应的历史剧情快照：完整选文为主体、所在与相邻段落、之前两个完整对话轮次、现有路径选取的相关角色资料和场景事实。辅助输入目标约 4000 tokens，按实际模型容量调整；先裁剪背景，不能静默截断主体。排除后续剧情、其他分支与未选回复。记录实际上下文来源、角色配置和模型路线快照。

LLM 输出共用场景/构图与每角色动态提示词。固定角色描述、风格等由程序组合，分块可编辑并可预览完整最终输入。直接手填可绕过 LLM。重新生成提示词建立新版本；用户当前修改不被角色/预设更新覆盖，显式应用新配置。

请求锚定标注的快照，继续聊天、切换会话不会使任务因当前 HEAD 变化而失效。结果保存到原标注；同一标注避免重复进行中的任务，失败只重试本步骤。服务器存活时关闭浏览器仍可执行；客户端卸载释放 UI 订阅，不自动取消服务器任务。删除标注拒绝晚到结果进入已删除位置，图片历史保留。

本地验证请求范围、配置优先级、两步骤独立、继续剧情期间的结果归属、取消与迟到结果；使用本地 Provider fake，不需要用户密钥。
