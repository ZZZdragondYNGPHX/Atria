# S2 — 官方插件交互

产品插件源码属于 main 产品树，不属于长期 plugin 工具工作空间。复用 Native 扩展运行时并补齐所需 SDK/官方注册入口。

双模式操作同一正文；桌面框选、手机长按原生文本选择创建草稿。标注高亮、单标注卡片、独立生成提示词/生成图片按钮及状态。跨相邻段落的连续范围是一次标注；卡片有角色、场景/构图、逐角色动态提示词、参数和历史。已有生成内容由 core 呈现，插件停用不删除内容。

全局绘图角色库：姓名、别名、固定角色提示词、可选默认服装、启用状态和可选剧情角色关联；作品选择启用角色。只匹配选文中的姓名/别名，不把全部背景人物纳入画面。同名歧义需用户选择；代词情形允许手动补充。固定外观优先，明确剧情服装覆盖默认服装。角色库修改不自动改已有提示词。

预设分风格/质量词、负面提示词、NovelAI 参数，作品默认、单标注覆盖。独立默认图片连接与提示词模型路线。提供可编辑的提示词整理模板与恢复官方默认。界面使用 Atria 主题与布局，无独立助手会话。

验证只覆盖实际触及的本地配置持久化、隔离、桌面/手机视口选择和卡片行为；明确标注浏览器模拟与真机证据的区别。
