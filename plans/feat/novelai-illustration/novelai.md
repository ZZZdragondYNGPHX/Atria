# S4 — NovelAI 与最终集成

官方和第三方兼容接口各自独立连接配置，复用 Atria 密钥系统；每次记录实际连接身份与非秘密参数。接入前核对官方协议以及用户实际第三方接口，按能力声明参数，不假定所有中转支持相同协议。

每处标注单独点击生成图片；只使用当前确认的提示词/参数，不重新调用 LLM。多人描述按角色组织，适配对应模型能力。图片生成任务与正文生成忙碌状态分开；队列只调度已提交任务，不启动未提交草稿。进度、取消和失败归属单个任务。重生成产生新版本，选择一个正文展示版本，完整历史保留。

客户端卸载不取消服务器任务。结果写入原会话/正文/标注；如果标注被删除，结果可保留历史但不恢复已删除标注。删除标注与清理图片分开，资产引用保护防止误删。

完成本地协议适配、任务归属/取消/重试验证，以及四阶段闭环回归。真实 API 证据依赖用户连接配置，未运行不得声称通过。不做全局批量生成、智绘姬助手、参考图/Vibe 或其他后端；它们不作为本任务完成条件。

全部阶段闭环后集成 main，运行最小相关本地验证，更新最终 Record，删除任务分支与 live HANDOFF。
