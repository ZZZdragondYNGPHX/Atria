# 前端体验重构 v3 — 百工即日常

状态：v3，2026-10-27。承接 [v2 卷中行](frontend-redesign.md) 的场景、阵盘、印、笺、香与四卷，不改其视觉 token。本稿重做 crafting.1 新增的副职与素材体验；规则、五次与批量、批次、真实工时和材料消耗以 [crafting-materials](crafting-materials.md) 为唯一权威，本稿只决定玩家在哪里遇到、怎样理解和怎样操作。现行 `frontend/crafting.js` 只作功能清单。

## 1. 诊断（2026-10-27 浏览器实测）

| 问题 | 实测表现 | 伤害 |
| --- | --- | --- |
| 百工是一个悬浮按钮 | 画面右缘与四卷签重叠的“百工”方框，任何地方都能打开 | 制作脱离地点，与“须到炉前”规则矛盾；像后台入口 |
| 一张表单做完所有事 | 三副职 × 六个标签（配材、方册、作业室、采矿采药、器具成品、加工）＋下拉框＋四个数字输入框 | 玩家在填工单，看不到炉、看不到料 |
| 一个数字框服务四种含义 | “每次加入／加工份数”“批量炉数／租用小时”共用输入 | 只能靠读说明猜 |
| 五次进度藏在文字里 | 方册行写“手工成功 2/5” | 最核心的成长没有分量 |
| 小游戏看不懂 | 炼丹是一条横框和一根红杆；按钮写“按住控火／点按锻打”三副职共用；没有当前成色 | 玩家不知道自己做得好不好，也不知道三者有何不同 |
| 结果只是一行字 | “制成3份基础疗伤散” | 精良、上品、废丹没有反馈；失败原因看不见 |
| 设施找不到 | 药铺画上没有丹房；租房在标签页里；内室“租用牌”点开是读告示 | 第一次玩的人不知道能租房 |
| 成品不能在行囊用 | 行囊只给基础疗伤散“服用”，其余在百工“器具成品”里 | 制作和使用断开 |
| 旧入口残留 | 己身·修为里仍有“炼制疗伤散”按钮 | 两套制作入口并存 |

## 2. 概念：百工即日常

副职是修行生活里的手艺，不是一个系统菜单。它只发生在三处：

- **野**：画上的采点与矿脉。余量、补长时辰和所需工具写在印下。
- **坊**：作业室里的作业台、客栈的临时炉位。一切配料、开工、加工都在“坊案”上做。
- **册**：己身卷的“百工”页，是记录：技艺、方册、五印进度、草案。看册不开炉。

三副职共用一套语言——**料架、炉口、所向、五印、成色、出炉帖**——但各有自己的器与手感：

| 副职 | 器 | 主色 | 手感 |
| --- | --- | --- | --- |
| 炼丹 | 丹炉 | 金焰、赭 | 守火：按住升火，松开回落 |
| 炼器 | 锻砧 | 铁青、炽橙 | 八锤：火星过砧心时落锤 |
| 制符 | 符案 | 朱砂、墨、黄符纸 | 行笔：笔锋跟着朱点走 |

朱砂印仍只用于“把意图交给世界”的那一下：开炉、量产、理料、租房。

## 4. 坊案

```text
╔ 普通炼丹房 · 租至 酉时 ▂▂▂▂▂▁▁ ═══════════════ 炼丹 一级 ═ 收 ╗
║ 料架            │           炉口                 │ 照方               ║
║ [药][矿][兽][工] │      ( 料 料 料 )              │ ▣凝血散 ●●○○○      ║
║ ▢草×4 ▢苔×2 ▢叶 │   ┌──────────────┐           │ ▣自配散 ●●●●● 可量产 ║
║ ▢根 ▢芽 ...     │   │   丹炉原图    │  形：散 丸 露 │ 所向（依所知）       ║
║ ─────────────── │   └──────────────┘           │ 活血 ███  调和 █     ║
║ 笺：止血苔 一级 平和   │  此炉：凝血散·原方 2/5         │ 器 公炉 · 投料 6/12  ║
║ 用途 活血 · 质地较净   │                              │ 约半个时辰 · 斗气 10 ║
║ [−][+][鉴定 3金]     │                              │ [开炉] [量产 ×3]    ║
╚══════════════════════════════════════════════════════════════════╝
```

- **料架**：只放材料批次，按“药、矿、兽、工（加工材）”分格。点一下放一份入炉并“拈起”它；笺显示名称、层次、寒热、用途、本人鉴定结论与 −／＋／鉴定。料架翻页即实际批次分页。
- **炉口**：炉体原图居中，已投料以小图环绕，角标份数；点炉口里的料取回一份。缺料（照方时不足）以虚框写“缺”。
- **形**：炼丹为散、丸、露三方小印；炼器、制符为已学器形或符式的小图卡，写制作级。
- **此炉是哪张方**：前端按副职、形态、材料与处理、约分后比例与方册比较，写“凝血散 · 原方 · 成 2/5”或“新方 · 未记”。这就是规则的配方身份，改名、换批次、等比放大不变。
- **所向（依所知）**：只汇总材料公开用途标签，按份数加权，最多四项，写明是推测。不读也不显示隐藏成分。
- **条件**：器具（公炉或自备，自备显示耐久）、投料／容量、预计工时、斗气、租期是否够。任何缺项写成人话并让开炉印不可落：“客栈只能自备炉具”“这炉要一个时辰，租期只剩半个时辰”。
- **开炉**与**量产**：未满五次时，量产位置是五方小印与“再成两次可量产”；满五次后变成量产印，带 −／＋ 炉数，并写总料、总时与“一般品质”。
- **理料模式**：坊案顶部“炼／理”切换。理料时，拈起一种材料，炉口位置换成该材料，下方给出适用的工艺小印（研磨、提纯、冶炼……），写“约得 N 份某某 · 若干分”，落“理料”印。
- **首次笺**：从没有任何方有过尝试时，坊案出现一张三步笺：点料入炉、看所向、落开炉印。由世界状态推断，不另存。

## 5. 手作：三种小游戏

共同结构：上方一炷**进程香**（10–20秒现实时长，与世界工时无关）；中央是器；右侧一条**成色**竖尺，刻“成 50／精 70／上 85”三道线，随操作实时上涨；下方一个大的操作按钮与“歇”印。开始前一张小帖写目标、按键和难度来源（“此方三级 · 你一级 · 越二级，火候带窄”）。

- **炼丹·守火**：丹炉右侧一根竖立的火候柱；玉色适宜带上下游移；火舌高度即火候。按住“火门”或空格升火，松开回落。火舌离带越远，炉体换危险图层。香尽时“收丹”印亮起。
- **炼器·八锤**：锻砧上方一条锤路，火星自左向右循环，过砧心刻痕时落锤（空格或“锤”）。坯上八道锻痕依次记录每一锤：金（正中）、铜（偏）、空（未中）；多余的锤写“多锤伤坯”。香尽“淬火”。
- **制符·行笔**：黄符纸上一串朱点是符路，笔锋所在朱点发光。按住符面拖笔或用方向键移动。笔锋走过的朱点变成墨点（随上）或断墨（偏离）。香尽“封符”。

暂停（Esc、失焦、“歇”印）冻结轨迹；暂停帖给“继续”“存下进度离开”“弃炉”。弃炉需二次确认并写明“已入炉之料不能取回，成功数不变”。

## 6. 出炉帖

工时由世界推进结算后，坊案中央出现出炉帖：成品原图、名称、品质印（一般／精良／上品／废），数量，已知效果的白话，消耗；下方五方小印，本次成功则新的一方落下。第五次时量产印同时落下。失败写原因：“成色 38，未到 50”或“材料冲突或残留过重”，并写“成功数不变”。操作：再炼一炉（同料重新核验库存）、为此方题名、收起。

## 7. 场景与册

- 宿主场所（药铺、修器坊、黑岩工坊、石漠市集等）画上放房门物件，印文“丹／锻／符”。阵盘：租一时辰、两时辰、半日（价格含公用器具）；持有适用器具时追加“只租房”；已租则“入”。
- 客栈画上放“炉位”与“寄存柜”。炉位印为“工”，打开坊案（自备器具）；寄存柜卡片列出存取。
- 内室租用牌：余时、续租一时辰、出房。
- 己身卷新增“百工”页：三门技艺、方册（成品图、所用材料、五印、收藏、备注、删草案）、待领产物。
- 行囊：药物“服用”、器物“佩用”、入门书“研读”、工具耐久不满“修器”。

## 8. Native 实现约束

- 状态 schema 仍 ≤256 节点：删去 `craftForm／craftTool／craftCount／craftTreatment`（改为本地表现状态并写入文本绑定），新增一项 `craftScore`。坊案沿用 `rowsA–D`、`tabs`、`log` 等共享列表。
- 只有三处规则侧小改：坊案料架需要材料批次优先的排序（投影顺序，不改分页规模）；前端目录补充加工方式的适用族与产出（作者公开数据）；`equip` 未给批次时取第一件实际制成的器物。其余全部沿用现有 `craft` 动作。
- 配方身份、条件预判、所向都只用公开投影与作者目录计算；结算一律以规则回执为准，预判与回执不一致时以回执为准并显示回执原文。
