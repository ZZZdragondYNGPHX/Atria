# 前端体验重构方案 v2 — 走进一幅会动的青绿长卷

状态：v2，2026-10-25。v1（2026-10-24，“墨框纸卷”，六项决定已确认）的三层结构仍然成立：场景常驻，情境占据场景，四卷半掩场景。v2 在其上重做视觉语言、交互方式、首次体验，以及 dungeon.1 新增的秘境和魔兽两套界面。规则、screen 字段语义和 Bridge 绑定不变。唯一的后端改动是公开投影新增两项可观察信息：魔兽的蓄势落点和首领阶段，见 §7.3。字段与动作以 [frontend-contract.md](frontend-contract.md) C4–C7 和包内 `integration/screen.schema.json` 为准。已确认的方向以 [decisions.md](decisions.md) 为准，其中 D127 是真实入口，D128 是场景优先。

本方案把现行 `package:doupo-living-world/frontend` 只当功能清单使用，包括 Codex 在 dungeon.1 加入的部分。秘境与魔兽界面从规则出发重新设计，不在现有组件上修补。

## 1. 诊断（2026-10-25 浏览器实测）

| 问题 | 实测表现 | 伤害 |
| --- | --- | --- |
| 画面像网页而不是世界 | 场景图是一块居中的矩形，四周是大片深色空底；铭牌、时辰、己身、四卷签都是带细边框的矩形盒子 | 每一处都在提醒玩家“这是一个应用” |
| 动作都是文字按钮 | 选中对象后，在右下角弹出一张纸面板，里面是竖排的矩形按钮（“走近四象试炼阵 · 入口 / 相距 11 步”） | 与 RPG 的直接操控相反，像在处理工单 |
| 操作多一步 | 走近和交互是两次点击、两个面板状态；面板挡住对象本身 | 节奏碎，玩家看不到自己点了什么 |
| 秘境没有分量 | 崩解倒计时只是时辰下面一行小字（“四象试炼阵 · 余 231 分钟”）；四个区域、来路去路完全不可见；场景里只有“区域通道 / 机关与遗藏 / 离境出口”三个通用文字签 | D110 的致命截止、D119 的四区结构、D122 的多解机关，这些核心张力全部没有表现出来 |
| 机关是灰按钮列表 | 五个“观察 / 依线索 / 付力 / 身法 / 防御”按钮，四个是灰的，下面写着系统原因 | 本应是“这道关有几种破法”的谜题，看起来却像权限不足 |
| 入境只是一句确认 | “试炼自本轮开启起四小时后崩解。必须严格提前完成离境。”出现在通用确认框里 | 生死规则没有仪式感，也没给玩家准备的机会 |
| 魔兽被当成人 | 魔兽进入 `people`；选中后打开“相处”，里面是“询问近况、赠礼、情谊” | 直接出戏；魔兽的阶位、习性、危险都看不到 |
| 首领机制看不见 | 首领蓄势只写在战斗日志里一行文字（“危险落点 x,y”），网格上没有标记 | D100 的“可观察征兆，有效应对”在界面上不存在 |
| 系统文字外露 | “这段活动已经完成。”“耗时1刻”“需要先观察本次固定线索” | 软件语言 |
| 首次体验空白 | 入世后直接落进场景，没有任何提示告诉玩家能做什么 | 新玩家不知道该点地面、点人，还是写字 |

## 2. 设计概念：卷中行

玩家不是在操作面板，而是在一幅青绿山水长卷里行走。界面上的每个元素都对应长卷世界里的一件实物：

- **画**：场景图铺满整个视窗（`cover`），四周以墨晕收边，没有框。
- **印**：一切行动都是印。选中一人或一物时，它身旁会浮现一圈印章（“阵盘”），每方印上一个字（谈、易、赠、斗、观、采、入、离……），旁边小字写耗时。点印即行，不再有按钮列表。
- **香**：时间是一炷香。平时是时辰香盘；进入秘境后变成一炷横置的线香，按剩余时间燃烧，60/30/10 分钟处各有一道香结。燃过香结时，画面边缘渗出裂纹。
- **符**：交锋时的斗技是一张张竖长的黄符，朱字写招名，下方写气耗；需蓄势的招式，符上有未干的墨。
- **笺**：消息、线索、引导都是撕边纸笺，角上盖出处印。
- **轴**：四卷是一幅从右侧展开的立轴，上下有轴头，展开时带卷轴动效。

**一处张扬**：朱砂印只用于“把意图交给世界”的那一下。除此之外界面安静：墨、绢、石青。

## 3. 视觉 token

色彩取自青绿山水的矿物颜料，不用“奶油底 + 赭红”的通用组合。

| 名称 | 值 | 用途 |
| --- | --- | --- |
| 墨 | `#14191B` | 浮层底、夜色、正文墨字 |
| 绢 | `#D3C29A` | 卷、笺、名帖的纸面（比宣纸更黄、更旧） |
| 旧绢 | `#A9946A` | 纸面边缘、次要线 |
| 石青 | `#2F5D6B` | 选中、秘境、己方 |
| 石绿 | `#4F8A68` | 气血、同伴、可行 |
| 朱砂 | `#B3382B` | 印：落印、致命、承诺 |
| 金焰 | `#E2A145` | 斗气、蓄势、首领 |

- **字体**：两套，不分发字体文件。楷体（Kaiti SC / STKaiti / KaiTi）用于地名、人名、印文、标题；宋体（Noto Serif SC / Songti SC / SimSun）用于正文与数字（`tabular-nums`）。不用黑体，不用全大写，元信息不用点号串联。
- **形**：印是带不规则缺角的圆角方块（`clip-path`）；笺是撕边多边形；墨条（气血、斗气）是两头收锋的笔触（`clip-path`）。不用统一圆角卡片，也不用通用阴影。
- **图标**：内联 SVG，单字印为主，图形只用于少数通用操作（关闭、翻页）。

- 铭牌、时辰、己身都是直接浮在画上的墨字，靠墨晕衬底，不画矩形框。
- 四卷签是右缘垂挂的四块木牌（楷书竖排），悬停时略微下坠。
- “在场”不再是常驻的人像盒子：人在画里。在场条缩成左下一行小圆像，只服务溢出和键盘用户；人数超出地图上限时写“此处还有 N 人”。
- 行记和言并排在底部的半透明墨带上。言只在玩家需要时展开（点“言”或按 `/`），平时是一行。

## 5. 交互规则

### 5.1 阵盘：选中即见可行之事

- 点人物、魔兽或物件：选中（零耗时 `focus`），同时在它旁边展开阵盘，最多八方印，按语境排序。
- **点印即行**：距离不够时，印的小字写“走近 · 1刻”，点下后前端先沿真实路径走近（`move`，规则结算），到位后立刻执行该事。走近失败或情势改变就停在原地，并说明原因。走近和交互合成一次点击。
- 不可行的事不显示成灰按钮。只在阵盘下方用一行笺写“还做不到：需先观察本次线索”。
- 阵盘也是情境的入口：人物的“谈”进入相处；柜台的“易”进入交易；魔兽的“斗”进入交锋确认。
- 键盘：数字键 1–8 选印，Esc 收起阵盘；Tab 在场景对象间移动。

### 5.2 确认分级（沿用 v1，并改写重大动作的样式）

零耗时操作无确认，短时动作落印即行。重大动作展开“此事当真？”二次印，写明后果：远行或长时安排、交锋、婚约家庭、冲关、换修、读档、退出、**入境**、**付力破坏**、**撕除封签**、**会触及崩解的行动**。入境改为“入境帖”，见 §6.2。

### 5.3 首次体验

入世后，前三件事各有一张贴在实物旁边的引导笺，做过一次就不再出现（由世界状态推断，不需要额外存储）：

1. 地面笺：“点地面即可行走；时间随行动流逝。”
2. 人物笺：“点人物，看能与他做什么。”
3. 卷签笺：“己身、人间、江湖录、山河。按 C、R、J、M 随时翻开。”

另外，“言”栏的占位文字随场景给一个具体例句（药铺里是“向苏晚禾打听最近的药价”），而不是“写下你想做的事”。

### 5.4 文案

不出现系统文字：“这段活动已经完成”换成“你走到了X近旁”；耗时写成“一刻”“约两个时辰”；规则原因改写成人话（“需要先观察本次固定线索”改为“先看清这道机关的纹样”）。只有前端自己产生的文字才改写；规则原文照常显示在详情里。

## 6. 秘境

### 6.1 体验目标

完整流程是：得知 → 找到入口 → 读入境帖、备好同伴 → 进入 → 在四区间选路 → 破机关、采药、取遗藏、战首领 → 看着香烧短 → 赶在截止前过门离境。界面要让玩家一直感到三件事：**我在哪**、**还剩多久**、**这里还有什么可做**。

### 6.2 入口与入境帖

- 场所里的秘境入口是画上一处带光晕的门印（用 `portal-*` 原图做小插画），比普通物件大一号，开放时有呼吸光。
- 入口阵盘：读（铭文）、开（试炼开轮）、入、核验领奖、补给。
- “入”打开**入境帖**，占场景中央：左侧是秘境入口原图；右侧写名称、模式（共享 / 本队独享）、本期截止（一炷完整的香，标出剩余）、人数上限、同行名单（可逐人“传达入场”），以及朱色死亡条款：“窗口末时空崩解。届时仍在其中者，无论何人，皆死。过门须在此之前完成；同刻不算。”底部一方朱印“入境”。

### 6.3 秘境内 HUD

- **线香**：替代时辰盘，放在顶部正中。香长按 `remaining / 窗口总长` 计算，四座秘境的窗口长度（24/48/4/12 小时）由前端静态目录提供。香头有火星。三个香结在 60/30/10 分钟处。`warning` 到 60 时香烟转灰红；到 30 时画面四角出现裂纹；到 10 时裂纹加深，四周微红。每次只显示当前最高的一级，不补播。
- **阵图**：左上铭牌下方是一块小罗盘，四个节点按菱形排布（A 在下，D 在上），节点上写区名首字。当前区实心；本次进入后到过的区为墨圈（前端本地记忆，重载后只保留当前区）；从当前区可以过门去的区，按 `portal` 选项点亮连线；其余为未知的“？”，不把地图骨架当作已知信息泄露。点亮的相邻节点可以直接点，效果等同点通道印。
- **同行**：左下一列圆像，像下用小字写在场、赶路、等候、暂离或已离世；点圆像打开此人的阵盘（招呼跟上、请其等候、交物、传达离境、扶背撤离）。

### 6.4 现场物件

画上每个秘境对象是一方小字印，选中后展开阵盘。

| 对象 | 印 | 阵盘 |
| --- | --- | --- |
| 区域通道 | 门 | 每个可去区一方印（印文是区名首字，小字写全名和耗时） |
| 离境出口 | 出 | 离境（含“严格提前”说明）、传达离境、扶背撤离 |
| 机关 | 机 | 打开**机关盘**，见下 |
| 采点 | 采 | 采集一份（显示余量） |
| 遗藏 / 石匣 | 藏 / 匣 | 逐件取、逐件存、闭合启动（显示余能） |
| 残存物 | 遗 | 现场回收 |

**机关盘**：一个圆盘分五瓣，分别是观、解、破、越、守。已看过纹样时，“观”瓣盖上已观之印。每瓣写代价（时间、斗气、风险）。条件不满足的瓣不变灰，而是写出所缺之物，例如“需学会身法”。“破”是重大动作，二次印写明“落石可能伤人并惊动兽群；强拆会损坏石匣阵芯”。

### 6.5 撤离与崩解

- 离境是重大动作，二次印写清剩余时间，并说明“过门完成须早于截止”。
- 规则返回 `deadline_risk` 时，二次印用朱色香图示意“此事做完时香已燃尽”。
- 崩解后，画面褪成灰墨，正中写一行“时空洪流吞没了X”。死亡则接原“此身已逝”页。

## 7. 魔兽

### 7.1 在场景里

- 魔兽是 key 以 `beast-` 开头的 marker，或在交锋中带 `species` 的参战者。按 `appearance.profile`（`creature-<id>`）从前端静态兽谱取名称、阶位、习性。
- Q版脚下画朱色兽圈，圈上用一到三颗金焰点表示一阶到三阶。精英的兽圈加金边；首领的兽圈更大，并有缓慢的旋纹。不画人物那种名牌盒，只在悬停或选中时显示名称。

### 7.2 兽谱卡

选中魔兽不进入相处，而是打开**兽谱卡**：一张小立轴，放在魔兽旁边。

- 兽的原图、名称、阶位焰点、“普通 / 精英 / 首领”。
- 习性一句：群居警戒、守区冲撞、伏击缠绕、借风扑击……来自静态兽谱，不是这只个体的私有状态。
- 可见体征（`signs`），以及能取得的材料方向（皮、骨、丝、魔核，都写“如有”）。
- 阵盘：观（调查踪迹，`investigate wildlife`）、斗（发起交锋，重大）、避（走开，即沿远离方向移动两格）。

### 7.3 交锋中的魔兽与首领（唯一的后端增量）

`combat.participants[]` 新增两个只含可观察事实的字段：

- `warn`：魔兽已蓄势时，给出 `{x,y,radius,skill}`，即落点、范围和招名。这些已经写在公开日志文本里，只是改为结构化输出。不可见的参战者不输出。
- `phase`：首领与阵灵的当前阶段名（例如“结网守卵”或“护巢露甲”）。只输出阶段名，不输出阈值。

界面表现：

- 网格上把蓄势落点范围画成朱色斜纹格，范围外描一圈香火色边。选中我方落点时，如果落点在危险范围内，就提示“此处在蛛母毒突的落点内”。
- 首领在顶部有一条**首领横幅**：原图小像、名称、阶段名（换阶段时有一次墨迹扩散）、可观察体况。不显示血量数字（规则也不公开）。

## 8. 交锋行动栏

```text
┌第三轮 · 选择行动────────────────┬首领：裂岩蛛母 · 护巢露甲──────────┐
│ 网格：可达格淡金点；危险格朱纹；选中目标金圈                           │
├────────────────────────────────────────────────────────────────────────┤
│ 移：走到 6,8 ✕   对：蛛母   行：碎石掌                       [印·本轮] │
│ 符：[出手][碎石掌 12][疾风步 18][…书架]   式：(守)(息)(药)(救)(撤)(降)(和)(蓄)│
│ 令：[陆青像] 牵制 / 施技 / 撤离                                         │
└────────────────────────────────────────────────────────────────────────┘
```

- 斗技是竖长黄符。所选的符抬起，上面加朱圈。符上写招名、气耗、范围。
- 小式（守、息、药、救、撤、降、和、蓄）是圆形小印。
- 秘境机关的战中操作在“式”的末尾加“机”印，占用主要行动。
- 锁定后，行动栏收成结算卷：日志逐条落下，“暂停后续”与“继续”保留。

## 9. 其余情境与四卷

保持 v1 的内容和覆盖表（v1 §4–§8 的功能映射继续有效），换成 v2 的材质：

- 相处：立绘从墨中浮出；对话在绢上；“常 / 情 / 斗”三方印切换可行之事。魔兽不会进入相处。
- 交易：货架是一排木格，物品原图放在格里；每格一个“买”印；行囊在右侧。
- 四卷：立轴展开。签页是轴头下的一排小木签。江湖录按 D128 只记录与寻路：约定、线索、探境记（本人进过的秘境：截止、同行、所得、残存物位置）、经历、书信、往事。

## 10. Native 实现

- 结构不变：单组件、stage class 串、共享的 `rowsA–D` 列表、10 字段行，仍在 256 节点预算内。阵盘复用一个列表，用 `gx/gy` 类定位到对象格；印的环形位置由 CSS `nth-child` 决定。
- 线香长度与阵图节点用已有的 `style:` 百分比绑定和 stage class 表达，不新增大量状态。
- 前端静态目录新增 `BESTIARY`（物种、精英与首领的名称、阶位、习性、材料方向）和 `DUNGEON_INFO`（四座秘境的名称、模式、窗口长度、区名），两者都是作者公开内容。
- 走近再行事是控制器里的两次串行提交，每次都用真实的 revision/key，失败时停下。现有的草稿防误发、CAS、续行和恢复语义不变。
