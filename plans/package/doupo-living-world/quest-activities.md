# 固定活动：拍卖、炼药师考核、试炼与市井交流

状态：`0.1.0-quests.2` 自然流程修正与补验已完成归档，2026-10-23；四类活动和六项拍卖周边工作沿用 `quests.1` 实现基线。已接入同一世界规则、人物钱物与主时钟。本页替代 v0.34 的候选领域细则；D49–D51 等已确认方向仍以 [decisions.md](decisions.md) 为唯一依据。下述费率、评分、数量、工时和容量为工程实现参数，不是新增用户确认或小说固定规则。

## 职责、实现位置与边界

v0.75制作依赖：[新副职完整方案](crafting-and-materials-plan.md)推荐考核调用同一工单与真实制作成果，详细生产规则归 [crafting-materials.md](crafting-materials.md)；活动仍负责报名、考官、四阶段评价和资格。普通10–20秒小游戏不把每炉变成完整考核，技艺成长也不自动授予公会认证。下文是既有考核实现，不能视为新材料、环境、器具或自创药物已接入。

活动领域规则位于 `source/rules/quest-activities.js`，空状态工厂位于 `source/rules/quest-state.js`，显式作者 Schema 位于 `tools/quest-activities-schema.mjs`。活动只有一份领域状态：解码后的 `world.questActivities`；人物余额、库存、技能、身体和所知沿用现有权威。实际接口唯一见 [frontend-contract.md 的 C5](frontend-contract.md#c5--quests1-活动接口2026-10-23)，通用合同仍归 [quest-system.md](quest-system.md)，QC 内容归 [quest-content.md](quest-content.md)。

拍卖与考核不是原有 `buy/sell/refine` 的重命名。模型和旁白只能解释已经发生的操作，不能创造拍品、补材料、代交成果、改分或发证。人物与场所沿用包内来源；新增具体场次、考题、周边差事与评分为游戏原创实现，不保证任何原著人物重演固定结局。

D33 不变：完整玩家战斗后续独立实施，QC28–QC30 随之安排。本次家族/佣兵试炼只有补给、本人走访记录核验、路线交接与训练结果；既有简单交锋和 NPC 后台冲突均不作为完整玩家战斗的替代。

## 生命周期、工时与容量

- 活动由现场实际操作创建，不因打开界面自动报名。主持人须实际在场、存活并能沟通；玩家须存活、意识可用且未受拘束。不同操作继续检查炼药、劳动或移动能力。
- 阶段操作将投入与过程写入同一世界，并记录 `workUntil`。后续阶段只能在主世界时间达到该值后提交；`activity_wait` 继续推进同一时钟。取消普通推进不会清除活动工时门槛，思考与现实离线不推进时间。
- 主时钟可以被到期人物事务等截断，界面应继续读取 `operation` 与活动等待状态。最终验收、交割或领奖发生在前段工时已经满足以后，不再先发奖、后附一段可取消的领奖工时。
- 主持人离场或失能时，依赖其现场权限的操作拒绝；保留已发生材料消耗与托管。退出按照原所有权退还可归还钱物，不能把托付货物远程传回。
- 实例上限8，包含活跃和最近终态；新增时先保留所有活跃实例，再在剩余位置保留最近终态。满活跃容量拒绝新增，不删除托管。历史上限24，玩家视图展示最近6条。认证表显式容量4，目前只有一种基础实操认证且同人不重复颁发。
- `at` 为创建时点，`workUntil` 是实际阶段门槛。当前 `due=at+1440` 仅为登记时点字段，尚未据此自动取消活动；不能把它渲染成已经实现的强制截止。

当前是玩家现场开启的有状态活动，不是独立后台定期场次调度器。NPC 可以按真实需求和资金在实际竞价节点出价，但尚无玩家不在场时自动举办完整拍卖/考试的承诺。

## 公开拍卖与真实钱物

主持地点为 `wutan.auction`，主持人雅妃须在场。

| 角色 | 当前实际规则 |
| --- | --- |
| 买家 | 从分号实际库存取一份拍品进入托管，起价为目录价的70%向下取整且至少1金币。玩家出价实际扣留对应资金；被合法超过才返还原占用 |
| 寄售卖家 | 交出本人库存中1–10份普通物品，不能再消费或另售同一数量。起价同样按实际总目录价计算；禁止本人对自己的拍品竞价 |
| 受托代拍 | 向在场、有该物真实未满足需求的 NPC 请求授权。校验其存活、需求、资金、与卖家冲突及预算；上限不得超过其现有金币和该拍品总目录价的两倍。实际扣其资金为专款，不能混作玩家收入 |
| 拍前拍后工作者 | 使用下节六项独立操作，关联真实拍品；报酬另行托管，不混入成交价款 |

当前只支持目录内普通物品和秘籍。`redleaf/relic` 等唯一物以及装备实例不进入本场普通寄售，防止绕过其现有归属/实例权威；没有声称已实现唯一宝物鉴伪或装备拍卖。

当前竞价采用公开递增：至少超过有效最高价1金币。金额支持现有 `qty` 小额通道，以及 `text` 十进制整数通道（1至1,000,000,000）；后者用于超过100金币的出价与代拍预算，不扩大通用动作数量边界。非法数字、指数、小数、负数与越界输入拒绝。有效出价与推进竞价各增加一轮；在达到三轮之前，推进节点会寻找现场具有真实未满足需求、足够金币和目录估值的 NPC。估值不读取玩家钱包或代理上限，寻访买家不保证成交。达到三轮后可落槌；前一出价占用、现占用和代理未用预算分别处理。

成交时，原托管拍品进入实际得主库存；成交价的5%向上取整付给主持人，余款进入原分号货款或真实寄售人余额。代拍所得归委托人，剩余专款退还。没有有效出价则流拍，原物与未用预算归还，不收流拍费。终态不能再次落槌发物或付款。

已有有效竞价不能单方撤拍。得主/主持人死亡或代理目标失效时允许受约束清算；若退款权利人已经不在当前合法读集中，保留托管并明确拒绝，不把款项凭空写给另一个人。继承人替代领取不是当前活动模块已经实现的功能。

## 六项拍卖周边工作

每项都必须引用实际拍品，每件拍品同类工作最多接受一次。报酬由现场实际付款方预先扣入本项托管，不能凭传入 NPC 名称直接创造同意。创建通常耗10分钟；`auction_job_perform` 提交工作并保留工时，`auction_job_finish` 在满足条件后验收、支付预留报酬。下表金额均为当前工程参数。

| 工作 | 实际操作与门槛 | 报酬与后果 |
| --- | --- | --- |
| 鉴定 | 以已掌握基础功法知识检视秘籍，或以丹方知识检视药材/成品；耗5斗气与30分钟。只依据已有目录和知识，不编造隐藏品质 | 雅妃托管4金币；记录该次检视的技能依据，完成后领取一次 |
| 核实来源 | 在主持人现场核对真实托管记录，区分分号库存与寄售人；耗20分钟 | 托管3金币；将核实来源写入本人所知，不披露私人钱包/动机 |
| 寻访买家 | 现场寻找真实未满足需求和支付能力相符的人物，记录具体联系人；无人合适时拒绝，不能用旁白生成买家；耗20分钟 | 托管4金币；形成实际需求联系，不能保证其出价或成交 |
| 运送筹备物资 | 仅针对主持人真实未满足需求，最多两份。先预留实际采购款，玩家亲赴 `wutan.market` 从真实库存采购，再返回拍卖场交接；采购后货物独立托管，不进入玩家可售库存 | 托管6金币；市场实际收款、库存减少，签收后原付款人取得实际物资，余款退还 |
| 协助寄售 | 主持人有可处分余货才同意，排除必要补给与唯一物；默认药草，也可选择其他合格普通物品。实际取一份余货进入托管，完成20分钟工作后形成新的真实拍品 | 托管4金币；拍品保留原物主，不给玩家复制库存；排拍满额时保留货物等待 |
| 成交后交付 | 已成交且仍有真实拍品的 NPC 买家在现场同意，登记住所须异于拍卖场。取其实际成交物为托付货物，玩家实际抵达登记住所，且买家本人在该处才能签收；耗20分钟交付工作 | 买家托管5金币；签收时原物返回收货人库存，支付一次报酬。自己给自己送货不产生该委托 |

运送/代交的托付货物不能自由消费或转卖。携货退出时必须回原交接地点联系原物主，才能归还货物并退还剩余专款/工资托管；未满足条件时保持义务。活动周边工作不等于自动接取另一份 QC 合同，同一物品或活动成果不能复制成两笔结算。

## 四阶段炼药师考核

地点为 `blackrock.guild`，由在场且能沟通的弗兰克或奥托主持。报名要求：火属性至少3、木至少1、灵魂至少3、已有 `formula` 与 `refining` 技能，且身体允许炼药。出生身份、原著记忆、私交、背包已有疗伤散均不能替代本人过程。

报名耗10分钟。材料自备；无报名费，也无免费补料。当前基础题的合格线为60，按本次过程累加评分：

| 阶段 | 选择、实际投入与工时 | 当前评分依据 |
| --- | --- | --- |
| 材料处理 | `careful` 两份药草/30分钟；`generous` 三份/30分钟；`quick` 两份/10分钟。提交即实际扣料 | 丹方等级×3，加仔细20、增料24或快速5；保存中间质量 |
| 控火提炼 | `steady` 或 `gentle` 耗15斗气；`strong` 耗25；均25分钟 | 控火等级×3，加火属性×2（最多12）；稳火+20、文火+12；猛火在火属性至少6时+24，否则−15 |
| 融合成丹 | 均耗10斗气；`layered`/`swift` 20分钟，`patient` 40分钟 | 灵魂×2（最多12），另加分次15、快速−10或温养20；前序分数不重置 |
| 验收 | 必须本人到场、前段工时完成、实际获准考官仍可主持；不能提交旧成品替换本次过程 | 达60则取得一份真实基础疗伤散、控火练习和一次 `basic-alchemist` 认证；否则无合格成品或新资格 |

失败和主动退出均不返还已经消耗的药草/斗气；背包中未使用药材保持原状。重考重新报名并投入材料，历史失败继续保留在有界记录中。认证记录含持有人、颁发者、时点、活动证据和规则版本；它是本游戏基础实操资格，不声称是原著某个完整品阶体系，也不自动授予高阶配方。资格在具体职业机会中的使用由任务规则核对，不由前端称号改变世界。

## 家族/佣兵试炼与市井交流

试炼可在 `wutan.clan`、`qingshan.guild`、`shimo.motie` 报名，分别要求实际在场的对应负责人。家族入口还要求旁支出身或本人已经接触林砚；身体须可行动与劳动。

试炼三步为：准备补给→核对本人路勘→交接。轻装耗一份干粮得10分，备足耗两份得25分，均20分钟；必须已实际走访家族对应的 `wutan.depot`、青山对应的 `qingshan.trail` 或漠铁对应的 `shimo.gate`。谨慎核对耗40分钟得35分，直接路线耗15分钟得20分。至少45分才合格，取得基础练习与负责人的履约信任；失败不退已经投入的补给。它核验真实 `visited`，不是完整战斗、组队护送战或新的战斗公式。

交流会开放于乌坦修器坊、听雨茶棚、青山药铺、黑岩公会，至少有真实现场参与者。报名后选择：

- 药材展示：本人有药草和丹方知识，实际交出一份样本；完成后练习丹方。
- 药品展示：本人有实际疗伤散和控火知识，实际交出一份成品；完成后练习控火。
- 路况交流：至少三个本人到访地点，只分享本人已到访依据；完成后取得基础练习。

展示耗20分钟；结清才增加相应技能与现场参与者信任，药品展示信任增量3，其他为1。不把现场交流变成全知消息查询，不免费授予高级知识或复制展示样品。
