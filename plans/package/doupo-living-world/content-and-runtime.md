# 首批内容与运行目标

状态：基础方向已确认，具体内容与技术目标在本轮整体制作方案中提出；决定只以 [decisions.md](decisions.md) 为准。

## 当前用途

首批地域、长期关系内容和运行取向已经确定。本模块展开它们与世界内容、人物生活和性能验证的关系，供整体制作方案使用，不重复询问已确认方向。

## 首批地域与世界范围

首批地域以 [D20](decisions.md#d20--首批地域与逐步扩展) 为准，以乌坦城生活内容为核心，串联青山镇与魔兽山脉的一部分探索内容，围绕人物日常、消息传播、出行和机缘竞争形成完整循环。Wiki 页面的事实依据见 [research.md](research.md)，精确路线、距离和赶路时间尚未核实，不从“首批串联”推定三地紧邻。

拟定内容分工为：

| 地域 | 玩家内容与制作重点 |
| --- | --- |
| 乌坦城 | 居所、坊市、商铺/拍卖场、家族与人物生活联系，关系和资源消息的持续变化 |
| 青山镇 | 佣兵活动、结伴准备、任务与药材消息，合作/竞争和城镇生活联系 |
| 魔兽山脉部分区域 | 线索追踪、资源采集、魔兽风险、分支路线与机缘争夺 |

首批可进入的场景、世界地理资料覆盖、远方模拟的范围分别定义；不能用已整理地图资料代替实际制作，也不能将首批场景范围擅自视为最终世界上限。

多种出身可以在同一地区形成不同身份、关系和资源条件；若背景需要远方出生地或组织，还需明确开局所在与原有联系，而不是任意传送全部背景到同一个不相关地点。

## 人物关系与日常的内容展开

建议基础内容包含熟悉与信任、友情、师徒、利益合作、恩情与债务、竞争和仇恨。关系需要影响人物是否同行、援助、分享线索、隐瞒、交易或报复，并保留具体事件与人物视角；不把所有关系压成一条无来源的好感值。

人物的谋生、修炼、休息、出行和求助等活动形成可观察的生活。关系与日常相互影响：接触机会取决于位置与活动，能否履约受实际资源与时间制约，已建立的联系能带来信息或义务。

亲密关系、婚姻与家庭以 [D21](decisions.md#d21--亲密关系婚姻与家庭) 为准，需与人物自主意愿、既有关系、日常资源和历史变化连接；同一主角方向不意味着玩家必须切换下一代。

基础内容方向已定，具体人物、关系规则、家庭活动与规模将在整体制作基线中拟定；不能把关系类型选择仍列为未回答事项。

源码补查已发现动态人物关系目标的接纳边界，见 [research.md](research.md)。它作为优先验证事项，与人物日常、事件来源和个人所知一起贯通；需要修补时沿用既有身份、认知与评价权威。

## 运行取向与性能验证

运行取向以 [D22](decisions.md#d22--电脑为主与质量优先) 为准。具体模型路线、连接能力、等待目标和实际调用配置在实施时核实。不能直接用开发机配置代替所有玩家设备，不能把所有生成行为放进同一个等待预算。

建议将普通操作、规则结算和模型交互分别衡量：对象选择、查看资料与输入应及时反馈；移动、交易、战斗和世界追赶要有可测的结算开销；重要对话、复杂意图与 NPC 决策再使用对应生成能力。

在产品范围确定后，用由小到大的可重复负载样本验证：人物总数、同时活动人数、关系记录、私有记忆、待处理事件、存档体积与历史长度分别计量。模板上限、记录预算和真实流畅规模区分，不预先把某个上限作为容量承诺。

确切模型、等待目标和调用配置按当前可用条件落实，不擅自增加每日调用额度或 RPM 硬上限。

本轮汇总首个贯通体验、长期关系、默认交互与美术、数据职责和实施依赖，并列出实际容量与玩法验证安排。具体公式和内容条目的工程细化遵循已定目标；整体方案由用户确认正式启动后进入制作。
