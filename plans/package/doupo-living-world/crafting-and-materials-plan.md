## 玩家体验

探索或购买原料 → 根据必要的公开信息选材 → 选择实际场地和器具 → 自由组合或使用经典方 → 手工小游戏 → 获得有实际效果的成品与配方经验 → 每张方子成功五次后批量生产 → 自用、装备、交易或履约。

低成本量产、均衡实用、特定用途与精品制作都应有需求。好的原料和器具影响实际结果，玩家的组合与操作同样重要。失败有真实耗材和可理解反馈；发现好方子后能稳定复用，不让每次日常补货都重复小游戏。

## 本轮成套推荐

这些推荐与已定要求一起供整体审阅，无需逐条回复。

| 主题 | 推荐选择 | 对体验和范围的影响 |
| --- | --- | --- |
| 副职范围 | 炼丹、炼器、制符均覆盖制作级1–5；原料处理无额外小游戏 | 三条路线有完整制作与使用，不只深化炼丹 |
| 越级量产 | 越级配方成功五次也解锁；不加批量专属职业等级锁 | 允许操作弥补技艺差距，依材料、能源、场地、工具及需求控制成本 |
| 配方身份 | 实质配材、约分比例、处理和结构确定身份；改名／等比例增量／同种换批次不清零 | 可优化供料与产量，真正改方仍需重新掌握，旧方进度保留 |
| 组合与品质 | 常规最多一主效两辅效；一般／精良／上品与废品区分，批量一般 | 材料决定作用，操作决定工艺；永久成长另由专门规则限制 |
| 研究与库存 | 稳定种类＋有限批次差异，鉴定给必要结论；普通材料不设普遍腐败 | 保留探索深度，避免每株鉴定和每日整理过期物 |
| 场所与工具 | 临时／普通／专业／高阶条件，公用或自备工具，公开租期费用 | 低成本生产与昂贵精品各有场所，不能免费永久继承过去设施加成 |
| 炼器小游戏 | 少量节奏锻打＋一次淬炼 | 保持短快，材料影响性能，操作影响成形 |
| 制符小游戏 | 短符路描绘＋一次封符，提供键盘等价操作 | 与炼丹区别明确，不要求复杂长图或像素级手速 |
| 批量与失败 | 合法条件下产一般品质，无额外随机废丹；真实材料冲突／缺陷仍可失败 | 稳定生产有价值；未知风险需靠知识和实验处理 |
| 中断与存档 | 未开炉可退；开工后实耗；失焦暂停；同炉种子、进度、投入精确恢复 | 不把网络异常当操作失败，不通过重开小游戏重抽或重复发奖 |
| NPC与经济 | 共用实际库存和制作规则；NPC用有记录的技艺表现；有限收购与供给 | 生产融入现有世界，避免孤立制作菜单和无限固定利润 |
| 版本策略 | 新局优先，本次不做旧版迁移；保留原存档，完成同规则恢复 | 集中于新材料与制作闭环，旧局不被静默改造 |

## 一条完整的验收体验

药铺学徒取得基础知识和普通药草 → 在药铺或客栈查看具体生产条件 → 借用或购入低阶炉 → 配材并完成短控火 → 实际消耗原料、推进世界工时、获得成品 → 保存并命名自己的方子 → 穿插一次失败，成功数保持 → 累计第五次成功解锁 → 选择已知低成本批次量产一般品质 → 成品用于真实治疗或有限交易。

另一条中阶体验为探索矿点与兽巢取得材料 → 加工为锭／皮／墨 → 炼制一件可装备器物和一张可使用符箓 → 在战斗或探索中验证效果与消费。越级样本需用实际高阶材料、工具与能源完成手工挑战并检验量产条件，不能使用调试按钮冒充自然获取。

以上是贯通样本，不是固定主线、必须选择药铺出身或强制新手教程。实际验证路径与覆盖归工程安排。
