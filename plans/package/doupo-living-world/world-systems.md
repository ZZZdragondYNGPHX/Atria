# 地区、资源、经济与社会的耦合世界

状态：v0.14 深化候选方案；承接 [decisions.md](decisions.md) 的世界整体运转、连续因果与全角色社交圈方向，以下机制、编制与数值均待讨论和实现核验，不新增冻结决定。

本模块负责让首批地区在没有玩家参与的推进窗口内持续运行：资源改变供给，供给影响生计与组织安排，人物实际执行，行动再改变地区和历史。人物是其中的行动者，世界还包含持续存在的场所、生态、库存、商路、家庭、组织和公共事务。
时间推进、过月调度、计算精度、人口与恢复的唯一细则见 [world-simulation.md](world-simulation.md)；人格、长期目标、个人规划与主动交往见 [npc-agency.md](npc-agency.md)，本模块只定义它们接收的世界压力及行动后果。
每个角色的社交圈、对第三者关系的认识和私有评价归 [social-graphs.md](social-graphs.md)；组织不能自动读取成员私有关系，成员也不自动掌握组织全部秘密。
无玩家参与指玩家等待、闭关或离开某地时，已提交的世界时间窗口内无人为当地提供指令；不改变思考、编辑和退出时暂停世界的既有方向。
本方案不能作为 BE2 已实现完整地区经济、生态或组织自治的声明；已有规则与本轮新增要求分别以源码、接口及同一 [Record](../../../records/package/doupo-living-world.md) 核验。

## 运行目标与首批范围

候选目标是一个能够自己产生需要、组织行动、消耗资源、处理成败并延续后果的地方社会。玩家可以加入、阻止、利用或完全错过其中的事情。
“整个世界动起来”先落到乌坦城、青山镇和魔兽山脉部分区域的真实耦合；首批以外只接入有限且有来源的来货、迁移与消息，不声称全大陆已经运行。
先把药材、基础补给、治疗、修炼和运输贯通，再扩展商品与产业；不同时制作完整产业树、领地战争或全套 4X 管理。
商铺、组织和资源点不能只有等待玩家点击的用途；常态消费、成员需求与组织承诺足以启动行动，玩家是否接取委托不决定它们是否存在。
世界可以经历修复、丰收、信任增长与长时期稳定；活跃程度不按冲突、死亡或突发事件的数量衡量。

## 相互作用的持久对象

以下是概念术语与职责，尚不是已实现字段、schema 或新的存储接口。

| 对象 | 候选持续事实 | 对其它层的影响 |
| --- | --- | --- |
| 地区与场所 | 可用设施、通行条件、当前压力、已完成建设 | 限定生产、照护、交易与行动机会 |
| 资源点与生态 | 可采存量、再生阶段、承载条件、危险来源 | 决定收益、采集压力与路线选择 |
| 库存与生产 | 持有者、可用量、预留量、原料、产能与损耗 | 形成交易、生产、求助与替代需求 |
| 商路与货运 | 路段、运力、载货、费用、在途进度与风险 | 传递真实货物、人员与部分消息 |
| 家庭与组织 | 成员、财物、义务、岗位、持续目标与项目 | 分配劳动、承担照护、建立合作与冲突 |
| 事件与历史 | 起因、参与者、条件、已发生阶段、结果依据 | 改变机会、关系、制度与后续事件条件 |

同一批药材在资源点、采集者、货运、商铺或消费者之间转移；不会为了不同界面和系统各复制一份。
各层通过已提交结果相互影响，保留从短缺、行动到变化的因果；新闻和人物感受随后按各自消息来源形成。

## 三地分工与往来

首批候选分工延续 [content-and-runtime.md](content-and-runtime.md) 的地域范围，不从玩法关系推定三地距离或原著地理。

| 地域 | 常态活动候选 | 与其它地区的真实往来 |
| --- | --- | --- |
| 乌坦城 | 家庭生活、基础加工、药铺经营、修炼与学习、组织采购 | 消耗药材与补给，支付采购和加工费用，提供部分成品与商机 |
| 青山镇 | 补给、药材收购、向导与佣兵协作、伤员照护 | 汇集山中来货，组织入山和运输，接收城中补给与订单 |
| 山脉部分区域 | 资源再生、采集、探索、魔兽活动、营地维护 | 产出有限资源，承担采集压力、途中风险与救援需求 |

这些是游戏原创的系统分工候选；具体商品、设施和人物职能采用前仍需核实设定与首批实际内容。
每地保留不同的资源、技能、需求和行路条件，让迁移和运输有原因；不以简单的永久高低价差保证无限套利。
某条路线停运后，可以通过库存缓冲、减少消费、改道、组织护送或替代品应对；替代途径必须已知且实际可用。
未建模的外部来货使用明确边界：来源、到货窗口、数量和成本有限，进入本地后继续遵守同一库存规则。
没有可用外部供给时如实保留短缺，不凭空刷货；也不把首批外所有地区都当成同样缺货。

## 生态、再生与采集压力

首批优先建立少量药材点与有限魔兽活动区域，每个资源点同时具有产出条件和获取代价。
普通药材的候选再生取决于剩余植株、恢复阶段及局部条件；连续采空降低后续产出，停采或养护可以改善恢复。
再生结算有存量上限和明确期间，不能把跨月简单解释为每个采集者分别获得一份完整产量。
稀缺遗留物与独特机缘有唯一归属和取得前提，不使用普通药材再生规则；已取走或破坏的对象持续改变现场。
采集需要人物到场、可用工具、运载空间与劳动时间；采得物进入实际持有者库存，受伤或撤退保留已发生的部分。
多人同时采集时共享可用存量，先后与合作结果按时间因果结算，不能在聚合阶段分别读取同一份旧资源。
采集压力既可以引发争夺，也可以促成分区、轮采、合伙、养护或暂时转行；具体选择交由人物和组织目标系统。

魔兽危险的候选来源包括既有活动范围、资源竞争、受扰动程度与当前个体状态，而不是玩家踏入时临时生成惩罚。
入山队伍、噪声、过度采集或捕猎可能改变局部危险，影响后续路线和他人工作；相关变化必须有规则允许的作用链。
减少某一区域的魔兽威胁可以改善通行，也可能改变资源竞争；不预设每次猎杀都必定触发更严重的灾难。
首批不做完整食物网；只追踪确实影响药材、采集和路线的少量生态关系，新增关系时补足来源与守恒边界。
魔兽材料需要可追踪的捕获或交易来源，不能由商铺库存更新直接生成；补充个体也遵守已建模的迁入或繁育条件。
山中风险不会随着主角境界自动同比增强；远方伤亡和救援机会须由当地行动及危险结算产生。
恢复良好的地区可保持平静；人口与事件调节仍按 world-simulation 的规则，不为追求热闹无条件制造兽潮。

## 生产、库存、消费与货运

首批候选商品只覆盖现有玩法所需类别：基础口粮或旅行补给、普通药材、基础治疗成品及少量修炼物资。
具体物品名称、配方、产量和周期待校准；这里定义实际流转要求，不把示例商品当作已经冻结的经济内容。
生产需要投入物、具备能力的人物、可用设施与时间；完成时消耗原料并产生成品，产能受到工时、伤势和工具约束。
原料不足、生产者离开或设施失效会使作业等待、变更或停止；不能继续按满产日历发货。
生产期间预留的原料不能再次出售或投入另一项目；中断时按已发生步骤结算可退回物与损耗。
居民和组织根据实际生活、治疗、旅行、修炼和项目活动消费；消耗与购买分开，购入物可以储备，也可能腐损或被夺。
劳动力不能在同一时间段被药铺生产、组织护送和家庭照护重复使用；时间占用与活动中断细则引用 world-simulation。
库存区分可用、已承诺与在途；订货不会立即改变目的地现货，库存归属变化和到货发生时点分别记录。

首批运输采用有限班次或明确的运输项目：出资、采购、集货、出发、途中、交付与清算都有完成条件。
货运需要运力、补给和承运者；人物作为护送者或随行者实际离开原场所，不能同时继续本地全职经营。
在途物资具有当前承运关系和路线状态；延误、损失、改道或截获只按实际事件改变货物归属及剩余量。
承运方不能拿尚未抵达的货物二次交付；重试、保存恢复与重复接收不增加货物或多付一次运费。
交易由买方资金和卖方可用库存共同限制；NPC 间采购也支付真实代价，拒绝玩家不表示库存永久闲置。
工资、佣金、报酬与赔付需要实际出资方和可用资金；公告可以承诺付款，资金不足须形成违约或重议。
首批允许明确的有限赊欠与债务，保存债权人、债务人和履约条件；不能用无限信用替代所有资源约束。
手续费、生活损耗和外部贸易分别有去向或边界记录，方便解释总量变化；不要求模拟完整大陆货币发行体系。

## 价格与生计反馈

价格候选由有限的供需压力、补货成本、运输风险与买卖关系共同影响，并设置有解释的反应速度及报价有效条件。
不采用“每次打开商店随机换价”；世界发生交易、缺货或路线变化后，持有相应信息的经营者才调整其报价。
高需求不会立即创造商品，也不会让所有人接受任何价格；家庭预算、替代品和实际用途限制支付意愿。
报价上涨可能吸引采集与运输，也可能令穷困家庭减少非必要消费；收益与生活压力反向影响人物当前目标。
收入减少时，人物可考虑找工作、变卖储备、求助熟人、结伴出行或迁居；选项仍受本人所知、意愿和可达性限制。
库存积压则可能降价、减产、暂停采购或改变经营方向；不能只模拟价格上涨而没有缓和与恢复机制。
短缺有从库存缓冲到实际失供的过程；一笔大额采购可以影响当地市场，但不保证立即造成全地区饥荒。
良性循环同样持续：稳定供货降低风险、提高履约和收入，支持家庭照护、技能学习与储备。
首批重点验证一两条价格与行为反馈，不把所有物品放入无法解释的统一经济黑箱。

## 家庭、组织与成员执行

家庭既有关系也有生活安排：共同居所、成员实际持有的财物、约定承担的供给与照护，以及成员各自可支配部分。
亲属关系不会自动合并全部库存或允许代替本人作出决定；共用物资和个人物资的取用须有已建立的权限与约定。
一名成员出门采药，另一名成员可能承担照护；收入和伤病改变分工，长期缺席可以促成求助、重议或迁居。
照护与供养需求可以面向亲属、邻里、雇工或组织提出；玩家只是可能的参与者，婚姻与子女细则仍归原模块。
家庭积累的技能、储备、债务和交往关系，使新一代进入已有地方社会；代际规则及人口名额引用 world-simulation。

首批组织候选采用少量商铺、佣兵协作团体和家族职能单位；具体名称、原著归属与编制依内容核实，不另铺满宗门势力表。
组织持久目标可以是维持药铺供给、保障成员生计、守住稳定商路或培养接班人；目标持续于多名成员的活动之间。
组织的财物、承诺、岗位和项目独立保留；组织意图不能直接在地图上生效，必须找到可执行的成员或合作方。
负责人提出候选项目，按经费、物资、人员、权限和风险决定是否启动；缺少条件时积累准备、缩小范围或放弃。
成员执行项目时占用真实活动时间，并保留个人利益、能力和服从边界；下令不等于所有成员必然接受并成功。
例如护送项目需有人采购、有人集货、有人押运、有人留守；任一环节失约会改变其余环节的进度及成本。
项目奖励、分成和损失承担在出发前形成约定，实际结算与履约经历影响后续合作；不凭空生成共享好感。
组织可向其它组织采购、请求协作、议价或竞争有限资源；同盟针对具体利益与承诺，不要求结成后永远一致。
成员可以隐瞒线索、争取职位、拖延、另谋生计或离开，行动来源和判断规则引用 npc-agency。

职位候选保留职责与任职条件。负责人离任、失能或死亡后，按已存在的成员资格、授权与组织惯例产生接任争议或交接。
继任不会自动生成更强人物、恢复资金或清空旧债；无人胜任可以留下职位空缺、降级运作或暂时停业。
旧组织可能缩小、调整制度、拆分、合并或消亡；首批只实现已具备资源和行动规则支撑的少量结果。
新组织需要真实成员、共同动机和可用资源，不为填补地图空位无条件刷新；身份与人口仍使用已有权威。

## 事件、群体项目与历史生成

候选事件从条件与行动产生，至少能说明压力来源、可行动者、已知信息、需要资源和可能被改变的阶段。
“药材供应吃紧”可来自采空、运输延误或消费增长；它们具有不同补救路径，不能共享一段与事实无关的固定剧情。
一项需求可以由本人解决、多个 NPC 协作、组织接手、继续拖延或最终失效；没有玩家接单时也进入这些分支。
主动求助、邀约、竞争、结盟、隐瞒与利用，都要能追溯到人物目标和已知经历；世界条件提供机会，不指定必定找玩家。
选择合作对象时考虑位置、能力、可联络性、已有义务和信任；已在远方的人物不会即时响应本地请求。
NPC 间可以共同筹资、约定轮采、共享护送、交换技能或联合竞价，并让分工和收益进入真实状态。
竞争者可以先行购买、占用运力、抢先抵达、散布自己掌握的消息或争取合作方；允许手段范围仍受实际玩法支持约束。
群体项目保存发起原因、贡献、承诺、已完成阶段与结果；中途加入、退出及部分失败不会抹掉此前投入。
一次成功护送可留下稳定伙伴和较低风险；一次分配失信可留下追债与疏远，后续变化应能追踪到具体经历。

事件进行前检查必要条件；已经缓解的短缺不会继续强制爆发争夺，遇害目标已经离开则原定伏击可能落空。
玩家在途中提供替代物资、改善路线或揭穿欺骗，会改变当前阶段与后续条件；不能只换一段文本后继续原结局。
条件消失时，尚未发生的事件取消或转向；已经发生的损失、付款、伤势和知情事实继续保留。
未发生的灾难不作为真实新闻发布；可以保留有关准备、预警与避免危险的实际行动及各人的理解。
长期事件之间允许有限关联：伤病影响劳力，劳力影响供货，缺货促成协作，协作可能改善下一轮风险。
不让每个小事件自动升级成跨地区灾难；传播需要接触、资源依赖、组织关系或消息渠道。
历史归纳只引用已提交变化：谁维持了商路、哪家药铺易主、为何一支队伍解散；不随机贴上盛世或衰世标签。
时代演化由这些事实在长期累积，既可形成兴衰，也可形成稳定延续的家庭、行业惯例与组织传承。

个人连续因果可以进入地区循环：一次采药冲突使某人受伤或怀怨，后续实际观察、联络与行动可能牵动亲属、朋友、共同雇主或当地组织。接收者各自判断和投入，不会因同一关系标签同步敌对。具体报复、求援或调停须有获知、能力、时间与资源条件，不能直接触发全族追杀。

社会动机也不必来自物资短缺。思念、感激、羞辱、责任与共同经历可以形成探望、分享、疏远或报复；这些目的仍通过真实旅行、赠物、交涉和冲突影响资源与地区。旁人有自己的安排，可能拒绝、误判或帮助缓和冲突，不只是主谋计划中的条件。

## 最小可运行耦合闭环

首个候选闭环采用“药材供给—治疗与生计—协作采运—地区恢复”，在三地各有至少一个实际作用点。
其最小内容是一个会恢复也会被采空的资源点、一家有生产投入的药铺、一条有耗时和运力的路线，以及有关家庭和协作成员。
先选少量能承担不同职责的人物贯通，沿用现有人口；不为展示世界运作一次增加大量匿名工人或新组织。
开局配置明确：各方有限库存与现金、近期正常消费、资源可采量、运路条件和已存在的照护或经营义务。
这些是该开局的初始事实；既有收入和经历若尚未模拟，只作为明确背景，不补造一串已经实际运行的历史。
初始供需不必人为制造极端短缺：正常治疗、日常消耗、库存预警与到期采购本身就足以产生行动。
药铺因库存和实际需求形成采购目标；采集者因家庭开支或成长目标决定是否接洽，组织根据资金决定是否凑成运输。
有人开始工作，有人因照护留守，有人希望独占更好的采点；初始意向必须有已知途径和可用资源，能在首次推进时执行。
公告是联络方式之一；不以“玩家接受了任务”作为生产、出发、运输或本地需求结算的启动条件。

| 闭环阶段 | 必须发生的规则连接 | 候选可变结果 |
| --- | --- | --- |
| 正常消费与采购 | 治疗和生活消耗影响真实库存、资金与需要 | 自行采购、求助、推迟消费、改用替代品 |
| 组队与入山 | 能力、关系和时间决定分工及实际出发 | 独行、协作、拒绝、改期或另找伙伴 |
| 采集与风险 | 有限资源、劳作和危险共同决定所得与代价 | 满载、受伤、分歧、撤退、轮采与养护 |
| 运输与交付 | 来货延迟、成本与损失传递到目的地 | 正常补货、改道、重议、违约或救援 |
| 生产与家庭 | 原料加工、报酬和照护影响下一轮活动 | 恢复生计、积累储备、债务、转行或迁居 |
| 持续后果 | 地方条件与经历改变下一轮目标和合作 | 稳定供应、长期短缺、伙伴形成或关系破裂 |

首批完成依据是这条链无需玩家推动也能运行并留下可查结果；多个独立作息脚本同时运行不能替代它。

## 无玩家样本与干预对照

以下是后续实施的候选验证设计，本轮不运行测试，不将设计写成通过结果；时间跨度和负载档位与 world-simulation 对齐。
无玩家样本通过等待或长时活动推进同一世界窗口，禁止在中途手工补库存、补人物、接取委托或修改目标。
分别观察正常条件、局部短缺、路线受阻、关键成员缺席和稳定合作；区分纯规则计算、真实宿主接线与需要模型的抉择证据。

| 样本 | 无玩家时检查什么 | 同初始条件的干预对照 |
| --- | --- | --- |
| 正常供需 | 自主采购、采集、交付、消费及再生产是否衔接 | 玩家参与一段护送后，比较成本、收益和合作经历 |
| 采点压力 | 存量下降是否改变劳动与计划，再生是否受实际采集影响 | 玩家协商轮采或提供替代来源，比较后续存量与收入 |
| 货运延误 | 在途货不进现货，短缺传到报价与需求，能否改期或改道 | 玩家排除已知障碍，检查事件变化及避免的损失 |
| 家庭失能 | 照护、劳动力与现金变化能否促成其它 NPC 主动互助 | 玩家帮助其中一项需要，比较实际分工与剩余压力 |
| 岗位空缺 | 组织承诺继续存在，成员接任或停业有依据 | 玩家支持候选人或提供资源，比较继任与履约后果 |
| 长期稳定 | 资源与生计可在合理范围持续，无强制灾变或任务堆积 | 玩家长期不介入，稳定本身仍是有效历史结果 |

对照固定初始世界、规则版本和已接受的外部输入；可确定部分比较因果与守恒，模型新增抉择按来源单独说明差异。
核对原料与成品转化、买卖双方资金、在途与现货、人物时间占用、承诺和唯一物归属，防止“世界热闹”掩盖重复结算。
读档后复核整条链，未来货物、已取消项目、继任关系和人物所知不得串入旧分支；具体恢复要求引用 world-simulation。
玩家可见证据通过货架、路况、人员去向、价目、书信、公告与当地经历呈现；调试时的全量因果不直接成为玩家全知信息。

## Package 与 Atria 的实现边界

本模块的资源再生、供需、生产、货运、价格、生计、组织目标、岗位和条件事件属于斗破 package 世界规则。
包内沿用 Native Subject、Domain、Clock、Simulation、Information、History 与 SavePoint/Branch，实际 schema 和接口由实现阶段核对。
Atria 提供通用的身份、授权、逻辑时间、有界调度、事务发布、确定性提交和模型交付；这些能力不自动提供斗破经济或组织自治。
常规消耗、再生、履约与库存结算优先用规则计算；人物复杂协商和新抉择按 npc-agency 的职责接纳，不能用模型文本直接补货或结盟。
先以包内事件组织、区间计算和有限集合读取实现闭环；确有共同调度、预算或事务能力阻断时，再提出最小 Atria 通用修补。
实施时先让单条闭环在无玩家条件下成立，再增加组织项目、其它资源与跨代后果；每次扩展承接已有世界事实和已测容量。
