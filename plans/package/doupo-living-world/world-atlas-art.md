# 世界地图与扩充美术

状态：2026-10-23，atlas.1兼容版与atlas.2高画质版均已完成并验收。本文件先于本轮实现创建，承接 content.1。

## 已授权目标

补齐 content.1 缺失的十名原著角色专属画像/Q版、二十处新增场所图及黑岩城/石漠城/塔戈尔外缘总览。普通原创居民沿用现有按年龄与性别匹配的成对外观；已完成的专属画像先核验再复用，不覆盖原素材。美术遵循既有写实国风手绘、克制矿物色、布料笔触和俯视场景；Q版保留角色身份，透明底。逐张生成与检查，来源/提示词/哈希写入素材记录。

世界地图覆盖斗气大陆主要地域与后续扩展位置，保持大陆→大区→已实装地区/场所层级。未实装区域显示“未解锁”，不提供点击、旅行、进入或其它动作；后端也拒绝以锁定区域 ID 发起移动/旅行。锁定地图节点不创建空人口、库存、生态和可行走场所，避免空壳进入世界演化。后续补齐地区、场所和路线后，在唯一地图内容池中开启节点即可。

## 调研与地理边界

依据 [Locations](https://battle-through-the-heavens.fandom.com/wiki/Locations)、[Dou Qi Continent](https://battle-through-the-heavens.fandom.com/wiki/Dou_Qi_Continent)、[Central Plains](https://battle-through-the-heavens.fandom.com/wiki/Central_Plains)、[Black-Corner Region](https://battle-through-the-heavens.fandom.com/wiki/Black-Corner_Region) 的可读检索正文核对：斗气大陆包含西北地域、中州；西北有加玛及周边帝国，黑角域包含迦南学院；中州有中、东、西、南、北分区。部分直接页面受限，不声称完整读取。具体大陆轮廓、相对画面位置和未详述疆域为原创示意，不标作小说精确地图。分区内列出已核实名称，缺少细节的远疆保留概括性位置，避免混入其它小说地图。

未解锁区域属于玩家可见的作品地图目录，不作为角色已知道路、秘密位置或开篇事件。秘境只以“独立空间”类别概括，不提前公开机缘位置或未来剧情。大千世界不属于本作当前斗气大陆可玩范围。

## 接入与视觉方案

- 在既有内容池中增加世界地图目录，地图坐标与状态集中维护；已实装节点引用六个现有地区，禁止复制地点与路线权威。
- 山河面板增加大陆手绘总览、明确状态图例和分区目录；已实装地区可以筛选本人已知地点，锁定区域只显示静态名称/状态。当前路线发现与旅行耗时不改变。
- 沿用现有深青灰底、米白文字、铜色强调、宋体标题与现有按钮/面板；大陆图作为唯一突出视觉。区域切换与键盘操作即时，避免装饰动画。地图文字由界面渲染，底图不烧入难维护的名称。
- 场景图片映射接入同一地理定义；人物继续使用 appearance 池与配对资产，不新建平行图片选择系统。

## 验收与发行

验证素材解码、尺寸、alpha、配对、来源哈希、重复与遗漏；全部新增人物和地点实际渲染，无缺图回退。检查地图锁定节点不存在动作、键盘不可触发、伪造请求拒绝且不耗时/不改状态，已开放地点仍可正常旅行。执行原生编译、最终包安装/新局/存档恢复及桌面/移动模拟视口浏览器流程。按 web-design-guidelines / review-animations 自查，不启动独立审查流程。新发行版本保留旧包，结果补入 Record。
