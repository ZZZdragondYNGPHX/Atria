# NPC 能动性：从人生目标到自主行动

状态：2026-10-22 候选设计。已确认方向包括：优先让整个开放沙盒世界动起来；NPC 可依据自身目标与经历主动求助、邀约、竞争、结盟、隐瞒和利用玩家；支持可中断、可分岔的复杂因果，以及包括玩家在内的全角色个人社交图谱。具体人格维度、规划算法、行为范围、数值和实施顺序仍供讨论，本文件不声明新机制已经实现或接口已经接通。

## 唯一职责与依据

本模块详细定义 NPC 为什么行动、怎样形成目标、怎样选择和推进活动，以及如何主动影响其他人物。跨模块已确认决定只归 [decisions.md](decisions.md)；本轮方向不能扩大为每项候选细节均获批准。

每位角色的社交圈、第三方关系认知、有向评价和玩家视角的唯一详细设计归 [social-graphs.md](social-graphs.md)；人物在这些获准所知内选择行动，不能通过规划器读取对方私有图谱。

时间推进、事件调度、跨图旅行、人口和计算精度的全局约束归 [world-simulation.md](world-simulation.md)；经济与组织的相互作用归 [world-systems.md](world-systems.md)，家庭玩法细目归 [content-and-runtime.md](content-and-runtime.md#亲密关系婚姻与家庭)。本模块只解释人物如何使用这些系统，不另定旅行时长、月长、工资、人口上限或生育参数。

包括玩家在内的个人社交图谱，其事实、知情范围、关系路径和可见表现归 [social-graphs.md](social-graphs.md)。本模块使用图谱形成动机和寻找联系，不复制一份关系真相；感知、相遇、同一时点和旅行时钟仍引用世界调度模块。

成长和战斗条件沿用 [player-and-combat.md](player-and-combat.md) 与 [progression-and-consequences.md](progression-and-consequences.md)。社会行动与玩家动作进入同一规则；不得为 NPC 另造可绕过条件的快捷通道。

## “动态”和“智能”分别要求什么

动态要求：玩家不接触人物时，人物仍能谋生、采购、照护、学习、迁居和竞争；活动改变真实资源、位置、能力、关系及后续机会。查看界面或思考时不推进世界，仍遵循既定时间方向。

智能要求：人物在自己所知的范围内，为目标权衡可执行途径；必要时询问、求助、合作或隐瞒；失败后会调整。判断可以有偏见、误信和短视，不要求人人最优，也不能靠后台全知伪装聪明。

可观察的差异应来自持续原因：同样缺钱，有人延后突破，有人接危险委托，有人借钱，有人出售秘密。换一句随机台词而结果不变，不能充当性格驱动的行动差异。

世界整体先动，意味着生活、交易、家人、雇主、竞争者与组织之间形成依赖。首批贯通不能只让两个重点 NPC 会出门，其余人永久站在出生位置等待玩家。

## 稳定性格、价值排序与情绪分开保存

| 层次 | 候选内容 | 变化方式与作用 |
| --- | --- | --- |
| 性格倾向 | 谨慎/冒险、耐心/急迫、独立/求援、坦率/隐瞒等少量行为倾向 | 通常稳定，影响风险估计、等待意愿、求助和披露；重大经历可缓慢改变 |
| 价值排序 | 家人安危、修炼成就、财富、名誉、自由、组织责任等 | 决定目标冲突时愿意牺牲什么；不要求所有人物拥有完全相同的条目 |
| 当前情绪 | 焦虑、愤怒、感激、疲倦或悲伤的强度及来源 | 随事件产生并随游戏时间变化，临时影响注意、信任判断和冲动成本 |
| 个人经历 | 履约、照护、背叛、竞争失败、获救及对应知情来源 | 改变对特定人或情境的预期，不自动改写全部人格 |
| 客观条件 | 身体、技能、库存、位置、义务、可支配时间 | 决定能否执行；情绪和文案不能绕开物资、能力或旅行限制 |

维度名称与数量只是候选，不把一套量表当成原著设定。人物可以谨慎但为亲属冒险，也可以重情却拒绝没有偿还能力的借款；规则应能解释价值冲突，而非按单个标签决定所有行为。

情绪与身体需求不能混为一谈。饥饿必须由食物与进食改变；“安心了”不能替代治疗。情绪变化读取已知事件，不因玩家在远处做了尚未传来的事立即感激或怨恨。

动态生成的人物沿用相同语义：来历给出倾向与目标的合理来源，入场后持续保存。人格重新生成不能成为模拟降级、地图切换或模型重试的副作用。

## 长期目标、阶段目标、当前活动与承诺

长期目标表达想维持或改变的人生状态，例如照护父亲、获得稳定生计、争取突破或维持家业；阶段目标是目前可检验的一段，例如攒够诊疗准备、获得可靠药源或完成一次雇佣。

当前活动表达人物此刻真实投入的过程，例如在铺中工作、前往买药、休养、等待回信。活动必须记录实际开始、预计结束、占用条件、已发生进度与可中断点；“修炼中”不能直接等于已经获得全部修为。

对外承诺独立于内心目标：人物可以不再想出行，却仍欠同行者一份解释或赔偿。更换长期目标不会清除债务、婚约、已交订金或被他人知晓的约定。

| 候选记录 | 最少要回答的问题 |
| --- | --- |
| 目标 | 为谁、因何产生、想达到什么状态、怎样确认成功或失去意义 |
| 目标状态 | 进行中、受阻、暂缓、已完成或放弃；原因来自什么已发生事件 |
| 阶段与进度 | 已筹到哪些真实资源、学会什么、联系到谁、仍缺哪项前提 |
| 当前活动 | 正在做什么、在哪做、使用谁的资源、何时有下一次可结算变化 |
| 义务与承诺 | 向谁保证了什么、双方接受哪些条款、期限和违约后果是什么 |
| 方案依据 | 用了哪些本人知道的渠道、消息有多旧、依赖谁愿意配合 |

进度优先引用库存、能力和已提交事件，而不是另外保存一条可随叙事上涨的“完成度”。治疗需要多阶段时，每次投入与病情变化都是真实结果；长期照护也可能是持续维持而非一次完成。

饥饿、危险等可打断长期安排，但不每次醒来就忘记原目标。拟用最低生存准备、已接受义务和目标持续性共同约束切换，避免人物在赚钱、修炼、采药之间每轮反复横跳。

原著人物同样有当时可成立的目标；后续剧情只提供候选压力。前提变化或本人取得新经历后应改策，不以“小说将来需要”强行恢复原路线。

## 候选行动评分与有界规划

规划入口拟来自真实变化：活动完成、身体或补给越界、机会消息抵达、承诺接近期限、伙伴退出、路线或市场条件改变。普通时段延续有效安排，不让每个 tick 都重新思考人生。

先用能力与本人所知生成小组候选，例如继续工作、买粮、休养、联系熟人、申请雇佣、求援或远行。未知渠道先形成打听和查证活动，不能直接跳到隐蔽资源的真实地点。

候选方案先检查可行前提，再比较收益。得分可综合目标推进、价值吻合、履约收益、情绪紧迫度、预计资源与时间成本、主观风险、失败损失和对现有安排的破坏；权重与尺度仍待校准。

评分中的“预计风险”和“他人是否可靠”使用人物信念；真正执行时使用客观条件。误信低风险路线可能导致真实受伤，不能让主观高分直接抹去环境危险。

拟采用短视野规划加阶段复评：只细化近期可执行步骤，为更远阶段保留条件与替代途径。搜索步数、候选数和重评频率按负载校准，不先承诺人人实时进行长链推演。

多步方案应识别依赖：先赚钱再买粮、先协商分配再共同出发；若已经具备前提则不重复做无用步骤。未知技能、物品或路线不得由模型为了补齐链条临时创造。

计划承诺期拟抑制无意义改道，但新危险、关键前提消失和重大责任可以触发提前重评。刚启程的人不能仅因下一次评分微差就无成本回到原地。

| 失败情况 | 候选后续，而非统一无限重试 |
| --- | --- |
| 库存售罄或被抢先取得 | 查其它已知渠道、等待补货、议价购买现持有者的物品或暂缓目标 |
| 资金不足或被拒绝赊欠 | 改接可承担工作、出售可支配物、求助其它联系或降低近期投入 |
| 遭遇伤病或危险超出判断 | 治疗、撤退、求救、改变路线；保留已发生耗费与损失 |
| 伙伴失约或利益冲突 | 重新谈判、寻找替代人、缩小计划、追偿或结束合作 |
| 消息被证伪或过期 | 修正本人信念与渠道评价，避免沿着同一错误消息反复空跑 |

## 自主执行与模型分工

候选流程为：取得个人投影 → 延续或重评目标 → 选择可声明活动 → 规则接纳与占用 → 到期或中断结算 → 写入个人可知结果 → 更新目标和下一活动。这是设计语义，不是已实现的新接口清单。

规则负责日常谋生、补给、等待、常规照护、已达成安排后的赶路与交付；同类活动可聚合推进，但仍支付相同来源的资源和时间。具体聚合边界归世界调度模块。

模型优先用于重要价值冲突、陌生复杂协商、自然语言互动和少量新目标构思。它只能在获准信息及行动目录内提出意图，不能直接宣布突破、转移物品、缔结婚姻或让别人同意。

模型未及时返回时，在后续获准的游戏时间推进中可执行与该抉择无冲突的既有安排；模型的现实等待本身不推进世界。需要等待的决定保留待定状态，依赖其结果的活动不得提前结算。超时处理可延续安全的已接受活动或暂缓该决定，不伪造新的同意或收益；结果仍按原分支/修订条件检查接纳。

模型文字与活动事实分开：说“明天一起走”只是提议；有双方接受、补给、集合与出发结果后才成为实际同行。接纳时重新检查时间、位置、库存和承诺是否仍有效。

## NPC 对 NPC、对玩家的主动社会行为

| 行为 | 从人物目标出发的起因 | 必须产生或检查的后果 |
| --- | --- | --- |
| 求助与委托 | 自身缺能力、时间、资源或可信渠道 | 请求有可追溯需求、可承担报酬和失效条件；拒绝后寻找其它方案 |
| 邀约与招募 | 需要同行者、护送、照护替班或共同谋生 | 考虑对方能力与已有义务，提出集合、准备、收益和退出条款 |
| 竞争 | 多方需要同一有限机会、职位或买方 | 查验实际所有权与时间顺序，允许抢先、竞价、协商或失去机会 |
| 结盟与互惠 | 单独完成成本过高，或有持续共同利益 | 双方自愿接受范围与分配，履约和共同经历影响后续合作 |
| 隐瞒与试探 | 暴露线索会增加竞争，或不信任请求者 | 控制实际披露内容；对方只能依可观察证据推断 |
| 利用与操纵 | 希望转嫁风险、廉价获取帮助或试探对方底线 | 需要可信说法或真实筹码；被拒、识破或伤害他人均有可能 |

同样规则首先用于 NPC 彼此互动；玩家只是可能有用、有风险或值得信任的一名参与者。可见的请求不应全部先发给主角，也不能因主角尚未见过双方就禁止他们交易、结盟或结怨。

人物主动不等于强迫玩家答应。玩家可拒绝、讨价还价、沉默、转荐或接受；没有接受的提议不生成玩家义务，也不能代扣物资或把玩家放进已启程队伍。

世界事件不会等所有请求被阅读。提议有截止条件或机会窗口；在玩家后续有意义的行动推进时间时，NPC 可以找别人、自己出发或放弃。思考输入期间仍暂停，不以现实回复速度惩罚玩家。

主动联系通过实际同地接触、约定渠道或可成立的传话到达。远方人物不能直接把秘密写入玩家日志；到达太晚的邀请可以成为过期消息，随后可调查结果。

为避免主动性退化为消息轰炸，候选联系策略考虑事情紧迫性、已有联系、近期重复请求与是否获得新依据。频率控制不能让临界危险失去结算，也不能伪造“你不回话世界就暂停”。

## 联合计划、委托、债务与欺骗

联合计划拟记录共同目标、参与者各自承诺、角色分工、准备条件、集合与等待期限、收益分配和退出处理。每人保留个人目标；同行后仍会因受伤、价值冲突或新义务要求改变安排。

“等伙伴”本身会占用世界时间与补给。伙伴迟到时可继续等、联系、改约或离开；是否违约以已接受条款和本人获知的经过判断，不能自动把所有不可抗力当背叛。

协作占用同一真实资源：订金、装备、携带粮、护送时间和独特物品不能同时承诺给多支队伍。规则接纳时处理冲突，谈成前的报价和意向不等于已经锁定全部资源。

委托有提出、协商、接受、履行、完成、撤回、过期与争议等候选状态；状态取舍可从首批够用流程开始。提出者在委托期间仍可采用替代方案，但应依已接受的独占或赔偿条款处理冲突。

债务记录实际借出与应偿内容、双方接受的期限及担保条件；一句“欠你人情”属于可影响意愿的经历，除非明确达成条款，不自动等于可强制提取的物品额度。

偿债从债务人的实际资源转移。违约可能引发协商、延期、担保处理、渠道声誉或冲突；具体经济与组织执行手段归 [world-systems.md](world-systems.md)，不能让债主通过台词无因扣走财物。

欺骗区分说话者所知、故意表达的内容、听者相信的内容与世界真实事实。允许保留线索、夸大能力或隐瞒分配意图；谎言不改写真正库存、位置或既有承诺。

听者是否相信取决于已有信任、渠道、证据、利害关系与可行查证，不采用人人立即识破或必定被骗的统一规则。识破须有获知过程，不能由全知结算直接向所有人广播。

同一件事可以产生非对称评价：获救者感激、受骗者不知情、旁观者误会。评价只引用本人可知经历；世界层面的已发生事实不随各方说法变成多份冲突的库存或生死。

## 普通人物与关键人物的精度升降

| 人物当前处境 | 候选处理方式 | 不能丢失的内容 |
| --- | --- | --- |
| 普通稳定生活、近期无冲突 | 按已接受生活安排聚合谋生、消耗与成长，遇到边界再唤醒选择 | 身份、倾向、目标、实际收支、家人和已接受义务 |
| 有目标受阻、临近期限或跨人依赖 | 保存阶段计划，按相关事件检查执行和替代方案 | 资源占用、信息来源、伙伴承诺与失败原因 |
| 临场交往、独特资源竞争或危险抉择 | 细化到活动、协商或交锋节点，必要时使用模型 | 行动先后、真实代价、个人判断与实际结果 |

“关键”是当前关联和后果，不只看原著身份或是否与玩家熟悉。一个陌生搬运者若持有唯一材料、承担家庭关键照护或卷入争议，也可提升精度；名人长期无关且安排稳定时也可降低频率。

升级从已存状态和历史展开，不补造过去每一天的细节。降级只压缩可聚合的过程，不取消人物目标、在途位置、债务、亲属和承诺；两种精度下同一资源仍只有一份。

精度选择与时钟、人口统计、长期追赶和保存恢复的约束统一引用 [world-simulation.md](world-simulation.md)。本模块不为高精度 NPC 增设免死、额外人口名额或隐形无限资金。

## 可执行设计例一：苏晚禾的长期照护

这是候选贯通设计，不新增原著药方、材料或确定治疗周期。父亲伤势、诊疗能力和药物适用条件必须来自已经制作的规则与可信渠道。

1. 长期目标为维持父亲生活并尽可能改善伤势；家庭责任较高、风险倾向较谨慎。当前阶段先保证生活、已有照护和诊疗准备，不是每天随机收到新药材任务。
2. 每次工作、吃饭、采购和照护都有实际收支；若需长期携带干粮，应购买并进入库存，不能把花钱吃过一餐当作已经补齐出行或成家的干粮。
3. 已知药物有效且买得起时，安排采购与照护；缺钱则比较继续工作、卖出可支配物、赊欠或求助。她不能一边全天在药铺谋生、一边被当成已在山中采药。
4. 她可先请熟悉医者评估、找家人替班或向可信玩家提出有限请求；请求的报酬来自她能支配的钱物、劳动或愿意披露的真实信息。
5. 玩家拒绝后，她可接受其它 NPC 的有偿帮助、降低近期修炼投入或改用较慢方案；病情仍按世界规则演变。拒绝不必立即转为仇恨，但反复失约会改变她对该人的预期。
6. 若可靠消息指向异地渠道，再形成“安排照护替班—准备补给—旅行—查证/交易—返回”的活动依赖。路线、耗时、中断和返回都引用世界旅行规则，不用一句“外出求药”跳过。
7. 父亲好转、治疗无效或发生死亡时，目标阶段相应完成、受阻或转变；保存已付成本、所欠人情和个人经历。不能只把 `plan` 改成一句新文案就抹去过去。

## 可执行设计例二：陆青、薄尧与赤叶竞争

这是首批原创药材机会的候选深化；赤叶是否适用于某种突破或治疗须由内容规则决定，不默认把全部人物目标绑到同一药材。

1. 陆青因自己的成长需要寻找有限材料，薄尧因采药生计或已接受订单行动。两人只知道各自得到的线索及其时效，不读取唯一资源的隐藏实时状态。
2. 陆青比较备粮独行、雇向导、与薄尧分工或等待查证；薄尧也可先答应护送、竞买消息或隐瞒生境。准备、雇佣与实际出发各有规则结果。
3. 陆青可主动邀请玩家带路或警戒，提出自己倾向的分配；也可只透露部分目的，试图让玩家承担风险。玩家拒绝、要求改价或转而加入薄尧均有可行空间。
4. 接受后形成联合计划；未接受则陆青按自己的替代方案继续。双方旅行采用同一可达路线和时间条件，不再按角色硬编码直达药谷，也不因玩家未出发而原地冻结。
5. 到达时重新检查线索与资源，按实际先后和取得条件确定归属；同一时刻的竞争采用明确冲突处理，不能把稳定记录 ID 排序包装成人物的聪明程度。
6. 未抢到者可查证、向持有者交易、协商其它报酬或在能力和价值允许时采取敌对行动；伤势、声誉、债务和已有承诺约束选择，不能凭失败台词重新刷出一份赤叶。
7. 获得者决定继续探索、交易、履约或返程，并真正建立后续活动。玩家后来见到不同地点、库存和关系，应能从当事人所知、足迹或消息追查原因。

## 经历怎样形成新的因果，而非触发预写剧情

本轮深化承接已确认的复杂因果方向；下述记录、评分与动作组织仍是候选。目标是让已发生的事改变当事人的后续选择，而不是为特定故事隐藏一条必然成功的任务链。

| 因果环节 | 候选语义与边界 |
| --- | --- |
| 事件感知 | 本人遭遇、目击、可信传话或调查得到具体内容；来源、时点与可见范围按 [world-simulation.md](world-simulation.md) |
| 主观归因 | 分清“谁做了什么”和“我认为他为何这样做”；同一次放行可以被理解为善意、轻蔑或设局 |
| 情绪与评价 | 恐惧、羞耻、感激、愤怒等有来源；对人的信任、敌意与能力估计分别变化，不能一条好感包办 |
| 新目标 | 自保、查证、索赔、报复、保护家人或修复关系；也可拒绝升级冲突、继续旧生活 |
| 行动候选 | 根据所知、实力、资源和义务比较接近、交涉、求援、撤退或敌对活动，逐段检验前提 |
| 跨人物反应 | 行动形成新的可感知事件，受害者、家人、伙伴、旁观者与组织各自取得消息并作判断 |

仇怨拟作为带对象、起因和未解决事项的持续倾向，区别于短时愤怒。情绪缓和不自动消除旧怨；赔偿、误会澄清、共同危险或更重要责任也可能降低报复意愿。不能规定受辱者必然复仇，或仁厚者永远不愤怒。

一次目标可以同时承载多种动机：C 想分享自己炼成的丹药，也想见老友、维持交情并看看对方近况。候选行动可兼顾它们；赠物失败或朋友外出时，其它动机仍可能支持拜访或改约。

因果链只保存已经发生的环节和有条件的后续意图。A 尚未发现 B 的家人时，可以想报复，却不能预先锁定后台已知家属；B 不知家人出事时，也不能因叙事需要立刻冲向 A。

关系推断和联系对象来自本人社交图谱。某人是 B 的亲属属于世界事实，A 得知这层关系是另外一次信息变化；知道亲属关系也不等于知道此刻位置、能力与生活安排。

### 面向他人的目标与有限后果预估

目标不仅描述本人缺钱、缺药，也可描述希望改变他人的处境或态度，例如补偿某人、取得引荐、挽回信任、使对方付出代价或迫使其回应。它们仍需有本人经历与价值依据，不能让所有反派共享无缘由的敌对脚本。

A正面交锋失败后，可以因自己记得的实力差距暂缓直接冲突；新获知的关系线索再打开间接交涉或敌对方案。选择涉及第三者的途径，需要A对B是否在意该人作主观估计；亲属身份不自动保证亲近，更不保证B会接受要求。A可以估计错误，后续真实反应会迫使其改策。

候选规划可保留“如果对方接受/拒绝/未回应，再考虑什么”的有限条件分支，但他人的响应只能由他人实际决定。模型或规则对别人反应的预测不是世界事实，不能为了计划顺利执行而控制所有参与者。计算只细化当前相关人物、近期步骤与关键分歧，不要求全世界持续穷举所有未来。

C炼丹成功可以成为分享/报喜的动机来源，久未见面的经历和对好友近况的关心又可支持拜访。多个动机可以强化同一活动，同时分别保存成果和未完成部分；不把炼丹成功后固定派发一次访友事件当成复合目标已成立。

## 潜在计划、机会性插队与旧计划恢复

潜在计划拟保留动机、目标对象、最近依据、尚缺前提、下一次复评条件和放弃条件。例如“找机会报复 B”可以跨月存在；它不意味着 A 每日全天跟踪，也不使 A 停止吃饭、挣钱或养伤。

短期规划结束不能清空尚有意义的长期计划。尚无机会时进入待机或暂缓；出现新的本人可知信息再唤醒，不为保持活跃反复走同一条无效路径。

机会性改道要求新感知使某个候选明显值得考虑：D 途中注意到 C，可能比较继续猎兽、交易、打探、抢劫或回避。看见一个人不自动等于得知其全部身家，更不自动等于选择抢劫。

插队时记录旧活动已做部分、当前位置、剩余资源、正在等待的人及退出代价。未发生的收益不提前到账；已猎得物、已付订金、已经耗去的路程和伤势不因改目标而撤销。

新活动结束后复评恢复、改期、缩减或放弃旧计划。若猎物已离开、朋友已出门、任务已过期，必须面对这些变化；“恢复计划”不能把世界退回插队前。

同一人物不能在两处并行执行互斥活动。多动机可由同一段旅行或会面兼顾，多目标所需的货物和时间却不能重复计算；规则占用与旅行检查沿用世界模块。

失败应改变后续空间：偷袭失败造成的伤势、补给损失、身份暴露和时间拖延，可能迫使 A 休养或逃离，令尾随或报复的机会消失。不得为了维持故事链自动补满其体力和库存。

## 复杂因果所需的动作语义目录

下表描述候选动作家族和应检查的事实，不是新增 API、命令 ID 或已实现能力。可复用现有移动、战斗、交易和信息原语的部分，仍需在实际实现时核对。

| 候选动作 | 前提与应落入世界的结果 |
| --- | --- |
| 观察、询问、查证 | 存在可成立的感知或联系渠道；得到有限内容，也可无所获、误信或暴露意图 |
| 尾随、保持关注 | 依据最近线索和实际位置持续追踪；耗时，可能跟丢、被发现或自行放弃 |
| 警告、饶恕、放行 | 当事人仍有选择条件；结束或改变当前冲突，不自动建立永久安全承诺 |
| 偷袭、抢劫尝试 | 实际接近和战斗条件成立；结算反抗、伤势、脱离与物品变化，尝试不等于得手 |
| 请求赔偿、交涉、对峙 | 以本人所知提出要求；对方可解释、拒绝、拖延、离开、求援或开战 |
| 绑架尝试 | 作为抽象敌对游戏动作检查位置、能力与遭遇结果；目标可反抗、逃脱、获救或未受控制 |
| 控制与转移状态 | 若已经成功限制他人行动，持续记录控制关系、位置、可行活动与看守占用，移动仍耗时 |
| 逃脱、求救、救援 | 依据受控者及援助者真实条件逐段结算；可能成功、失败或改变控制关系与伤势 |
| 传话、报告、隐瞒 | 内容进入有来源的个人所知；发送不等于立即送达，也不保证接收者相信 |
| 赠送、邀访、探望 | 有可支配物品和联系条件；同意、会面与物品交付分别形成事实 |
| 求援、调停、共同应对 | 图谱中存在可联系对象；对方按自身目标决定是否投入时间、物资与风险 |
| 撤退、停止追逐、恢复旧活动 | 保留已经发生的损失与义务，重新检查旧计划是否仍可执行 |

绑架仅按抽象游戏状态表达被限制的自由行动、所在位置、持续代价、逃脱和救援机会，不设计现实操作方法。控制者不能无限期零成本冻结对方；受控者的身体、生存与其它人物反应继续进入世界。

be.2 目前有玩家发起的交锋、退避、投降和物品交付等基础分支，不能据此声称已有 NPC 主动偷袭、抢劫、绑架、控制、逃脱或救援闭环。自主敌对选择、持续追踪、跨人物感知与连锁反应也需实现；现有对话 `choice` 不足以执行这些动作。

动作完成只形成真实结果，随后是否被谁知道另行传播。抢劫失败者逃走不会自动向受害者公开住处；一次求救也不能无因让全部亲友或同族同时抵达。

## 候选贯通样本三：放行、记仇与家人危机

该样本对应 A 与 B 的开放因果链，供设计与后续验证；它不要求每次运行都走完所有环节，更不预定绑架、获救、对峙或报复的结果。

| 已有前提与候选阶段 | 允许发生的分岔 |
| --- | --- |
| 外地 A 因自身目标到药谷，与持药或采药的 B 实际相遇 | 未发现药物、评估实力不利、受旧伤影响时可不发难，也可能交易或离开 |
| A 尝试偷袭抢药，B 在这次交锋中占优 | A 可重伤、退走、死亡或仍在冲突中；不能保送 A 活到下一幕 |
| 若 B 有条件作出选择，其仁厚倾向支持警告后放行 | B 也可要求赔偿、寻求见证或改变警戒；仁厚不是每次都放行的固定按钮 |
| 活下来的 A 把此事归因为羞辱，形成潜在报复意图 | 也可畏惧、感恩、悔悟、转移目标或因更重要责任暂缓；情绪不决定唯一后续 |
| A 尾随或查访，可能获知 B 与某家人的联系 | 必须存在信息来源，可跟丢、认错、被发现；不能直接读取 B 的全量亲属与实时位置 |
| A 据新消息考虑把家人当筹码，并尝试绑架 | 受害者可反抗、避开、逃脱或求助；亲友、邻人或守卫可能提前介入，也可能未能察觉 |
| 事件或消息抵达 B，使其重新判断责任和危险 | B 可愤怒并求证、护家、找援助、谈判或追索 A；消息不足时不会自动知道控制地点 |
| B 与 A 若实际相遇，可发生对峙与新的选择 | A 可逃避、撒谎、求和或抵抗；B 可救人、调停、拒绝要求或交锋，继续产生分岔 |

家人是有目标、能力与联系的独立人物。失踪前后可以改变安排、留下可成立的消息、尝试逃脱或保护他人；旁观者可以作证、误判、离开或求助。系统不能只计算 A 的计划，再把其它人当作自动成功的条件。

若 A 失败或死亡，B 的家人也可能仍因警告而暂避，B 可能追查其同伙或误会后澄清；若尚无人知道经过，就不自动出现全城复仇。后果取决于实际事实与各人所知，不能强制补齐一幕“家属获悉”。

同族、同伴、仁厚、重点角色或原著身份均不赋予 NPC 免死。保护、援助或复仇须由活着的人得知并实际行动；无法挽回的损失可以留在本局历史中。

## 候选贯通样本四：分享丹药、访友与途中改抢

该样本用 C 与 D 检验多动机目标和机会性中断，不预定 C 遇劫，也不将 C 的物品、技能与同伴强度免费公开给 D。

1. C 按炼药规则真实消耗材料、时间与斗气并得到成品；随后想分享部分丹药，同时拜访老友。可赠份额从同一库存划分，已出售、服用或承诺出去的部分不能重复赠送。
2. C 依据本人社交图谱选择朋友与渠道，考虑对方是否在场、是否愿见及自身旅行准备；朋友已离开时可先联系、改期或选择别的安排，不用瞬移完成访友。
3. D 原本在执行猎魔兽计划，只有实际时空相遇且形成可感知信息，才可能注意到 C。知道 C 是炼药者也不代表知道这次炼成了什么、带了多少或愿意怎样分配。
4. 若可见表现、本人获知的说法或线索使 D 怀疑有利可图，D 比较继续猎兽、问询交易、抢劫或回避。人格、已有义务、主观实力判断和当前伤势共同影响选择。
5. D 选择敌对尝试时中断旧活动并承担其机会成本；C、同行者与旁观者按各自能力和所知反应。C 可以交涉、逃离、求助、交锋或失去物品，D 也可能判断失误、重伤或死亡。
6. 事件后 C 可继续拜访、先治疗、改送求助消息或暂缓赠药；D 可恢复猎兽、改向买方、休养或逃离。朋友是否知道失约原因取决于联络，不自动拥有沿途经历。

丹药被夺、损毁或消费后要改变实际归属和剩余量；不能一边在 D 处作为战利品，又按原计划出现在朋友手中。D 追击 C 的期间也不能同步结算已被中断的完整猎兽收益。

D 也可能只看见普通旅人而继续猎兽，C 顺利访友；也可能误判一个没有携药的人，留下冲突与错误信念。这样的分岔是系统允许的结果，不以“样本未演到抢劫”判定失败。

## 玩家选择、链条中断与后续交付边界

玩家拥有个人社交图谱与同样的身体、位置、资源和知情限制，但玩家的主观理解、愤怒与采取何种行动由用户决定。若 B、C、家人或旁观者是玩家角色，系统呈现其可知局势与可行动条件，不代玩家决定报复、赴约、赠药、求和或舍命救人。

既定时间规则下，危险和 NPC 行动可改变玩家处境；强制交还决策和交锋处理仍遵循玩家行动模块。一次威胁、索求或 NPC 自称“你已经答应”不能代替用户接受承诺，更不能后台自动支付赎金或指定玩家感情。

候选贯通依据是能从来源追踪到判断、行动、真实结果和新反应，并在失败、迟到、拒绝、失联、死亡或读档后合理接续。允许链条提前结束、长期潜伏或转成别的冲突；不按是否复刻固定戏剧结果验收。

## 贯通范围与下一步讨论

候选首批应覆盖普通生计与补给、家庭照护、多人合作和有限机会竞争，并让这些活动彼此影响。修炼者需求可以带动采药者、商铺、搬运与向导；价格、供给和组织的详细规则归世界系统模块，不能靠模型为每个人随机派一条无关任务。

优先讨论真实的取舍：人物为长期目标愿意放弃多少短期收益；承诺与亲属责任冲突时如何选择；玩家能看到多少计划与意图；利用和欺骗允许多大损失及何种可察觉线索。方向已经确认，无需重复询问 NPC 是否应主动行动。

后续实施完成依据应落到可复述事实：玩家不参与仍有人工作采购和照护；主动请求可拒绝且世界继续；竞争会失手并改策；合作有实际分工与成本；读档恢复目标、承诺、消息和在途活动。执行与验证范围归后续任务，不将这些候选场景写成已通过。
