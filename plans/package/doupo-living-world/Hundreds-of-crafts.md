## 1．现有基础与缺口

已检查 `local/package-source` 工作树、实际 `docs` 工作树的 Plan 入口、相关方案与 Record，并阅读制作、材料、NPC 生活、交易和前端实现。两个工作树都有大量未提交内容；已提交的 `docs` 分支明显落后于本地文件，因此不能只依据分支快照判断完成度。

| 领域 | 当前实现事实 | 尚未具备的完整能力 |
|---|---|---|
| 三副职 | 独立经验与1–5级技艺；炼丹保留火木、灵魂条件；工具、场地、身体、斗气参与开工判断 | 完整师承、细分专长及职业生涯 |
| 配方与手作 | 配方按职业、形态、材料、处理方式和约分比例识别；每方手工成功五次解锁量产 | 不应把这套计数机械复制给采集、诊疗、勘探等职业 |
| 批量生产 | 逐炉投入、逐炉推进游戏时间，固定一般品质；后续条件不足会停下 | 面向客户的通用生产委托和经营决策 |
| 材料 | 批次、来源、隐藏性质、加工状态及实际转移已有承载 | 完整的批次鉴定证据、职业知识积累和材料市场 |
| NPC | 已有采药、运输交付、基础炼药、药铺加工、采购、治疗和维修行为 | 多职业自主选品、采办、生产、出售与培养专长 |
| 市场 | 有限库存、付款额度、收购上限、报价版本；部分来货有成本与延迟 | 目前交易仍以物品固定价为主，未形成品质与用途驱动的价格 |
| 前端 | 已有场景实物入口、坊案、三种手作、百工册和结果反馈 | 人物服务、需求发现及跨职业生活体验 |

几个特别影响后续设计的事实：

- `startNpcCraft` 目前只主动制作“两份药草 → 基础疗伤散”，不是完整三副职生产代理。
- 人物模板已有织补者、窑工、烧炭匠等背景，但不能据此认定对应产业已经运行。
- 采集／加工待办目前放在单一的 `w.crafting.pending` 中，不能直接让所有 NPC 并发使用。
- 当前“鉴定”会收费、给出判断并增加材料种类知识，但不要求真实鉴定者到场，尚不是鉴宝师服务。
- 商铺资金目前附着在各商品库存行上，尚不能直接等同于一个经营者的完整经营资金。

这些判断主要依据本地游戏源码的 `source/rules/crafting.js`、`craft-world.js`、`life.js`、`engine.js`、`craft-actions.js` 和 `materials.js`，源码不上传文档分支。当前设计入口是 [Plan Index](index.md)，历史验证仅按 [Record](../../../records/package/doupo-living-world.md) 理解，不当作本轮重新验证。

## 2．技艺、职业、专长与身份

建议采用下面的边界：

| 概念 | 含义 | 例子 |
|---|---|---|
| 通用生活技能 | 普通人也能学习的基础能力 | 生火、简单烹调、辨认常见药草、包扎、基础修补 |
| 职业技艺 | 有独立知识、反复决策和专业成果，能够形成长期成长 | 炼丹、医术、采药、勘矿、裁造 |
| 专业分支 | 同一职业内不同的问题与方法 | 采药中的毒草辨治、药圃培育；裁造中的皮甲、行装 |
| 社会身份 | 谁雇用你、你拥有什么责任与权利 | 学徒、店主、佣兵、家族供奉、公会鉴定人 |
| 声誉与资格 | 别人为什么相信你、允许你做什么 | 师承认可、当地口碑、公会认证、履约记录 |

例如，“药铺掌柜”不必本人炼丹最强；他可以擅长识材与经营，雇用炼药师。宗门供奉也不是一棵新职业树，而是附带供货义务、资源配给和关系约束的身份。

**是否值得独立成职业，我建议用三个问题判断：有没有不可替代的判断？能否积累可迁移的知识？别人是否持续需要它的成果？** 三者都不足，就先做生活技能或专业分支。

下面是推荐方向，优先级表示实施顺序，不表示世界中的高低贵贱。

| 方向与定位 | 值得反复参与的核心体验 | 成长、成本与收益 |
|---|---|---|
| **炼丹：保留并深化，首批核心** | 针对使用者的伤势、承受能力和预算配药；在产量、药力、负担间取舍；保留现有控火 | 积累配伍、处理及实际使用反馈；承担珍材、租房、失败成本；收益来自常备药与针对性订单 |
| **炼器：保留并深化，首批核心** | 根据用途选择结构、重量、韧性和导气能力；制造、修理、改装形成不同任务 | 从材料失效和使用反馈积累工艺知识；设备投入较高；持续收益来自工具、维护和定制 |
| **制符：保留，明确应用边界** | 将一次性能力做成便携准备：护行、警戒、应急、局部辅助；纸墨承载与符式匹配 | 积累符路与载体知识；消耗纸墨及斗气；保留现有行笔，避免成为低成本万能斗技替代品 |
| **采药：独立职业，首批新增重点** | 判断采哪部分、何时采、如何处理、是否留种；决定路线和风险，满足买家的用途 | 生境笔记、物候观察、样本比较形成专长；入门成本低，远行成本高；出售药材、处理服务与可靠产地线索 |
| **勘矿：独立职业，逐步扩展** | 从露头、伴生物、样本判断矿脉；在确定性、勘探费用和开采收益间取舍 | 积累地域矿性、试样与工具知识；先勘探后投入；出售矿料、勘查报告，受雇寻找合用材料 |
| **猎业：独立职业，依托现有战斗** | 追踪、选猎物、判断撤退；安全击杀与保全皮、筋、腺体之间取舍 | 物种习性、解剖与路线知识成长；承担补给、伤病、运输成本；提供兽材、向导和清除威胁服务 |
| **医术：独立服务职业，优先级高** | 检查、判断、处置、复诊；区分该用药、固定伤处还是休养 | 积累病例和处置经验；占用诊疗时间、用品与信誉；不要求复制炼丹天赋，也不让丹药包办医疗 |
| **裁造：独立职业，中期重点** | 根据身体、旅途和战斗方式裁制；防护、灵活、重量、气候适应之间取舍 | 学习版型、接缝、皮革与织物处理；中等设备成本；提供衣甲、行装、修补和改制 |
| **膳食与酿造：共享近邻知识，分别成长** | 为旅途、恢复、宴饮准备不同食物；鲜食、耐存、药性与口味取舍；酿造强调配比、容器和熟成时机 | 分别积累专业实践；成本以原料、厨房、储存空间为主；日常客源、队伍供餐及宴席形成需求 |
| **鉴物：独立专业方向** | 用有限检验确定“适不适用、可能有什么风险、值不值得买”，必要时承认不确定 | 积累样本、出处与检验经验；承担耗样、工具和信用成本；服务交易、选材和委托验收 |

这张表中，我最想强调三个区别：

- **采药不是多一个采集成功率。** 专业采药人应能提供“适合今晚炼药的鲜材”或“适合长途保存的处理材”，而不只是比别人多捡两份。
- **猎人不是战斗等级的别名。** 强者可能轻易杀死魔兽，却毁掉客户要的完整皮膜；猎人知道如何取得需要的成果。
- **医者不是低阶炼药师。** 有些伤势需要诊断、固定、清创和持续照料，药物只是其中一种投入。

其他方向作如下取舍：

- **药圃培育**先作为采药的分支。稳定种植常见药材，野外仍承担特殊生境与珍稀资源；不必立即增加一套全作物种田系统。
- **驭兽**为独立成长方向，从照料、行为观察、驮运与协作开始，保留有分量的战斗合作。必须有饲养成本、信任、栖身条件和相应风险；不默认所有魔兽都能收服，也不把高智慧存在统一宠物化。
- **阵法**为器符结合的独立场地工艺专业：勘察、布设、供能、维修，通过空间布局和负载管理形成差异；社会称“阵法师”，不能只是给所有工坊挂一个增益按钮。
- **织布、制皮、造纸、制墨、制陶、制炭**先作为加工专长与 NPC 生计。它们可供玩家学习，但不急于各做一套完整职业等级。
- **商人、镖师、向导、店主**主要是谋生身份与业务方向。议价、辨路、组织护送等能力可以成长，不需要每种社会角色都对应制造系统。

世界风格上，我建议保持炼药的特殊地位；其他行业以斗气、魔兽材料、当地设施与人物生活为基础发展。已有制符保留，但不因此扩张出一整套泛修仙式万能符阵体系。“灵厨”也可以先以药膳、兽材料理和地方饮食呈现，避免人人靠吃饭获得永久修为。

## 3．成长与自由兼修

职业成长建议包含四种成果：

- **技艺熟练**：操作容错、处理能力、稳定性提升。
- **知识积累**：认识生境、病症、材料组合和失败原因。
- **具体掌握**：现有配方成功次数、已学结构，以及未来的病例或勘查经验。
- **社会资本**：师承、客户、供货伙伴、设施使用权和信誉。

这四者不要合并成一条经验值。一个技艺不错但没有客户的工匠，与手艺普通但供货稳定的老师傅，应有不同生活。

入门建议同时保留三条路：

1. **自学**：书籍加低成本实践，保持现有入门书价值。
2. **跟工**：做有真实产出的助工工作，获得工资、观察机会与基础教学。
3. **正式拜师**：获得针对性指导和较深知识，同时承担授课时间、学费或有限义务。

师傅不是无限技能商店。教师只能教自己会的内容；关系改善可以带来愿意纠错、借用工具、引荐客户，而不是凭好感直接给满级。

境界与功法应影响**实际能力**：

- 更高斗气支持更大负载、持续作业与危险地区行动。
- 灵魂能力支持精细感知，但不自动识破全部材料。
- 身法、耐力、控火等已有能力，只有确实影响行动时才提供作用。
- 低境界老匠依靠经验和设施，可以胜过高境界新手；危险产地仍可能需要护送。

兼修采用机会成本，不推荐“最多只能选两门”的硬锁：

- 时间同时用于修炼、谋生、学习、旅行。
- 工具、设施、材料与供货关系需要投资。
- 高阶专长需要有差异的实践，不能靠反复最低阶生产刷满。
- 技能不因几天没用就强制退化，避免职业维护变成打卡。

玩家可以什么都学一点，但长期成为多领域大师应是一段人生。**专精一门、购买其他人的服务，必须是一条完整且舒适的路线。**

长期目标也不应只有升到最高级：留下可靠配方、经营一块药圃、成为一条商路熟悉的医者、拥有稳定客户、培养继承人，都可以成为职业成就。

## 4．NPC 职业与共同规则

NPC 职业应由“能力＋知识＋谋生安排＋实际条件”组成。身份、性格、境界影响选择，而不是直接产生物品。

例如：

| 人物类型 | 主要生活安排 | 容易产生的互动 |
|---|---|---|
| 专职工匠 | 保住客户、设备与稳定收入，预留休息和家事时间 | 接单、采购、维修、收徒、赶工 |
| 兼修修士 | 为突破或远行筹资，阶段性工作 | 临时供货、停接新单、出售储备 |
| 独立采集者 | 根据所知产地、天气／环境条件、风险和行情行动 | 卖材、结伴、出售线索、寻找护卫 |
| 商铺经营者 | 管理现金、库存、采购与雇工 | 收购、代销、订货、压缩滞销品 |
| 家族或宗门供奉 | 获得稳定配给，履行约定服务 | 内部订单、额度之外的私活、引荐与资格 |
| 学徒 | 助工、学习、完成逐渐复杂的任务 | 跟工、代交、共同试作、未来接班 |

初始老匠应明确配置已有专长、熟方与有限资产，作为开局背景；不能全员从零经验起步，也不能伪造一串“已经模拟过”的历史。后续人物则通过实际学习与实践成长。

NPC 的工作选择可沿现有目标与活动系统扩展：

> 发现自身或客户需求 → 查看已知供货和服务 → 比较自己做、购买、委托、替代、延期 → 确认钱物与时间 → 执行 → 使用或交付 → 更新经验、库存和关系。

决策只在库存触及阈值、订单变化、工作结束、受伤、收到消息等时点发生。每次考虑少量可执行方案，不让所有 NPC 扫描全大陆物价。

**制造委托至少要说清六件事：** 谁提供原料、谁付设施费、要什么效果／品质、何时交付、失败怎样分担、余料和成品归谁。

这些条款复用现有委托、托付物、付款与履约能力。不能另建一套“职业任务系统”。NPC 之间也使用相同机制；玩家看到的只是自己获知的那些需求。

关系应由具体行为改变：

- 保密供货让对方愿意介绍珍材渠道。
- 按时交付让商铺愿意下更稳定的订单。
- 擅换材料、迟交或隐瞒缺陷影响对应客户的信任。
- 同行竞争可能围绕房间、材料与客户，也可能变成分工合作。

不能让一次成功交货给全城统一加好感。

## 5．生产联系与持续用途

我建议先围绕下面几条链组织内容：

| 生活需要 | 供应与加工链 | 持续需求与取舍 |
|---|---|---|
| 受伤后继续生活 | 采药／药圃 → 清理、干燥、提取 → 炼药 → 医者选择与处置 | 药物实际消耗；处置占用服务时间；普通药与针对性药各有市场 |
| 安全入山与远行 | 猎业兽材 → 鞣制／纺织 → 裁造行装；勘矿矿料 → 炼器工具；膳酿提供补给 | 路途磨损、补给消耗、用途差异产生需求，不靠每天强制报废 |
| 城镇常备品 | 采集／基础农业供给 → 饮食、药物、纸墨及器具生产 → 商铺与居民 | 按真实消费和库存目标补货，积压则减产 |
| 稳定专业生产 | 矿材、木材、皮革 → 工具／容器／辅助设施 → 工匠生产 | 工具维修、设施维护及扩产；基础生产不强制依赖高级阵法 |
| 珍材与高价交易 | 采猎所得／旧物 → 鉴物与试样 → 指定用途订单或拍卖 | 鉴定减少用途不匹配与信息风险，不把所有隐藏属性公开 |
| 队伍长期活动 | 多类生产者 → 采购、加工、修补、供餐与照料 → 佣兵／探索队 | 活动计划产生一组真实需求，可以分别购买或整包委托 |

同一种材料可以有多个去处，但必须保留取舍。例如一张完整兽皮可以制作护具；裁切后的边料可供修补或某些载体使用，但不能同时再按完整兽皮交付。猎物分解得到的肉、皮、骨也必须来自同一个实际产出额度，不能每条职业链各领一份完整战利品。

几个必要的经济约束：

- **低阶链保持短。** 普通药材、普通工具和基础维修必须有当地可用渠道，不形成“先有高级工具才能制造第一把工具”的死锁。
- **跨职业依赖以增益和选择为主。** 专业加工能提高效果或节省损耗，但普通制作有可行的基础路线。
- **按需求生产。** 常备品设置合理库存目标；昂贵定制品优先接单再做。
- **允许转行、减产和替代。** 没有人买精致护具时，裁缝可以接修补与普通衣物。
- **不靠无限收购消化产能。** 买家有用途、预算和库存上限；品质溢价受其需要及认识约束。
- **不靠全背包腐败维持需求。** 保留现有避免普遍腐败倒计时的方向，只对鲜食等确有意义的条目设置明确保存规则。
- **不要用无限维修惩罚玩家。** 持续价值也可以来自改装、适配、借用、维护服务和新客户。

价格建议逐步改为“物品基础价值＋买家已知品质／适用性＋当地供需与补货成本”，并沿用报价版本。买家也不能读取隐藏真值后精准估价，否则会泄露信息、消灭鉴物玩法。

世界维持基本运转，靠有限开局储备、正常生产、消费降级、替代品和有限外部贸易共同完成。**保留能说明来源、数量、成本和到货时间的外部供给，比把未开放大陆假装全部模拟更合适。** 但外部供给不能自动填平所有珍材短缺。

还要核算货币流动：当前租金等存在系统回收，部分劳动存在明确产币。若逐步转成经营者账户，必须重新评估工资、采购和居民支出，否则可能出现“货物链完整，所有人却越来越没钱”的停摆。

## 6．模拟精度与存档

建议采用三种处理：

| 情况 | 必须精确的部分 | 可以简化的部分 |
|---|---|---|
| 与玩家、争夺资源或关键事件有关 | 身份、位置、时间、材料归属、资金、工具状态、交割、中断结果 | NPC 不必播放操作动画 |
| 普通 NPC 的稳定职业活动 | 开工条件、投入、设施占用、完成时间、产物、收入与经验 | 手作表现由能力、条件和固定结果记录生成 |
| 已建模地区之外的供给 | 边界来源、数量、费用、出发／抵达和实际入库 | 不展开外部每个工匠的生活 |

稳定重复活动可以在既有调度中分段聚合，但必须在下一次缺料、工具失效、租期结束、共享资源竞争、客户到达或其他相关事件之前停下。

例如 NPC 连做三炉药，可以省掉三套界面过程；仍要保证第二炉没有使用已被别人买走的材料，不能越过一次实际受伤事件继续满负荷生产。

存档只保存必要状态：

- 当前活动及已投入材料；
- 到期时间、设施占用和待交付物；
- 稳定的操作结果或随机依据；
- 职业知识、经验、有限订单与关系后果。

已完成普通生产保留紧凑累计与必要来源；违约、事故、重要创制等保留具体事件。不要为所有 NPC 永久保存逐帧手作轨迹。

性能方面，已有长期验证说明大规模长时推进仍有成本，不能直接承诺新增职业后多年瞬间结算。首轮应沿用现有人口与调度，控制每人的活动和订单规模；具体预算在实现时测量。

## 7．前端体验

现有“场景、坊案、册页”的方向值得保留；[当前百工设计](frontend-crafting.md) 已经比职业总面板更接近目标。需要扩展的是人与生活，而不只是再增加几张工作台。

我建议体验沿三条线组织：

- **在场景中发现机会。** 药铺晾架空了，掌柜正在收货；裁缝在修一件破损护具；采药人准备返山。只呈现玩家可观察或已经听说的信息。
- **在人物交往中形成关系。** 认识对方会什么、正在忙什么、愿意接什么、何时可能有空。选择“请他修补这件护具”后，再展开材料、费用和时间。
- **在个人册页中整理自己的生活。** 记录熟方、产地笔记、病例心得、已知工匠和未完成约定；不远程操作所有工坊。

不同职业需要不同的操作中心：

| 职业 | 主要交互 |
|---|---|
| 采药 | 生境观察、标本比较、选取部位与处理方式 |
| 勘矿 | 地形线索、有限试样、选择勘探位置和投入 |
| 猎业 | 足迹与习性判断、路线、战斗后的分解选择 |
| 医术 | 症状与伤处检查、处置顺序、复诊结果 |
| 裁造 | 用途与版型、材料铺排、局部补强 |
| 膳酿 | 菜品用途、备料搭配、保存／熟成安排 |
| 鉴物 | 选择检验方法、证据对照、形成有限结论 |
| 三副职 | 延续现有守火、锻打、行笔，各自反馈 |

并非每项都需要实时小游戏。勘矿的价值可以来自下注前的判断；医术来自证据与处置；酿造来自安排。不能为了交互差异，强迫所有职业加入反应速度考验。

统一的是信息顺序：

> 我想解决什么 → 目前知道什么 → 有哪些选择 → 要付出什么 → 已经发生什么 → 下一步可去哪里。

新手只需要先获得一个清楚的机会。比如作为普通入山者，发现护具需要修补，可以购买成品、请人修、跟工学基础修补；完成后才认识皮料、猎人和裁造专长。即使永远不学裁造，这段体验也完整成立。

视觉继续使用现有场景、人物和器物语言；数字保持清楚，材料与空间承担辨识，不用一排职业徽章代替内容。图形操作同时保留键盘和列表途径，避免拖拽成为唯一操作方式。动效重点落在材料被取用、成果完成、人物回应等变化上。

## 8．未来实施顺序与既有衔接

这里的阶段是实现依赖和验证范围，不是完整体系的取舍清单。所有已列职业、分支和社会生产关系均需在设计阶段明确玩法、成长、供需与边界；后期实现不能成为只保留职业名称而省略设计的理由。

我推荐以下分阶段范围：

| 阶段 | 实际目标 | 完成时应该能看到的结果 |
|---|---|---|
| **第一阶段：职业进入现有生活** | 完善人物专长、现有三副职 NPC 生产、采办与服务委托；衔接采药、医疗、维修 | 玩家不亲自制作，也能获得常备药、工具和服务；NPC 会因需求而生产，并因条件不足而停下 |
| **第二阶段：形成两条完整产业链** | 深化药材—炼药—医疗；接通猎材／矿材—裁造／炼器—使用维护 | 专精采药、猎业或工艺都能谋生；一个行业的变化会影响具体伙伴 |
| **第三阶段：丰富日常生活** | 膳酿、药圃、鉴物、师承与稳定合作 | 职业不只服务战斗，还影响旅行、休养、交往与人生安排 |
| **第四阶段：高阶专业网络** | 有限驯兽、场地阵法、复杂定制和跨地区经营 | 成长带来新的问题和关系，仍受真实条件约束 |

最适合先做深的范围，是乌坦城、青山镇与周边山地，沿用现有人物和场所。其他开放地区维持现有行为与有限贸易，再逐步加入特有行业；不一次把六地区全部改成复杂经济实验。

与现有实现衔接时，我建议明确记录这些变更成本：

| 建议变更 | 原因与影响 | 成本判断 |
|---|---|---|
| 保留配方身份、五次成功、批量一般品质 | 保住现有学习与制作成果 | 低；继续复用 |
| 采集／加工活动改为有明确执行者的待办 | 支持 NPC 并发，避免全局槽位冲突 | 中；涉及状态、调度和恢复 |
| 扩展 NPC 制作选择 | 从单一疗伤散走向按需选方与采办 | 中；复用制作判定，补决策 |
| 需求接入既有委托和托付物 | 支持加工、维修、教学与合作 | 中；避免第二套订单系统 |
| 商铺绑定经营主体与一致资金归属 | 支持真实经营和雇工支付 | 中高；需处理原库存行资金映射 |
| 增加批次证据与专业鉴物服务 | 避免一键鉴定代替职业，也避免知识泄露 | 中；保留基础识材能力，明确专业增量 |
| 改造价格与持续消费 | 让精品、常备品和服务都有真实买家 | 高；需校准，不能只加涨价公式 |

现有采药者与玩家采集还存在流程和节奏差异，接入同一作业规则时要明确说明收益与工时变化，不能借“统一底层”悄悄改掉平衡。新旧存档策略由本次 D142 明确：新局验收，保留旧包与原存档，不并入跨版本迁移。

## 9．各职业的完整玩法与成长路线（已定设计）

以下覆盖完整设计范围。职业不是必须加入的组织，也不是占用一个排他名额。分支是可以逐渐兼得的知识与实践专长，差异由时间、经历、设施和交往形成，不靠一次选择永久封锁其他分支。成长路线描述能力变化，不是所有人必须完成的固定任务链；所有职业均可自学、拜师、购买服务或与别人合作。

三副职沿用原有制作级与成功计数；下列“入门、独当一面、专长、传承”不是新建一条统一等级。新增职业的数值成长及知识项目规模待内容编制，不强行全部套用三副职 1–5 级，更不与原著品阶混同。

### 9.1 炼丹：为具体的人与用途配药

**独特判断。** 先明确用途、对象承受条件、预算与所需数量，再决定配伍和制作。便宜、负担低、便于储备的常备药，与为一位特殊伤者定制的药同样有价值。不能让药效最高成为唯一正确答案。现有短控火保留，不把每炉扩成多阶段诊疗小游戏。

**一次玩法。** 一名行者购买赶路用的恢复药：玩家了解已知身体限制与旅程，比较普通方、低负担改方和更昂贵的浓缩方；选实际批次，处理已知杂质，开炉。交付验收数量与约定的已知效果；客户后续实际使用可以提供反馈，但交易不会无条件泄露其私有伤势。

**成长。** 入门能读懂常备方并稳定制作；独当一面能解释一次废丹并选择合用批次；专长者能在特定用途内提出可验证的替材与配比方案；成熟药师留下经过实践的药方、稳定供货关系或门人。新药反馈来自原料、工艺、实际效果，不能靠模型命名创造功效。分支推荐常备供给、伤药与解毒、修炼辅助、特殊材料配伍，彼此可兼修。

**成本与谋生。** 原料、处理损耗、工具、场地、斗气、工时和失败风险进入成本；精品按客户需要定价，常备药靠稳定周转。医者提供用药需求和病例相关信息，采药人提供适用批次，器匠维护丹炉。NPC 在可支付需求与库存不足时生产；药铺不收货则减产、换用已掌握的产品或接来料加工，不为刷经验烧光生活费。

**失败与边界。** 配伍或操作失败沿原机制真实耗材；尚未入炉的材料不被下一炉预扣。炼丹不能代替全部医疗，不新增无限永久成长药，不让 NPC 代工增加玩家本人的五次手工成功。

### 9.2 炼器：把材料做成适用且可维护的器物

**独特判断。** 以实际用途决定结构：采矿镐需要合适硬度与韧性，行路武器要考虑负担，丹炉需要承载与稳定。通用精品、低价耐用品、可维修器物之间存在需求差异。结构设计放在现有锻打之前，不用追加几十次敲击表达专业性。

**一次玩法。** 客户带来崩口的镐，玩家检查已有损伤和使用目的，选择修补、换头或整件重造。换头保留可用部分，必须扣除新料与工时；若旧结构根本不适合目标矿层，继续修理也不会变成高级镐。诊断收费、修理收费与购买新品分别表达，客户可拒绝。

**成长。** 从工具保养和简单成形，到熟悉某类材料的锻造与淬炼，再到根据使用反馈改良器形，最终形成被同行采用的工艺或长期设施维护业务。分支为工具与生产器具、兵刃、硬质护具、精细构件。能力成长体现为能处理更复杂的约束、知道何时不能修，不是所有旧物一键变新。

**成本与谋生。** 设备资本较高，租台、来料加工可降低入门门槛。矿工、裁造者和场地工艺师提供材料或配件；采集者、猎人、其他工匠持续购买工具与服务。NPC 保留常用维修料，昂贵器物以订单生产为主，未售出的库存不会自动变成收入。

**失败与边界。** 失效发生在相应部件和承载上；材料回收有损耗，拆解所得不超过原投入，不形成反复修理刷经验或拆造套利。现有器物与耐久权威继续使用；新增部件只在确有玩法价值的器物上表示，不给每件普通工具铺十个装备槽。

### 9.3 制符：把有限能力预先准备好

**独特判断。** 在符式、载体与实际用途间匹配：携行应急重便携，警戒重触发条件，恶劣环境重稳定。效果来自已学符式与真实材料，不允许凭自由绘图生成任意能力。现有行笔保持短小，准备决策与操作技艺各有作用。

**一次玩法。** 入山队伍准备夜宿警戒，制符者根据可用符式说明覆盖边界、耗尽方式和可能误报；在成本与稳定之间选纸墨并制作。使用者实际布置、触发或主动启用后消耗对应符物；未触发但有持续耗能的条目须明确，不能默认每张符每日过期。

**成长。** 从学会一种符路、稳定封符，到熟悉不同载体，再到为特定环境选择和组合已支持的功能。分支推荐护行与应急、交锋符具、警戒与生产辅助。成熟成果可以是稳定的一套行旅准备方案，不必都追求最大伤害。

**成本与谋生。** 纸墨、加工材、符笔损耗、斗气与工时；为旅人和队伍提供消耗品，为工坊提供限定用途的辅助符具。NPC 根据已知出行计划、实际消耗与少量常备需求补货，不从全世界隐藏战斗计划预知销量。

**失败与边界。** 符式生产失败与使用条件不满足分开；失效原因可检查。符箓不替代施用者的所有战斗资格、行动代价和承受限制；不自动增加复活、空间保护、远程读心或无限能源。现有警戒符已可提示近处魔兽动静；扩展到场地布设、识别来者和社会感知仍是待实现规则，不把已有基础提示误写为缺失或完整警戒网络。

### 9.4 采药与药圃：经营对生境的认识

**独特判断。** 采集的对象是具体用途的材料，不是地图上的统一收益点。看成熟程度、部位、污染与可达性；选择保留根株、采叶、采实或整株取得。哪些选择适用由物种配置，不能所有植物都套同一菜单。

**一次玩法。** 同一片药地可以满足今晚鲜用，也可以支持数日后的供货。玩家观察已知迹象，决定采多少、带回哪部分、是否现场处理以及是否留下繁育条件；携带量、返程与买家收货时间改变最优选择。常见熟悉采点允许按既定方式直接采，不重复做无意义辨认题。

**成长。** 从认常见种和避免基本损伤，到掌握特定生境的路线与采收方法，再到理解产量、品质、再生和供货的关系。知识记录“何处、何时、什么条件下见过什么”，不是永久精确导航。分支为野采、毒性／特殊材料处理、药圃培育；新地域可迁移基础知识，但不能凭等级知道所有产地。

**药圃的完整玩法。** 选择可栽培种、取得繁育材料、使用合法地块和水土条件；安排种植、必要照料与采收，比较短周期供货和长期培育。多人照料必须占用实际工时。常见基础药可稳定栽培，依赖特殊生境的珍材不能通用田地量产。熟悉作物可以交给雇工按计划照料，只在缺水、供货变更等有意义节点要求介入，不做每日浇水打卡。产量受地块、繁育材料、周期和劳力共同限制；当前未实现的季节／天气不作为凭空补齐的系统前提，先用明确环境条件，未来接入时再说明变化。

**成本与谋生。** 野采资本低但有旅行风险；药圃投入地块、繁育材料与占用时间。向药铺、炼药师、酿造者、医者出售不同处理状态的原料，亦可收取采收或养护服务费。当地买家已满仓时，NPC 停采、处理储备或转向已知有需求的品种，而非无限挖草。

**失败与边界。** 误采、处理失当影响这批产出，不因一次错误灭掉整片生态。过采与恢复关系必须实际配置并可被观察，不能按剧情临时惩罚。勘知、采集许可、土地使用权和物品所有权分别处理，发现资源不等于私有整座山。

### 9.5 勘矿与采炼：先判断值不值得挖

**独特判断。** 勘察解决成分、位置、可采条件和投入回报的不确定性；开采解决工时、工具和运出；选矿、初炼解决得率与用途。三者同属一条知识链，但可以由不同人分工。

**一次玩法。** 锻铺需要耐热材料，玩家先比较已知露头，选择有限试样。试样可能说明“不适合此炉，却适合普通工具”；继续勘探、出售报告、受雇开采或放弃都是有效结果。报告记载证据、地点和调查时间，不能自动保证未来剩余储量。

**成长。** 从识别可采露头与保养镐具，到用伴生物和试样缩小范围，再到估计一个开采项目的材料适用性与可交付量。分支为踏勘、采炼、特殊矿材检验。资深者少走冤路、能解释风险，并非把所有矿点直接透视出来。

**成本与谋生。** 试样有时间与消耗，较大开采需要工具、运力、劳力与许可。可卖原矿、经处理的合用料，也可出售一次勘查服务；普通开采可由受训雇工承担。NPC 以已知订单和现金流决定开采，不在无客户时无限囤积重矿。

**失败与边界。** 找不到合用矿也可形成有效负面证据，但不能无限刷同一块石头领经验。出售线索会带来竞争，不承诺买方独占；独占须另有可执行约定。现有矿点有限储量与周期补充先保留；若改为更真实的枯竭矿层，需作为独立规则变更讨论，不暗改再生。坍塌、掘洞等未承载灾害不先写成必备玩法。

### 9.6 猎业：带着目的进入危险地带

**独特判断。** 确认目标与踪迹，选择出行路线、队伍和取得方式；在生存、安全撤离与材料完整之间取舍。使用既有战斗与魔兽权威，不另做“打猎战斗”。非战斗的观察和取材构成职业差异。

**一次玩法。** 裁造者要一张完整皮膜，猎人根据已知习性找目标，比较风险较低但品质普通的个体与更危险的个体。战斗方式确有材质影响时留下损伤事实；事后选择优先保全皮膜、快速分解还是放弃沉重部分。不能所有部位一并无损入包。

**成长。** 从辨踪、避险与基础解剖，到熟悉某类魔兽的行为、材料和队伍准备，再到主持针对性猎取与带新人安全返程。分支为追踪向导、专业取材、危险清除与捕捉协作。捕捉技能不等于已经驯服；战斗强但取材差与战斗普通但经验深的猎人都可存在。

**成本与谋生。** 补给、护具、工具、伤病与返程时间，必要时分担护卫费用。客户包括裁造者、炼药师、制符者和厨房；没有材料需求时，可受雇带路或清除已存在威胁。NPC 根据真实猎物和共享生态安排活动，不能在后台固定周期发兽皮。

**失败与边界。** 追踪失效、猎物迁移、负伤撤退可以无产物完成一次行动；已经得到的材料按实际携带保留。对未掌握知识的风险只给合理迹象，不全知预警。有限生态与普通兽群恢复归魔兽系统；不为每天维持猎人收入强制生成伤人事件。

### 9.7 医术：让人恢复可生活的能力

**独特判断。** 从可见症状、获准检查和陈述判断处置优先级；治疗即时危险、稳定伤处和长期恢复是不同工作。药物制造与诊疗分工明确。玩法使用游戏身体规则，不扩成现实医疗教学。

**一次玩法。** 两名伤者抵达诊舍，一人需要及时止血，一人旧伤影响行动。玩家可先处理急伤、请助手照料另一人、转诊，或在资源不足时说明只能稳定不能完成治疗。诊疗呈现检查所得与可行选项，不用未经铺垫的知识竞猜逼玩家误治。

**成长。** 从基础包扎和认识必须求助的症状，到独立处理已有身体模型支持的伤类，再到对复杂组合伤势安排连续治疗。分支为外伤、毒伤与药物反应、康复照料。病例价值来自判断与结果差异，不鼓励反复伤害同一个人刷经验；成熟医者可以改善诊舍协作、培养助手或成为商队长期医者。

**成本与谋生。** 检查、耗材、药物、照护空间与工时分开计价；收入可来自诊疗、复诊、组织聘用。药铺与炼丹师按病例需求供药，裁造者或普通作坊提供适用布料，运输者负责真正需要的转送。没有急诊时，NPC 备料、复诊、教学或休息，不为了就业制造伤员。

**失败与边界。** 病人可以拒绝检查或治疗；服务约定保证按约实施，不保证任何病症必愈。知识不足时可承认、稳定或转诊。失约、材料缺失与不可治愈分别说明。具体伤势仍受角色所知限制，诊断报告需授权分享；能力规则不支持的再生、复活不因职业升级开放。

### 9.8 裁造：让穿戴真正适合身体和生活

**独特判断。** 根据使用者、用途与材料形状安排版型、接缝和补强。完整护皮、柔软拼接、重量与活动余量间存在取舍；并非把兽皮放进炼器炉换一个输出名称。

**一次玩法。** 猎人带来一件肩部磨损的护衣，玩家检查可用部分与未来用途，决定局部补强、改成轻便款或重裁。简洁版面呈现有限部位与材料排布；提供可直接采用的版型和键盘选择，不强制像素级拼图。减少废料、保留完整防护与节省时间可产生不同解。

**成长。** 从织补和处理常见皮布，到熟悉版型、接缝与穿戴适配，再到对特定旅途或作战方式定制。分支为衣装与气候适应、皮质护具、行装与专业附件。正式服饰的价值可在礼仪、身份表达和关系场景中体现，但不能换套衣服自动获得官职或组织权限。

**成本与谋生。** 皮布、线、衬材、工作空间和工时；修补与基础衣物提供日常收入，高级护具与定制是低频业务。猎人、织造与制皮者供料，器匠供扣件和必要硬构件；基础布衣不依赖所有工种。NPC 可以从新衣转向修补、改制或组织制装，不只等待玩家换装备。

**失败与边界。** 不合适的版型产生具体不便或返工需求；返工保留已裁切事实。织物不自动拥有炼器效果；新气候适应、行装容量等用途必须先有实际规则，不以文案冒充。既有装备实例和容量限制继续作为权威。

### 9.9 膳食与酿造：同源知识，两种不同工作节奏

推荐保留“膳酿”作为场所与知识的近邻分类，**膳食和酿造分别积累专业实践**。会炒菜不自动精通熟成。下述两条路线均有完整成长，不把酿造降为烹饪的一项长倒计时。

**膳食的独特玩法。** 从食客、用餐时间与携行条件出发安排一餐：即时食用、旅途口粮和恢复期药膳各有要求。选择适用原料与处理方式，控制份量和备餐顺序，避免一味追求最高增益。常规熟悉菜可直接按方案制作，只有新组合或特别宴席需要更多注意，不要求每顿饭重复小游戏。

**膳食成长。** 基础饭食 → 稳定供餐与保存 → 野外／地域食材、药膳或宴席专长 → 一间有熟客的厨房、一支队伍的长期供餐者或可教授的地方手艺。通用做饭仍可满足基础生活；专业者的价值在处理难材、可靠供给、适口与具体用途，不制造“不吃高级菜就不能战斗”的门槛。

**酿造的独特玩法。** 决定原料、初始处理、容器和目标用途；熟成中按有限检查窗口观察气味、澄清等角色可知迹象，选择封存、调整或提前收取。继续熟成可能改变风味和用途，也会占用容器与周转资金；不能等得越久无限变好。过程以游戏时间推进，现实离线不自动熟成。

**酿造成长。** 稳定做成基础饮品 → 认识容器与材料的差异 → 地方风味、药用浸制或耐储饮品专长 → 稳定批次与自己的客源。酿造记录包括处理和熟成策略，但不自动修改既有三副职的配方身份算法；是否使用独立过程参数在第 13 节列作新增设计。

**NPC 闭环与成本。** 客栈实际住客、居民和队伍采购形成供餐量；酿造按有限销售预期与订单占用容器。输入来自普通粮食边界、猎人和采药人；支出包含原料、厨房／容器、必要燃料和劳动。原料并不因写了菜单就入库，宴席也不凭空生成客人。日常饮食、长途补给、馈赠与真实聚会构成不同消费。

**失败与边界。** 对鲜食提供明确保存和转用方案，只对适用条目追踪期限；干粮与普通材料不连带新增全面腐败。过熟、污染或用途不合可能使产物降格，但只有存在规则支持的替代用途才能回收。食物以维持生活、恢复准备和有限用途为主，不叠满永久修为；宴席改善交往机会，不保证任何人的好感。醉酒等效果只在明确加入身体／行为规则后生效。

### 9.10 鉴物：给出有证据、有边界的判断

**独特判断。** 先问委托人需要知道什么：真假、材质、剩余可用程度、适不适合某个用途，还是来源可信度。选择目验、对照、试样或请另一领域专家共同判断；不同方法有信息收益、耗样和时间代价。

**一次玩法。** 买家带来一块号称耐高温的矿料，玩家可以进行低成本筛查，或获准取样做更强检验。结果是“对本次丹炉负载有依据／证据不足／发现不适用迹象”，不是弹出全部后台数值。鉴定费用为实际检查劳动支付，不能通过重复盖章无限抬高售价。

**成长。** 认识一类材料 → 会选择检验方法并表达不确定 → 跨来源对照、识别伪装或委托专业复验 → 形成被某些买家信任的鉴定业务。分支为药材与药物、器物矿材、来源与交易凭据。鉴定者可懂得判断成品却不会制造它；制造经验提供相关知识，但不授予跨领域全知。

**NPC 闭环与成本。** 高价交易、陌生供应商、可疑批次或委托验收产生需求。普通熟悉商品不强制付费鉴定；费用不能超过检验的实际用途还照常有人无脑购买。NPC 依据自己知道的证据和委托范围判断，买家按自己对证据与鉴定者的信任报价，不直接调用隐藏真值。

**失败与边界。** 报告保留对象、方法、时点、结论与置信边界；后续加工或损坏可能使旧报告不再适用。错误判断、蓄意欺骗和未知风险分别处理，信誉只沿实际知情者传播。不得把“高等级鉴宝”变成看破私人库存、人物动机或未来命运。

### 9.11 驭兽：与持续存在的生命共同工作

推荐玩家可成长的独立专业，社会常称驯兽师；完整范围包括照料、行为训练、运输协作与有分量的战斗合作。少量长期伙伴的定位沿 D139；它的核心成果是某个个体与人的可靠协作，不是生产可堆叠的兽宠道具。

**一次玩法。** 商队需要稳定的驮运伙伴，驭兽者检查可接触个体的身体、警惕、食性和过往训练；决定是否适合接单。建立熟悉、练习有限指令、适应负载和交接给新照料者各需实际时间。能跟随驭兽者，不代表交给陌生买家就立刻听从。

**成长。** 从安全接近和日常照料，到理解某类魔兽的压力信号与稳定行为，再到特定个体的驮运、营地协作或战斗配合。分支为照料与伤后恢复、驮运协作、野外救助与行为训练、战斗合作。知识可迁移，个体信任不能批量复制；同一位大师也可能不被另一头个体接受。

**投入与收入。** 合法取得的接触或照料关系、饲料、栖身空间、器具、医治和持续工时；收入来自照料、寄养、训练服务、合约内运输协作，不只出售活物。NPC 先考虑现有照料容量和身体条件，不能无上限收养；驮运需求来自真实货物和路线，空载绕城不生成利润。

**失败与边界。** 疲劳、惊惧、伤势或不合适环境会降低协作，解决办法是调整条件、休息或终止训练，不只是加钱。失败可表现为进度停滞或拒绝，而非逢失败必狂暴。首次捕获要依既有战斗、受控状态与个体权威补足真实规则，不能见面点击收服。具备充分智慧与交流能力的存在按人物关系和自愿合作处理，不自动出售或套宠物模板。

**长期与取舍。** 普通人可以购买运输服务，不必养兽；主人可付费寄养，但要有实际照料者和容量。繁育属于后续完整设计中的专长：必须有真实亲本、适用物种、生长期、场地与照料，不能在未承载前当作默认供给。首轮实现可以后置繁育，但不能用后台无来源刷新替代其事实。

### 9.12 阵法与场地工艺：把一个地方改造成可持续工作的环境

定位为**可独立成长与接项目的专业方向**，社会称“阵法师”，知识上连接炼器、制符与场所；不要求玩家先把两门职业练满。基础布设使用购买的标准构件即可入门，高阶可自行制作或与工匠合作；能力限定为本节及第 19.15 节的有界场地工艺。

**独特判断。** 观察场所的范围、障碍、供能、负载和维护条件，选择节点位置及连接；覆盖范围、能耗、稳定和可修复性相互制约。与制符的区别是持续工作的空间配置，与炼器的区别是安装现场及运行状态。

**一次玩法。** 工坊想改善炉旁的稳定条件，玩家勘察后提出小范围低耗布局或更大范围高耗布局，列出真实构件和维护方式。通过有限节点布置与试运行找出瓶颈，验收对应场地效果；客户根据收益和维护费用决定是否采用。基础工坊仍能不依赖阵法生产。

**成长。** 看懂简单布设并维护 → 安装已学标准布局 → 针对场地调整 → 主持有清晰上限的复合工程。分支为生产环境、营地警戒、有限防护与故障诊断。积累的是场地案例与失效经验，不是记忆一张图后任何地形都完美适用。

**NPC 闭环与成本。** 工坊停机损失、队伍驻留计划或已有防护需求触发项目；器匠供构件、制符者供适用载体、其他工匠承接普通安装。勘察、制作、安装、试运行和维护分别占用实际人员时间，费用由项目方支付。NPC 比较租用、修旧和新建，不为每座房子无限升级。

**失败与边界。** 负载超出时停机、降效或耗材，具体失效模式由条目决定，不默认爆炸。供能必须来自定义过的消耗品、设备或有容量的供能设施，不能随便写“吸收天地能量”绕过成本；若增加新能源材料须先说明必要性。方案不得制造无限增益循环、通用秘境免死、无限储物、传送或凭空提高资源再生。

### 9.13 基础百工与社会身份：完整生活不能只服务冒险者

织造、制皮、造纸、制墨、制陶、制炭、普通木作、粮食生产和运输都有生产位置，但不一律建设独立职业菜单。它们以可学习的加工专长、设施与明确产出表达；玩家可以靠其中一项谋生，也可雇人完成。某一方向以后满足独特判断、知识积累和持续需求三项标准，才讨论提升为完整职业。

| 社会工作 | 完整生产职责 | 玩家价值及限制 |
| --- | --- | --- |
| 织造、制皮 | 把真实纤维／皮材变为适用批次，选择柔软、强韧、得率 | 为裁造或载体供料；不是对原料无限提纯升级 |
| 造纸、制墨 | 按用途处理纸基、胶料和色料，保留原批次性质 | 为制符、书写及凭据供料；基础写字不必消耗昂贵符纸 |
| 制陶、木作 | 容器、普通家具、储存与设施修补 | 服务酿造、药铺和家庭；普通货物可采用批次，真正影响密封或容量时才加状态 |
| 制炭与燃料处理 | 有来源的原料经过工时处理为适用燃料 | 支持明确需要燃料的生产；既有斗气耗能不自动被新燃料税叠加 |
| 粮食与普通畜养 | 在有容量的生产设施中投入劳力、种源／饲料和周期 | 支撑居民生活；尚未细化的外部供给明确作为边界，不假装本地无投入闭环 |
| 运输、仓储 | 承运、保管实际交付物，约定运费、签收和风险 | 可以专业谋生；不复制运输背包、不无源补丢货，不要求每份普通货物有完整车队动画 |

商人负责选择买卖与经营，不拥有无限顾客；向导出售所知路线与陪同劳动，不传送客户；镖师提供既有战斗能力和行程占用，不承诺保送；店主、供奉、学徒、领工是职责和关系，不是与技艺重复的等级条。

普通居民对饭食、衣物、容器、照护和住宿的需求也有预算、使用周期与生活事件。耐用品不因开启职业生态而全部改成每日损耗；人口、迁居、破损和已有使用规则产生更换需求。供给成熟后允许产业平稳和工匠休闲，不能用强制灾难或每日报废维持所谓活跃世界。

## 10．共同成长、入门与职业人生（已定设计）

### 10.1 共同承载，不统一成同一种经验劳动

| 成长事实 | 玩家如何理解 | 取得方式 | 不产生的权利 |
| --- | --- | --- | --- |
| 技艺熟练 | 能稳定处理什么难度的工作 | 有实际投入、适当挑战的实践和教学 | 不等于认证，不免材料和设备条件 |
| 知识与认识 | 看懂了哪些材料、症状、习性或工艺 | 书籍、实际观察、试样、教师解释、验证过的反馈 | 不自动公开全部隐藏真值 |
| 专项掌握 | 哪些方、器形、病例类型、布局已经熟悉 | 对应实际过程与结果 | 不把同一计数用于所有职业 |
| 社会关系与记录 | 谁愿意合作、曾完成哪些作品 | 履约、共同实践、传授与传播 | 不自动获得全城好感、全部商业信息或场地权限 |

沿用既有人物技能、职业经验、知识和关系权威扩展，先明确哪些事实确实需要保存，再决定字段；不另加四套相互竞争的总分。玩家通常看到能做的事、熟悉的领域和真实记录，不必面对四根经验条。

成长体现为信息质量、可选方法、容错、适用范围和组织工作的能力。降低资源消耗只能来自有依据的处理、少返工等效果，不能加一个高等级全物品凭空翻倍被动。常规劳动有收入价值，可以不给高阶成长；失败有观察或新证据时可留下知识，不按失败次数自动升级。

### 10.2 三条入门方式及真实人物关系

- **自学：** 买得起的基础书与简单工具，能完成低风险工作；普通饭食、基础识材等不因没有正式职业资格而封锁。书籍教内容，实践验证判断，不读一本书就自动成为资深专家。
- **跟工：** 与实际工匠约定一次可完成的助工，说明工钱、材料归属、学习机会与时间。协助清理、选料等有独立成果，但不把主操作者的手工成功复制给每个围观者。
- **拜师：** 先通过相处、跟工或作品认识，再约定授课内容与方式。师傅有自己的生产和生活安排，双方可改期或退出；已经提供的教学与已发生的费用不回滚。老师的弱项可以引荐他人，不要求一位师傅包办所有职业。

不把全职业都变成同一套“交三件材料—送礼刷好感—考试”的入门任务。采药师可带一次路线，医者可让学徒参与检查与复诊，匠人可共同分析坏工具，酿造者可开放一批酒的有限观察。玩家在行动中得到足够指导，不先背一页专业术语。

### 10.3 专长、作品与认证

专长来自连续相关实践和知识理解，可以形成称呼或人物评价，不要求互斥天赋点。具体作品包括一张稳定配方、一套耐用器形、一份可靠产地记录、一段持续照料、一批地方风味饮品或一个实际运行的场地工程。它们是原规则对象的引用和成果，不另建“成就物品”复制物资。

高级能力需要能力、知识和生产条件，不要求所有人先通过社会声望门槛才能尝试；现有越级制作规则继续成立。公会认证可以用于特定岗位、客户信任或设施准入，只在有具体社会用途时加入；不能用新认证悄悄取代已有五次成功的批量资格。

独行者可以长期自学、卖给陌生买家或只为自己制作。社会关系能提供便利、合作与职业人生，但不成为每项专业操作的强制前置。客户口碑与行业认可允许并存，也允许本人不追求公开名声。

### 10.4 能力、地域与组织如何改变路径

- 炼丹保留既有天赋条件；普通医术、采药、裁造等不复制该条件。功法只在已定义的控火、感知、行动或承载效果上帮助职业，不因功法名字相近就额外加成。
- 境界影响实际可达性、能源和危险承担；专业知识不能通过战斗经验自动填满。高级修士可租用服务解决自己不熟悉的工作。
- 推荐乌坦城侧重普通消费、客户与学徒机会；青山镇侧重采猎、野外医疗和整备；山地侧重资源认识与共享竞争；黑岩城侧重专业工坊、复验与较复杂订单；石漠城及沙漠外缘侧重耐存补给、行装、路线和适用材料。以上是针对现有地域的原创玩法分工，不是原著地理定论。
- 各地有基础替代服务，不用地域分工逼玩家为初级维修跨城；高阶稀有能力可以形成旅行和引荐理由。
- 组织供奉通过工资／配给换取明确的服务时段和职责，不可同时无限接私活。供货许可、师承与职位分别取得；成员身份不自动授权使用所有组织库存。

### 10.5 长期经营、传承与退出

高阶职业生活可以是留名作品、固定供货、培养学徒、维护一处设施或长期随队，不强迫最终开店。经营者需要委托、雇工和停业安排，让玩家可以离开城镇修炼；能离开多久取决于真实库存、劳动安排与约定，不是离线奖励。

技能不按日衰退；市场、客户和材料会变化，但旧熟方仍保留。选择关闭药圃、暂停接单或转行时，处理现有订单、雇工约定、存放物和可退投入，不清空人物过去的知识与关系。继任与传承必须有实际接班人和取得权限，师傅死亡不会自动把全部知识转入玩家脑中。

## 11．NPC 从需求到履约的完整循环（已定设计）

### 11.1 需求必须来自世界事实

| 需求来源 | 触发依据 | 可能行动 | 需求结束的依据 |
| --- | --- | --- | --- |
| 维持生活 | 实际口粮、健康、已有生活安排 | 购买、做工、使用储备、求助 | 取得并使用足够补给，或计划改变 |
| 恢复能力 | 身体伤势、损坏器具、需要的设施不可用 | 治疗、修理、替换、暂缓活动 | 能力恢复或接受替代方案 |
| 补充常备库存 | 近期真实消耗和库存目标 | 买入或排入有限生产 | 现货加可信在途达到目标 |
| 已承诺工作 | 生效委托、供货期次、授课约定 | 采办、生产、找协作者、改约 | 实际交割、正式取消或违约清算 |
| 个人计划 | 已知出行、修炼、家庭或组织目标 | 整备、储蓄、预订服务 | 计划完成、撤销或失效 |
| 学习与探索 | 有知识目标、学习资源和可支配时间 | 求教、试作、检验 | 得到相关认识或决定放弃 |

每个需求关联已有目标、委托或实际物资缺口，不能被公告、个人订单和商铺采购重复计算三次。已经委托在途的两份材料不能再被同一需求无限下单；允许明确的安全储备，但不无限扩大目标。

### 11.2 决策使用本人所知和可以负担的选择

先处理即时生命／能力限制，再比较到期承诺、基本生计、既定个人目标和可选收益；这是候选顺序，性格、关系与事实可影响取舍，不是所有人相同的强制行动表。谨慎者多备补给，爱惜名声者避免超额接单，有照护责任者可能放弃远行，急需突破者可能暂时停止营业。

每次只从本人熟悉的地点、联系人和已收到的机会中选少量方案，比较：是否可执行、是否付得起、能否按时、预计收入能否覆盖投入，以及本人愿不愿承担风险。无可行方案可休息、普通劳动、求助、减少非必要消费或等候实际消息；不允许永远重试同一个缺料工单。

报价、库存和工匠位置有时效。NPC 跑到店里发现货已卖完可以改变计划，不能在出发前靠全局真值确保永不扑空；高成本出行可以先付费联系或使用已有通信能力。规划语言由模型表达也不能越过规则可执行边界，不需要为每次常备补货调用模型。

### 11.3 一份工作的权利与资金流

推荐沿已有委托与物品托付表示以下业务状态：询价／联系 → 双方接受 → 条件齐备 → 实际开工 → 产出或服务结束 → 交付／验收 → 清算。未接受的询价不锁住全城工具和资金。普通现货买卖继续直接交易，不强制套完整委托流程。

接单至少确定成果、材料来源、工时与期限、价格或上限、失败责任、物品归属。原料可以由客户提供，也可由工匠报价采购；不是客户允许代买就能无限超预算。来料托管、工匠自有料和组织物资保持原所有权和用途权限。

制造开工沿现有规则扣除真正投入的材料并保存工单中的投入状态；不能在完成时再次扣一遍。尚未开始的炉次不视为已消耗，可在已接受委托中预留但不能被另卖。采集共享存量的占用与结算采用同一资源权威，不能玩家在完成扣量、NPC 另开一套每日产量绕过竞争；具体预留策略须与现有采集规则一起落实。

商铺是有所有者或经营组织的库存，柜台上的钱不是店员的私人资产。若统一经营账户，原来各库存行金额只能迁入一次，不能账户保留一份、商品行又保留一份可花现金。工资、设施租金、代理费分别支付实际收款者；确属未模拟外部服务的费用保留明确边界，不假装进入不存在的人物账户。

**来料试作与保证交付分开。** 试作约定可以支付劳动费并由客户承担事先知情的材料风险；保证交付则由工匠计入返工风险，不能失败后临时改口。验收依据事先可判定的数量、品质和用途，不要求客户获得隐藏数值才能维权。无力赔付形成现有规则能承载的欠款、追偿或重议，不凭空补足余额。

### 11.4 劳动力、设施与被动过程分别占用

一个人同一时段不能既操作丹炉、出门采药又教课。生产者、助工和教师分别拥有真实活动；团队工单共享成果而不复制每人一份产出。

新增酿造、药圃等允许明确区分主动劳动和被动过程：投料／种植占用人物，熟成／生长占用容器或地块，必要检查和采收再次占用人物。被动期间可以外出，但已经接受的检查与交付期限仍存在。这个区分不自动把现有炼丹、炼器改成无人值守。

设施容量按实际工位、容器或地块定义。公用设备必须能容纳真实使用者；多人共用空间不等于可以同时占用唯一炉台。组织雇工是在既有人口内分配工作，不能为了产量额外生成没有身份、生活和存档的隐藏劳动力。

### 11.5 NPC 如何学习、研究与成为具体人物

普通从业者主要积累常做业务的经验，有足够钱粮与空闲才选择学习；研究不挤掉必须履行的每一份订单。教师的教学内容和空闲时段有限，学徒通过实际工序参与成长。初始熟练职业配置可以声明已有知识与熟方，属于背景能力，不计作玩家或其他人的实践。

NPC 无需操纵界面小游戏，但其工艺表现要基于同一能力与工具条件；难度差、材料风险和身体变化应真正参与结果。三副职的五次进度来自该人物亲自完成的有效操作实例或明确初始化掌握，不能把自动批量结果反过来伪装成五次手工，也不能所有 NPC 永久使用无条件合格分数。保存过程结果后不随观察重抽。

每位重要职业人物只需少量可感知差异：最熟悉的业务、看重的交付条件、常合作的人、愿意教的内容及当前生活目标。熟悉便宜耐用品的匠人不必被“全面更强的高级匠人”淘汰，高级者可能收费更高、工期更长、无意接小修；这是机会成本与偏好，不是人为禁止接低级活。

### 11.6 持续模拟与记录边界

活动开始、阶段检查、完成、资源或约定变化时唤醒相关行动者；先扩展既有调度，是否增加依赖索引由真实成本决定，不预建一套并行经济引擎。远处的具名职业人物保留同样的库存和生活事实，不随玩家靠近才生成产出。

可以合并没有干扰的稳定工作片段，但跨越共享库存变化、伤病、到期约定、迁移、死亡和容量边界时必须切开；相同时间的竞争使用现有稳定顺序与冲突处理，不重复使用旧库存。一次长等待与多次短等待应保留一致的物质和关键因果结果，不能因为推进按钮按法不同就多产一批货。

个人只保存当前所需工单和紧凑经验，普通历史归原记录机制。已完成委托的来源、交付凭据与重要关系后果继续可查，不能为了缩短热列表删掉债务或所有权依据。容量满时停止新承诺并清楚说明，不静默丢弃材料或把未完成订单算完成。

## 12．跨职业供需闭环与扰动样例（已定设计）

下列场景是用于推敲设计的规则样例，不是已经运行的测试，也不是预写必然剧情。数量只用于说明守恒；最终价格、时长和产能依既有内容与后续校准。完整体系包含六类消费：维持生活、恢复能力、活动准备、知识服务、社交表达、组织／设施运行。

### 12.1 药铺、诊舍与采药人的常备循环

诊舍需要四份基础药，柜台只有一份，且现有订单和可信在途没有覆盖另外三份。掌柜决定补三份，按现有基础示例每份投入两份药草，共需六份；组织现有四份，因此只采购缺少的两份。未接受供货的询问不当作在途库存。

一位采药人持有两份合用药草，可以直接交付；若需要去采，就实际前往有限生境、花工时取得并返程。掌柜与生产者约定工资或加工费，核对六份药草、斗气、工位和足够租期；三个炉次按真实状态逐次完成。成功三炉后库存由一份增为四份；诊舍付钱取得需要的药，实际治疗时才消耗。药卖出和药被使用不是同一次物质事件。

资金可行条件是：药铺可动用资金覆盖缺料采购、加工、设施与必要储备，且买家有钱或有生效保障。客户销售收入需要覆盖可持续成本，长期低于成本就应重议价格、改变供应或由明确的组织预算承担，不能拿“NPC 会生产”替代经济可行性。

若第二炉因真实变化失败，只有已完成成果可交付，失败材料按原规则损失；第三炉是否继续取决于剩余条件与合同。诊舍可以接受部分交货、换合用药或转诊。玩家可以卖药、卖材、接加工、担任医者、帮助恢复供货，也可以完全不介入；其他 NPC 仍会按自身条件尝试解决。

### 12.2 猎业、裁造、饮食与整备循环

一支已有出行计划的队伍需要修补护具和准备口粮。猎人根据实际订单取得一头真实猎物，尸体只登记一次可取得材料；完整皮、可食部分、筋骨的取得来自适用部位与分解方式，先取得的部分会改变余下可取物。

制皮者购买或受托处理皮，裁造者按旧护具状态决定局部补片或重制；适合食用的部分由厨房按订单加工，不能因“魔兽肉”名字直接让所有种类可食。实际劳动者分别收取款项，参与者的同一工作时间不重复出售。队伍使用补给并承担旅途消耗，返程后的实际损伤再产生维修需求。

没有猎物时，裁造者可用已有库存或合用织物，厨房可用普通粮食；基础生活不因此同时断供。没有订单时，猎人可减少捕猎、转向向导工作或休息。玩家大量购买完整皮会影响其他客户，但不会因为打开商店就强制触发价格暴涨与抢劫事件。

### 12.3 勘矿、炼器与工坊服务循环

工坊实际设备不足或损坏，先委托检查；器匠区分可修、需换构件和需整件替换。需要特定矿性时，请勘矿者调查或向已有供应商采购；双方不是强制串联，库存中有合用料就直接使用。

勘矿者取得样本与有限报告，出资者根据运费、工具、产量和自身需求决定是否开采。材料入库后器匠制造或维修，旧件可以有损回收。场地工艺师在确有收益时安装辅助布设，后续维护消耗实际材料和服务时间；没有阵法的普通工坊仍可运行。

如果新设备减少返工或扩大承载，收益来自真实生产改善，不额外凭空发一笔“效率金币”。项目没有订单收益时可以取消或缩小；已消耗的勘察和制造投入按约承担，未开始部分不继续扣款。

### 12.4 膳酿、种植、容器与交往循环

客栈根据已有住客和近期实际消费安排基础饭食，提前接受宴席或队伍订单时才扩大采购。种植者、粮商和猎人提供适用原料，普通陶工提供容器；酿造者按现有容器容量安排批次，不把一份原料同时用于现做饭食和酿造。

完成的食品入真实库存，熟成品在到期并满足条件后才可交付；未被购买的不变现。取消宴席会减少需求，经营者可按条目允许的方式保存、转售或承担损失。社交效果通过实际到场、交谈和馈赠发生，不把“办席”兑换成全员固定好感。

普通居民持续吃饭提供底层需求，精品饮品与宴席是可选消费；低收入居民使用普通食物，不能为高级厨师的销路被迫破产。玩家闭关期间客栈继续服务其他人，自己委托的有限供餐仍需资金、产能和配送条件。

### 12.5 驭兽、商路与照护循环

真实商货超过当前运力或需要特定协作能力，承运者租用、雇用或与驭兽者合作；支付费用覆盖照料、饲料、器具和劳力，不仅支付一次购买价。接受运输的个体不能同时参与别处战斗或训练。

驭兽者从厨房、普通供给或适用生产者采购真实饲料，伤病向有能力者求助；不能把所有物种喂同一份“宠物粮”。抵达后按实际剩余货物签收，疲劳个体休息，下一趟计划相应改变。运力不足时可以分批、改期或使用可用替代运输，不自动生成新坐骑。

玩家可提供饲养、训练、护送、货物或资金中的一项，不需要同时经营全部环节。合作伙伴离开、死亡或关系恶化时，已有财产与合同仍按原权威处理，不用删除整个职业模块解决问题。

### 12.6 鉴物、定制与信任循环

陌生供应商出售珍材，买家可先做低成本检查，再为高价值用途请求鉴物者和对应工匠共同判断。明确谁批准耗样、谁支付费用；取得的报告能减少不确定，但不保证所有未来用途。

后续制作结果提供新证据：与报告范围一致则增加相关客户信任，发现报告外的问题不自动认定欺骗；已有证据却故意隐瞒才进入欺诈争议。复验和争议沿现有委托、所知与关系处理，不凭一次随机判定让全城拉黑某人。

信誉提高会带来更愿意合作的客户或更重要委托，也会增加责任；不能靠互相低价鉴定、反复转售同一报告无限创造价值。陌生玩家仍可选择便宜的基础交易，不强制每件商品走鉴定公证。

### 12.7 无玩家参与、短缺与过剩

| 扰动 | NPC 可采取的实际行为 | 保留的后果 | 不使用的兜底 |
| --- | --- | --- | --- |
| 采点暂时耗尽 | 等恢复、换已知地点、采购替代材、缩小订单 | 工期或收入改变 | 为每名采集者各刷新一份 |
| 师傅受伤／离开 | 停接新单、让有能力的学徒做部分业务、寻找同行 | 产能下降，客户选择改变 | 标签仍在便照常满产 |
| 普通商品积压 | 减产、降价、停止采购、改接服务 | 工人有更多空闲或需另谋生计 | 商店无限收购销毁库存 |
| 钱紧 | 使用储备、收取合理订金、普通劳动、重议或暂停非必要活动 | 订单和生活安排调整 | 无限制贷款或每期补满现金 |
| 商路延误 | 消耗缓冲库存、改道、分批、替代、延期 | 现货不足与价格变化 | 把在途当现货卖出 |
| 玩家垄断一类货 | 寻找替代供应、按需求改变报价、减少非必要购买 | 局部竞争、真实机会 | 全世界立刻知道并联手惩罚 |

基础生计可通过既有普通劳动和有限外部来货维持，但必须标明其产出边界、劳动条件、数量和货币来源。不能一边保留抽象粮食劳动产出，一边让新农业再为同一劳动产出第二份粮食。外部需求和供给可作为有限边界，不能无限收购本地产品以掩盖供需失衡。

经营是否可持续要同时看资源再生、净消费、劳动时间和现金回流。初始化库存只是缓冲，不证明长期闭环。未来实现按实际发现的问题校准，不承诺所有企业永不失败；基本可玩性通过多条现实可行的替代路径保障，不能保证每个玩家随时买到任何珍品。

正式实现时，原领域模块按职责同步实际接入的已定变化，并链接本文件的职业内容；若某条详细规则改归另一领域，明确转移其权威，不能两处各维护一个版本。本文件作为 D142 已定扩展入口，不要求先复制整份设计到所有旧模块才开工。实施前按实际源码重新核对本节，不拿本轮静态快照覆盖之后已完成的开发。

## 14．定稿结论与实施校准

完整方案按 D138–D142 确认。职业边界、少量长期伙伴、三位原创人物、差异操作、学习反馈、服务验收，以及第 24–28 节长期经济与单职业生计均纳入完整范围；新物种、阵法尺度和新局策略以第 29 节为准。

设计讨论结束，价格、时长、产量、有限人物初始化、具体产品编制及界面布局按已定目标实施校准，不再逐项审批。仅当实际证据要求改变核心体验、角色设定、资源规则或完整范围时，说明原因、影响和可行替代再讨论。

第 29.5 节提供新对话开工入口。当前定稿不写代码、不创建交接快照；开工后阶段组织依赖与验证，不成为自动停止点，也不允许将较后职业移出范围后宣称完整交付。

### 15.7 驭兽伙伴的内容边界

当前十个物种都是已有野外／秘境生态与战斗内容；已有物种不等于已支持驯养。脊灰狼、岩背豕、崖风隼可分别作为追踪协作、地面负载与空中近域观察的候选，但必须有个体适配与实际训练，不能所有同种个体自动接受同一种用途。岩背豕是否适合稳定商运须按其性情和能力设计，不为省一个物种把领地性魔兽直接当温顺牲口。

陶栖开局配置少量长期照料的实际个体，其中一名稳定驮运伙伴采用新增原创低阶“砂行驮兽”（暂名），按 D142 纳入内容。它擅长承载、稳定行路和保护性应对，不提供免费提速、无限容量或高阶输出。物种与个体尚待实现，不冒称已有兽种或原著生物；普通运输仍有独立生存空间，不能把已接受但未实现的物种当作当前存档的供给。

战斗协作推荐从可靠的退回、掩护、牵制和有限追击中选择适合该个体的少量动作，使用既有同伴意图、行动与战斗结算承载。它的价值来自实际改变局势，而不是额外叠一整套无代价行动；拒绝、疲劳、受伤和撤退也保留。不得用笼中批量召唤、战后自动复活或把死亡伙伴换成同名新品抹去长期关系。

该网络让舒雁的普通衣物业务、杜衡的工具业务和苏晚禾的药物业务各有直接客户，又能在合适时合作。职业独立生存不要求孤立于社会，但必须有不依赖另一门高级职业的基础收入渠道。

### 17.6 与既有任务内容合流

| 现有内容基础 | 职业生态如何接入 | 不改变的边界 |
| --- | --- | --- |
| QC01、QC07 苏晚禾的缺料与炼药 | 同一实际库存缺口可转成采购、来料加工或生产排班 | 不能 NPC 已补齐后仍循环发同一缺口奖励；托付与已做工时仍须清算 |
| QC02 两处缺药 | 医疗、常备生产与资金压力影响双方真实选择 | 一份材料不能给两边重复计入，不能把取舍预写为某人必恶意 |
| QC08、QC15 维修与损坏争议 | 铁承提供真实诊断，客户选择修关键件或复验 | 接单不制造损坏，证词不能直接没收第三方财产 |
| QC03、QC22 包裹和收件人 | 容青穗、宋轻羽的职业交接使用相同托付物 | 职业运输不建立另一份货物，不自动签收失联者的包裹 |
| QC09 琳菲的本人练习 | 教师、同学与玩家协作但实践归各人 | 雪魅记录需授权，别人操作不增加琳菲或玩家的个人成功数 |

| QC16、QC17、QC23 路线与出行 | 向导、商人、补给者和驭兽者可形成实际准备链 | 报告只含亲见或合法获知内容，仍可拒绝、延期与改计划 |

这些是现有种子的职业化内容和共同需求来源，不是第二套每天重复的职业任务。普通订单和公开竞争继续沿各自现有规则；NPC 自行解决问题影响需求，但不把玩家已完成的受雇劳动无偿抹去。

### 17.7 没有玩家的一个普通推进窗口

候选样例：何照川有已接受的出行安排，先核对自己知道的补给与损伤；铁承接受一件真实维修，连芷接受有限口粮订单，宁素只在需要且有接诊条件时检查。唐汀根据实际常备药消耗采购，薄尧考虑这次交货能否覆盖返程和生活；陆青可能选择保留材料修炼。玩家未出现，不影响这些人联系、付款、工作或拒绝。

这不是每次等待都必须重演的脚本。何照川取消行程，其他尚未接受的需求自然结束；铁承已经完成的维修仍应付费；连芷已经投入的食物按约处理。平静时没人负伤，医者可以备料或学习，不生成假病人维持收入。经营收益与收缩通过真实业务表现，不靠旁白直接宣称全城繁荣。

## 18．玩家怎样认识这些人并形成自己的职业路线

以下是可由条件触发的体验候选，不是新增必做主线或未接任务就不运行的世界。每个机会应允许购买现成服务、亲自参与、介绍他人或不管；专业路线从这些选择逐渐展开。

### 18.1 杜衡与舒雁：一次修理认识两种手艺

玩家因自己的护具真实磨损来询价。杜衡检查后若判断主要问题属于软衬／接缝，可说明自己能处理什么、舒雁可能更合适；只在角色知道对方且愿意引荐时提供联系。玩家可以接受普通修理、当面请舒雁改制、自己学基础修补，或暂时不处理。

舒雁先问用途，再展示原物哪些部分能留、需要哪些料、要多久。玩家只想赶路就选合用的现成方案；愿意学则在她有时间时参与有限工序。完成反馈落到这件原物与实际费用，随后还会遇到她给普通居民做衣物、为家庭安排时间。关系因真实合作发展，不需要先刷几轮送礼才允许看懂报价。

长期可以从小修、同行、共同定制发展到互相信任的协作者；杜衡希望给学徒留铺面是个人目标，不保证最终送给玩家。舒雁也不因成为合作对象就放弃自己的经营与家庭选择。

### 18.2 苏家药铺与宁素：原料、制作和治疗各有位置

苏晚禾真实缺料或需要空出照护时间时，玩家可以卖药草、接基础炼药、推荐有能力的合作者；材料与成果依原委托结算。苏守义可在愿意且身体允许时解释某批料为什么适合或不适合当前用途。

父亲旧伤若仍未解决，苏晚禾已有对宁素的医者联系可成为求医渠道，但宁素必须实际能接诊，患者需真正抵达或安排医者到场。玩家制作再多疗伤散也不能把交药等同于治好骨折。这个过程让三种不同成就成立：可靠供货、做好一炉药、完成照护／治疗协作，不要求一个人全学会。

苏晚禾的成长也可来自玩家之外的教学、生产与合作；关系亲密与职业成功分别演化，不把救父亲作为交易亲密关系的筹码。

### 18.3 一次矿样委托：没有找到宝矿也能体现专业

铁承收到真实器物项目，现存料不合适；在岳岑已实装且双方相识的前提下，他可以委托调查或建议玩家带样询问。玩家跟随实际调查、取有限试样，再决定是否扩大勘探或找祝铁生复验。

得到“不适合这个项目”的可靠报告仍是勘查服务成果；若承诺的是交付矿料，则未取得矿料不能领全部供货款。玩家可先靠小范围调查与普通采炼谋生，逐渐形成地域认识，再承担昂贵项目。价格高并不意味着该矿料对每个人都有用。

### 18.4 从一批饭食到自己的手艺

燕宁需要一班真实帮工时，玩家可加入既有厨房劳动，在完成备餐与清点后获得约定工钱和学习。连芷的队伍订单让玩家看到耐存、份量与恢复需求的区别；谷茗则可以开放一批实际饮品的观察与熟成安排。

玩家可只学会一种可靠旅粮，之后按需要直接制作；也可研究不同原料和供应方式，成为随队供餐者。职业成长不要求重复端盘小游戏。没有食客需求时，玩家可以自用、少做或研究，不能靠陈槐无限高价收下剩饭。

### 18.5 纪砚秋与许弦：会画符不等于会安排一个场地

实际营地或工坊有需求时，纪砚秋可以先解释现有符物能做到的范围，再提议有成本的现场布设。玩家可只买几张合用符、跟随勘察、负责购买构件，或与许弦一起做有能力承担的安装。

试运行给出具体反馈：哪些区域覆盖、哪里超过负载、维护要花什么。失败可以收窄范围、换合用构件或停止工程，已完成物和未用料各归其主。学会标准布局后，玩家可独立承接相近项目；复杂场地需要新的判断，而非把同一图案放大就无限有效。

### 18.6 陶栖与一个长期伙伴：先共同生活，再承担责任

玩家在实际运输或寄养场景中认识陶栖，先看到具体个体的吃食、休息、偏好和工作状态。入门可以从照料一段时间、学习观察压力信号开始，不强制先捕获一头幼兽。

若玩家与某个允许建立合作的个体形成关系，下一步是练习少量可靠行为：保持距离、跟随、退回、接受适量负载。随后在真实野外行动中形成协作，例如发现近处迹象并示意、短时牵制让同伴撤离。战斗贡献按实际行动发生，不因屏幕上出现伙伴头像就永久加属性。

个体受伤或不愿继续时，玩家需要照料、休息、安排有能力的寄养者或改变计划。长期伙伴可以教玩家理解其行为，玩家也能调整训练；关系深厚不是永不恐惧或无条件服从。没有玩家时，陶栖仍可照料其已有个体并接受其他实际客户的有限业务，不等玩家触发“驭兽任务”才开始生活。

### 18.7 新增范围与实现边界

第 15–18 节已把主要职业落到现有作者人物、实际条目和条件供需关系；三位专业补充人物按 D140 接受，砂行驮兽、裁造新产品、专业菜品与场地布设按 D142 纳入完整设计，具体内容由实施编制。没有给旧存档人物写入技能、关系、库存或新活动，也没有改造当前物品配方。

操作、学习反馈与验收继续在第 19–22 节深化。无需重新确认三位人物、自由兼修、完整体系设计范围或少量长期伙伴方向。具体价格、学习时长与普通产量不逐项索取批准，按最终体验目标校准。

## 19．各职业亲手做什么（v0.4 设计，D141 已接受）

本节是未来玩法规格，不是已实现功能表。每项操作必须改变方案、获得有用证据或推进实际工作；不能只换场景图片，再统一点选材料等进度。下述例子使用已有具名人物作为生活入口，其新增技能、委托与交互仍须实现。新物性、部位、检查方法与用途只有接入实际规则后才能决定结果，叙述不能代替它们生效。

### 19.1 先区分职业的操作重心

| 方向 | 玩家最常做的关键动作 | 重复参与仍有变化的来源 | 熟悉后省掉什么 |
| --- | --- | --- | --- |
| 炼丹 | 比较配伍与批次，短时守火，收丹 | 本次用途、材料差异、能力与炉况 | 熟方准备可沿用；量产仍遵守本方五次手成 |
| 炼器 | 检查受力与损坏，选修造方案，八锤与淬火 | 工具用途、可保留部分、材料与预算 | 熟悉器形可预填；不省真实维修成本 |
| 制符 | 选择符式和载体，跟随符路，封符 | 使用条件、纸墨适配、稳定与携行需求 | 熟式与用量可沿用；不自动覆盖新环境 |
| 采药 | 在具体植株／采点上选部位、数量和处理时机 | 成熟状态、用途、返程、再生条件 | 已知常见采点按惯例采收 |
| 药圃 | 安排地块与采收批次，处理少数异常 | 地块条件、交货时间、劳力和占地 | 例行照料交给有能力且有工时的人 |
| 勘矿 | 选调查位置和检验方法，决定是否继续取样 | 地质迹象、样本代表性、运输与用途 | 已查区域直接读旧记录及失效提示 |
| 猎业 | 辨踪选路、选择接敌／避让，分配取材优先级 | 活体行动、队伍、身体与材料需求 | 熟悉踪迹由角色识别，不反复考物种名 |
| 医术 | 问诊、有限检查、安排处置和复诊 | 伤势组合、病人意愿、时间与耗材 | 稳定同类病例采用已知方案，异常才展开 |
| 裁造 | 对体型与材料排布裁片，选择接缝与补强 | 材料完整性、活动余量、重量和用途 | 熟版自动排好可行初稿，仍须适配对象 |
| 膳食 | 按用餐时点分配原料、份量和工序顺序 | 食客、到店时间、携行与厨房占用 | 日常菜单按人数排产，不逐锅点火 |
| 酿造 | 确定批次目标，在检查窗口选择收取或续养 | 容器、批次变化、交期与周转 | 稳定策略按约照管，异常和到期再提醒 |
| 鉴物 | 提出要核实的用途，选择能区分疑点的试验 | 来历、证据缺口、耗样与用途差异 | 可信普通商品无需逐件重复深验 |
| 驭兽 | 观察反应、调整接近与负载，发出少量协作信号 | 个体状态、共同经历、环境和操作者 | 稳定日常行为直接完成，不逐次投食点击 |
| 场地工艺 | 安排有限节点，试运行定位负载瓶颈 | 场地、障碍、覆盖、能耗与维修可达性 | 标准布局可套用后检查，不每次从白纸绘图 |

“沿用方案”是保存意图和可复用知识，不是复制上次成功结果。若目标、材料、工具或参与者变化，应明确显示哪些条件需要重新判断；NPC 使用相同检查。熟练不能删除成本，也不意味着每次必须打开全部细节。

### 19.2 炼丹：让准备和守火互相解释

以苏晚禾的常备伤药供货为入门：玩家先看到买方要什么、何时要、能接受什么成品；需要诊断的病例由医者提供获准分享的用药需求，炼丹界面不强迫再做一轮问诊。将真实药材批次放上料架，能比较已知处理状态、来源与适用信息；未知性质保留未知。更换批次应能解释预期变化，不能只出现红绿评分。

开炉前可比较熟方和自己的改方、选择是否另做已支持的前处理。改变组成或处理可能成为不同实际配方，沿原身份算法判断；给方子改名不会变新方。入炉后保留现有按住升火、松开回落与一次收丹，不追加辨药、搅拌、排序三套小游戏。当前手作底座为确定性的 300 个 50ms 步，约 15 秒；这一事实不是新设计要求拉长操作的理由。

结算先给实际产物和用途，再指出可验证的工艺表现：例如有效控火时间不足可以由操作记录解释，材料不适配须有规则事实及角色已知证据，不能把所有失败都归咎于隐藏杂质。未知原因只提出值得检查的方向。老师可以示范一次或指出一次明显偏离，但不替玩家完成自己的成功计数；批量一般品质、逐炉扣料及时间保持原样。

成长的手感是从“照方能成”到“知道本次为什么换这批料、为什么不值得追精品”。新手提示控制方式，中阶提示可比较的影响，高阶保留快速开炉和结果回看；不是等级越高按钮越多。订单按约定药物、数量、品质及可验证用途验收，不能要求新手替伤者保证治愈。

### 19.3 炼器：先决定旧物还有什么值得留下

杜衡接到坏镐时，器物旁显示已有可见损伤和用途。玩家可点选工作端、握持部等有实际意义的检查位置；普通完整工具不强制拆成多件。由检查得到“可修”“需替换”“无法支持目标工作”等范围，再比较省料修补、换掉已坏部分或重造。修好旧镐不会改变它原本能处理的矿层资格。

新增部件化方案只在规则支持的器物上开放；当前整体耐久维修继续按原规则服务，不把现有蓝铁矿维修暗换成复杂拆件。在制作环节仍是八锤与淬火：每次落锤有明确时机反馈，多打不会靠次数得高分；不让玩家选过八次材料再打八次锤。新的结构决策在开工前，锻造控制表达执行质量。

完工可进行用途相关的有限试用：镐检验实际适用的采掘能力，护具检查佩用与已有耐久状态。若新增结构负载测试，须明确试料与磨损，不凭动画宣布通过。学习回看区分“方案本就不合适”和“方案可行但锻打失误”；前者应改方案，后者可练同一工艺。长期专长体现为少量材料修复合用器物、诊断复杂损伤和维护稳定客户，而非每个订单都重新升级装备。

### 19.4 制符：手上的符路与将来的使用场景

纪砚秋先让学徒说清用途：随身应急、已有警戒效果或制作辅助。界面展示已掌握符式的实际触发条件和作用范围；纸墨选择只影响规则已经承载的部分。当前参考符式使用二级灵血墨时，实际工具门槛不能因符名低阶就降为一级。

手作保留短时行笔、符路容差与封符，鼠标／触控跟随和已有键盘操作可以表达同一控制。目标是稳定跟随已学符路，不要求玩家记住复杂汉字，也不开放自由画线生成任意法术。反馈显示哪段明显离路、是否完成封符；笔迹可以回看关键片段，不能只给“灵性不足”的泛泛失败词。

交付一张警戒符与承包营地警戒是两种服务：前者按实物与已知功能验收；后者涉及现场使用条件，属于场地工作。试用消耗符物时要事先列入成本，不能验完后仍把消耗品当完整商品出售。玩家成长表现为在实际旅途反馈中学会选择载体和备用量；纪砚秋不靠卖同一张符无限重验刷信誉。现有警戒符的近处魔兽提示不被本节直接扩为全营地自动识敌。

### 19.5 采药：同一种药也未必应该同样采

跟薄尧走药路时，先显示角色能辨认的植株和局部迹象。点选采点后，只有该物种实际支持的部位可选；新手可看到“留下生长部位”“取尽本次可采部分”等有解释的方案，不要求背原著药典。基础辨认足够时直接给出种名，不藏在反复猜谜之后。

例如药铺要鲜用叶材，而另一买家需要适合加工的原料：玩家决定采多少、先回镇交付还是继续采下一处；只有已经定义鲜度差异的条目才受此选择影响。采收手法通过少量有后果的选项表达，熟悉采点可以“按上次方式采”，无需每株拖剪刀。稀有采点允许更细的探查，但消耗的时间、药铲状态和可采量必须真实。

反馈将“取到了什么”与“对采地留下什么影响”并列，标明已观察的再生迹象，不立即揭晓下次刷新精确时刻。一次保留根株的选择可以增加相关知识；反复打开同一植株不会产新经验。进阶者学会缩短无效路线、识别需另行处理的批次和安排稳定交货，不因专业等级高便自动拥有山地资源。

### 19.6 药圃：安排能履约的一季工作，而非每日打卡

这里的“一季工作”指一个生产安排，不以新增完整季节系统为前提。玩家围绕实际地块放置可种植的批次，比较两种不同安排：全部同时成熟便于集中加工，分批种植则有持续鲜用供给，但占地、繁育材料、劳力与交期不同。水土适配显示已知适宜范围，不让玩家做现实农业考试。

例行照料可以由本人预留活动或雇工承担；到达游戏时间的工作节点时核对人员与条件。只有缺料、缺人、异常生长或订单变化时需要新决定。玩家可查看叶色、成活与生长差异等已有检查结果；检查本身消耗工时，纯浏览记录不消耗。错过一次照料按具体作物规则影响，不默认整圃瞬间枯死。

验收种植代管时，区分“按约照料”与另行承诺的成活／交付目标；收成买卖则验实际批次与数量。若收成不足，先缩减可选外售、动用有权支配的储备或采购补单，不把缺口转给玩家强制种全品种。学习重点是看懂上次安排为何集中缺工，以及如何调整下一批，既有采点再生保持原状。

### 19.7 勘矿：用有限证据决定在哪里继续花钱

岳岑带玩家面对一份明确问题，例如铁承要寻找适合某类器具的料。调查画面以已走到的露头、路径和已有试样为中心，玩家选检查位置，而非在未探索地图任意点击得矿。表面观察、有限取样、已支持的小试有不同信息价值与耗费；每份试样都来自真实资源，标记来源和调查时点。

一次完整操作可为：在两处已知露头中选一处取样 → 看角色能辨别的夹杂与加工反馈 → 决定换位置对照、扩大取样、转交工匠试用，或结束调查。提示解释“这个样本只证明这里”，不会强迫玩家用统计学术语作答。地图上的范围可以缩小或保留疑问，不能一次采样就揭示整座山精确储量。

报告由实际证据生成，玩家选择结论范围，例如“这处暂不适合本次用途”或“有合用迹象，建议再查”；自由措辞不改变证据。岳岑的教学可肯定及时停止亏损调查，错误则指出越过证据的推断。发现更好矿并非唯一成长，重复卖同一报告不会产生新知识或复制独占权。

采矿阶段改为决定投入多少工时、用什么工具、运走哪批材料；不再做第二遍找矿游戏。勘查费为调查支付，采矿采购按真实到货支付。铁承可接受有依据的否定报告并购买别处现货；这让勘矿能够服务生产，而不是保证每份委托生成矿藏。

### 19.8 猎业：材料目标从出发前贯穿到返程

何照川说明路途条件，舒雁若需要完整兽皮，则成为另一项目标。玩家在已见的足迹、残留物、叫声或同伴报告之间选择追踪路线；只有真实活动留下的线索可作为证据，旧踪迹允许过时。认识常见迹象由角色知识负责，玩家决定是否值得追、是否绕开更危险的活动范围。

接敌后完全使用既有战斗。只有当伤害方式确实写入部位／材料状态时，取皮才会受相应影响；在这层尚未接通前，不宣称“用了火就烧坏皮”。逃离、避战或转接已有清除需求都是合理结束，不为猎业小游戏另建战斗。

事后以实际可取部分做优先分配：完整取皮、优先某种筋骨、快速取可携部分分别占用工作量和携带能力。已取部分标记在原尸体／掉落权威里，不能先领取默认全掉落再额外剥一次。回镇后买家指出皮材缺口或适用部分，猎人能把结果与实际战斗、取材和运输联系起来。普通兽食肉不能未经新食材规则直接成为人用菜品。

成长是追踪判断、风险控制与取材经验的组合。战斗境界提高能处理更危险个体，但不能代替取材知识；善于采材的低境界者可与护卫合作。护卫受雇保护行动，裁造订单验材料，二者不应捆成“任何人受伤都不给皮钱”的模糊承诺。

### 19.9 医术：把有限检查用在真正影响处置的地方

宁素的教学从一位同意被检查的患者开始。玩家看到患者陈述、可见情况与已获准共享的历史，选择有实际诊断作用的检查；角色已掌握的常识直接体现在可选方案中。未经观察的内部状态不展示，已经明确的结果也不要求猜术语。

操作重心是处置次序和资源分配：先处理现有规则中的紧迫状态、进一步检查、请求助手、转诊或安排复诊。每项显示能解决的范围、所需材料和时间；药物作用仍按身体与物品规则计算。多名患者时排先后有意义，单一熟悉伤类则可直接采用稳定方案，不强行扩成排班游戏。

反馈分成即时变化、尚未解决的限制和约定复查。示例话语可以是“这次处理改善了当前情况，行动受限仍需观察”，具体词句必须来自实际状态；不把角色暂时缓解写成彻底治愈。教师点评是否检查了关键疑点、是否超出能力，而非只按最终是否痊愈判分。

基础照料 → 独立处理已支持的伤类 → 联合用药／康复安排是知识扩展，不解锁无依据的身体再生。医疗服务验真实检查与处置、耗材和复诊履约；不保证一定恢复，也不能以“结果不可保证”为由收费后什么都没做。此处只设计游戏内伤势交互，不提供现实治疗操作。

### 19.10 裁造：让玩家看见一刀下去保住了什么

舒雁先请使用者说明动作和用途，已有合身衣物也可作为尺寸参考。裁案只显示少量有意义的身体区域、材料片和接缝位置；玩家通过选取裁片、旋转／更换排法、指定补强位置作决定。必须提供点击与键盘选项，拖拽只是快捷方式，不要求像素级拼接或手绘衣样。

例如为常背重物的人改肩部内衬：完整料集中在受力位置可减少该处接缝，却可能多耗材料；拼接方案更省料，但接缝位置会影响特定动作。预览显示已经能判断的覆盖、余量、用料及未知适配项，不用一个总分替所有人选出同款最优解。活动或摩擦效果须有明确规则，不能只画红点就扣人物属性。

裁切前可任意改草图；实际裁切才改变材料。切下的边料按支持的副产物和得率返回，不能撤销裁切恢复整张皮。制作后安排短暂试穿／动作检查；不合适时可放宽、改接缝或重新取料，代价由实际剩余材料决定。学习反馈指向“这条接缝限制了约定动作”等具体问题。

成长从织补和熟版适配，到理解不同材料、处理不规则皮材和复杂用途，再形成可教授的个人版型。客户按自己的体型和约定活动验收，特殊审美偏好事先说明；不会制符的裁造者仍能做有价值的护手、内衬和行装。已有炼器护甲及配方继续保留，分工通过合作而非职业改名夺走旧成果。

### 19.11 膳食：把一餐做得合时、合量、合人

在连芷厨房，玩家先看到实际食客／订单、开饭时点、可用食材和灶位。面前可以是一张简单的备餐案：把原料分给热食、携行口粮或获准的特别饮食，再安排先做什么、什么留到临近上桌。普通住客用常备菜单，特别订单才展开原料替换和多道工序。

独特操作是有限工序的先后安排。例如先处理耗时原料可保证准时，但会占用锅具；先做另一批能应付眼前食客，却可能拖延远行队伍。预览只给当前可知的完成时段、份量和资源冲突。没有新食材／保鲜规则时不使用“凉掉就报废”等虚构后果；待加入后，也仅适用于相应条目。

熟悉菜直接按方案做；需要亲手参与的新工艺可在关键步骤选择收火、转用或调整份量，但不默认每锅都加反应计时。反馈是少了几份、哪道延误、食客是否接受已说明的替材及实际消费。角色掌握的食材适用性会减少无效组合；玩家无需记现实菜谱。

成长体现为在有限厨房中稳定供餐、用地区食材满足不同场景，以及与熟客形成偏好知识。学徒真实参与备料或一道工序，只积累这部分经验；燕宁可以带基础班次，不因客栈身份瞬间成为药膳大师。验收用量、到餐时间和约定用途，原料加工后的基础供养量不得无源翻倍；口味影响复购，不在饭吃完后临时成为拒付借口。

### 19.12 酿造：在变化已经发生时决定要不要再等

谷茗带玩家确定本批目标，再选实际原料、已定义处理和有限容器。放入以后形成占用容器的真实批次，角色可以离开去做别的事；只有酿造等新过程使用这种被动推进，不把既有炼丹炉一并改成离场挂机。

检查窗口给出角色能观察的气味、澄清或其他已定义迹象，与前次记录并列。玩家可以现在收取满足眼前用途、继续等待争取另一风味，或在规则许可时调整。展示下一次检查需要什么，不给一条必然通向最高品质的进度条。不同目标应有不同合适窗口，等得久不等于更好；采样量、损耗和调整材料实际扣除。

错过检查不要求现实时间守屏：可预先安排本人日程或付费交给合格照管者，游戏时间到节点时结算。自动方案遇到未授权的异常就保守停在可停状态，若工艺不可暂停则按已接受的自然变化推进并记录，不能凭暂停界面冻结整批。主动工作和容器占用分别收费。

入门能稳定复现一种饮品，中阶会判断何时提前收取、哪些变化值得复验，专长形成地区风味与客源。反馈回到本批处理、容器、观察和收取时点，不把所有差异都写成随机品质。验收前约定的试饮份量真实消耗，测试样与售出批次关联；鉴赏者的个人偏好不成为全市场统一高价。

### 19.13 鉴物：选择能排除疑点的一次检查

乔澜可以引荐相关专业者，雅妃可作为有真实采购需要的委托人，但接待和经营身份不自动授予鉴定能力。玩家先明确问题是“是不是宣称的材料”“是否适合这次用途”还是“来历凭据是否可靠”；不同问题不能用一次鉴定按钮全部回答。

案上呈现物件、已有凭据和可用检查方法。玩家选对照已知样本、检查工艺痕迹或获准取样；每种方法说明能回答哪类问题、是否损伤物件及费用。线索通过选择检查自然累积，不要求拖红线解谜。没有证据时允许写“尚不能判断”，也可请岳岑、杜衡等在其真实专长内复验。

结论必须绑定对象或批次、检查范围与时点，分开显示观察事实和推断。老师评价的是方法是否切中疑点、有没有越过证据，不拿后台隐藏数值直接告诉学生真相。高级角色能用更多可靠方法、减少不必要取样，仍不能保证所有未知物一眼看穿。

鉴定费支付检查劳动；买方采信报告后形成自己的报价，报告本身不改变实物属性。将同一矿料轮流交给多人盖章，不会叠出固定售价。物件被改造、换批或损坏后提示旧报告的适用范围变化；原样复验如果没有新证据，也没有新的知识收益。

### 19.14 驭兽：学会在不合适的时候停手

陶栖先让玩家观察一个具体个体：它对人靠近、器具放置、负载和陌生环境有什么可见反应。人物知识帮助解释信号，界面不直接给一个全知“信任 73”。玩家选择接近距离、工作目的和本次少量练习；可试一次熟悉信号、调整条件、休息或结束，不靠连续按键压满驯服条。

一次负载训练可这样发生：空具接近已被接受 → 加入约定范围内的实际货物 → 个体回避或动作不稳 → 玩家检查并调整两侧负担，或发现当前不宜继续而卸载。原因来自个体、器具和环境状态，不能每次随机拒绝再让玩家猜。奖励是实际照料或认可的训练环节，不把无来源食物变成无限成功按钮。

训练反馈描述可重复的行为及条件，例如“在熟悉的安静场地接受此人带领”“换到陌生路线仍会停步”。会跟随陶栖不等于会跟随玩家；教学要包含指定操作者的共同练习。入门照料知识可迁移，个体的共同经历不转移。熟练日常行为直接执行，只有新条件、异常或目标变化时展开观察。

战斗协作保留实质作用：在既有战斗行动与位置规则允许时，约定牵制、掩护撤离、侧向支援等少量行为。伙伴必须在场、具备能力并承担自己的行动成本和风险；牵制失败不会直接变成人类白送的额外回合。玩家控制协作意图，个体按当前理解与状态响应，不把亲密关系写成无条件赴死。表现和复盘说明它是否听懂、是否来得及、是否有能力，不另起宠物专用战斗结算。

服务验收区分照料、运输和训练：寄养验真实照料履约；运输验实际货物到达；训练以指定人、指定行为、已说明条件下的有限示范检查。不能保证战斗永不失误，也不能用“它有性格”掩盖从未训练。高级成长包括理解个体边界、安排跨环境练习与伤后恢复，长期价值来自共同经历而非频繁换掉低阶伙伴。

### 19.15 场地工艺：同一套构件放在哪里才值得

纪砚秋与许弦可在各自能力内合作：先检查现场用途、已有障碍、实际供能与构件，再选择已学标准布局。玩家在少量合法安装点上放置节点和连结，显示已知的覆盖、负载与维护通路；不是自由画法阵生成效果，也不要求用数学解电路。

例如工坊希望改善一处工作位，覆盖整个房间会增加成本，覆盖炉旁则可能足够。正式安装前，纸面预览可以随意修改；现场安装、拆移和试运行分别耗工时与材料，拆下的可用构件进入原库存，不允许复制。具体辅助效果必须对应已定义能力；当前清尘辅助不是所有场地加成的通用替代物。

试运行沿实际布设逐段显示哪个节点未供能、哪处超载或哪块区域不在范围内。知识不足时可以定位异常但暂不知原因，向器匠或符师付费排查。新手看懂一个局部问题，熟练者能调整布局、隔离故障并估计维护成本；作品是经过使用的场地方案，而非解过一次固定拼图。

验收约定空间、实际负载、试运行时段和维护条件。扩大范围、增加设备后须重新核对，不能拿原验收承诺无限扩建。普通工坊可照常生产，场地工程的价值来自具体改善和长期维护，不成为所有职业入门的硬性前置。

### 19.16 基础百工与经营服务也要能亲自参与

不独立设职业树的生活技能仍需实际工作：制皮比较柔韧与得率，纸墨加工选择适用批次，木陶作安排容量／密封用途与修补，运输选择装载、路线和交付窗口。这些操作按真实工序复用材料加工和活动承载，不另做十三套手作小游戏。当前八种加工的配方、时长和产物先保持，新增参数明确作为扩展。

经营者的独特决定是接多少订单、给谁留库存、采购还是外包、如何安排真实周转。店主或供奉不因社会身份新增第二条技能等级；有生活技能的人可以学经营，商人也可雇合格工匠。学徒可先参与低风险工序并得到实际工资／折抵学费，劳动与教学分别有可验证内容，不能用免费无限打工替代成长。

## 20．学习怎样给反馈，而不是只跳经验（v0.4 设计，D141 已接受）

### 20.1 一次工作留下三种可读结果

首先给**实际变化**：得到什么、消耗什么、用了多久、谁接收了结果、还有什么没完成。随后给**有依据的解释**：已观察的关键过程及它可能说明什么；最后给**可选择的下一步**：照旧继续、换一种检验、练某段操作、询问具体人物或暂不投入。三者放在同一件事的结果中，默认只突出一两个重要发现，不弹出三张结算表。

不以失败自动揭晓隐藏属性。确定的操作错误可直接说明；相关性只写成线索；无法区分的原因保留未知。玩家可展开“依据”看到来源于自己的哪次观察、工序记录或谁的说明。老师也受知识范围限制，会承认不懂或建议复验；模型可润色说法，不能创造导致世界变化的诊断。

### 20.2 成长是可见能力变化，不是新的全职业四维评分

| 学习阶段 | 玩家能感到的变化 | 教师能提供什么 | 不应发生什么 |
| --- | --- | --- | --- |
| 第一次接触 | 能用一个低成本方案做出有用贡献，知道开工条件 | 实物示范、少量关键提示，说明何时应停 | 一次教学解锁整门职业所有知识 |
| 能独立完成熟悉工作 | 角色自动识别常见迹象，可复用自己的可行方案 | 回看本人遇到的具体问题，给下一次练习建议 | 每次必须重复答入门题或重做全流程教程 |
| 进入陌生材料／地域／对象 | 旧知识能迁移一部分，剩余疑点清楚可查 | 对照案例、共同检查、有条件的专业解释 | 只因等级够就泄露所有隐藏真值 |
| 形成专长 | 能处理较复杂约束，别人因真实成果找来 | 同行讨论、合作研究、教授自己真正会的部分 | 一次选分支永久封禁其他专长 |
| 形成职业成就 | 稳定客户、可复验作品、可靠门人或成熟合作方式 | 传授自己的方法并承担教学责任 | 必须买店、做宗门首席或清空全职业列表 |

“阶段”是体验描述，不增加统一等级条或强制晋级考试。既有三副职经验、等级与五次手工成功保持原样；本节不能以“案例已熟”替代第五次。其他职业的实践进步只记录真实承担且有学习价值的工作，熟活仍有生计收益，但同一证据反复盖章不反复发经验。

### 20.3 三位教师有不同的教法

纪砚秋适合让学生把一张符带到实际用途里，再回来解释哪里好用、哪里超出边界。教学可以指出一段行笔偏离，但真正的进步是学生能为下一次出行准备合用符物；不能要求每次制作都多跑一次往返才算成功。

岳岑适合让学生先选一处有限取样，再说明“这个证据足够支持什么”。负面结果也能形成有用案例；教学可在同一地点完成，只有确有新问题才扩大调查。玩家不必长篇输入论证，可选择系统根据真实证据提供的结论范围。

陶栖适合先示范观察，再让学生与同一个体共同练习。点评应区分玩家没读懂信号、安排不适当与个体暂时不适应；不能把所有不服从都说成玩家技艺不够。跨环境训练是有目的的实践，不是换地图重复喂食。

上述教法与人物口吻是推荐内容；人物接受不等于固定全部性格。宁素偏病例处置次序，杜衡偏坏件原因，舒雁偏试穿前后对照，谷茗偏批次记录，它们共享学习事实，却不共享一张“完成教学 0/5”清单。

### 20.4 作品、习惯与知识分开保留

百工册保存少量有意义案例：对象或批次引用、用途、重要条件、实际结果、已知原因及未解疑点。普通重复劳动汇总次数与最近结果；决定声誉、争议、个人突破或教学的案例单独保留。不要把所有鼠标轨迹、每句点评和每次采样都永久存档。

“自己的习惯方案”可保存取材优先级、熟悉版型、备餐安排或训练目标，并标注适用条件；不是把隐藏的最佳参数开放为万能预设。其他人得到图样或报告只获得其中写明的信息，仍需学习、材料、资格与工时；玩家的亲身经验和伙伴关系不会随复制文书一起转移。

## 21．服务怎样验收并形成可信的生意（v0.4 设计，D141 已接受）

### 21.1 普通生意一句话说清，复杂项目才展开约定

共同约定最少回答：**谁提供什么、交给谁、何时完成、按什么检查、费用包含什么。** 这些数据复用既有任务、约定、交付与资金结算，不新建职业订单系统。标准小服务使用固定说明直接成交，例如“按现有工具维修规则修到所示状态”；缺少材料或排不上时如实告知。

来料、贵重物品、长途运输、多段工程和结果有明显不确定性的服务才展开附加条件：材料所有权、可消耗样量、试用损耗、部分交付、返工与终止方式。无需每次买饭签五页合同。口头约定同样需要有限结构事实支撑，界面可用人物简短复述让玩家确认实际选择。

承诺分四类：交付实物、实施明确工序、通过限定条件下的试用、在一段时间内提供维护／照料。一个项目可以包含多类，但必须分别知道付钱买的是什么。后续世界变化不倒改已验收的事实，尚未履行的维护义务也不能随一次交货自动抹掉。

### 21.2 各职业各验什么

| 业务与人物例子 | 约定后能检查的核心内容 | 不应偷偷附加的结果保证 | 不合格时合理处理 |
| --- | --- | --- | --- |
| 苏晚禾供药／韩素灯加工 | 对应配方或已约定用途、实物数量、可核验品质；来料加工核对投入与余料 | 所有伤者必愈、服用者必定突破 | 可分开收下合格批，未接收部分返工或终止，耗材按责任结算 |
| 杜衡／铁承修器 | 指定器物身份、约定耐久／可用状态与原适用范围 | 旧镐升级采新矿、修后永不磨损 | 指定缺陷复修；无法实现时在继续耗料前改约或退未履行费用 |
| 纪砚秋售符 | 实物符式、数量、已知功能及载体条件 | 凭低阶符确保整段旅途安全 | 区分制成缺陷和使用条件不符；必要测试实际消耗测试份 |
| 薄尧／沙青芦供材 | 实际材料种类、部位／处理、批次与已约定检查范围 | 未调查的整片产地永远稳定供货 | 拒收确不符合部分、接受事先允许的替代批，不事后贬价全部吞货 |
| 药圃代管／供苗 | 已安排且实际执行的照料、已约定成活或交付目标 | 未承诺且超出条件的收成、所有珍材都能栽培 | 查实际缺料缺工与异常，补做可补工作；不能虚报死株为活苗 |
| 岳岑勘查 | 指定区域内真实观察、取样及有证据边界的报告 | 必有富矿、样本代表整座山、独占未约定矿区 | 未完成调查则补做或退该部分；完成后否定结论照约收费 |
| 猎人供皮／何照川带路 | 到货材料的约定完整性；带路另验路线、陪同与承诺时段 | 必遇稀兽、野外零风险、护卫替所有人无伤战斗 | 材料不足只结已接收部分；陪同劳动不能因没猎到目标自动归零 |
| 宁素诊疗 | 获准且实际完成的检查／处置、用料、说明及约定复诊 | 所有病症必愈、未承诺长期看护 | 未做项目不收费；实际误处置与身体暂不能恢复分开处理 |
| 舒雁裁造 | 约定对象、覆盖／活动要求、实物用料及允许的接缝范围 | 所有人通用、未约定审美、无限容量与防御 | 在可返工范围改版，保留实际裁切；客户改用途则另议新工 |
| 连芷供餐 | 份量、交付时点、食材约束与明确的携行用途 | 所有食客满意、永久增益 | 缺份补份、延误按原约处理；已吃掉的合格饭食不能无故全部退款 |
| 谷茗交饮品 | 指定批次、数量、约定的可检查风味／用途范围与样量 | 越久越好、所有买家有同一偏好 | 约定允许时降格交付或改期，否则终止未交部分 |
| 专业者鉴物 | 对象、方法、检查实际发生、结论边界与凭据 | 任何隐藏缺陷都必发现、报告必提高售价 | 补漏检项目、复验争议；检查如实完成但未知仍在，不等同未履约 |
| 陶栖照料／训练／承运 | 照料期内真实工作；指定操作者下的有限协作示范；实际货物到达 | 永久服从、训练消除一切恐惧、运输无条件零损失 | 缺做则补做，条件不适合则调整或终止；不强迫个体受伤完成验收 |
| 纪砚秋／许弦场地工作 | 指定范围、实际负载下的试运行、构件清单与维护说明 | 无限扩大覆盖、永不耗材、所有工序增益 | 定位并修正约定范围内缺陷，客户新增负载另行安排 |
| 普通加工／运输／仓储 | 约定处理与实际产出、接收货物及归还／交付、工时和空间 | 无损加工、无成本运输、库存凭空补齐 | 按来源和占用事实查缺口，不用第二套账抹平损失 |

表中部位、风味、适配与场地负载等新增检查量必须先有规则支持；没有实现的指标不能仅靠验收文案判定达标。既有物品、耐久、配方和品质可直接复用原权威，具体新指标只为带来真实选择而增加。

### 21.3 验收不是全知鉴定，也不是另一套刁难小游戏

事实层记录真实物品、材料、工作与试用结果；人物层依据自己看到的交货、获准查看的记录、检验能力和可信见证作决定。规则可以防止复制物品、虚构支付，不能借验收让每个买家瞬间知道全部隐藏性质。没有被发现的缺陷可能日后在实际使用中暴露，届时形成新证据与相应争议，不追溯把此前人物写成早已知道。

标准熟悉商品默认用已有检查方式完成验收；只在新供应者、贵重批次、争议或指定用途上考虑额外检验。检验耗费应与价值相称。验收界面先显示符合项与明确缺口，允许看细节，不在交货后突然出知识题。私密医疗或个人资料仅向有权知悉者开放。

随机失败仍须来自已定义机制；履约演出不得再掷一次独立“客户满意”骰否定已合格产品。口味、风格等偏好影响以后购买与关系；若要作为本次拒收标准，应在接单时给出可理解条件，不能事后凭 NPC 情绪没收成品和报酬。

### 21.4 失败、返工、部分交付与信誉

首先区分四种原因：工作尚未完成；提供方可归责的制作／履约缺陷；客户后来改变要求或使用条件；原本已说明且未保证消除的不确定结果。原因依真实证据判断；有争议时保留双方所知，不让一句“系统判定”直接广播罪名。

部分交付只转移实际接受的数量与对应货款；拒收品和未用来料按原所有权处理，不自动销毁或无成本还原。返工继续耗用实际工时和材料，不能每点一次退货就恢复一批新料。来料风险、预约费用与返工责任在需要时事先明确，简单小单采用一致默认，避免交易各有一套隐形规则。

隐瞒、失约、无力完成和善意但证据不足的判断不应受到相同信誉反馈。信誉由实际知情者、传播路径和可核实记录形成，诚实报告没找到矿不降低“找矿成功率”而连带扣所有职业名声。好作品可以带来转介绍，但关系好不能让 NPC 无限付款、凭空拿材料或无视身体限制。

训练验收、医疗复诊或工程试运行是履约工作，不是可无限领取奖励的重复任务。已验收事件保存完成身份，重开窗口、重复交互和载入存档不能重复结算；后来的维护需求必须来自新的时间段、使用或真实变化。

## 22．把这些规则呈现成生活，并接回现有模拟（v0.4 设计，D141 已接受）

### 22.1 统一信息层级，不统一所有职业的工作台

入口首先是人和物：杜衡案上的坏器、舒雁展开的皮料、岳岑带回的试样、谷茗正在查看的容器、陶栖正在照看的个体。玩家先明白此人在做什么、当前哪里需要帮助，再进入相应操作。熟客和自己管理的长期工作可从百工册直达记录；远程查看不能绕过到场、物流和付费通信条件。

所有专业共用一套信息次序：当前用途与对象 → 眼前可知情况 → 可执行的少量选择及代价 → 工作反馈与去向。默认把注意力留在当前问题；批次细节、既往案例、报告与账目按需展开。共用字级、颜色语义、焦点和按钮规则，画面主体分别是炉火、器物、符面、野地、裁案、厨房、样本、个体与场地，不再给每项职业复制同样的矩形表单。

新手知道现在能做的一件事、它对谁有用、缺条件时具体去找谁。成长后逐步出现更复杂委托、可比较方案和自己的惯用操作；解锁信息源于能力、发现或真实关系，不让玩家一进城看见全大陆每个工匠的库存和订单。

### 22.2 操作成本与易用性边界

浏览已有信息、摆草图和比较方案不自动消耗游戏时间；实际检查、取样、切料、安装、照护和教学才按原活动方式推进。开始前说明本次会消耗什么、占用谁和哪里。未实施的方案可退出，已经发生的采样、裁切或用料不能因关闭窗口回退。

现有三副职的开工、暂停、停手、结算语义沿原权威；新增职业的规划与分步操作不用于绕过其手作耗材规则。一般多步服务在可停的工序边界保留进度，后续预约能取消，但已经发生的劳动与损耗如实结算；不能承诺任何过程都随时无损暂停。

空间排布有键盘选择和点击替代，关键信息不只靠颜色、声音或微小动画；降低动效后仍能看清状态。反馈必须对应规则已接纳的动作，重复输入和迟到结果不重复扣料或交货；技术提交失败不能伪装成角色制作失败。名称与备注编辑不接管中文输入法候选键，操作焦点与快捷键冲突按统一控件规则处理。这些是后续实现要求，本轮没有浏览器验证或原型。

### 22.3 NPC 不演玩家小游戏，但必须完成同一份工作

材料适配、工位与工具、时间、所有权、结果及验收标准共用；NPC 免去玩家的鼠标轨迹和逐项界面选择。其方案只能使用本人所知、有限熟方与可承担条件。执行质量由能力、条件和已定义的过程风险结算，不能把“后台自动做”当成永远成功，也不能让 NPC 用简单模拟凭空生成上品。

当前 NPC 制作仍是有限行为，不能把本节当成已有通用生产链。未来在原调度上细化：接单／准备 → 真正开工 → 关键检查或条件变化 → 完成／停工 → 实际验收。药圃和熟成允许设施占用期间人物做别的事；主动操作、教学和出行仍占其实际工时。玩家到场可以看到当前正在发生的工作，不能在后台已结算以后再演一次同样扣料。

精确结算物品／批次转移、货币、工位容量、人物占用、活体状态、有限资源、关键检查证据、结果与付款身份。远处普通重复工作可按有效时段汇总，但遇到库存耗尽、工具不可用、工位冲突、订单到期、缺勤或资源变化必须切段；不能把整月产量先发出来再补成本。近处显示更多过程，远处少显示过程，不能因玩家走近就改变同一工作的产出。

没有新信息时继续熟悉方案，有实际短缺才采购或减产；不会为每位 NPC 每分钟扫描全部职业／顾客。保存当前工作和下一关键时点、必要证据、承诺与对象引用；无关重复经历可摘要。品质或风险的已结算结果必须随事务固定，不能因重载界面重新抽取。容量、调度开销与保存预算在实施时用真实世界测量，不在文档声称已经通过性能验证。

### 22.4 后续实现必须证明的体验差异

以下是未来场景验收目标，本轮未执行游戏测试：

- 同一批不规则皮材在舒雁案上能产生两种各有取舍的可行排法，玩家能看到试穿差异和真实边料；不能只是同一制作按钮换了图。
- 岳岑完成了约定调查、得出不适合用途的结论，仍能按约收费；证据不足却承诺整片富矿应暴露为判断问题，不生成矿藏补齐承诺。
- 陶栖的伙伴已会与陶栖协作，却在玩家操作下需要共同练习；调整实际负载或结束不适当训练可以比反复下令更有效，战斗合作由真实行动产生贡献。
- 谷茗同一批饮品可因目标与交期选择合适的提前收取或继续熟成；现实等一天不替代游戏内经过一天，容器和照管者的占用能够核实。
- 同一已验收服务在重复点击与存档恢复后不重复给物或收钱；客户新增用途不追溯判旧单违约，已有五次手成也不因新反馈系统失效。
- 玩家不从事某门职业时，具备条件的 NPC 仍会采购、生产、消费和拒绝亏损工作；玩家介入改变某条真实供需，而不是唤醒整座停摆的城。

上述场景覆盖完整体系的设计要求，不代表下一阶段只实现这些职业。具体数值、内容编制与代码安排进入实施校准；本轮定稿没有修改游戏规则、物品或 NPC 存档。

## 23．长期经济的实际底座与缺口（v0.5 补查）

本节补查当前工作树的 `source/rules/state.js`、`engine.js`、`life.js`、`crafting.js`、`craft-world.js` 与物品内容；不以旧世界方案里的候选机制代替实现事实。下文源码路径相对游戏根目录。

| 当前事实 | 已能支持什么 | 仍需扩展或明确改变什么 |
| --- | --- | --- |
| `state.js` 的 `price` 读取物品固定价；玩家买卖核对报价版本，出售按总基础价六折取整，商家资金和库存有限，收购后数量不能超过 16 | 有限现货、真实付款、防旧报价重复成交 | 报价版本改变不代表价格已动态变化；库存上限也不等于按用途产生的真实需求 |
| `life.js` 中 NPC 购买补给、药铺组织买草及售药、采药人交货已有不同固定价路径 | NPC 已参与部分真实流转 | 尚无玩家／NPC 一致的经营报价与通用供需接单；不能只更新玩家商店价格 |
| NPC 实际采药、库存不足时采购、有限炼药及修理行为已存在；药铺生产由实际成员执行 | 不是纯职业标签或所有物品按月无源补齐 | 通用多职业计划、有限生产队列、委托验收与合作采购尚需扩展；部分寻找商品的实现直接查询世界库存，不等同已完成有限市场知识 |
| NPC 普通劳动片段由当地食品库存行支付工资，同时增加相应补给产出 | 有出资者、劳动时间和基础生计 | 这是抽象生活生产，尚非完整粮食原料链；若加入农业／厨房不得为同一劳动再产一份食物 |
| 玩家普通做工现为半日 6 金，长期工作按日 12 金记入 `producedGold`；部分租用、鉴定等费用记入 `consumedGold` | 有明确记账的抽象收入和流出 | 不是所有收入来自本地客户、所有服务费回到 NPC；长期循环不能仅靠现有有限初始金币来证明 |
| 常规非制作商品有付费周期补货；高阶材料／工具有有限付费进口及在途到达，制作成品被排除在常规补货之外 | 明确存在外部供给边界，不是全大陆生产已模拟 | 需说明来源容量、现金流和本地生产的分工；外部出口需求不能默认为无限存在 |
| 现有租用占实际工位，制作扣真实原料；普通采集／加工仍有世界级 `pending` 单槽 | 已有应复用的资源与工位权威 | 支持多人活动需按执行者扩展原调度；不另造职业库存／经济时钟 |

第 24–28 节长期经济设计已由 D142 确认，尚待实现与验证。通用世界、目标、约定与时间规则仍引用原领域模块；这里细化职业业务。旧 world-systems 中少量地域／商品的首批范围不是完整百工体系的边界。其泛化生产描述也不改变当前三副职开工扣料的事实。

## 24．NPC 怎样采购、生产与接单（已定设计）

### 24.1 每个人都有够用的生活目标，而非无限利润目标

职业安排同时考虑：本人及已承担的家庭生活、现有承诺、维持工作能力、当前修炼／个人目标，以及愿意承担的经营风险。先过滤实际不能做的事，再按第 11 节与 npc-agency 的动机选择，不能把所有人物改成利润最大化机器。满足近期需要后可以休息、访友、学艺或修炼；没有增长也是正常经营。

| 人物类型与例子 | 安排工作的习惯推荐 | 可感知的取舍 |
| --- | --- | --- |
| 专职工匠：杜衡、舒雁 | 留足基础工具与周转料，围绕已接维修／定制排工，少量常备品 | 临近交付减少教学；熟客可以提前预约，但不能无限插队 |
| 兼修者：苏晚禾及实际掌握技艺的修士 | 先积累到下一段生活与修炼所需，再预告停接或减少接单 | 玩家能知道何时可来取货；修炼中不会继续按全职产能出货 |
| 独立采集者：薄尧、沙青芦 | 看已知买家、采地与返程成本，保留本人补给，满足需要后停采 | 采地休养或价格低时换已知路线、接采收服务、做别的生活安排 |
| 商铺经营者：唐汀、石闻舟 | 比较真实周转、客户需要与在途风险，为可靠供应和运力付费 | 缺钱时可能有货却不收货；跨城价差须覆盖实际运输 |
| 专业服务者：岳岑、陶栖 | 接有限调查或照料／运输，保留准备、检查与收尾时间 | 陶栖的伙伴需要休息，岳岑远行时不能同时做本地检验 |
| 组织成员／供奉身份 | 按已经接受的职责、可支配预算和实际能力做工 | 组织付款买的是工作范围和可用时段，不永久占有成员私人技艺 |

以上不是固定 AI 脚本。苏晚禾的家庭照护变化、杜衡的个人目标或石闻舟实际获知的商路消息，都能改变当前安排；专业能力不替代人格。

### 24.2 经营前先看清可用量、承诺和现金

同一库存保留所有者与用途权限；“自用”“已承诺”“待售”是可用量的划分或引用，不是三份复制仓库。可售量不能包含客户托付的来料。已购在途可以用于估计交期，但到达前不能制作、交付或当作可用现金。

以一段计划窗口估计补货量：已接受订单所需量，加上有上限的常备目标，再减去可分配现货和同期限内可信的已安排供给。现货、在制产物、采购在途必须按同一需求归属抵扣一次；宣传公告、客户询问、采购请求不各算一份需求。未确认报价不计入已安排供给。

例如目标是交付 6 份标准成品并留 2 份常备，已有 2 份可用成品、另有预计按期完成且尚未重复分配的 2 份在制产物，则尚缺 4 份。再按实际配方产量折算投入，不直接把“4 份成品缺口”当“买 4 份原料”。若在制订单已经属于其他客户，便不能抵扣此缺口。该算例只说明数量关系，不指定某张现有配方的产量。

周转金也按权限区分：可支配现金减去已经承诺支付的工资、采购、退款责任，以及本人愿意保留的生活缓冲，才是新增支出空间。库存估值、未售精品和客户口头说愿意买，都不是现金。预付款能用于约定工作，但不能同时被当成已赚利润、可退款余额和另一份采购资金。

缓冲目标依据补货前置时间、近期实际用量、服务价值和风险承受能力；不是所有 NPC 固定囤满同一数量。长期没人买的商品逐步减目标，已有少量样品或研究储备可按个人目的保留，不能由预测器无限增长。

### 24.3 五类业务决定不同的生产时机

| 业务方式 | 何时投入 | 谁承担主要周转 | 适用例子 |
| --- | --- | --- | --- |
| 少量常备现货 | 有近期消费依据且低于目标库存时 | 生产者承担未售风险 | 常备药、日常符物、基础口粮、普通修补料 |
| 确认后制作 | 条件、工期和付款安排成立后 | 按约定订金及工匠投入分担 | 舒雁定制衣装、复杂器具、特定用途符物 |
| 来料加工／维修 | 实际收料并核对能否承作后 | 客户承担来料，工匠承担约定劳动及责任 | 韩素灯前处理、杜衡修器、专业酿制 |
| 服务预约 | 人员、地点和必要工具可安排后 | 有限预约费或阶段付款，不凭空印钱 | 岳岑勘查、宁素复诊、陶栖训练、教学 |
| 分期供货／照料 | 每一期在约定提前期内确认与准备 | 合作方按实际交付分期结算 | 药铺补货、客栈供餐、伙伴寄养、场地维护 |

长期合作默认是约定范围内的优先联系、有限采购量或保留时段；不是永远照单全收。若要求专门保留产能，应由真实客户支付约定的保留费用，并限制时段和责任。未经确认的“以后可能需要”不封住工匠全部工位。

### 24.4 一次接单检查要能拒绝、缩单或给出替代日期

接单依次核对：本人是否懂并愿意做；能否取得合用材料；人员、工位、工具、路程是否能排进期限；现金能否撑到收款；报酬和风险是否值得；已有承诺会不会因此落空。只细化近期可执行步骤，远期保存条件安排，不为一张小单搜索全大陆产业链。

材料和工位已就绪，可给确定开工与交期；依赖可信到货，可给条件性日期并说明关键条件；只有未经确认的线索，则先提供采购／调查服务或候补机会，不冒充保证交付。客户可以接受分批、改期、推荐同行或取消。

真正接受时检查资源版本并建立有限预留；预留引用原库存和时段，开工消耗后解除对应预留，不能同时保留两份。询价不预留，待确认约定有明确失效条件。取消后释放未使用的资源，已发生费用沿第 21 节结算。资源分配继续使用原调度的确定性顺序，同一物资不能被两位工匠同时承诺；不得因玩家临时打开界面而获得时间倒流式优先权。

默认不接受需要各方无限互相等待的工作链。先确保现有工具能完成最初工序，必要时租赁、用现货或缩小批次；未取得的未来成品不能抵押成现在的实际材料。允许有边界的阶段付款和已支持债务，但不以互开欠条使全链条无资源开工。

### 24.5 采购选择与生产批量

采购比较的是到场总成本和适用性：购买价、实际路途／运费、预期到货时间、获知的批次证据、供应可靠性及是否能接受替代。贵一点但就在附近的合用材料，可能优于遥远低价；关系好可减少核验、允许小额信用或提前联系，不消除物资和运费。

先从少量已知渠道询问，找不到再付出打听和联系成本。收到缺货回复会更新本人认识并安排有间隔的复查，不每分钟反复向同一空店采购；已下单在途未失效时不因看到另一条公告再订同样数量。给远处商家打听不会立即获知全库存或保证其保留货物。

批量上限取决于实际可售需求、未占用材料、工位容量、工时、现金缓冲和可承受的滞销风险。常备品小批补货，贵重定制按单生产；跨城运输可以合并已有货物分摊成本，但没有订单就不必凑满一车。批量效率必须来自已支持的工序安排，不能新加一个无来源的数量乘数。

### 24.6 用一位 NPC 的工作安排检验闭环

假设杜衡已接受一件维修，手头有必需材料和可用时段；舒雁又询问一批扣件，另有路人提出急修。这些是情境样例，不写入开局固定任务。杜衡先保留既有维修的料与工时，按余量判断扣件能否接；路人若肯等则预约，否则介绍实际可联系的同行。急单愿意加钱，也不能无代价删除已接承诺。

完成维修后，实际交付和收款增加可支配现金；若扣件获确认且材料足够，才开始下一项。青铁不足时，杜衡比较本地购入、联系岳岑所知矿料渠道和延期，不要求玩家亲自勘矿。零件交给舒雁，后者继续自己的裁造业务；双方没有共享库存或凭空转授技能。

身体不适、工位被合法占用、客户改期等事件到来才触发必要重排；小幅价格变化通常只影响下批采购，不中断半件已做成的器物。保留计划承诺和适度切换成本，避免人物每次醒来就在生产、修炼和抢单之间来回跳。

## 25．价格、需求与市场信息（已定设计）

### 25.1 报价是某人愿意怎样交易，不是物品全局价值

同一种物品可以同时有不同的有效报价，差异来自地点、用途、已知质量、数量、交期、买家预算与供应成本。基础价保留为内容校准和缺少交易信息时的参考，不当作每笔交易必须遵守的实际成交价。买卖使用同一报价依据，NPC 专属半价和玩家固定六折路径不能与新体系无限并存。

卖方考虑替换／补货成本、已发生费用、可售量、下一笔已知机会、合理劳动收益与当前周转需要；买方考虑适用价值、替代途径、预算和愿意等待的时间。两者没有交集时可以不成交。卖方成本很高不意味着世界必须有人接盘；已存在积压品可以亏本出售回笼现金。

| 交易情况 | 报价变化应依据什么 | 玩家能理解的说明 |
| --- | --- | --- |
| 本地现货少、近期有真实购买需要 | 替代货何时能到、实际缺口、可支付需求 | “这批只够现有预约，新客要等下批。” |
| 材料贵但客户用途低廉 | 客户可接受的替代或缩量 | “这种品质做普通内衬不划算，我只收便宜合用料。” |
| 库存积压且现金紧 | 真实库龄／周转、后续需求、当前采购承诺 | “现货可以便宜卖，原料本期暂不再收。” |
| 熟客稳定订货 | 减少寻客、检查或运输的真实成本；有限合作约定 | “按期确认并集中交付，可以按约少收这部分费用。” |
| 急单或指定稀有批次 | 加急确实增加的成本、可让出的时段和履约风险 | “能提前，但要另租工位；已有订单仍照约完成。” |

表中话语为呈现示例，实际必须由该人物所知与报价原因生成。质量溢价需买家有证据并确实需要，不能按后台隐藏属性直接定出精确真价。炼丹精品的用途优势、普通品的低成本和批量可得性应各有客户。

### 25.2 有支付能力的需求和希望拥有的东西分开

居民想买高级药却付不起，是未满足愿望，不是已成交需求。采购公告要有真实主体、接受条件、数量、时限与支付能力；求助可以没有钱，但应明确是求助，不包装成有奖订单。店铺预计转卖也受预期客户、周转金和仓储约束，不能以“可能有人要”无限采购。

常备目标来自实际销售／消耗、已经确认的近期计划和有上限的试销量。近期卖出很多，可能是一次远行采购，不应永远按该高峰满产；没有成交也可能是暂时断供，不能误判为永远无人需要。只保存足够区分持续需求、一次事件和供给受阻的短摘要，不追踪每位居民对所有物品的完整需求曲线。

订单、告示和柜台购买共享需求来源。一个队伍预订十份补给之后，不会同时以队伍公告、队长个人采购和店主备货再次买三遍。队伍取消行程，尚未承诺的购买需求结束，已经接受的订单按约取消和赔付，不能悄悄抹掉工匠投入。

### 25.3 价格有反应速度，不能由点击频率操纵

报价在实际交易改变可售量、经营计划重评、关键消息到达或成本发生实质变化时更新。普通小变动在下一次合理经营检查统一考虑，短缺／恢复采用不同的进入与解除条件，避免刚买一件就翻倍、刚卖回一件就暴跌。具体变化幅度和窗口是校准参数，不写死全城一条波动线。

报价标明有效数量、条件及必要的有效期。超出数量重新询价；一次多件交易与拆成多次购买应遵守同样的数量分段和有限收购量，不能靠拆单重置优惠、取整收益或需求。成交时复核版本及资源；已接受的订单价不因后续涨价追溯改变。

NPC 可参考自己真正收到的价格和货源信息，地区行情只汇总可公开的真实交易或报告；不公布所有私人库存和隐藏委托。玩家可以通过熟客问讯、商人消息和实际走访获得优势，但旧消息会过时，也未必有足够运力把价差变成收益。

### 25.4 允许有成本的交易收益，阻止无代价循环

跨城买卖、加工增值、可靠代购和承担滞销风险应当可以赚钱。来回买卖同一未改变的商品、自己与受控账户对敲、反复鉴定或拆分报价则不能凭空获得资源、信誉或永久抬价。玩家与 NPC 都受同样约束；一个人经营多家店不会自动产生两位独立终端消费者。

商人的获利来自运输、资金占用、质量核验、分销和承担风险；收购价与零售价可以不同，但差额须能解释服务和机会成本。并非所有渠道都固定六折。直接向客户交付可提高工匠收入，同时增加寻客、等待和履约工作；卖给商铺回款快但报价通常较低，二者都保留用途。

囤货是可能的经营选择，也可能亏损。垄断一处货源会引起已知客户找替代品、缩量、等待、合购或寻新渠道；只有实际看到或得知相关行为的人才产生评价。普通囤积不自动触发全城敌对，更不触发无来源强制补货。关键供给失衡时应有真实救济、采购或治理行动的主体和经费，不能靠无形系统罚款保持平衡。

## 26．短缺、过剩怎样改变合作与竞争（已定设计）

### 26.1 先判断缺的到底是什么

| 瓶颈 | 最先变化的行为 | 可能形成的合作／竞争 | 为什么单纯涨价不够 |
| --- | --- | --- | --- |
| 合用原料不足 | 限量、替材、改期、采购已知来源 | 采集者议价、合伙运输、轮采或争夺现有采点 | 没有可采资源或路途过长时，高价不能即时变出原料 |
| 有料但没有熟练工时 | 排队、拆分工序、转介、暂停教学或非紧急业务 | 同行分包、学徒承担合格工序、争取供奉时段 | 未训练者不会因工资高立刻掌握技艺 |
| 工位／容器／工具不足 | 调整批次、错峰、租用、修理或购置 | 合租、有限共享、器匠订单 | 工位与人物都有限，买料再多也不增产 |
| 有货但买家没钱 | 缩单、来料加工、有限信用或交换 | 共同采购、分期供给、寻找有预算的新客户 | 标高价格只会进一步减少成交 |
| 在途受阻 | 使用缓冲、联系承运者、分批或改道 | 合并已有货物、组织护送、争取有限运力 | 在途所有权不等于目的地现货 |
| 供求双方互不知道 | 打听、介绍、展示样品和已完成作品 | 中介、长期采购联系、专业声誉 | 全城价格统一变化不能代替消息传播 |

短缺从“常备下降、少量等待”发展到“无法按约交货”需要真实过程。应先给参与者可理解的迹象与调整空间；不是库存稍低就立刻全城停产。所有应对均有条件，不保证每次冲击都能无损化解。

### 26.2 青山镇药材吃紧：不同人承担不同后果

样例从一次已经发生的药材延误或采地可采量下降开始，不固定编造事故。唐汀先核对可售库存、已接供货和可信在途；宁素根据实际病例和预算购买，连芷可能暂缓非必要的特别饮食原料。已保留给客户的材料不能因新客出价高就自动挪走。

薄尧收到新的有限报价后比较采集路程与收益，沙青芦只在当地资源与联系条件成立时形成自己的供给选择；不能跨城瞬时补货。苏晚禾可以缩减非必要试作、按真实适用条件换方或提前告知交期，客户也可以改买合用的普通成品。新品方仍走原学习与手作规则，短缺不自动授予替方。

若还有可用资源，较高但可支付的报价可能吸引有限新供给；若缺口来自交通，则护送、运力与交货窗口更关键。玩家只炼丹也能以客户来料承担加工，或购买已到货的合用材料完成高价值需求；不要求转去采药、开药圃、驯兽三门齐修。

到货后，先完成已有缺口，再决定是否降低采购量与新报价。采集者也许仍在返程，短期会出现一批较多库存；经营者允许分批出售、处理适用储备或暂缓下一次采集，而非全体看到高价后永远满产。价格恢复、合作保留和未履约损失分别记录。

### 26.3 普通护具与符物积压：过剩必须真的让人停下来

假设出行需求下降，或玩家与 NPC 都生产了过多普通装备。商铺先降低收购数量、停止新采购或对可售现货降价；已经接受的货仍履约，不在交货时临时说“市场不好所以不付钱”。生产者看到自己实际积压后降低常备目标，改接确有需求的维修、来料加工或同职业其他用途，也可以修炼、教学或休息。

舒雁可以利用已有可用边料承接具体修补，但不能为制造需求让全城衣物突然报废。纪砚秋可以服务实际工坊的辅助符需求，前提是掌握相应符式且客户有需要；把所有滞销警戒符自动改成清尘符会违背材料与符式事实。

不能用改名、打包或重新鉴定重置需求；转用与回收必须有真实适用工序、损耗和下一位消费者。有限外地订单是可能渠道，运输成本、买方资金与数量同样约束。若本地根本没有足够需求，减产、转移业务范围或迁居是合理结果，不能用强制破坏和战争救市。

### 26.4 竞争的主要内容是可靠、适合和可达

普通业务可比较价格、交期、用途适配、质量证据与真实信用。高级工匠可以接基础活，但高级能力、珍贵工具和工时成本不保证低价优势；初学者可做自己有能力承担的修补、常备加工和助工。相同熟练程度的人也可因地区知识、客户关系和愿意接小单而有不同生计。

陆青与薄尧的采地竞争可涉及先到、是否愿意分享线索、共同运输或各走熟悉路线；冲突仍由原人格、所知和行动条件形成，不给每次降价加仇恨。恶意破坏、欺骗或暴力只有在现有世界行为支持且人物真的选择执行时发生，不是职业系统固定的促销手段。

合作可以保留不同利益：唐汀愿意以稳定验收和回款换取有限优先供货，薄尧仍保留其他客户；杜衡与舒雁共用部分订单信息但不共享全部库存；陶栖与石闻舟按运输时段和负载合作，不为赶单透支伙伴。拒绝不合理条件、改找另一位供货者、诚实推荐同行都可以成为有意义的关系经历。

### 26.5 合作如何从一次生意变成长期关系

第一次凭实物、预算和短约完成交易；成功后双方形成关于这次履约的具体认识。多次稳定合作才可能减少重复检查、提前通报需求、保留有限产能、共同出资改善设施或介绍客户。不是统一好感达到阈值就无限赊账，长期合作也要重新核对新用途与大额风险。

失约时先区分诚实告知的延误、能力不足、隐瞒与挪用；伙伴可以选择宽限、缩单、要求更多保障或结束合作。双方对原因的认识可能不同，知情证据经实际往来传播。合作结束释放未来承诺，但已欠款、来料所有权和既有成果不会被删除。

## 27．玩家只专精一门，怎样持续谋生（已定设计）

### 27.1 生计目标是有选择地养活修炼生活

推荐在合理开局和正常供需条件下，每个独立职业都应有一条无需学习其他专业的低资本入门路径、一类可重复但有限的常规收入、一类体现专长的进阶业务，以及遇到淡季时仍在本专业内可采取的调整。工具、材料、鉴定、运输与协作者可通过交易取得；通用整理、基本自理不算强制兼修专业。

这要求匹配现有人口与业务密度：低频专业可以跨熟悉的几个客户、以兼职或项目形式供给，不要求每座城都供养一整套全职大师。完整职业能力与成长路线仍保留；如果需要扩大外部客户边界，明确有限来单和支付来源，不能为了证明生计凭空增加匿名顾客或无身份劳工。

持续谋生不等于任何城市都欢迎无限产品，也不等于初学者马上负担所有高级修炼资源。能力相当的稳定专业劳动应能覆盖基本生活、维护和必要周转，并逐步留下可支配盈余；更高成长目标需要专长、客户或合适机会。若正常条件下专业工作长期不如无门槛做工，须检查投入、产量、需求与交易价，而不能要求玩家免费自采一切来掩盖亏损。

### 27.2 各职业的收入组合与可购买的支撑

| 专精方向 | 低资本起步与常规收入 | 专长带来的进阶业务 | 他职支撑与淡季选择 |
| --- | --- | --- | --- |
| 炼丹 | 租炉、来料制作、合用常备药小批交付 | 特定用途配伍、可靠分期供货、实际教学 | 买处理好的药材、请人修炉；减少囤药，做已确认来料单 |
| 炼器 | 借／租台，做能力内维修和普通器具 | 专用工具、复杂修复、工坊维护 | 买合用金属与附件；新品少卖时做真实维护，不必自行采矿 |
| 制符 | 租用合格工具，小批常用符或来料制作 | 特定环境备符、稳定辅助供货、符式教学 | 买纸墨、器匠修笔；调整已掌握用途，不必兼修场地工程 |
| 采药／药圃 | 熟悉药路有限交货、受雇采收；培育分支可租地／代管 | 难材处理、稳定批次供给、特定生境知识 | 买工具和前处理服务；淡季按真实需要养护、带采，不要求同时经营药铺 |
| 勘矿／采炼 | 工具租用、有限踏勘／取样费、已有矿点受雇开采 | 用途调查、项目供料、矿材复验 | 买工具、加工与运输；无需承诺每次找到富矿；无调查单时可做合格普通采炼 |
| 猎业 | 接真实取材需求、熟悉地区的追踪陪同 | 目标材料、风险清除、专业取材协作 | 购买补给、维修和战斗护卫；减少无买家的猎取，转实际向导／取材服务 |
| 医术 | 能力内照料、检查、复诊或诊舍受雇 | 复杂病例协作、长期有限照护、带教 | 向炼丹者购药、购买耗材及转送；没伤者时允许休息，不制造患者 |
| 裁造 | 修补、改制、来料按熟版制作 | 活动适配、专业附件、真实组织制装 | 买皮布、扣件和加工服务；无需猎兽炼器，淡季依修补或已确认制装 |
| 膳食 | 使用客栈厨房受雇、有限餐食或口粮订单 | 稳定队伍供餐、特殊食材处理、真实宴席 | 买食材与器具；按实到食客缩量，不靠食品增益叠加硬造需求 |
| 酿造 | 租有限容器、受雇照管或有订量的小批制作 | 地方风味、稳定熟成、指定用途饮品 | 买原料、容器与运输；在批次间承接本专业照管，不能靠新订金填旧亏空 |
| 鉴物 | 学成某类有限检查后受雇检验、验收协助 | 高价值交易、疑难复验、来源证据业务 | 租检验条件、请领域专家合作；低频行业可跨熟悉客户服务，不能每个路人强制鉴定 |
| 驭兽 | 先受雇照料、协助训练，不必买下伙伴 | 指定个体训练、有限寄养、运输／野外协作 | 买饲料、驮具和有能力者照护；无运单时不能让空载行走产钱，也不靠出售幼兽维生 |
| 场地工艺 | 学有限标准布局、受雇安装／检修，构件可外购 | 场地改造、故障定位、有限维护约定 | 向器匠和符师购买构件；新建减少时做实际检查维护，无需求时无需硬造故障 |
| 基础加工专长 | 利用现有设施做制皮、纸墨等已掌握来料工序 | 适用批次与可靠交期 | 用订单与本地加工需求谋生，不必因没有独立职业树而无法领取劳动收入 |

这张表不是保证每日都有单。鉴物、场地工艺等业务本来较低频，应通过足以支付准备与空档的合理服务价格、多位实际客户、阶段项目和有限聘用形成收入，不能把所有专业强改成每天消耗一个成品的行业。专业供奉是一种可选择关系，不是高阶谋生的唯一出口。

### 27.3 新手不用先有店，也不用跑遍全职业

普通起步可从已知职业人物的合格助工、来料小单或租用设施开始。教师需要学生的实际劳动，学生也需要明确所得；教学费、工资与来料所有权分别记录。入口应至少让新手知道一个可联系的买家／雇主、一个材料或设施渠道，以及近期能承担的工作，不承诺这些渠道永远有货。

玩家可以选择只负责炼制、裁造或检验，把采购／运输交给合作者并支付费用。报价须看得到这些费用怎样影响盈余，委托他人不能复制职业经验或把其完成的手作算给自己。独立营业、受雇、流动接单、组织聘用和小规模合作都是可持续目标，不必先买建筑才能认真从业。

### 27.4 从“卖出一件”走向稳定但不过度捆绑的客源

推荐形成少量稳定客户，再保留部分可变业务。例如裁造者有一位会带来真实修补需要的向导、一家间歇制装的组织，以及零散改衣客户；其中任何人没有需要便不下单。不同业务错开使生活更稳定，但不会自动让所有订单期限重合或每期刷新同一任务。

熟客提供需求预告和转介绍，使玩家少做无意义搜单；玩家可设置在可支配工时内愿意接的业务、交期和采购上限，由已建立的经营／委托规则处理询价。重大替材、超预算或超出承诺的情况再提出决定。不能因为省操作就自动替玩家接无限订单或远程完成手作。

需要闭关或远行时，可停止接新单、完成／改约现有工作、处理存货，或支付给实际合格者代管。没有接下持续义务，就不应因现实离线或主动休息自动失去客户和收入资格；已经承诺的游戏内期限仍会随世界时间推进。职业生活允许间歇，避免经营成为强制打卡。

### 27.5 核算一次完整经营窗口，而非只展示售价

以下为虚构教学算例，用来说明应展示什么，不是当前物价、产量或已验证收益：一位裁造者在一个七日经营窗口内，从有限客户收到合格交付货款 90 金；合用皮布、扣件与外包加工实际支付 40 金，生活和场地支付 20 金，另保留 10 金工具维护准备，剩 20 金可用于储蓄或修炼。每笔费用只归一次；这 20 金是留给本人积累与承担风险的可支配余量，没有额外虚构一份已领取的自雇工资，不能再声称另有 90 金利润。

验收通过但尚未收到的货款另列，未售成品按库存显示，不计收入；工具维护准备是留下的现金，不伪装成已付给修器者的支出。也要看七日里实际做工、采购、交付和等待分别用了多久，不能用一小时操作的售价除一小时就宣称日赚同样数额。

若次期只收到 50 金而支出与准备仍为 70 金，则需动用 20 金储备，或减少未承诺的新采购、缩减场地占用、寻找实际订单。不能自动提高售价到顾客必须买，也不能因此要求玩家转行学采猎。若这种亏损在正常供需下普遍持续，是内容与经济平衡问题；若是明确的局部冲击，则应有可理解的应对与恢复过程。

上述算例中的服务方、材料供应者、房主和生活供给者也分别受到真实资金／产能约束。完整闭环必须找到 90 金货款来自哪些有限客户及其收入，不以一张漂亮账本代替世界运转。

## 28．让职业生态长期运行而不失真（已定设计）

### 28.1 同时闭合物资、工时与资金

物资要能解释初始量、真实产出／再生、进口、使用、损耗、出口和期末量；原料转化与成品消费分别核对。时间要能解释谁做了工作、谁在旅行／照护／修炼，以及工位和容器何时占用。钱要能解释初始现金、本地转移、明确外部收入与外部支出。任一条失衡都可能让“有供需关系”的图在几轮之后停转。

本地付款只在主体间转移，不增加总钱量；开票、估值和借贷也不创造可花金币。借款是实际出借人转移现金并增加债权／债务，偿还与失约均保留；不以无资金的银行或万能宗门担保填缺口。基础规则已有的抽象收入按边界记账，不能既保留铸入又让雇主再支付同一工资。

开局需同时配置有限生活／经营储备、可用基础工具、实际可支付的近期需要和能执行的供给者；不能全部持有昂贵货物却没人有周转金，也不能所有人从同一空店开始等料。背景存货与技能可作为明确初始事实，不伪造已经执行的交易历史。后续再生产和收入必须接上这些条件，初始储备耗尽前的繁荣不算长期验证通过。

金币大量流向没有收款者的租金或进口而没有外部回流时，有限初始现金会逐步减少；靠降价不能解决全部资金退出。反过来，持续无条件发做工工资而不限制外部需求，也可能积累过多可支配钱。应显式设计收支边界，而非在每月结算偷偷重置余额。

### 28.2 推荐有限开放的地方经济

不要求完整模拟斗气大陆每个粮户和矿商。推荐本地关键职业链精确运行，未展开的普通基础生产与远方贸易使用有来源说明、有限容量和明确结算的边界；边界不伪装成已存在却无身份的 NPC。地方可以自给一部分、输入一部分、输出一部分，单一职业不必完成全部上游。

| 边界或收支 | 推荐处理 | 与当前规则的衔接 |
| --- | --- | --- |
| 本地修理、教学、照护、加工和租用 | 有明确经营主体时真实付款；收款方按自身生活和经营需要使用所得 | 当前部分系统收费改为主体收入属于显式迁移，不能两处同时入账 |
| 抽象基础粮食／普通劳动 | 有生产场所、可用劳动、产出容量及真实工资来源；未展开原料链明确说明 | 现有 NPC 劳动产粮可先作为受限抽象，农业／厨房接管同一工序时只替换一次 |
| 现有玩家普通做工 | 在完整替代路径可用前保留；未来接具体雇主或有预算、容量的外部劳务边界 | 不在本次设计中悄悄删除当前半日 6 金／每日 12 金规则，不并行支付两份工资 |
| 外部进口 | 有限来源类别、支付成本、统一可用供给量、运输与到达条件 | 扩展现有付费来货；同一来源容量供所有买家竞争，不为每人复制一套配额 |
| 外部采购本地货物／劳务 | 有明确采购类别、预算、数量与交货条件；货物实际离开本地，完成才按约收款 | 属新增边界，不是当前已实现出口；不能无限收走滞销品或逐玩家重置需求 |
| 救济与组织支持 | 从实际可支配储备出资，可缩量、拒绝或暂时耗尽 | 不默认每次短缺都有免费宗门补给 |

外部周期容量可以由明确的内容规则随外部生产窗口更新，但必须标明这是边界假设，不能宣称模拟了远方生产；未用额度不无限累积，刷新按游戏时点一次结算，不因重开界面、读档或新增商铺重复发放。进口与出口不需每次严格等额，但在正常长期样本中应有可解释的资金流入／流出范围。

允许局部停业、迁居和一段时间的真实短缺；“长期可运行”不等于每一家店永不倒闭。只要普通条件下基本生计与主要产业不会因必然的结构性断粮／钱荒集体崩溃，同时任何恢复都有资源和行动依据，地方经济就可以存在兴衰。

### 28.3 防止缓慢失效的几类问题

| 长期问题 | 应观察的迹象 | 设计上的处理 |
| --- | --- | --- |
| 无人买也不停生产 | 成品增、现金减、预期需求不降 | 有限常备目标，区分一次事件与持续需求，库存积压时减产 |
| 全体追涨造成过剩再同时弃业 | 采购／价格反复急转、同批次工单集中 | 信息有到达过程，计划具有持续性，逐批调整；不是全城读同一全知信号 |
| 现金被少数人永久囤住 | 有需求有劳力却普遍付不起 | 查看真实消费、工资、组织支出和外部回流；允许储蓄，不强制没收富人金币 |
| 必需环节相互等待 | 造工具等矿、采矿等新工具、全部订金悬空 | 初始可用基础工具／租用、少量储备与分段开工；不先要求高级全链条 |
| 低级工匠永久无活 | 基础业务被无成本高阶产能覆盖 | 检验工时、工具成本、地点与交期差异；高阶不能同时无限接单，也不禁止公平竞争 |
| 服务为维持收入虚构问题 | 没人受伤却不断诊疗、完好设施反复维修 | 需求由真实状态与约定产生，允许空闲、合并服务和较低频较高价值项目 |
| 债务与预约越滚越大 | 收新订金补旧单、订单不关闭 | 限制实际偿付与承作能力，停止新承诺、重议及真实清算，不抹债补钱 |
| 长等待多算／漏算需求 | 一次闭关与分段等待产出不同 | 同一事实边界切段，消费、库存、支付和活动顺序保持一致 |

死亡、失能或离开导致的专业空缺，可以由现有人物的真实能力、学习、招聘与迁居逐渐补位；没有条件时保留空缺或缩小业务。不能给继任者瞬间继承全部技艺，不能以维持每种职业总有一个人为由突破人口和资产规则。

### 28.4 玩家怎样感到这些变化

货架减少、取货日期延后、工匠改接维修、客栈调整菜式、熟人询问下一批货，足以呈现市场。玩家与 NPC 的交谈可说明自己掌握的原因，例如“这批料还在路上”“本期工位已排满”“货还有，暂时没有收货的钱”。不知道原因时只报告所见，不让店员替全世界作经济诊断。

经营记录默认只呈现已接工作、待确认机会、下一项缺口、可支配资金及最近实际盈余；需要时再展开账目。价格变化显示与上次本人所知报价的比较及已知原因，不能变成每分钟红绿闪烁的证券行情。单职业玩家通过可靠联系人少跑冤路，同时仍需承担真实交付和路程。

### 28.5 后续校准与验证范围

以下为未来实施的验证设计，本轮没有运行经济模拟或宣称达标。时间跨度需覆盖多个生产／补货／消费周期，而非只看开局现货；同时核对正常、短缺、过剩、师傅缺席、路线延误、单职业玩家和无玩家介入的情形。

- **专业生计：** 每一独立职业至少有一条合理入门路径，正常条件下能从有限真实客户获得覆盖生活、维护和周转的收入；计入失败、寻客、运输与等待，不以全部材料免费取得为前提。
- **产能与承诺：** 不超卖来料或工时，缺料不会连续接无限新单；同一需求没有在告示、订单和库存目标中重复计算；候补与已接受订单明确区分。
- **市场响应：** 短缺能先反映为数量／交期／替代变化，价格受支付意愿限制；供给恢复后减少过度采购，过剩后确实减产；不是所有价格只能涨。
- **资金与物资：** 能追溯收支边界、真实消费与资源来源；经营资产、私人钱和组织预算不重复迁入；没有依赖每月补满钱箱的稳定假象。
- **合作与竞争：** 能出现双方都有收益的有限合作，也允许拒单、换客户和正常失败；玩家不兼修其他专业即可购买支撑，竞争者不因主角职业自动升级或消失。
- **长期恢复：** 外部流量、人口与资源容量固定时，一次长推进和多次短推进保持应有的一致性；读档不重置报价数量、外部配额、债务或已付工资。
- **运行成本：** 按活动／到期／关键变化唤醒有限相关人物；记录活跃承诺及紧凑经营摘要，不扩成每人每物每分钟重新估价。容量不足时明确停止新承诺，不丢资产或隐藏待办。

校准不只看平均收入：还要看普通从业者是否持续破产、客户是否能负担、等待是否过长、库存是否单向膨胀、资源是否耗尽、正常工作是否挤掉全部修炼与生活。阶段实施可以先贯通代表链再扩展内容，但这些完整职业与长期要求均保留在设计范围内。
