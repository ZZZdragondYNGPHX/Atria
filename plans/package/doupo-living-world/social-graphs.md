# 每位角色的关系图谱与社交圈

状态：第三轮深化候选方案。角色包括玩家在内均有自己的关系图谱与社交圈；复杂社会因果与个人有限认知承接 [decisions.md](decisions.md) 的 D30、D31。以下表示方法、可见能力和算法细节尚未冻结，不声明已经实现。

本模块是关系图谱的唯一详细设计来源；人物目标与行动选择归 [npc-agency.md](npc-agency.md)，地区、家庭和组织循环归 [world-systems.md](world-systems.md)，消息传播、时间、计算精度与完整恢复归 [world-simulation.md](world-simulation.md)。
图谱要回答的是“这是谁与谁的关系、谁知道或相信、依据什么、如今是否仍适用”，使人物能够沿自己掌握的渠道寻找援助、合作、竞争和利益相关者。
概念术语与表格不是已实现 schema，不改写 [frontend-contract.md](frontend-contract.md) 的 C2 实际接口；新增可见能力后续经实现与接线核验再进入契约。

## 同一角色语义与不同控制方式

玩家是由人控制的特殊角色，NPC 是由规则及获准模型驱动的角色；两者都占据世界中的身份、位置、资源、经历和社会联系。
复用玩家现有 Actor 身份与 NPC 现有 Subject 身份，沿用 Native 身份解析和授权；不为“社交人物”再创建一套 ID，不把玩家复制成另一个 NPC。
图谱中的同一已识别人物始终指向同一现有身份，跨地图、改名、组织变更或死亡不更换节点身份。
角色统一的是关系与信息语义，不要求人类玩家与 NPC 使用相同决策控制器，也不让自动规划代替玩家选择立场或行动。
组织、家庭和项目可以作为人物联系所指向的既有世界对象；它们不是额外生成的可行动人物。
尚未识别的目击对象以证据中的待辨识描述保留，不凭一条传闻生成真实新人物；身份确认后再关联现有身份，并保留辨识依据。

## 三层分开：世界事实、个人社会认知、个人评价

| 层次 | 候选表达 | 能回答什么 | 不允许直接推出什么 |
| --- | --- | --- | --- |
| 客观关系事实 | B 与 C 的亲属关系、共同项目、已接受的债务、组织任职及有效期间 | 世界已经成立过或仍成立的关系 | A 必然知道这些关系，或双方必然亲近 |
| 每人的社会认知 | A 认为 B 与 C 是家人、A 听说 D 可引荐医者、A 认定某人欠债 | A 如何理解他人的网络与可用渠道 | 该说法必然为真，或它已进入 B 的所知 |
| 有向评价与信念 | A 对 B 的信任、可靠预期、感激、畏惧、竞争与具体判断 | A 愿意如何对待 B、依据与不确定程度 | B 对 A 有相同评价，或某个分值直接决定行动 |

客观事实由真实关系、契约或行动结果形成；认知与评价由每人的获知经历形成，不能让传播一条消息改写客观亲属或真实债务。
“A 认为 B 是 C 的家人”是 A 对 B—C 这条关系的理解，不等于只有 A—B、A—C 两条好感边；个人图谱能够包含对第三方关系的认识。
同一关系可以同时存在真实事实、A 的正确认识、D 的误认和 B 的刻意隐瞒；不合并为一条全世界共享的已知边。
已经履行的共同项目是经历事实，但它是否代表友情由各方判断；有亲属身份也可以疏远，有高信任也不等于有实际借贷能力。
多维评价分别保留来源和对象，维度、尺度与变化规则仍待校准；不把所有社会联系压成总好感、阵营敌我或单一声望。
不确定程度可以用有限等级或经验证的数值表示，具体取舍未定；不得让一个没有来源的精确概率伪装成人物已经查证。

## 个人图谱最少需要保留的语义

以下项目说明需要回答的问题，不要求拆成固定表、图数据库或一份全量 JSON。

| 概念 | 最少要说明的问题 |
| --- | --- |
| 认知主体 | 谁掌握这项认识，哪个个人视角可以使用 |
| 关系命题 | 认为哪些人具有什么联系，指的是当前状态还是过去经历 |
| 获知方式 | 本人目击、亲历、对方自述、第三方转述、公开公告或推断 |
| 证据与来源链 | 关联哪次真实接触或收到的消息，哪些是原说法、哪些是后续判断 |
| 时间与适用性 | 事实指向何时、何时获知、上次核实何时、是否已过期或遭到反证 |
| 主观把握 | 相信、怀疑、待查或已否定的程度，依据是来源可靠性还是本人偏见 |
| 披露与联系条件 | 是否愿意向谁透露，通过什么已知方式能接触有关人物 |
| 关系后果 | 与本人哪些目标、承诺、渠道、风险或旧经历有关 |

一项消息可以支持多个命题，但不自动证明全部：看见 B 给 C 送药，能证明一次送药经历，不足以单独证明亲属或长期忠诚。
同一原始传闻被多个人重复转述仍可能只有一个源头；来源链用于避免把重复传播误当成多个独立证人。
公开事实也需要实际接收渠道；公告发布不意味着所有 NPC 同时阅读，玩家打开已获知档案则不再收取一次行动时间。
未知关系没有边不等于确认双方毫无关系；查无证据、明确否认与已被证伪分别表达。

## 隐私、误认、欺骗与澄清

每位角色规划时只读取本人的获准图谱和可用消息，不读取对方私图，也不查询隐藏真实亲属来优化自己的选择。
宿主规则可以读取必要客观事实来裁定行动；裁定只向相关视角提供其能够感知的结果，不把后台答案顺带写进全部人物记忆。
传话者可以如实说、漏掉部分、撒谎或自己已经误信；接收者分别记录“对方说了什么”及“自己目前是否相信”。
谎称家人、冒名与隐瞒必须通过游戏允许的表达和辨识过程成立；说谎不能直接修改真实家庭、职位或财产权限。
误认保留认知来源：A 跟错人时，A 的图谱可以暂时把某次目击归给 B；后台真实身份不因此改变。
发现矛盾后可形成待查状态、寻找其它渠道或改变判断；不要求出现一条反对消息就立即全盘推翻既有经历。
澄清需要实际获知：当事人说明、可信见证或后来亲历可修正某人认知，但不会远程修正所有曾听过旧说法的人。
已否定的认识可退出当前行动依据，历史中仍保留曾经误信及由此做过的事；不能删除误会来抹掉错误行动的后果。
一项秘密被 A 发现后仅对 A 成为已知，是否再传播受本人目标、约定与行动限制；不默认升级成世界公共新闻。

## 非对称评价、位置与联系渠道

A 可以信任 B，但 B 只把 A 当临时雇主；C 对 B 的敌意也不会直接成为 A 的敌意，即使 A 知道双方有冲突。
人物对消息来源的评价影响采信与查证，不等于该来源每次都说真话；一次谎言被识破也不必自动抹去所有真实旧经历。
关系、联系能力与位置分开：认识某人不代表知道其当前去向，知道住址不代表对方此刻在家，亲属也可能多年失联。
旧位置保存上次看见或获悉的时点及来源；收到过期消息后，人物可能扑空、等待或询问，不从全局位置自动导航到目标。
联系渠道可包括同地交谈、已知住处、可信中间人、可用书信或组织联络方式；途径的耗时、费用和可达性沿用世界规则。
目标不在场时，人物可找家人或合作者转告，但须先知道有关联系且对方愿意配合；社交边不是无限传送或强制配合通道。

## 图谱怎样进入目标与计划

人物为目标先检索自己的有关联系：谁可能有能力、资源、可靠渠道或共同利益，哪些关系存在义务、风险与代价。
候选检索可以先看熟人，再沿本人知道的转介关系扩展少量渠道；搜索深度、候选数和重评频率按实际负载校准。
“朋友的朋友可能懂医术”先形成询问或引荐目标，得到回应前不视为已认识医者，也不提前拥有治疗资格或安排。
求助、邀约、结盟和竞争同时检查关系与实际条件；熟人拒绝、失联、无钱或有其它承诺时，原目标可以受阻或另寻渠道。
人物也可以从已知利益冲突推测竞争者、寻找对手的合作方或隐瞒关键消息；这些只是有依据的候选，不强制所有人使用最激烈手段。
利用关系链的计划必须逐步取得条件：先知道有关人物，找到可达渠道，再实际接触和执行；图上存在一条路径不等于全链已经完成。
“谁在意谁、在意什么”可以作为有来源的主观判断，支持送礼、求援、调停、利益交换或敌对目标的候选选择；不能从亲属标签直接推导必定亲近或必定愿意付出。对他人可能反应的预测保留不确定性，不修改被预测者的真实意愿。
复杂因果的活动、时间、反应与中断按 npc-agency 和 world-simulation 执行；图谱不单独制造报复、同意、伤亡或资源转移。
每一步可能增加、削弱或证伪后续依据，行动者也可能被察觉、误导、拒绝或反过来利用；不能用一条预写长链保证终点。

## 从社会遭遇到知识边：候选例子

例一，A 在药铺亲眼看见 B 向 C 交付一包药，随后听 B 称 C 为姐姐。
这次接触先形成目击交付的经历与“B 称 C 为姐姐”的来源记录；具体亲属判断保留原话及本人理解，不由后台补全族谱。
A 可暂信亲属关系，也可因既有矛盾存疑；C 没有因此自动知道 A 在观察，A 也未自动获知 C 的住址、财产或其它亲属。
A 后来为送药目标请求 B 引荐 C；只有询问、接受和实际引荐后，才形成新的联系经历，C 对 A 的评价由 C 自己的获知与判断形成。
若 B 后来承认只是尊称，A 修正亲属信念并保留原接触；这不会删除已经发生的交付、引荐或因误认造成的失礼。

例二，A 与 B 有过冲突，A 想找出 B 在意的人，候选过程如下；目标选择及行为边界不由图谱模块强行决定。

1. A 先依据自己记得的冲突与个人价值形成目标；并不知道 B 全部亲属，只有有限的旧去向或接触线索。
2. A 尝试跟踪或打听，活动消耗世界时间并接受可达性、观察和被察觉的检查；跟踪失败就不能自动获得后续关系。
3. 若观察到 B 多次拜访 C 的住处，A 得到“B 与 C 有持续接触”的线索；仅凭拜访不能确认 C 是家人。
4. A 从实际对话、转述或进一步目击形成“C 可能是 B 的家人”的认识，可能正确，也可能被误导或仍待核实。
5. A 据此比较谈判、威胁、报复、撤回或其它可行方案；选择受本人目标与判断约束，不因发现亲属自动触发攻击。
6. 真正找到 C 并采取行动时仍检查 C 的实际状态和反应；B 得知经过需要自己的消息渠道，不能无因立即锁定 A。
7. C、B、见证者和玩家分别获得自己能知道的部分，形成新的信任、恐惧、债务、误会或调查；后续历史承接实际结果。

若 C 并非 B 的亲属，错误依据可能导致错误行动与新的后果；若 A 察觉身份不符，可以中止或改策，不能强行补造亲属来接上预定剧情。

## 玩家自己的社交圈与表达权

玩家图谱候选展示本人已见、已听或已明确记录的人物、关系线索、承诺、共同经历和可用联系，标明传闻、推断、过期与矛盾。
玩家可查看“自己知道 B 与 C 有什么联系”，不能默认展开 B 的秘密家人、私下盟约或 B 对所有人的内部评价。
NPC 对玩家的隐藏信任、畏惧或利用意图仍属于 NPC 私有判断；玩家可以得到语气、拒绝、转述等线索，但不能默认看见精确后台值。
“C 说 B 不信任我”作为来源明确的说法保存，不直接升级成已经核实的 B 内心事实。
系统可自动整理人物经历、本人亲历的结果和已接受的公开承诺；不能代玩家宣布喜欢、仇恨、原谅、信任或下一步行动。
玩家自己写下的评价、怀疑或提醒应与系统整理的事实、NPC 隐藏评价分开；用户笔记也不改变真实亲属或他人看法。
提出请求、听到建议和看到图谱不会自动替玩家接受债务、结盟或报复；有后果的选择仍由玩家提交并由规则接纳。
可见图谱先服务查人、回忆来源、联系与理解关系链；布局、筛选和操作形式是后续表现设计，不要求首轮制作复杂可视化编辑器。

## 稀疏规模、索引与完整恢复

每个角色都有个人图谱语义，包括仅知道家人、只有一名熟人、暂时失忆或尚无已知联系的稀疏图/空图；空图不等于角色不存在。
不初始化全体角色彼此互知，不存 N² 条默认好感，不为每个人复制世界客观族谱、组织表或完整关系网。
候选存储按认知主体、命题涉及身份、有效状态与证据引用建立可用索引；客观关系与来源记录尽量引用复用，具体数据布局未定。
共享证据的引用不能扩大阅读授权；索引服务可以定位有关记录，向某角色返回的仍仅是其本人有权使用的部分。
规划只取当前目标有关的局部子图，界面按人物与关系分页读取；容量分别衡量节点、关系命题、评价、证据和历史增长。
降低模拟精度时可压缩重复普通经历，不重生关系、不覆盖来源，也不让普通人物为了省内存忘掉家人、债务或重要约定。
死者保留原身份和旧关系，相关命题可标为历史或适用条件已变；生者获知死亡仍需要渠道，不能因节点死亡就自动向所有人更新消息。
家族变动、分居、还债和组织解散改变有关事实的有效期间，旧状态仍能从历史解释；旧关系也可能继续影响记忆与动机。
个人所知、评价、辨识状态、证据及来源链与世界一起保存和恢复；索引是可重建派生数据，不成为另一份关系真相。
读档后清理未来分支的传播、模型结果与界面缓存，避免尚未见面的人已经认识、旧仇提前出现或未来亲属关系泄露。

## 现有起点与候选落地样本

BE2 已有部分 appraisal 关系维度、人物评价、家庭关系和个人信息来源；这些基础不等于完整的每人社会网络、第三方关系信念或可查询社交图。
本模块优先复用这些 Native 身份、Information/Cognition、Domain、History 与分支能力；事实和私人认知的实际承载方式需在实现阶段核验。
首批候选从少量人物的真实亲属、一次协作/债务及一条可传播的误认线索开始，检验 NPC 与玩家使用同一关系语义且各自只见获准信息。
至少覆盖正确认识、错误推断、单向评价、过期位置、转介失败、谎言被澄清、死者旧关系与完整读档；比较同一初始世界中消息被截断或澄清后的行动差异。
无关角色不得因后台新增关系而突然改变计划；知情角色的改变须能追踪到证据与目标，玩家图谱不能泄露 NPC 私图。
这些是后续实施与自查的候选完成依据，本轮只更新方案，不运行测试、不改源码、不把设计记录为接口已交付。
