# NPC 自主成长与后台冲突

状态：2026-10-22 候选实施设计。承接已确认的 NPC 自主修炼、NPC 与 NPC 后台战斗，以及按功法、装备、道具和实际损耗结算的方向；具体成长公式、战术、器物属性、损耗参数和字段仍为候选。玩家与 NPC 的完整战斗机制属于未来较大改动，当前不展开其机制或界面，也不宣称本文件内容已经实现。

## 职责与范围

本模块保存 NPC 修炼活动、NPC 互战和器物使用的详细候选规则。目标形成与自动策略归 [npc-agency.md](npc-agency.md)，感知、相遇、时间、同时点与多尺度结算归 [world-simulation.md](world-simulation.md)，个人所知与评价归 [social-graphs.md](social-graphs.md)，资源生产、交易、维修需求与地区后果归 [world-systems.md](world-systems.md)。

部位完整性、伤病实例与治疗唯一细则归 [character-condition.md](character-condition.md)，总 `injury` 不替代这些事实。伤势、装备和受控状态通过统一能力限制决定可用活动，策略层按本人可知情况选择与改策。骨折、缺肢或拘束等结果须先按 [implementation-readiness.md](implementation-readiness.md) 补齐 schema、合法写入、实际效果、投影和恢复，再由冲突规则产生并叙述，不能让模型先写结果、事后补字段。

角色的身体、境界、所学、物品和位置沿用同一权威事实。后台 NPC 不使用另一套无限斗气、免费丹药或叙事装备；本模块中的记录名称仅说明概念职责，不冻结 schema、Domain、命令或新接口。

未来玩家战斗可复用角色数据、效果与结算语义；复用不等于已经确定未来完整战斗的规则、操作或呈现。本轮只为后台 NPC 活动落实所需规则，不顺带重做玩家战斗。

## NPC 修炼是可以选择与被打断的活动

NPC 因成长目标、生活压力、身体状态和当前承诺决定何时修炼、求学、筹资或休息。修炼占用真实时间与地点，不能同时取得整段工作收入、完成旅行并享受全天闭关收益。

| 环节 | 候选条件与结果 |
| --- | --- |
| 准备与选择功法 | 已经学会且满足适用条件，具备必要身体、场所与补给；有秘籍不等于已经掌握或正在运行 |
| 求学与演练 | 有实际渠道、前置能力和可用时间；进度、费用及教师占用真实结算，不由对话宣布学会 |
| 持续修炼 | 根据实际运行功法、资质、环境、身体和有效投入累计进度，使用丹药或材料则从库存扣除 |
| 突破尝试 | 检查积累与相应条件，支付实际准备和尝试代价；开始、成功、失败、中止分别形成结果 |
| 恢复与调整 | 休息、疗伤和补充斗气有过程；受伤、缺粮、来信或敌对事件可中断活动并改变选择 |

境界、功法掌握、斗技熟练和身体恢复分别表达，不能把所有成长压进职业日经验。原著资格与游戏原创参数分别注明，具体倍率、寿元和突破门槛不在这里凭空锁定。

累计只覆盖已经发生且满足条件的区间。被打断时保留已发生进度与消耗，重新开始检查剩余条件；中断后的空白时间不能继续算完整闭关，降低模拟精度也不重抽已完成的突破。

NPC 可为修炼主动购买、交换或保留资源，也会因家人、工作、危险而延后。常规活动可由规则选择和执行；复杂取舍才按需调用模型，不要求全员每段修炼都生成一次判断。

## 自动策略选择与真实战斗执行分开

策略依据本人所知：可见动作与装备、自己掌握的能力、经历形成的对手估计、目标和撤退意愿。对手隐藏的丹药数量、未展示斗技、真实伤势与潜在援手不能直接进入其全知战术。

规则依据双方真实条件：实际境界、已学功法斗技及掌握程度、当前运行与可用效果、已装备器物状态、可用道具、斗气、身体、位置与环境。错误估计可以导致失败，但主观相信自己有药不会生成一份药。

| 决策层提出的候选 | 执行层必须检查 |
| --- | --- |
| 用斗技压制、阻拦或突围 | 是否掌握、是否能施展、斗气和身体能否承担、目标与位置是否有效 |
| 使用丹药或器物 | 实际持有、次数/数量、使用条件和时机；不能同一份药重复服用或在被夺后继续使用 |
| 防御、掩护、调整位置 | 可行动条件、保护对象、同伴配合、地形与真实占用；口头喊援不能立即生成援手 |
| 退却、投降、交涉或追击 | 是否有实际脱离或联系条件、对方如何回应、所需时间与代价；意图不保证成功 |

境界提供重要能力差距，却不能单用 `rank` 抽一个胜负或由模型指定赢家。功法、装备或道具改变结果也须通过具体可声明效果，不接受临时一句“有底牌”便反转结算。

模型可提出可执行战术、解释取舍或表达交涉；伤害、耗费、控制、生死与归属由规则产生。无需模型时，有限策略目录仍可依目标和条件推进，而不是退回文本判输赢。

## 有限分段冲突与可持续结果

候选冲突记录包含参与者、各自目的、所在位置、当前分段、已经发生的资源/身体变化与下一事件边界。它是正在进行的世界活动，不是结算后再补写的一段故事。

每段按已接纳动作和实际条件执行，再给存活且能反应的参与者选择继续、用物、援护、退却、投降或交涉。段数、耗时与具体公式按目标负载校准，不预设人人逐帧模拟。

处理预算耗尽只代表本次提交暂停，保存剩余冲突与待办；不能为了有限计算次数强行判定某方死亡或取胜。旅行、援手到达、家人求救等外部事件按同一时钟介入，不跳过其它世界活动。

偷袭、战斗、取得战利品和俘获是不同结果。击倒不自动等于已搬走目标或搜得全部物品；抢夺要有可转移物与实际取得过程，俘获须建立抽象控制关系并保留逃脱、释放与救援可能。

NPC 可为驱离、护送、夺物、求生或复仇战斗，不必每次打到死亡；投降是否被接受、警告后是否放行取决于目的和条件。仁厚、同族、重点人物或原著身份均不赋予免死。

双方的斗气、伤势、装备状态、道具和同伴后果持续保存。战斗后不能靠下次生活调度一律 `qi=100` 抹掉成本；恢复、维修和再出发会占用后续资源与时间。月度恢复不能清空伤实例、受控事实、损坏器物或缺失部位；普通治疗与永久结构恢复分别检查，变化后重新派生活动与 AI 可用能力，不另写一套战斗专用伤势真相。

## 装备、道具、次数和耐久分类处理

用户要求考虑损耗，不等于所有道具都采用同一耐久条。每种物品由内容规则声明适用的消耗与状态；以下分类、效果和参数仍属候选。

| 类型 | 拟定语义 |
| --- | --- |
| 一次性耗材 | 使用后减少实际数量，可能有条件、间隔或使用风险；没有数量就不能再次生效 |
| 有限次数或充能器物 | 保留同一器物及剩余次数/能量；耗尽后按规则失效，补充需对应来源与过程 |
| 可磨损装备 | 只有规则声明的使用、受击或环境条件才产生损耗；状态可能影响可用效果或造成损坏 |
| 可维修物 | 维修需要相应渠道、能力、时间与材料/费用；修复当前状态与恢复永久损伤是否可行分别声明 |
| 不按使用次数损耗的物品 | 仍可能被夺、丢失或按具体事件损坏，不能因没有耐久就视作不可破坏 |
| 普通同类资源 | 可用数量或批次聚合记录普通损耗，不要求每份粮、每株草独立生成器物身份 |

装备只有实际持有、处于有效装备/使用状态且符合条件时才产生效果。背包内多件互斥装备不能同时叠加；损坏、卸下、借出或被夺后及时改变可用能力。

具有持续状态的器物沿用同一实例：磨损、修复、借用、掉落、被夺、拾取或成为战利品都不重新生成满状态副本。普通同类耗材按数量转移，稀有与唯一物仍保持其稳定身份和归属。

战利品来自失败者或现场真正保有的物品，不按境界重新生成随机掉落。没有掉落的装备继续属于原持有人；已毁器物、已用丹药和已耗次数不能在尸体、遗产或读档后的当前分支重复出现。

器物效果变化与维修需求会进入谋生、交易和组织供给。维修并非免费重置，替换装备也要从实际库存取得；具体生产与经济细则引用世界系统模块，避免再建一套战斗物资真相。

## 时序、恢复与普通损耗的聚合边界

后台冲突中的共享目标、同伴入场和抢夺按同一事件次序处理。多方不能各自用旧快照拿走一件器物，也不能让同伴在同一段时间同时护送两支互不相容的队伍；感知与同刻规则统一归世界调度模块。

稳定训练、普通磨损或恢复可按有效区间聚合，但到期突破、临界身体状态、药物使用、装备损坏、援手到达和稀有物转移应形成检查边界。月度结算不能再次扣除已经分段结算的普通消耗。

保存恢复包含已接纳策略、当前冲突、身体与斗气、所学与修炼进度、装备实例状态、道具数量/次数、物品归属和事件随机依据。读取旧档恢复对应世界，不沿用未来分支的胜负、见闻或已消耗状态。

在相同已接受决策与随机依据下，细分推进和长区间追赶保持关键结果及守恒；新感知或新策略可以改变历史，文本措辞不要求一致。不能以“后台粗算”为由重刷稀有物、重置器物或丢失败者伤势。

## 对既有世界链的直接影响

药谷 A 偷袭失败的候选链先结算双方真实战斗；A 是否能活着离开、追踪、养伤或筹资取决于该结果。B 若选择放行，A 仍带着伤势、已耗道具和时间成本，不能无条件接上尾随、绑架或复仇。

C 炼药成功先满足本人资格与真实投入，再得到有限成品；访友分享、保留自用和偿还承诺从同一库存安排。途中冲突如果消耗、夺走或毁掉丹药，会改变赠送目标与后续关系，不补刷一份保证故事继续。

D 由狩猎改为抢劫时，已有消耗、装备磨损和身体条件继续生效；若中止抢劫恢复旧计划，也不能追回被错过的猎物或同步获取整段收益。家人、受害者与旁观者根据可知经过行动，具体归因与潜在目标仍归 NPC 能动性模块。

## 候选验证与当前玩家边界

| 候选样本 | 应能证明的差异 |
| --- | --- |
| 无玩家参与的成长 | NPC 按功法/身体/补给选择修炼或筹资，活动中断保留进度；不是只等待一次职业日经验和自动升阶 |
| 相同境界不同实际条件 | 已学斗技、有效装备、斗气和道具改变可执行行动及后果；隐藏能力不直接变成对手全知 |
| 数量、次数与损耗 | 耗材不能重复使用，空充能不生效，可磨损器物保持状态；维修有投入，未声明耐久的物品不被统一扣条 |
| 败退与世界长链 | 受伤、逃脱、投降、被夺或俘获改变原计划，允许复仇链中止、转向或等待，不保证复刻样例 |
| 多方、分片与读档 | 援助按时空抵达，稀有物仅一份，跨段损耗不重扣；恢复后冲突和器物接续正确历史 |

这些是后续必要自查的候选依据，不是新增独立审查流程或已通过记录。普通稳定活动先证明规则可持续运行，再用需要模型的取舍验证人物表现；无需为了后台每次施招调用模型。

玩家加入冲突时不得被 NPC 策略层接管。既有 be.2 玩家分支按原状态保留；未来完整玩家与 NPC 战斗的策略输入、操作、规则扩展和界面另行深化。本轮不以后台自动判定替代用户选择，也不把未来大修改变成 NPC 自主世界开工的前置条件。
