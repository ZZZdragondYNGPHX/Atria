## 深度成长规则的展开

v0.68路由：副职与素材扩展的详细设计归 [crafting-materials.md](crafting-materials.md)，确认范围归D129–D130。本文旧炼药条目保留资格、资源和成长依赖，不将“学习配方”解释为所有自创组合必须先拥有固定丹方；新制作尚未实施。

成长深度以 [D17](decisions.md#d17--深度成长与路线组合) 为准。资质与修炼条件影响成长，功法、斗技与资源形成选择，材料和丹药有真实来源与消耗，伤势及恢复影响可执行行动。具体小说资格限制与数值，在取得可核实依据后编写，不凭空设定境界寿元、成功率或倍率。

本轮已按用户允许的 Wiki/百科口径补充机制结构，见 [research.md](research.md)。境界、功法、斗技、灵魂与炼药资格可分开设计；小说或百科明确给出的适用条件和使用次数应进入相应规则，未提供的通用公式由游戏设计并标注为设计结果。

同一人物的实力不能只是一条随剧情变化的描述。建议分清境界与修炼积累、已掌握能力、当前身体与资源条件、临场战术和环境。对明显越出能力范围的意图，反馈可执行边界；是否允许何种越阶挑战由具体规则决定，尚未冻结。

建议让修炼、斗技、炼药、探索、社交与组织活动互相支撑，并允许随经历形成路线；具体资格和师承条件仍遵循小说。多种出身提供不同起点，不预先永久锁定一种职业。此为候选设计，不把炼药设为所有主角必须完成的主线。

深度规则与路线组合已经确认。具体公式、物品数量、完整路线与学习渠道在对应系统模块细化，不再保留轻量模式为待选择方向。

## 主角死亡与完整世界恢复

死亡与存档方向以 [D18](decisions.md#d18--自由存档与完整世界恢复) 为准；同一主角游玩不自动赋予主角免死或永生。世界内的死亡有实际后果，玩家可通过存档恢复此前的世界状态。

自由手动存档、自动保存节点和未完成行动的拟定处理见下文，随机重放要求见 [世界模块](world-simulation.md#d4-时间与中断默认方案)。读档是玩家操作；小说中的具体存活或恢复能力仍按各能力条件结算，不把读档解释成角色天然拥有的世界能力。

Atria 的精确 Revision 与分支恢复可作为技术基础，证据见 [research.md](research.md)。它们不等于已经完成游戏存档 UI、容量和全部子系统恢复验证。

存档体验需要覆盖游戏持久化的全部相关状态；跨 Session 的长期记忆或外部账本若被采用，还须明确隔离与恢复方式。后台任务与个人记忆的恢复一致性作为实现验证内容，完整世界恢复是必须达成的目标，尚未完成验证。

## 首个贯通体验

首个活动优先级以 [D19](decisions.md#d19--首个贯通活动优先级) 为准。NPC 自主生活与长期时代演化仍为最高目标，首个体验将它们落实到人物交往、日常目标、信息传播和机缘争夺中。

| 活动 | 玩家可能做什么 | 要验证的世界联系 |
| --- | --- | --- |
| 探索与争夺机缘 | 获取线索、远行、竞争、协作或冒险取得资源 | 人物位置与所知、机缘归属、时间与风险 |
| 炼药与交易 | 寻找材料、筹资、求教、炼制与出售 | 库存、技能资格、材料消耗、价格与人物成长 |
| 家族或宗门生活 | 建立身份、履约、争取资源、处理立场与冲突 | 关系、组织成员、义务、职位与势力变化 |
| NPC 关系与日常生活 | 结识、交往、互助、结仇、观察人物目标与经历 | 个人记忆、联系、信息传播与人生持续性 |
| 势力经营 | 组织人员、分配资源、制定目标与处理竞争 | 组织能力、资源流向、成员行动和地区格局 |

表中其它活动用于表达后续可能的系统联系，其具体广度尚未冻结。修炼与战斗作为首个贯通体验中的基础环节；具体活动前置、数量、地域和内容广度，结合运行目标落到实施分解。

## 候选贯通场景

玩家通过熟人、交易或观察得到一处机缘的线索，决定独行、结伴、交换消息或争夺。NPC 有自己的目标和认知，会选择同行、竞争、保密、求助或另寻机会。出行与交锋改变资源、身体、关系和所知。玩家之后修炼或等待，再次见面时，人物应保留经历并推进自己的生活。保存和读取此前节点，可以验证整个世界的历史分支一致性。

这是一条贯通体验候选，不预设剧情走向、地图数量、主角出身或必须获得的宝物。

## D4 成长与资源默认方案

拟将成长拆成境界/积累、功法运行、斗技掌握、身体伤势、属性适性、灵魂与技艺资格。境界决定能力条件与重要实力差距，功法和斗技分别决定资源运转与可用行动；有秘籍不等于已学会，满足资格也不等于掌握所有配方。

| 环节 | 规则输入与实际后果 |
| --- | --- |
| 修炼与突破 | 时间、功法、环境、身体与资源影响积累；突破检查条件、消耗和结果，失败/中止后按实际过程处理 |
| 学习与换修 | 传授渠道、秘籍持有、前置能力、时间与训练；换修有明确过程，不能选择菜单后保留互斥功法的所有收益 |
| 斗技与战斗 | 已学招式、熟练、斗气与身体条件决定可用战术；交锋消耗、受伤与恢复反过来改变修炼和生活 |
| 炼药入门 | 先验证属性/灵魂等资格，再学习配方与操控；药材、器具、火种与时间真实占用，炼制失败也有结算 |
| 丹药与治疗 | 效果、适用条件、重复使用限制与服用历史进入状态；不能绕过次数或境界限制靠自由文字重复获益 |
| 交易与收入 | 钱货同次结算、库存有来源；进货和供给会改变稀缺与价格，人物不能为满足对话任意创造资源 |
| 寿元与长期性 | 年龄、身体与有依据的延寿条件可影响人生；未核实的境界寿元与倍率不伪称原著规则，设计值另标注 |

首批需要一组可连通这些环节的低阶功法、斗技、药材与丹药，而不是先填完整百科。拟先覆盖基础修炼、攻防与身法选择、补气/疗伤和一次有资格门槛的炼药链；具体原著条目通过 P0 核实再列入资产清单。它们允许路线组合，不要求所有角色修炼炼药。

NPC 使用与玩家一致的关键能力与资源规则；普通生活活动可按合理区间聚合，独特材料、突破、伤亡和争夺必须有可解释结果。初始物资、普通产出、组织收益与特殊资源分别记来源，记录消耗、转移和销毁，避免长期运行中物品无因膨胀。

## NPC成长、物品与后台冲突的新增依赖

具体NPC修炼/突破选择、后台战斗、装备/道具及数量消耗/次数或充能/可选耐久的唯一细则归 [npc-progression-conflict.md](npc-progression-conflict.md)。本模块保留通用成长和资源守恒原则，不再复制一套战斗公式。

NPC学习、修炼和突破需要已学功法、身体条件、可支配时间与实际物资；未具备的材料或技能形成采购/求学/探索目标。受伤、耗尽补给、装备受损和昂贵道具用尽后，恢复/修理/补购进入生活与经济循环，不能在下一经营周期无因全部重置。

身体部位、伤病与治疗的唯一细则归 [character-condition.md](character-condition.md)；总 `injury` 不替代骨折、缺失和持续伤实例。身体、装备与受控事实通过统一能力限制影响工作、旅行、施技、修炼及 AI 改策；普通回血、通用减伤或月度恢复不能清空新状态。具体效果先按 [implementation-readiness.md](implementation-readiness.md) 具备 schema、合法写入、能力作用、授权投影与恢复路径，再作为结果叙述，不以旁白先宣布伤残来替代实现。

玩家和NPC共用角色能力与物品事实，不意味着本轮制作完整玩家战斗机制。按D33，当前先实现NPC/NPC后台冲突，未来玩家战斗单独大修改；现有be.2玩家交锋和使用物品的分支只记录真实能力，不把它们升级表述为新机制已完成。

物品是否损耗由其类型与规则明确，不能给所有对象机械增加同一耐久条。可损耗的同一实例被交易、夺取或继承时保留状态，堆叠消耗品保留实际剩余数量；保存/恢复同时覆盖装备状态、在用/预留资源、消耗与维修过程，具体表示由实现核验。

## 保存与恢复默认流程

拟在已提交的稳定状态允许自由手动保存，提供快捷存取入口；提交中提示状态并在最近的完整提交点完成保存，不产生半笔交易或半次关系更新的存档。自动存档覆盖新局、危险行动前的稳定节点、旅行/长时活动检查点与重要行动完成后，保留轮换版本，不覆盖手动命名档。自动档保留数量通过体积与体验测试确定。

存档列表显示角色、游戏时间、地点、包版本和最近事件摘要。死亡后可选择读取已有档；游戏内的救治/复活能力单独遵循条件，不能用读档叙事替换。恢复从精确历史 Revision 派生新分支，原有分支保留；浏览器选中对象和未提交草稿可以重置，影响世界的计划、在途行动和个人记忆必须恢复/重绑定。

恢复核对清单：主角与 NPC 状态（含部位完整性、伤病实例、治疗进度和临界时间）、位置与时钟、普通库存与唯一物品、装备实例与受控事实、成长/使用历史、关系/婚姻/亲属、组织、任务与承诺、机会归属、个人知识与记忆、世界历史、随机结算依据、待办和后台结果。恢复后从同一事实重新派生能力限制；检查“保存—继续—读回—再继续”后的演化，不能只比较读回瞬间画面。

恢复后未来分支的知识、死亡和关系变动不能渗入当前分支；挂起模型请求或外部记忆若无法可靠隔离，视为完整恢复的实质失败，先修补再扩大内容。首批默认模型记忆局限本局的职责见 [制作稿](production-plan.md#数据与生成职责)。

## 长期体验验收

由执行代理用代表性样本验证：NPC 不等玩家推进才谋生或探索；同一资源不会被多人同时消费；改变原著前提后不会强行回轨；人物离屏死亡和势力消亡有后续影响；家庭关系跨旅行/闭关/代际变化持续；消息有传播过程；同一主角面对真实损失仍可按完整世界存档恢复。验证样本、等待与规模记录为实际结果，不把尚未执行的清单写成通过。
