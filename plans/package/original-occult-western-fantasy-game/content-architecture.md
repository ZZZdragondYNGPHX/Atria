### 6.40 Round 8 question — content scale and authoring architecture

Round 8 must determine:

- how much of the main city / surrounding region is explicitly authored at launch;
- how many institutions require deep authored content versus generic systemic support;
- how many Tier A / Tier B NPCs should exist initially;
- what can be generated from archetypes without losing continuity;
- how Cases are authored as reusable structures rather than linear quests;
- which anomaly families need explicit design;
- how large the starter Claim Catalog should be;
- how long-form Eastbank content is distributed without one giant lore dump;
- how replay variation changes access, interpretation and consequences without duplicating the whole campaign;
- how Package content is split into maintainable modules / data resources;
- which content must be human-authored and reviewed versus model-assisted;
- how to prevent uncontrolled content proliferation and giant always-loaded worldbooks.
