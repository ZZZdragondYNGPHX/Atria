### 6.32 Round 6 question — world simulation and information architecture

Round 6 must determine:

- which facts are authoritative Truth;
- which records are actor / institution Belief;
- how Memory differs from current Belief and narrative history;
- how Exposure controls what the player, narrator, NPCs and Model Tasks may see;
- how Case / Evidence / Testimony / Finding / Hypothesis / Settlement Records map to state;
- how institutional Agendas advance through logical time;
- how Scene / Day / Arc time maps onto lifecycle clocks;
- how NPC availability is represented without simulating every person every second;
- which world changes are deterministic commands versus model proposals;
- how Knowledge views remain bounded and perspective-correct;
- how old information is compacted without losing referenced or important historical facts;
- how regenerated narrative stays downstream of already-persisted authoritative state;
- how the architecture uses existing Atria Native capabilities rather than creating a parallel ad-hoc state engine.
