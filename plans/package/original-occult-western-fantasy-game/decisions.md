# Original Occult Western Fantasy Game — Frozen Decisions

> This file is a compact cross-module decision index. Detailed rules remain authoritative in the linked module and should not be duplicated here.

## Decisions

- **Original-setting boundary:** build an original occult Western fantasy and borrow design methodology rather than one-to-one LoM setting/progression structures. **Authority:** `foundation.md`.
- **World-law-first design:** supernatural systems, institutions, progression and history derive from a small coherent world-law set. **Authority:** `foundation.md`, `metaphysics.md`.
- **Unified ontology:** Layer C explains why, Layer A describes observable stability/anchors, Layer B describes civilizational technology; these are one ontology. **Authority:** `metaphysics.md`.
- **Progression grammar:** Breach / Investiture enters the supernatural; Claims are constrained by Anchor, Price and Jurisdiction; modular builds must remain self-consistent. **Authority:** `metaphysics.md`.
- **Principle taxonomy:** the Common Eight are a human operational taxonomy rather than guaranteed final cosmic truth; Claims normally combine one or two Principles. **Authority:** `metaphysics.md`.
- **Public supernatural / restricted mechanism:** abnormality is socially known while reliable operational knowledge is institutionally restricted. **Authority:** `society.md`.
- **Modernity as stabilization:** state, Church, Academy and Capital are major reality authorities; registries, finance, courts, press and related systems participate in Anchor infrastructure. **Authority:** `society.md`.
- **Divinity:** gods are transpersonal Identities with multiple possible origins; worship is Anchor rather than generic mana; doctrine does not automatically prove metaphysical truth. **Authority:** `religion.md`.
- **Religious ecology:** an ecumenical religious world contains multiple sacred centers, saints, local cults and office-based priesthood with Church/State/Academy tensions. **Authority:** `religion.md`.
- **Political stage:** the primary state is a constitutional monarchy; the principal stage is an industrial second city within a focused regional scope, contrasted with neighboring political systems. **Authority:** `geography.md`.
- **Player opening:** the protagonist begins as an independent Civil Verifier, with controlled background Anchors, encounters the Eastbank second-death case, and reaches the supernatural through an action-caused Breach rather than destiny. **Authority:** `player.md`.
- **First Claim authority:** resolved actions create discrete Breach Imprints; a curated Claim Catalog yields narrow Claim Seeds that require Anchor/Price stabilization; the model cannot invent mechanical Claims. **Authority:** `player.md`, `metaphysics.md`.
- **Core gameplay loop:** Acquire → Interpret → Commit → Consequence → Continue; investigation separates Evidence/Testimony/Finding/Hypothesis, failure creates persistent state, time is strategic, combat is uncommon and dangerous, and downtime maintains ordinary Identity. **Authority:** `gameplay.md`.
- **Risk resolution:** Native authority builds Resolution Frames, distinguishes Automatic / Impossible / Uncertain actions, uses qualitative risk tiers and bounded Fortune, persists outcome before narration, and never lets regeneration reroll reality. **Authority:** `gameplay.md`.
- **Case architecture:** Cases are unresolved problems rather than quest checklists; Evidence belongs to the world, Cases may merge/split/reopen, closure creates durable Settlement history, and Truth / Finding / Official Settlement / Public Belief remain distinct. **Authority:** `gameplay.md`.
- **Simulation authority:** Atria Lifecycle + Information own world simulation; Truth, Institutional State, Artifact assertions, Belief, Memory and Open Loops stay distinct; one canonical world clock schedules Agenda state machines; narrator/NPC/model perspectives are bounded projections downstream of committed state. **Authority:** `simulation.md`.
- **State decomposition:** simulation uses fourteen logical authority domains with no generic reputation, schedule, economy, quest-progress, truth-percentage, sanity or faction-clock shadow state; mutations follow Hard / Perspective / Intent authority classes. **Authority:** `simulation.md`.
- **Context projection:** Narrator, Actor, Agenda, Reflection and Advisory tasks receive different bounded Context Packages; information transfer is explicit world state, recent narrative is low-authority, and no task gets a universal omniscient prompt. **Authority:** `simulation.md`.
- **World scheduling:** deterministic and conditional world updates run before bounded deliberative Model Tasks; background work is relevance-gated, same-tick commits are deterministic, reaction depth is bounded, and fast-forward is event-driven. **Authority:** `simulation.md`.
- **State authority:** deterministic Atria Native state owns authoritative facts; the language model receives curated projections instead of implicitly owning world state. **Authority:** `platform-and-gameplay.md`.
- **Frontend planning boundary:** this Plan defines only player-visible information, required interactions and anti-leakage constraints; visual design and detailed UX are delegated to a frontend-specialized AI / frontend skill. **Authority:** `platform-and-gameplay.md`.
- **Frontend interaction constraints:** player-facing UI may inspect only player-safe projections, must preserve Evidence/Testimony/Finding/Hypothesis and Claim/Seed distinctions, must expose qualitative known risk rather than hidden backend truth, and must not reveal private NPC cognition or secret Agenda state. **Authority:** `platform-and-gameplay.md`.
- **Content scale:** launch content favors authored causal depth plus generated surface breadth: focused region, tiered NPC simulation, 6–8 Signature Cases, reusable Institutional Case / Anomaly / Claim assets, fragmented Eastbank Canon, and strict hard-authored versus bounded/generated content boundaries. **Authority:** `content-architecture.md`.
- **Signature Case network:** launch uses eight distinct Signature Case responsibility slots; only Second Death is mandatory, Cases 2–7 form a semi-open network, and Eastbank convergence depends on cross-source Revelation Predicates rather than chapter completion. **Authority:** `content-architecture.md`.
- **Content production contract:** major assets separate Canon Core / Perspective Layer / Generation Envelope, use stable IDs / disclosure / generation policy / invariants, and expose structured semantic payload rather than relying on unstructured prose as runtime authority. **Authority:** `content-architecture.md`.
- **Package runtime mapping:** Package Data owns definitions, Lifecycle owns mutable authority, Information owns bounded perspective, Task Runtime owns bounded AI reasoning, and authority-first game logic resolves player intent before Narrator rendering. **Authority:** `technical-design.md`.
- **Implementation gate:** the project remains pre-production; no module is an implementation baseline until explicit approval and Round 10 staging.
