# 已确认方向与待定事项

> 已被 [Doupo Living World](../doupo-living-world/index.md) 取代，仅保留前期设计资料，不从这里开工或恢复执行限制。

## 已确认

1. 作品基于 Atria，题材为《斗破苍穹》，目标是有持续后果、可长期游玩的真实世界。
2. 玩家使用自创角色，与原著人物共处。自创角色是否穿越、起始年代和出身尚未确定。
3. 参考《上古卷轴》《辐射》的正统开放世界交互：玩家进入场所，选择场内人物或对象，直接开始相应行为。
4. 自由文字贯穿功能。用户给出的基准例子是进入客栈、点击掌柜、打字与其对话。地图、人物档案等完整界面仍需支持这一体验。
5. 先广泛调研，与用户讨论若干轮，确定后正式开工。第二轮起先创建／更新方案，再讨论。
6. 充分发挥 Atria；开发中遇到实际影响目标的框架缺陷，可以连同必要根因修补一并处理。
7. 画面采用类似《这是我的战争》的 2D 游戏表现。具体横向镜头、剖面、分层、移动粒度与美术表现仍需细化。
8. 世界时间主要随有意义的行动推进，让玩家可以从容输入与思考。行动耗时、对话耗时和离线行为的详细规则尚未确定。

## 待定

| 事项 | 当前状态 | 为什么需要讨论 |
| --- | --- | --- |
| 空间细节与美术 | 已定类似《这是我的战争》的 2D；镜头、移动粒度和美术未定 | 决定场景结构、角色动画和资产量 |
| 原著规则与历史 | 原作规则优先级、主线是否可改写未回答 | 决定关键人物死亡、机缘归属和剧情因果 |
| 时间细则 | 已定主要随有意义行动推进；各类耗时、长时行动打断和退出后行为未定 | 决定对话、离屏调度与长时闭关 |
| 玩家定位 | 出身、年代、起点、强度、原著知识未定 | 决定首个体验、信息权限与成长循环 |
| 操作与战斗 | 自由输入与按钮分工、战斗节奏未定 | 决定即时反馈、等待模型时的世界行为 |
| 内容与模拟广度 | 地理范围、具名角色量、可进入场所和普通人口层次未定 | 决定制作规模和数据结构 |
| 运行条件 | 目标设备、模型路线、可接受等待与费用未定 | 决定可检验的性能与质量目标 |

## 建议的讨论顺序

空间表现与基本时间方向已定。接着确认原作设定优先级、历史可变程度与玩家首个核心循环；再细化成长／战斗／生活系统、世界自主性、内容规模与性能目标。只提出当前会改变产品方向的问题，普通技术细节由执行者处理。
