# 已确认的产品决策

本模块是跨模块冻结方向的唯一权威。以下均来自用户在本对话的明确表达或对提案的确认；具体设计细节交由执行者处理，不逐题请求用户决定。

| 编号 | 冻结决定 | 详细规则归属 |
| --- | --- | --- |
| D01 | 开放式自然语言文字扮演；职业与动向不锁定；调查只是可选经历 | player-experience |
| D02 | 开局以若干问题与选项自动组合背景，不直接要求挑职业模板；不额外调用 AI生成开局 | player-experience |
| D03 | 玩家表达意图，世界裁定实际结果；AI理解与叙述，不能任意改写世界事实 | runtime-contracts |
| D04 | 稳定因果为主，风险行动允许规则约束的随机性 | runtime-contracts |
| D05 | 保留并深化超凡机制、Claim、锚点与代价，不采用统一刷经验升级路线 | world-supernatural |
| D06 | 机构传承是主流；野路子可探索建立自己的 Claim，但惩罚和风险更高 | world-supernatural |
| D07 | 野路子被官方视为非法，可能遭追查与制裁 | world-supernatural |
| D08 | 多个官方机构传承、立场与义务不同，竞争或冲突，并共同禁止非法超凡实践 | world-supernatural |
| D09 | 人物与世界有限继续发展，按重要程度和有效游玩轮次控制 AI更新频率与次数 | world-supernatural、runtime-contracts |
| D10 | 固定世界与超凡底座允许动态扩展人物、地点和事件，重要内容持续存在 | world-supernatural |
| D11 | 长生与跨世代是可选路线，不是默认目标或核心机制前置条件 | player-experience |
| D12 | 玩家自定方向，世界主动提供机会、压力与行为后果；无唯一必经主线；支持短篇闭环 | player-experience |
| D13 | 允许真实死亡，故事结束；普通模式可读档，铁人模式一命通关、确认死亡后删该局档 | runtime-contracts |
| D14 | 整体前端重构，入口与旧三个导航均可改变；用户 TXT 为视觉护栏，HTML 为参考案例 | frontend |

## 委托给执行者的细节

问答题目、选项、素材组合及冲突消解；更新轮次、重要度阈值和调用预算；具体能力、代价、处罚的表现；页面组合、组件细节和符合护栏的无障碍修正。细节应可追溯到上述方向，不自动扩展为全城市逐轮模拟或传统数值 RPG。

## 不作额外承诺

没有承诺任意背景声明可覆盖 Canon、所有输入都必然成功、无限人口／地域模拟、全部旧存档自动迁移或所有旧调查模块继续保留。没有授权当前阶段开始实现、发行新版本或删除现有数据。

铁人模式选择后不可直接变更等具体防回退策略、机构具体名单与能力参数将在 Phase 1／3设计，不将讨论中的提案悄悄改写为已经实现的事实。模式必须清楚说明，删档范围限定该局由产品管理的存档。

## 实质变更

2026-10-04：用户明确否定固定调查职业与卷宗中心，随后确认 D01–D14。此任务独立于已完成的长期世界扩展，沿用可复用资产与能力，但不继承其默认职业、必经案件与长生主目标。
