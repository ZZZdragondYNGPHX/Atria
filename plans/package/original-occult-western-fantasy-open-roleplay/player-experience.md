# 玩家体验与开局

## 责任与范围

本模块拥有玩家如何进入故事、表达行动和选择生活方向的设计。超凡与世界具体规则见 [world-supernatural.md](world-supernatural.md)，执行和持久化边界见 [runtime-contracts.md](runtime-contracts.md)，视觉见 [frontend.md](frontend.md)。

## 引导式开局

入口支持新故事与已有故事的继续，保存选择按真实宿主能力提供。普通／铁人模式规则明确呈现，不让玩家在不知情时进入铁人。

开局通过一组有选项的问题引出生活处境、关系牵挂、过往经历、超凡接触及眼下打算。选项是体验偏好与起始处境，不是唯一职业清单；具体题目由执行者设计。UI不采用原生 select、checkbox 或 radio，交互表现可为文字选项卡片，仍需正确语义、键盘和选中态。

用已编写的世界素材与规则组合起始背景和预写开篇片段，不新增开局生成调用或专用模型接口。规则显式解决互斥／依赖，用户可返回调整；确认后的背景建立实际起始关系、资源与境况。展示摘要与建立角色不能分别写入矛盾事实。复杂 schema 和自由文字修饰是否保留由 Phase 1定案，不把已有模板数量当作职业上限。

组合结果决定起点，不决定后续职业、路线或人生目标。无需先完成调查教程、接受家族案件或成为核验者。

## 自然语言扮演循环

阅读场景与人物回应 → 写出言行／尝试／打算 → 世界处理 → 阅读结果与变化 → 继续表达或按需查看资料。

玩家决定自己的表达与态度，不直接声明他人服从、能力获得或世界事实成立。界面允许目录之外的意图；如何以通用规则支持它，必须核对实际运行契约，而不能把未知输入硬转为旧调查命令。

建议动作只填入草稿，不自动发送，不构成全部合法行动清单。普通交流与日常行为无需每轮风险同意表单。重大、不可逆后果可提供符合世界知识的提示；详细确认策略在契约设计中限定。

一段输入可包含连续意图；到重要反馈或不可逆节点时回应并让玩家继续决定，不能一次长描述替玩家走完一生。角色无法做到的尝试可以成为有意义的拒绝、失误、代价或新处境，不能每次失败都把剧情清空。

## 多种生活与主动世界

支持日常、谋生、交流、关系、旅行探索和超凡实践。活动自然交织，不强制切换专用“侦探／经营／冒险模式”，不以相同任务清单换职业皮肤。

玩家可以自定目标、改变打算。人物请求、职责到期、环境变化、机会和追查可主动推动事态；内容须源于已知处境与已发生行为，不每轮强塞突发事件或惩罚。故事不要求所有人走同一终极主线。

单段经历可有起承转合和结果，形成短期可玩闭环；继续生活可再展开新经历。核心超凡规则能较早体验，不能靠大量回合与多年跳跃才解锁产品特色。

## 长期与终局

普通生活同样完整，无家族、组织或资产经营也能游玩。长生、跨世代、身份更换和大型委托体系按角色选择、机会与规则出现，不在开局默认向所有玩家展示完整长期管理面板。

死亡结束这一角色的人生，不自动转为后代或凭空救援。具体复生只有在事先成立的世界规则和能力条件中才可能，不属于默认保护。结局呈现已有经历的已知影响；是否保留不可恢复的纪念文字由实现设计决定，不能以纪念页藏回退档。普通／铁人存档语义按 runtime-contracts。

## 最小可玩证明

至少以两种非固定调查起点进入真实角色状态；自然语言行动可进入不同生活方向；有一次完整机构超凡体验以及风险后果；无家族与普通寿命路线可形成短篇结束并继续／终结。野路子不是第一轮必选入口，但需能按规则进入并承担代价。

以上是真实实现阶段的目标，不把参考 HTML 的三个预写演示场景当作运行时证明。
