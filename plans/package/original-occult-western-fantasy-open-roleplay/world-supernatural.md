# 世界与超凡体系

## 责任

拥有机构／野路子、成长、动态世界的详细设计；随机与提交语义见 [runtime-contracts.md](runtime-contracts.md)。保留现有西幻／神秘底座与超凡基本法则，移除固定调查框架对体验的支配。

## 主流与野路子

成熟机构提供传承、训练、见证、锚点支持和风险控制，伴随真实义务与代价。多个官方机构拥有不同立场、培养方式与利益，可以竞争和冲突，共同反对非法实践。机构身份不等于唯一职业；义务应进入角色生活，不变成人人必做的公文任务循环。

野路子支持在世界规则下探索并逐步建立自己的 Claim。不能凭一句能力描述即时发布；获得过程、可作用范围、锚点、代价与稳定条件必须成立。更大探索空间对应更重失败、反噬、失控和违法风险，仍须是能玩下去的路线。

非法实践可能留下痕迹、被目击／举报或造成损害，机构根据获得的信息推进追查与制裁。强度应有因果与可察觉征兆，不凭全知扫描立即惩罚。追查、资源封锁、拘捕／处置的具体规则与机构权力边界由设计者制定。惩罚主要由具体超凡实践及相关行为触发。

## 超凡成长

成长体现理解边界、能力新用法、稳定运用、锚点深化、义务及 Price变化。不同角色可从同一传承发展出不同特点；生活、关系与实践均可贡献成长，不默认刷战斗／案件经验。

力量扩大需有支持条件和承担的后果，不让叙述默默绕过管辖、资格或代价。既有 Seed／Claim／Anchor／Price 的可复用契约与新要求的差异在 Phase 1逐项映射，不假设原有闭合目录已支持自由 Claim Engineering。

## 固定底座与动态扩展

固定层：底层超凡法则、关键世界历史、主要社会结构和机构。动态层：具体人物、地点、工作、关系、遭遇与地方事务。动态扩展可以生成新的现象，但不能推翻固定底座来临时解释输入。

重要新内容取得稳定身份及来源，影响故事后可持续引用；旧地点或人物重新出现须保持已发生事实。普通描述和一次性氛围不需要全部实体化。未获知的真相、机构内部信息与人物动机不因系统存在而自动展示给玩家。

## 有限世界演化

重要程度由当前参与、关系、持续事务、风险与玩家关切共同决定，不只看地理距离。当前场景融入正常回应；重要非当前对象按间隔轮次更新；低关联远方内容低频发展，重新接触时依据连续历史更新。具体间隔和每轮／每次调用预算交由执行者制定并持久化。

同次演化合并有联系的对象，不给所有 NPC 每轮独立调用。不调用模型也能确定的时限、日期与资源变化优先按规则处理。具体触发、轮次推进、待处理与重试权威见 runtime-contracts。

世界主动提供机会与压力，但不得每轮强迫行动。追查与机构 Agenda 也受信息、重要度和预算约束；“有限更新”不能成为相关人物忘记刚发生事实的理由。

## 设计待定与最小范围

Phase 1复用与首批范围如下；Phase 3编写并验证素材、机构能力与合法／非法路径。不要在首个版本追求全世界人口、完整宏观经济、所有职业、所有法术、全地域地图或百年压力门槛。超凡核心、自由表达的多方向体验与稳定后果优先。

## Phase 1：首批机构与超凡闭环

复用Package `data/defs.institutions.json` 的既有机构身份（church、academy、abnormal）及 `defs.claims.seeds.json`/`defs.claims.archetypes.json` 的Principle/primitive、禁止扩展、Anchor/Price底座。现有compileOpening只把两个Seed接在Second Death核验后，convergence.claim是封闭受监督载体；目录中有tradition不等于能自由构造能力。新内容另编写实践资格，不改固定法则来迁就玩家输入。

| 机构 | 首版传承与生活入口设计 | Anchor/Price与竞争 |
| --- | --- | --- |
| 既有Church | 公共礼仪/社区帮助 → 有人见证的矛盾载体 → 记忆/见证传承训练 | 共同誓约与保留载体；不得明知而否认已见证事实、定期维护。优先保护当事人与见证责任 |
| 既有Academy | 文书/助手/公开课程 → 隔离演示与复核 → 命名/边界传承训练 | 可检验的校准载体及导师监督；记录误差、限制用途、承担重复校准费用。优先可复核性与研究开放 |
| 既有Abnormal机构 | 公共求助/危险异常转介，可招募但非人人必选的职业 | 负责危险线索收集与执法协作；和前两者争论归属/公开尺度，共同禁止非法Investiture |

Church和Academy至少各有一条完整接触 → 训练 → 条件成立 → 明确接受Anchor/Price → 首次窄运用 → 维护或失约后果路径。路径不以签同一案件/刷经验换皮。机构承认资格/同意、成员义务与普通谋生分开，不自动把所有角色变机构办事员。名称展示沿用既有素材正式名称。

首版力量族限Memory/Witness与Name/Boundary：保留对一个已亲自验证矛盾事实的识别；识别一个已检验身份载体的不匹配。不能操纵他人心智、发现真名、恢复毁文、改写历史或强迫承认。新场景用普通生活中的物件/承诺/身份载体建立资格；Second Death证据不作全角色前置。学院路线需要编写新的合格见证/边界训练材料，不能把“任意上课”直接算Investiture。

成长记录有限阶段：已接触、已理解边界、可稳定运用、可扩展用途。每次进展必须引用真实实践/见证来源，满足已编写条件后增加一个新用法或扩大一个已明确管辖；重复相同输入不刷成长。Anchor记录载体/关系ID、validity、维护到期；Price记录accepted、义务及违约状态。失约先显露条件变化/不稳定，再由规则处理能力失效、机构处置或反噬，不由Narrator补罚。

## Phase 1：非法探索与处罚设计

玩家可围绕已知Seed提出自己的用途/锚定办法；文本只是研究提案。首版只允许在上述两力量族的已编写工程选项中试验，例如改变个人载体、缩窄条件、承担更重维护义务；禁止字段或未支持的效力返回边界解释/继续研究机会，不发布新规则。保留“建立自己的Claim”的可玩过程，任意模型发明可执行超凡规则暂缓。

需要实际见证、可用载体、准备及对代价的确认；非机构锚点缺少外部见证保护，初始处境至少比同条件合法实践差一档（五处境的下限Desperate），没有资格/载体则Impossible。失败按已编写风险家族留下疲惫、载体破损或可知反噬；严重风险才能真实致死，事前依据已知知识提示，不让普通闲谈突然致死。风险随机/幂等及death提交归runtime-contracts。

追查状态按“未获线索 → 已接到署名举报/目击/残留 → 核实 → 限制/传唤 → 有充分依据的拘捕/处置”推进，每步保存sourceID、该机构实际已知信息和时间。单纯研究/怀疑不自动等于已证实非法实践。隐匿、补救、求助或正式担保可改变下一阶段，但不能抹掉已发生证据。处置先有资源/行动限制和可处理机会；致命执行需明确世界权限、充分依据及可预见严重情境，不设系统全知击杀。

## Phase 1：世界更新所有权

动态身份、提案推广、8槽上限、有效轮数、hot/warm/cold间隔、最多3对象批次、发送预算、stale与重试的唯一详细权威在 [runtime-contracts.md](runtime-contracts.md)。本模块拥有内容重要性及因果：亲密关系、当前委托/义务、正在追查或近期行动后果属于重要对象；前台刚发生的事实立即写入，不能等下一次AI演化才记住。

确定性维护、付款、时限和机构程序先用声明规则；只有确需创作新的地方人物/场所/事务或回应的批次才用AI。机会与压力可延期而非每轮必出。重要对象满额时持续推进现有故事、延期扩展，明确首版容量；不会用新名字覆盖旧人物。跨世代、区域宏观与企业经营仅按后续自选需要复用，第一批不启用跨局continuity/realm转移。
