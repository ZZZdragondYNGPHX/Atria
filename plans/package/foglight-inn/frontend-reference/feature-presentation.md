# 《雾灯旅舍》功能表现与交互说明 (Galgame 演出强化版)

通过转向经典的 ADV（视觉小说/Galgame）界面布局，我们将《雾灯旅舍》的叙事载体从“下拉滚动的文字流”变成了**“以画面、立绘、对话框和音效驱动的切片式演出”**。这不仅能完美容纳生存与经营要素，还能将“人物陪伴感”拉伸到极致。

## 1. 全新信息架构与核心流程

- **场景层 (Background CG)**：大面积的全屏图片承载当前所在地点与天气。背景图可通过 CSS 滤镜与动画（如模糊、雨雪飘落特效）增强环境感。
- **立绘层 (Character Sprite)**：在场人物不再是右侧边栏里冷冰冰的卡片，而是以大尺寸立绘（带呼吸动画）的形式站立于画面中央偏下，极大增强生动演出（Staging）。
- **底图对话框 (ADV Box)**：位于屏幕底部的半透明磨砂玻璃框。所有的文本阅读、人物发言都在此进行。
- **历史记录 (Log System)**：这是 Galgame 架构的核心配套。因为当前屏幕只显示当前语句，过去的对话会自动收纳进通过右上角 `📓 LOG` 按钮唤起的“历史记事面板”中。

## 2. 逐界面说明 (S01 - S13)

| ID | 界面职责 | Galgame 视觉化表现 |
| :--- | :--- | :--- |
| **S01** | 作品入口 | 经典的 VN 标题界面：全屏精致插画，Title 居中偏右，左下角一列文字菜单（开始游戏、继续、设置）。 |
| **S02** | 开局与设定 | 对话框直接转化为“系统提问”，玩家在中央浮现的精美信纸（模态框）上填写姓名和选择偏好。 |
| **S03** | 主游戏 | 本地 HTML 核心演示。包含全屏背景、立绘、顶部 HUD 和底部沉浸式 ADV 对话框。 |
| **S04** | 岛上简图 | 点击右上角 🗺️ 图标，全屏弹出带有毛玻璃背景的地图。各节点配以缩略场景图和文字说明。 |
| **S05** | 人物与交谈 | **无需额外面板！**交谈直接通过画面中的立绘呈现。立绘表情的差分和对话框上的“名签”就是最直观的人物状态。 |
| **S06** | 物资设施 | S03 顶部 HUD 的 🍞🪵⚙️ 图标直观显示当前资源，保持画面的干净。 |
| **S07** | 旅舍记事 | 点击 📓 打开覆盖全屏的“笔记本”。左侧 Tab 为 Log（历史对话），右侧为线索与承诺（事实清单）。 |
| **S08** | 无线电室 | S03 的变体：背景图切换为电台，立绘隐藏，屏幕中央出现特写的“旋钮与频道”交互部件。 |
| **S09** | 行动预览 | 强打断的中央模态框（见 HTML 演示）。背景变暗，卡片清晰展示代价，要求玩家二次确认。 |
| **S10** | 结果与交接 | 确认 S09 后，模态框消失。底部的 ADV Box 变为系统提示色，并配合打字机特效和特定音效打出结算结果。 |
| **S11** | 保存与进程 | 经典的 Galgame 存读档界面：一整屏带有缩略图（当时场景截屏）、日期与时间的存档位列表。 |
| **S12** | 结局后记 | 隐藏 HUD 和控制按钮，纯粹的音乐配合 CG 画面，对话框徐徐打出尾声字幕。 |

## 3. 核心操作映射 (A01 - A37 适配说明)

| ID | 玩家可见名称 | 触发入口与演出反馈 |
| :--- | :--- | :--- |
| **A06** | 观察/查看 | 点击 ADV Box 上方的动作标签。触发环境图微放大（Zoom in），对话框打出描述。 |
| **A07** | 简图移动 | 打开地图面板 -> 点击节点。触发画面的黑屏渐变（Fade In/Out）和环境音效切换。 |
| **A09** | 闲聊 | ADV Box 推进。如果人物在说话，名签旁的“语音/动效指示器”会跳动，配合人物立绘表情变换。 |
| **A12** | 检修设备 | 点击 ADV Box 上方的动作标签。触发 S09 中央确认面板。 |
| **A16** | 自由表达 | 对话框上方的“输入框”。Focus 时展开，提交后 ADV Box 进入 Loading 态。 |
| **A20** | 等候/休息 | ADV Box 内的系统指令。确认后，时间文字发生翻页特效，背景图的光照（如从暮色变黑夜）通过 CSS 滤镜过渡。 |

## 4. 边界与异常状态表现 (ST01 - ST16)

- **ST03 (条件不可用)**：ADV Box 顶部的动作按钮变为半透明。如果强行点击，ADV Box 会发出轻微的“笃”声（如果开启音效），并打出红色提示文本。
- **ST04 (意图理解)**：对话框区域的文本变为“*（正在整理你的打算...）*”，同时右下角出现 Loading 旋转图标。
- **ST09 (请求失败)**：ADV Box 会震动一下（CSS `animation: shake`），弹出系统故障文本。
- **ST15 (图片/声音缺失)**：由于重度依赖演出，若图片加载失败，底层黑色背景和 ADV Box 依然有效，游戏完全可以像纯文字 MUD 一样降级游玩，不阻塞通关。
