# 《雾灯旅舍》前端设计规范 (生动演出 ADV 篇)

本规范旨在指导开发团队如何在 Web 环境下，构建一个表现力不逊色于原生 Galgame / 视觉小说引擎（如 Ren'Py 或 Krkr）的高品质前端。

## 1. 设计观点 (Design Proposition)

**“沉浸的剧场，触手可及的情绪。” (An Immersive Theater, Emotions within Reach)**

我们放弃了死板的网页排版，拥抱“舞台演出”的概念。整个屏幕就是一个舞台：背景图是布景，立绘是演员，底部的 ADV Box 是字幕机，顶部的 HUD 则是幕后的场记。界面必须极其干净（浅色玻璃感），把 80% 的视觉重心让渡给人物与环境，辅以细致入微的动效与音效（Audio-Visual Staging）。

## 2. 颜色、材质与排版 (Colors & Typography)

### 色彩与材质
由于背景图（场景/CG）色彩千变万化，UI 组件必须具备极强的**适应性材质**：
- **Frosted White Glass (白霜玻璃)**：UI 面板（如 ADV Box, HUD）使用 `rgba(255, 255, 255, 0.85)` 配合 `backdrop-filter: blur(24px)`。它既能透出背景的色彩，又能保证黑/深灰文字的绝对清晰。
- **文字颜色 (Text)**：对白文本使用 `#1A252F`，切忌纯黑；系统提示使用中性灰 `#5D6D7E`；危险或代价高亮使用暖橘色 `#E67E22`。
- **名签点缀 (Name Tag)**：发言者的名签背景使用主色调蓝色 `#5A98D6`，这是整个画面中最吸睛的 UI 焦点。

### 排版 (Typography)
- **对话框文本 (ADV Text)**：必须使用衬线体（`Noto Serif SC` / 思源宋体），字号要足够大（`1.35rem` 及以上），行高 `1.8`，文字需要有一层极淡的白色发光（`text-shadow: 0 1px 0 rgba(255,255,255,0.8)`）以对抗极其明亮的背景图片。
- **界面与按钮 (UI Text)**：使用无衬线体 `Nunito`，加粗显示（`font-weight: 600/700`），保证点击操作的明确感。

## 3. 演出与动效核心规范 (Staging & Animation Rules)

前端实施时，这三项是决定游戏品质（拉高上限）的关键：

1. **立绘呼吸与切换 (Sprite Presence)**
   - 角色立绘不能是静态的死图。必须挂载一个 `4s` 周期的极缓平移 `transform: translateY` 动画，模拟人物的轻微呼吸。
   - 角色切换时，必须采用 `opacity` 渐变（Fade In/Out，0.3s），切忌硬切闪烁。
2. **打字机特效 (Typewriter Effect)**
   - 文字不应该瞬间出现。每句对白必须通过 JS 逐字打出（间隔 `30ms-50ms`），玩家点击鼠标/屏幕可立即跳过动画显示全句。
3. **音效联动 (Audio Sync)**
   - **重点表现**：配合打字机特效，名签栏旁边可以放置一个 CSS 制作的“波形小动画（Voice Icon）”。当文字正在输出时波形跳动，文字打完或玩家打断时，波形停止。
   - 按钮的 `Hover` 和 `Click` 虽然企划要求克制，但如果资源允许，可以加入极其轻微的“纸张摩擦”或“轻叩木头”的 UI 反馈音。

## 4. 空间与响应式布局 (Responsive Layout)

- **桌面端 (Desktop)**：
  - 采用宽屏电影感，立绘高度设置为 `80vh`，底部 ADV Box 宽度限制在 `1000px` 左右居中，两边留出呼吸空间。
- **窄屏端 (Mobile < 768px)**：
  - **HUD 折叠**：顶部的资源图标简化为横排无背景排列。
  - **立绘缩放**：人物立绘的高度需缩减至 `60vh`，避免挡住最重要的操作按钮。
  - **ADV Box 贴边**：对话框宽度拉满至 `95%`，并紧贴屏幕底边，为手指点按提供最大区域。

## 5. 实施与对接避坑指南 (Implementation Watch-outs)

1. **图片遮罩层 (Mask Image)**：
   为了让矩形的角色图看起来像“立绘”，如果后端返回的是带背景的矩形 AI 图，前端可以通过 `mask-image: linear-gradient` 让人物下半部分渐渐融入对话框背后，避免生硬的矩形边缘。
2. **历史记录 (Log System) 的实现**：
   因为 ADV Box 只显示当前语句，前端必须在内存中维护一个 `DialogHistory Array`。当按下 `LOG` 按钮时，弹出一个遮罩层，通过简单的 `<ul><li>` 列表将历史 Array 渲染出来并滚动到底部，这是 Galgame 玩家最核心的刚需。
3. **焦点拦截**：
   当弹出 S09 确认模态框时，必须给底层的 ADV Box 加上 `pointer-events: none`，防止玩家在确认行动的间隙，误触背景触发对话“下一句”的步进。
