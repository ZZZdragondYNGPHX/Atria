## 2. 正式采纳的设计意图

**让玩家进入一幅有人的海岛生活场景，通过底部对白与眼前行动参与其中。**

主游戏采用 ADV 舞台：场景占据主要空间、当前交谈者以稳定立绘在场、底部浅色半透明阅读区承载短篇幅叙述和对白；上方保留轻量处境与资源；动作和自由输入贴近阅读区。保留原件的海蓝名签、柔和圆角、清楚层级和空间感。地图、记事、人物详情与设施详情作为同一设计语言的信息层按需打开。

温暖、克制、旧式海岛生活、轻悬疑和自主安排的群像冒险维持既定方向。ADV 是呈现结构，不新增恋爱数值或其他玩法。人物的公开状态、工作占用和承诺要能查阅；表达情绪的立绘不能替代这些事实。

原 HTML 中的现代摄影肖像与帆船海面是示意资源，不确立林岚外貌或旅舍空间。正式图采用柔和叙事插画、可信木屋与旧设备材质，表现室内暖灯与海岛冷雨；构图参考舞台层次，内容服从 [story.md](story.md)。用户在正式制作中明确：人物采用二次元动漫形象，不做仿真；保持成年人物的年龄辨识与稳定身份，场景与立绘画风协调。

## 4. 可执行的布局、阅读和交互规则

### 舞台与信息层

桌面以原件约 1000px 的底部阅读宽度为参考上限，宽度随宿主空间变化。阅读区保留短段、发言者和当前动作；长结果与资料有足够纵向空间和滚动，不强塞固定高度。场景与人物为正文让出裁切空间。多人在场用可读姓名入口选择当前交谈者；同屏大立绘不必把四人挤满。

记事、人物、地图、设施和设置沿用浅色面板、清楚标题与返回。一次只开一个主要信息层；引用详情在层内保留返回链。打开层时保存场景阅读位置与未提交输入，返回后恢复；新内容给“有新记录”提示，不抢走当前阅读。

窄屏将顶部处境与系统入口分行布局，避免原件 390px 下的重叠。资源数量始终可见或一步可查，不能只放 hover 提示。自由输入使用可收缩布局、明确发送名与中文输入法组合输入处理；输入法展开后正文、取消和发送仍可达。容器以可用高度布局，允许必要纵向滚动，不沿用全局 `overflow:hidden` 截断长内容。

### 文字与颜色

保留原参考的正文衬线、UI 无衬线分工；中文正文提供许可合适的本地字体或 `Source Han Serif SC / Noto Serif SC / Songti SC / SimSun / serif` 回退，界面提供完整中文无衬线回退。桌面正文参考 `1.35rem`、行高 `1.8`，窄屏参考 `1.15rem` 起，用户可放大与调行距。不能锁浏览器缩放。

沿用浅色阅读表面、`#1A252F` 正文、`#5D6D7E` 次级文字、`#5A98D6` 海蓝与暖橘。浅蓝/暖橘可作装饰；小字与实心按钮必要时使用深色语义变体，如 `#2D6A9F` 行动色、`#9A4B13` 成本色，保持原有色相。关键成本、错误和状态同时有文字，面板无模糊支持时提供足够不透明的底色。

### 白话演出与阅读控制

已提交的结果先提供完整可回看的事实摘要，叙述可随后自然演出。若使用打字机，沿用参考 30—50ms 的可调整字符节奏，点击或键盘一次只补全本段，再一次才推进已产生的段落。设置允许即时显示；`prefers-reduced-motion` 与作品设置生效后关闭循环呼吸、位移、摇晃和逐字强制等待，使用立即切换或短淡变。

AUTO 仅播放已有阅读段落，遇输入、成本预览、配给、最终决策、错误或新信息层暂停。HIDE 只隐藏舞台阅读装饰，不隐藏“显示界面”入口与必要宿主退出/恢复路径。回看不消费 AP，读得快慢不推进天气或人物工作。

### 预览、结果与焦点

正式动作在原风格的中心卡片说明对象、地点、成本、资源预留、时间推进和已知风险；提供明确确认、修改与取消。打开时进入可取消的安全焦点，背景不可交互，键盘焦点不穿透；关闭可取消预览时 Escape/按钮返回触发点。执行中停止的语义交给宿主，不把关闭动画当成撤销。

入夜时先呈现已提交工作结果，再单独展示配给决定；后者跨保存/恢复保留。人物主动事件与广播通过结果/时段摘要衔接，需要决定的项目有自己的确认。新记录和非阻断变化不逐个叠模态框。
