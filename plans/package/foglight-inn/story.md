## 1. 故事承诺与玩家位置

灯岬岛入秋后的最后一场大风将至。玩家替叶姨照看三天旅舍；叶姨去了内陆陪家人就医，原定返岛的船因风浪改期。玩家已经来过这里，熟悉做饭、登记和锁门等日常事务，但不具备电气、航海或气象专业能力。玩家能在公开说明与必要的安全指导下完成玩法模块定义的有限工作；亲自动手不意味着突然拥有专家能力。姓名、性别、说话方式和待人态度由玩家表达；不预设救世使命、隐秘血统或与旧事故的私人关系。

旅舍尚未关门，四位因为工作、船期与各自打算而滞留的客人先后住下。第三夜末、风暴峰值到来前仍有一次末班船机会，是否能够靠岸取决于真实的天气、引航与协调条件；旅舍原有建筑与基本防寒条件已经能够保住所有人的基本安全，留在这里等待风停也是可负责的安排，不以额外加固任务为门槛。开局就交代这些条件，之后只因新的观测与船务回报更新，不靠突然取消已承诺的交通制造戏剧。

玩家承担协调的职责，也会被照顾。周守川会提醒玩家先吃热饭；林岚会叫停危险的尝试；许澄会替大家核实消息；沈遥会主动承担清点和联络。人物的生活并不都围着玩家转，他们也能彼此建立信任、交换意见。

故事核心是让眼前的人在风暴中有一个可信的去处。旧呼号帮助众人重新理解等待、回应和未能完成的告别；不调查旧事，也能完成这段现实故事。

## 2. 世界与五个地点

时代为架空近现代：岛上有电灯、柴油发电设备、固定电话、短波/岸台无线电和定期渡船，尚无普及的随身联网设备。旅舍的固定电话线路在开局已因风损中断，检修时间由岛外线路员告知；现用报务台承担对外信息。技术限制在开局明确，不随剧情方便任意失效。

| ID | 地点 | 叙事职责 | 场所细节 |
| --- | --- | --- | --- |
| `inn` | 旅舍公共厅 | 日常相处、共同计划、阶段收束 | 窗下长桌、煤油备用灯、旧木地板、保温水壶、叶姨的值守便笺；暖光里看得见窗外的海雾 |
| `store` | 厨房与储物间 | 做饭、清点、分配与私下交谈 | 厨房与干燥储物间属于同一紧凑场景；取物与备餐有实际后果，炉边也容得下闲谈 |
| `radio` | 旧无线电室 | 现用报务、记录查证、旧呼号 | 同一房间内区分仍用于岸台联系的现用报务台，与断开业务用途的退役接收机；后者不能替代安全通信 |
| `lighthouse` | 灯塔 | 实体维修、岸线观察、周的旧事 | 当年与现在均为电气灯组；维修围绕接点、供电和安全通行展开，灯塔不是迷宫或战斗场 |
| `pier` | 避风码头 | 物资、船务、替代转运与告别 | 外侧泊位和背风的小艇接驳点同属此地，开局可理解其区别；不是结尾临时新增的逃生地 |

地点之间的路径与天气影响按玩法模块呈现。岛外有海事岸台、渡船船员、家人和同事，但不扩展为可探索地图或新增核心 NPC。无线电收到的官方回报有来源，传言不会冒充正式海况。

## 3. 人物卡

人物不以隐藏好感条向玩家解释。作者可以维护其记忆、所知和合作状态；玩家只看到言行、明确答复与可观察的关系变化。以下 private 内容不得作为开局简介、默认人物卡或未揭露立绘的文字。

### 3.1 `zhou` — 周守川，61 岁，男，退休灯塔管理员

| 字段 | 设计 |
| --- | --- |
| Public | 住在岛上，风季按惯例到旅舍住几晚，退休后仍会绕路看看灯塔。说话慢，偶尔有干幽默，擅长辨认岸线、旧设备和风浪留下的痕迹。身体能做日常事务，长距离负重与爬高需要量力而行。 |
| Private | 十八年前当班时灯塔失灯，归鹭七号后来失踪。他知道事故并非一句“某个人做错了”可以解释，却一直把自己没能让灯重新亮起当作一种欠账。正式调查没有认定他失职；这份结论没有替他完成告别。 |
| Wants | 当下想确保大家把安全安排说清楚，不愿年轻人为了证明什么冒险；个人层面想把旧值班本交出去，又怕别人只想替他洗清或审判。 |
| Knows | 灯塔结构、背风岸线、当年的值班过程、旧呼号的前半句；不知道船最后沉没的位置、船员最后的想法或异常的来源。 |
| Initiatives | 首日主动检查门窗并提醒灯塔旧接点；第二天提出可行的岸线观察办法；无论是否谈过旧事，都会在最终计划中提供自己知道的安全信息。 |
| Boundaries | 不愿把已失踪的人讲成用来烘托气氛的传说；拒绝高风险登塔和让玩家独自冒险夜行。被逼问时可以终止私人谈话，仍履行眼前的安全协作。 |
| Arc | 从“我得再守一次灯”走向“守住人也算守住灯”。是否说出旧事、是否交出值班本形成后记层次；无需以自我牺牲赎罪。 |

公开可见话术：“灯要修，人也要吃饭。先把手里的碗放稳。”

### 3.5 群像关系与内容控制

- 周与林岚围绕“旧东西是否必须一直修下去”有温和分歧，可以共同完成维修而不互相说服全部人生选择。
- 许澄与沈遥把观测和船务消息核对给大家，意见不同时指出数据来源和更新时间，不制造为了悬疑而互相隐瞒安全条件的桥段。
- 四人中只有周直接承担十八年前灯塔当值的创伤，沈只是见过当年善后的一名少年；林与许拥有独立于旧事故的人生议题。没有“四名客人全是死者亲属”的串联。
- 玩家能请求陪同、帮忙、说明理由、道歉或保留距离；每个人仍按能力和明确边界决定。热情语气不能自动换取技术成功或所有私人故事。
- 每人一个主要可深入场景，配少量随阶段变化的公共厅短交流。人物不会要求四条等长任务全部完成，首轮也不以全收集衡量好坏。

## 5. 信息、谜团与作者真相

### 5.1 玩家记录的分级

| 类型 | 可记录内容 | 禁止混写 |
| --- | --- | --- |
| 亲见/实物记录 | 玩家实际听见的话、当面检查的设备、读到的原始记录和当前可观察结果，注明来源与阶段 | 把 NPC 转述写成“你看见”；把读到事故报告写成亲见沉没过程 |
| 人物证词 | 某人说自己记得、听见或判断了什么；保留说话者与时点 | 证词自动升级成作者判定；把“不记得”补成确定的遗漏 |
| 待核实推测 | 玩家或人物对呼号、动机及因果的猜测，可与现有证据关联 | 为了日志整齐自动揭晓秘密；把肯定句外观用于未经证实结论 |

事实之间可以交叉支持，界面无需替玩家显示真伪分数。原文和短摘要可回看。新证据能修订推测，保留“为什么改了判断”的来源。

| Clue ID | 可证实结论 | 记录渠道 A | 证词/独立材料渠道 B |

渠道 A 是地点内纸面记录链；渠道 B 是人物说明与其持有的独立可核对材料链。玩家不必两链都走，也不必听完周的完整私事。档案不是因好感不足而凭空锁门，人物资料的借阅按普通说明与尊重隐私处理。关键副本不需要偷信获得。

旧事的主结论是：当年的风暴里，有人没能回来，也有人因为他们的行动活了下来。玩家能够让这件事被认真记起，不能证明“只要换一个决定，所有人都能生还”，不能从材料中推出对死者意愿的全知解释。

### 5.3 作者保密区 — 不进入外部前端设计包

**以下是作者侧确定事实，未揭露时不进入模型对玩家的叙述、人物卡、媒体提示词或展示数据。**

1. 归鹭七号的三名船员已在十八年前那场风暴中死亡，尸体与完整残骸未全部寻回。当前的呼叫不意味着可以开一条隐藏救援线让他们复生。
2. 当年的灯塔确实失灯。灯组盐水故障和损坏的梯段使周无法安全完成修复；他留在报务端持续提供岸线信息，直到通信中断。调查未认定他故意或疏忽造成事故。没有隐藏的凶手、保险骗局或客人串谋。
3. 归鹭七号在失踪前协助三名渔民脱险，其船员之后的决定无法从现有材料完整还原。不会用新发现证明所有旧痛都毫无必要，也不把遇难者塑造成只为周获得释怀而存在的符号。
4. 三晚呼号确有超自然成分。其声音和节奏来自当年的一次呼叫，异常为何出现在现在、是否由死者有意回应，作者不作可向玩家讲解的宇宙规则。结尾不能由专家、全知旁白或彩蛋解释成全梦、恶作剧、设备录音回放或普通串台。
5. 第二夜唯一最强目击证据为：林在当天白日完成一次普通的外观检查后，退役接收机已经拔下电源，打开的电池槽内没有电池，此后一直未重新接电；夜间报时一过，接收机指示灯仍亮起约八秒，响起同一句呼号。玩家在场且核实过供电条件，才记为完整的亲见事实；未核实的条件仍标为林的说明。林若也在场，可以独立确认供电条件。现用报务台继续按正常物理条件运作，不参与这种无电发声。
6. 这次现象只发生一次。禁止玩家借此无限供电、拆出超自然零件、要求机器预报、绕过专业检修，或通过重复问话召唤答案。后续检查只得到普通退役机器的结果。没看见这一幕的路线不补出一个同强度奇观。
7. 第三夜最后的声音仍是有限回响，不主动叫出玩家姓名，不透露未被承认的私人秘密，不给出安全路线、天气或物资。可以在前半句之后留一小段像呼吸一样的停顿；是否有人在另一端听见当前回答，保持未明。
8. 过去不可逆、现实准备靠人、异常来源不解释，是同一故事边界。不能为某个“全收集结局”撤销它们。

最强异常不是主线通关证明题。没有亲见者的故事里，玩家可以继续把收到的东西理解为未解的消息；作者真实世界仍保持上述事实。

### 5.4 披露边界与可错过内容

- D1 允许出现未知旧呼号、周短暂的停顿、退役设备与当年日期尚不对应的物件；禁止默认说出船员死亡、周的内疚和各人私人打算。
- D2 可以经调查认出船名、当年救援与失踪事实；人物私事需要适当场景和对方愿意谈，不因为拿到档案就能读心。
- D3 的公开会合只谈当前安排和每个人愿意说的部分，不举行强制轮流坦白大会。玩家可在不知道全部秘密时作出负责决定。
- 可错过的是异常亲见、私人谈话、物件细节和旧事完整证据链。不可错过的是海况更新、已知安全边界、当前目标、已提交行动后果和可选现实去向。
- 任何跨阶段补报都明确为转述或新读到的材料，不把历史日志改写成玩家当时在场。

## 6. 主线与人物支线

### 6.1 现实主线：为大家安排一个可靠去处

从清点现状、了解海况与设备开始，逐步决定要优先投入哪些准备，并在第三天核对最终安排。灯塔引航、避风转运、安全留守三种方向均预先介绍；路线的操作条件、是否已经可行及现实代价按玩法模块明确呈现。

主线冲突来自有限时间、物资、人的体力与专业边界。没有坏人故意毁掉所有准备，也没有人物因为好感低就偷走逃生工具。失约会影响后续信任与自愿的额外帮助，基本专业协作和共同安全不成为私情人质。

### 6.2 调查支线：给七号一份回应

听见或获知旧呼号 → 识别船名与年份 → 了解当年失踪及被救起的人 → 决定怎样回应与记住。

允许只完成前半段、完成历史调查但错过最强异常、亲见异常但不深究，以及完全不主动调查。终局都不发额外物资或解锁神迹。调查主要改变玩家理解、周愿意说的话、共处气氛和部分后记。

### 6.3 两组相互照应的人物支线

为控制体量，人物不各自拉出一套独立跑腿链，采用两个主题组、四个可深入场景：

- **留下什么：周与林。** 周可交出值班本，林可整理工具抽屉；两人通过实际合作承认旧物能被继续使用，人也能离开。玩家的倾听、尊重与兑现的具体小承诺影响场景展开，不要求把两人都劝成同一观点。
- **把话交出去：许与沈。** 许整理交接便笺，沈处理自己的未寄信；一份记录或一封信只有交到别人手里才会开始新的关系，但发出之后无法保证得到理想回应。玩家帮助表达和安排，对方保有最后决定。

首轮可深入一至两人，同时在公共事件中理解其余人。若玩家只处理现实准备，四人仍会履行基本职责，并在结尾保留各自尚未说出的生活。

这些物件只是明确的剧情交付对象，不成为额外可交易库存，不计入生存物资，不重复领取。完成承诺不自动等于听完私人故事、治愈遗憾或获得额外安全协助。接受后若玩家取消或主动破坏约定，人物按具体行为回应；公共安全职责与已经完成的维修登记仍然保留。

结局 ID 只用于作者与实现。开局不向玩家展示三张结局卡、隐藏条件清单、真结局标签或完成率。触发条件、优先级及回退只引用玩法模块。

| ID / 标题 | 实际收束 | 情绪与代价 |

| `light` / 灯亮之前 | 灯塔恢复引航，末班船按确认的安排靠泊。人们在亮灯和收拾行李之间完成各自的交接。 | 一件难事由几个人一起做成；岛并未因此永远平安，过去的人也没有回来。离开可以是承诺新的见面。 |

## 8. 文案与声音叙事准则

- 默认用第二人称贴近玩家，短段叙述与自然对话相接。客人的内心通过动作、话语和后来改变表现；不由全知旁白直接报出私密动机。
- 日常有轻松和朴素幽默，避免四个人轮流讲创伤。风雨之间可以讨论面包烤焦、湿袜子和谁把杯子放错地方。
- 行动反馈先交代完成了什么、用了什么、还缺什么，再容许一句环境或人物细节。不把失败写成只有气氛、没有可执行信息。
- 不要求玩家选择宽恕、告别或接纳这类抽象道德标签；让他选择具体的说法、帮助方式和是否继续交谈。
- 广播语音和环境音不能成为唯一信息来源。旧呼号有可阅读字幕，来源、在场条件和是否为转述保持清楚；画面不画出已逝船员或直接展示海中幽灵确认来源。
- 音乐与音效服务场所和停顿。旧呼号出现时不使用惊吓爆音、尖叫、红屏或恐怖游戏警报；听不见声音的人仍能完整理解线索。
