# 《雾灯旅舍》正式制作 — 新对话启动请求

以下正文可直接复制到新对话。这是新游戏制作的任务入口；企划与外部参考已在本地归档，无需重新上传 Downloads 文件。它不启动当前对话中的产品实现。

---

请正式制作 Atria 的首个完整游戏《雾灯旅舍》，按以下企划和前端参考推进到可安装、可通关的 `.atria` 作品包与必要产品配套。

企划入口为 `D:/Dev/Atria-worktrees/docs/plans/package/foglight-inn/index.md`。如果本地路径不同，先从实际 Git 工作树定位 `docs` 工作空间，再读取 `plans/package/foglight-inn/index.md`；不要假设产品主线中的 `docs/` 就是这份独立企划。

按企划继续已定方向，具体细节、常规适配、故障诊断和必要产品修复由你处理，持续完成本任务。

必须先理解前端意图：

1. 阅读 `index.md`，再读 `frontend-integration.md` 的采用决定、完整界面/操作/状态落点与参考局限。
2. **实际在浏览器打开** `frontend-reference/foglight-inn-concept.html`，观察桌面与窄屏的场景、人物、底部阅读区、动作/输入和预览层次；同时全文阅读同目录的 `feature-presentation.md` 与 `frontend-guidelines.md`。如果浏览器不允许本地文件，可使用只服务该参考文件的本地预览。
3. 对照 `frontend-design-package/interface-requirements.md` 的完整 S/A/ST 与 M01—M07 清单。外部 HTML 允许局部示意，未画出的功能必须按整合方案实现。
4. 阅读 `gameplay.md`、`media-and-runtime.md`、`delivery.md`。内容与信息披露合同设计时完整读取 `story.md`，后续按模块定位，不必每次重载全部企划。

三份前端参考均是用户带回的原件，已经随企划保存。它们负责传达大场景、人物在场、浅色 ADV 阅读区和精致面板的意图。正式实现应保持这种视觉层次与阅读体验；具体缺漏、错误自评和与 Atria 不匹配的技术写法已在 `frontend-integration.md` 处理。不能只抄配色后做成通用聊天后台，也不能把示例照片、alert、硬编码数字和任意 DOM 脚本当作正式游戏。

游戏是温暖、克制、带轻悬疑的旧式海岛群像冒险。玩家临时代管旅舍，在三天有限窗口里自主安排人与事；四名核心人物、五地点、有限资源与行动，少量真实而不明说的超自然。有些遗憾无法弥补，最后留下温暖和希望。ADV 是呈现方式，故事、玩法与人物边界按各权威模块执行。

实施时特别保持这些语义，并以玩法模块的完整规则为准：

- 关键行为先解释/选择方案，再展示成本与条件，明确确认后才正式结算。自由输入不直接改世界；
- 查看、普通移动、回看与阅读控制不推进时间。工作结果和入夜配给分别确认；待配给可保存恢复，不能当旧弹窗丢弃。
- NPC 的在场、已知去向、协助占用/预留/取消和承诺可查。人物所知与说法有来源，作者秘密不串人。
- 三条完整收束路线可依法达到，安全留守始终可达；窗口结束后仍能免费确认最终安排，不能由 AUTO、查看记录或演出替玩家决定。
- 正式历史、存档、角色与资源复用 Atria 的既有权威；前端只投影与缓存。走现行 SavePoint 和宿主导入导出路径，不恢复旧 retry/fork/regenerate 接口，不发明覆盖/删除存档能力。

图片在制作期通过生图接口制作、筛选并随作品交付，游玩按正式状态切换。按媒体模块先做两场景、一人物小样，再扩充计划资产；人物主立绘真正透明且身份稳定，保留阅读和窄屏裁切安全区。音效由你选择并处理，建立许可/来源清单，采用随包环境与事件音，阅读与静音下信息均完整。正式图片、音频、字体或 Package 内容放在 `package` 工作空间。

现有音频播放、分组音量、环境切换与事件去重存在已记录的宿主配套需求。先对照实际产品版本核实，在现有媒体/Presentation 边界补齐有界能力，复用现有状态与保存流程；产品改动放在适当语义源码分支。不要为了显示样稿开放任意 DOM/WebAudio 或另建剧情/音频世界状态。企划的旧源码基线仅是核查依据，实际 Git 与现行合同优先。

按 `delivery.md` 的 M0—M4 依赖推进：合同与媒体准备 → 一段真实规则/模型/媒体/存档闭环 → 必需音频能力 → 三天完整游戏 → 表现打磨与作品交付。遇失败继续诊断和修复，如实区分模拟与真实调用证据。API 测试、记录和持久化按当前 Governance 执行，不从旧文档恢复额外限额或审批。

用同一场景、相近文字密度对照原参考与整合决定，保证视觉意图确实落地。旁白/人物自然度和图片/声音不能只靠 mock 或接口存在来宣称通过。

最终交付完整游戏源码与必要媒体、构建/安装可用的 `.atria`，保留历史发布版本，覆盖三条收束与人物后记、存档恢复和宿主导入导出路径。不要创建新对话；在本对话中完成正式制作。
