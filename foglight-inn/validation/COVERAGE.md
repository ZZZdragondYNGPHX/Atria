# 界面与语义落点

本表映射企划完整清单；“有实现”与“真实模型质量通过”是不同结论。实际验证与剩余限制统一记录在 `docs:records/package/foglight-inn.md`。浏览器工具连接真实 Core 与 Native Frontend，生成供应商为明确标记的本机模拟。

| 界面 | 实现落点 |
| --- | --- |
| S01 | `Main.aui` 标题；继续/新进程由宿主 Play/Library 管理，已有进程不覆盖 |
| S02 | 开局便笺、称呼、表达偏好、Persona、声音选择 |
| S03 | 大场景、透明动漫立绘、HUD、轻色 ADV、自由输入和当前行动 |
| S04 | `Panel` 的 `map`：五地点与已知去向，移动进入零 AP 预览 |
| S05 | `people/person`：公开身份、在场/工作状态、话题、协助、约定、正式交谈回应回看 |
| S06 | `resources`：总量/预留/可用、设施步骤、有限补给和置换 |
| S07 | `notes`：分类、筛选、承诺、进行中协助、来源、详情与已取得的物件图 |
| S08 | `messages`：按获知时间回看海况/船务，当前登记/协调入口 |
| S09 | `preview`：对象、AP、资源、条件、余量、确认/取消和过期检查 |
| S10 | `game.last` 与正式行动回执；多事件分段、独立持久待配给和日终小结 |
| S11 | `saves/log/export`；固定 SavePoint 创建/恢复，宿主文件管理说明 |
| S12 | `final` 条件核对、免费最终决定、三个结局图、四人后记与可选回响 |
| S13 | `settings`、主舞台状态与固定宿主恢复/退出控件 |

| 操作 | 实现落点 |
| --- | --- |
| A01 | 标题进入开局；已有进程引导另开新进程 |
| A02 | 宿主 Play 继续精确进程，恢复后重建场景 |
| A03 | 称呼校验及平和/简洁直接偏好，不授予能力 |
| A04 | 用户点击启用声音或静音开始；菜单可以改变选择 |
| A05 | `start` 闭合事务，防重复与失败核对 |
| A06 | `observe`、HIDE 和已知物件详情，均免费 |
| A07 | 简图、零 AP `move` 预览与明确确认 |
| A08 | 在场人物入口和人物列表的已知去向 |
| A09 | 公开/私人话题、普通闲聊、退出、按人物读取正式回应记录 |
| A10 | 协助方案、预留、预计交付、人物占用与免费取消 |
| A11 | 接受/婉拒/取消/实际交付，显示期限并进入预览 |
| A12 | 地点维修、行装、留守和共同围坐 |
| A13 | 储物间清点与码头一次置换，数量、成本与限次可查 |
| A14 | 地点显式 `investigate`，已获记录可免费重读 |
| A15 | 记事来源/物件与约定交付，不建立可交易剧情库存 |
| A16 | `fog.intent` 只返回最多三个已声明候选；Enter 换行，Ctrl+Enter 理解 |
| A17 | 取消未提交预览后保留原输入，另选/修改 |
| A18 | 唯一闭合行动事务，锁定提交、幂等键和过期检查 |
| A19 | 未执行预览取消免费；执行中取消预览按钮禁用，返回场景不撤销 |
| A20 | 显式 `wait` 花一次 AP，无挂机推进 |
| A21 | 正文前后分段、只读历史和固定结果回执 |
| A22 | 全部/进行中/公共消息/线索分类及文字筛选 |
| A23 | 已知条目详情、来源和返回记事；主阅读位置与草稿不被覆盖 |
| A24 | 约定状态与期限回看；不存在勾选即结算 |
| A25 | 三次主动递进提示，不自动解谜 |
| A26 | 消息免费回看；报务台维修和正式联络另行预览 |
| A27 | 创建新不可变 SavePoint，真实成功/失败反馈 |
| A28 | 选择存档、二次确认、恢复后清除旧草稿/预览，待配给保留 |
| A29 | Play / History & saves 导出；Library 导入校验；精确原始包依赖 |
| A30 | 正式 Timeline 只读分页，不提供旧 fork/retry/regenerate |
| A31 | 总静音、两组增益、标准/大字、减少动态效果及提示 |
| A32 | 调用宿主停止；明确不等于撤销，随后核对当前结果 |
| A33 | 保留输入；已提交则读取，未确认则重新预览；不盲目重发扣账 |
| A34 | 公开准备条件，24 AP 后免费确认；留守始终存在 |
| A35 | 三个收束正文、各四人后记、历史和回响 |
| A36 | 引导宿主另开新进程，保留本局，无跨局资源/秘密 |
| A37 | 保存建议、确认退出、宿主释放音频 |

| 状态 | 实现落点 |

| ST08 | 多事件分段、来源记事、独立配给及日终小结 |
| ST09 | 失败不伪装成功，输入保留，核对/恢复入口 |

| 验收组 | 实现与检查入口 |
| --- | --- |
| M01 | `verify-ui` 开局；完整 Library 安装/用途配置/Play 挂载 |
| M02 | `verify-ui` 移动/维修/人物；`verify-rules` 协助；`verify-story` 四人约定与所知 |
| M03 | `verify-ui` 输入法/澄清/取消/失败恢复；Core 重复 finalize 幂等与 revision 约束 |
| M04 | 记事分类、消息时点、来源详情、LOG、三层主动提示 |
| M05 | `verify-rules` 三条合法路线、三晚配给、最终零 AP 决策；`verify-story` 差异后记 |
| M06 | `verify-portable` 精确依赖/干净存储/损坏文件；真实宿主 UI 导出和导入校验路径 |
| M07 | `verify-media`、实际浏览器参考与挂载对照、真实 WAV 解码/播放、音频宿主回归测试 |

真实旁白、自由表达识别质量、人物自然度和目标设备主观听感不由模拟结果推断；真实模型联测已按用户指示暂缓。
