# 图片制作记录

制作方式：OpenAI 内置 `image_gen`，制作期生成并筛选，2026-10-15。没有使用 CLI 回退。PNG 原件保存于 `images/`，WEBP 为随包编码。人物透明背景由接口直接生成；不以白底或格纹代替 alpha。
