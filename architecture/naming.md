# Atria Naming Policy

- Product, UI and distributable package identity: **Atria**.
- New Atria-owned code should prefer concise `atri_*` names where practical, such as `atri_memory`, `atri_agent`, and `atri_workspace`.
- SillyTavern upstream identifiers remain unchanged unless Atria intentionally overrides that subsystem.
- Legacy Luker persisted keys, protocol fields, data paths and compatibility surfaces may remain until a dedicated migration can preserve backward compatibility.
- New work should not introduce new Luker-branded product identity.
