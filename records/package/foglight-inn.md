## M1 — 真实规则、媒体、存档闭环

Lifecycle 保存正式游戏与只读投影，Authority Transaction 执行闭合动作；自由输入与闲聊声明为 Host Task，不直接写世界。产品补齐显式、精确类型的 `{computed: path}` JSON 复制，保持普通公式不能复制整段私有记录。前端重复项按钮通过受限 `data-value` 和事件目标标识接线。

协助延迟与预留实际扣减、待配给快照恢复及阻止下一耗时行动均通过。

实际 Native Frontend 挂载已操作：开局、阅读分段、移动预览取消、免费移动、维修预览和结算。已修复嵌套组件高度导致信息面板超出窗口的问题。完整浏览器结果见 M4；没有将参考 HTML 演示当成正式宿主证据。

`.atriasave` 已使用 NativeSaveSystem 执行干净存储导入：缺少精确 Package 被识别；安装原始同一份归档后快照状态一致；篡改文件被拒绝且有效进度保留；完整进程导出成功。
