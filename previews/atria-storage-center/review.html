视觉方向与 tokens

使用 Atria 现有纸白底、墨色文字、橙色强调和字体。标题负责定位，数字负责比较，细分隔线负责分组；不使用装饰性计数动画。中文使用系统中文无衬线字体，数字使用内嵌 Plus Jakarta Sans，品牌字标使用 Playfair Display。两种内嵌字体附有原 SIL OFL 许可证。

拒绝增加：总览占比条和数字的扫入／计数动画（影响数值读取）；导航与搜索结果的入场动画（高频与键盘路径）；批量结果逐行 stagger（拖慢查看）；无限闪烁骨架屏（不增加信息）；资源行滑动删除（风险操作不应只依赖手势）。

筛选结论：只保留操作反馈、层级连续性和直接操纵。滚动继续使用浏览器原生惯性，不实现自定义滚动。

中断与时序：抽屉从当前呈现值接管；手势释放携带速度，重新拖动可打断。500ms 只用于手势的物理收敛，普通 UI 进入和退出均低于 300ms。未加入弹性装饰或内容 stagger。

可访问性：键盘开启抽屉立即显示；减少动态效果取消位移与弹簧；偏好在运行中改变时取消当前位移动画。hover 仅对支持 hover 的精细指针启用。按钮按压为非对称时序。

性能：无布局属性动画、逐帧继承变量或预设 will-change。桌面 Chromium 的这次交互检查未观察到明确卡顿，未触发 animation-performance 的性能修复流程；没有 GPU、低端设备帧率或完整性能 trace 的达标结论。

浏览器与 Web Interface Guidelines

已读取本轮最新指南，按实际 HTML 审查语义链接、控件名称、可见焦点、原生 dialog、live region、表单标签、IME、减少动态效果、移动端安全区与滚动。发现的问题已在草稿修正并做相关复测。没有运行 axe 或声称完整 WCAG 认证。

  • 本地 Chromium：服务器九类、选择与整页预览、受保护项、停止与重新核对、跨页状态一致、原 ID 恢复、浏览器永久删除确认和取消。
  • 加载、部分读取、刷新失败、空建议、超配额；搜索空结果、清空、分页；键盘即时抽屉、Tab 循环、Escape 焦点恢复、减少动态效果。
  • 1440px 桌面；390px 手机抽屉与指针手势；320/768px 布局溢出检查。手机是模拟视口，不是手机实机。
  • 抽屉回弹中断、二次拖动、切换范围后的迟到刷新、运行时减少动态效果、键盘焦点避开底部导航：补充检查结果见同一 Record。
  • 范围、查询、排序与分页写入 URL；浏览器范围的筛选深链接及刷新保留实际检查通过。
