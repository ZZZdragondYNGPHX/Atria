# Atria 是什么

Atria 是源自 SillyTavern 的角色扮演与互动作品平台。它将对话、Native 作品和会话与创作、记忆、Agent 编排及资源管理工具结合在一起。

- **Play 和 Library** 用于访问已安装的作品及其会话。
- **Build → Atria Studio** 提供项目编辑、预览和打包工具。
- **Runtime** 管理连接和生成设置。
- 存储中心提供用量、清理建议和恢复操作。

具体说明见[快速开始](/zh-CN/guide/getting-started)、[Native 编排](/zh-CN/features/native-orchestration)和[存储管理](/zh-CN/features/storage-inspector)。

Atria 可以导入支持的角色卡文件。其数据、设置和扩展已经独立演进，不保证与 SillyTavern 完全兼容或无损双向迁移；迁移前请参阅[备份与迁移](/zh-CN/guide/migration)。
