# 备份与迁移

在 Atria 的 **备份与同步 → 归档与恢复** 中，可以将账户数据迁移到另一套 Atria。先在源设备选择数据范围并创建 ZIP 备份，再在目标设备选择该文件，检查预检报告和恢复模式后开始恢复。确认恢复结果前，请保留原始备份。

Native 备份包含作品、会话、资料库、运行时、项目源码及其所需的资源文件。设置、密钥、资源文件和向量索引有各自的选项；请核对两侧的选择，恢复 API 密钥需要选择“密钥”。

需要在 Atria 设备之间反复同步选定文件时，可使用[局域网同步](/zh-CN/improvements/lan-sync)。作品、会话、资料库、运行时和项目的迁移仍使用 Native 归档。

Atria 可以导入支持的角色卡文件，但不保证整个 SillyTavern 数据目录、配置或扩展都能迁移或无损迁回。请独立保留源数据，并在使用前核对导入结果。
