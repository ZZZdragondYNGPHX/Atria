# 存储管理

从 Atria 工作区打开存储中心，切换 **服务器账户**或**当前浏览器**，分别查看两处占用。

- **概览**按资源归属展示用量，包括已安装作品及其包数据。未分类的数据以只读方式显示在**其他数据**中。
- **清理建议**列出相应资源管理器确认可清理的数据。
- **备份与回收站**展示可恢复项目及其操作；早期恢复点在此单独列出，仅在原路径空闲时恢复。
- **操作记录**展示清理和恢复任务。

可执行的操作取决于资源及其引用。清理前请查看预览；正在使用或恢复所需的资源可能受到保护。

浏览器存储与服务器存储分别统计。浏览器的站点估算和已知小计采用不同口径，不会相加；部分数据库和缓存无法提供单项大小。

账户归档和迁移见[备份与迁移](/zh-CN/guide/migration)。
