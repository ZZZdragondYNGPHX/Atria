# 存储管理

从 Atria 工作区打开存储中心，切换 **服务器账户**或**当前浏览器**，分别查看两处占用。

- **概览**按资源归属展示用量。
- **清理建议**列出相应资源管理器确认可清理的数据。
- **备份与回收站**展示可恢复项目及其操作。
- **操作记录**展示清理和恢复任务。
- **高级工具**提供原始存储检查，用于查看旧版或未分类文件。

可执行的操作取决于资源及其引用。清理前请查看预览；正在使用或恢复所需的资源可能受到保护。

原始检查器的**其他**类别包含 `assets` 目录，其中可能有正在使用的 Native 作品包和媒体。占用空间本身不能说明文件已经过期或可以删除；作品及其依赖应通过资料库或存储中心提供的操作管理。

账户归档和迁移见[备份与迁移](/zh-CN/guide/migration)。
