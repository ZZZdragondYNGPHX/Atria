# 如何选择执行模式

先选择**辅助正文**或**接管正文**。辅助模式先生成一份指引，再交给原正文模型；导演创作直接写入回复。

| 模式 | 它负责什么 | 选择它的理由 |
|---|---|---|
| 自主调研 · Loop | 一个代理连续查资料，决定何时提交指引 | 资料要边查边判断，不需要专家分工 |
| 固定流程 · Spec | 执行你规定的阶段、节点和审查 | 每回合都必须做同一套检查 |
| 动态分工 · Agenda | 规划者维护任务清单，按需要派专家，最后汇总 | 任务不确定，适合分给不同角色处理 |
| 导演创作 · Director | 写正文草稿、审稿、修订并提交 | 需要检查和修改实际写出的文字 |

模式选择器按产物分组，兼容入口仍可选择旧 Single。两个选择器联动；切到“辅助正文”时，已有辅助模式保持原样，从 Director 返回则推荐 Loop。已有用户的模式不会自动迁移。

工具、世界书、记忆、Notes 和 Skill 是共同能力。Spec 的 worker 与 Agenda 的工作代理也可以使用工具；模式差异在于流程由谁控制。

## 用同一个回合比较

你把一封旧信交给 NPC，问她为什么瞒着你：

- **Loop**：查前文里关于这封信的约定，确认人物知道哪些事实，再给正文模型指引。
- **Spec**：固定执行“人物认知 → 情绪边界 → 玩家自主性审查 → 汇总”，每轮都走完。
- **Agenda**：事情涉及数个组织，先派历史与阵营专家，发现时间线矛盾后再派人查证。
- **Director**：先写出她的反应，再检查草稿有没有泄露角色不该知道的信息，修改后提交。

这四个模式互为选项，不会自动串成流水线。更多代理或轮次也不保证更高质量。

## 快捷指引与旧 Single

点击**新建快捷指引工作流**可创建一个关闭探索工具的单节点 Spec。它提供两个简化字段，也可以在完整编辑器和迭代工作台中继续扩展。添加阶段、审查节点或节点专属提示词后，使用完整编辑器。

旧 Single 仍在**兼容入口**中，提示词仍是原来的全局字段。它不参加角色级模式预设库。

点击**复制为固定流程预设**，预览提示词后填写名称和保存范围。只有勾选**保存后启用此工作流**才切换模式；不勾选则只新增副本。重名也创建独立条目。原 Single 提示词始终保留，随时可切回。

新模板关闭探索工具；复制旧 Single 时保留当前继承的工具和模型绑定。两者继续共享全局注入设置。Skill 的预设作用域仍按新预设名称解析，已有仅绑定某个预设的 Skill 需要按需求检查绑定。

## 生效来源与编辑范围

面板同时显示“本次生效”和“正在编辑”。你可以编辑全局 Spec，同时继续运行角色自己的 Spec。选择全局编辑不会关闭角色覆盖；显式启用一个全局快捷副本时，才会关闭该角色的 Spec 覆盖。

Agenda 仍兼容已有聊天级覆盖，它优先于角色和全局配置。角色覆盖开关与角色是否保存了预设库是两个不同状态。

## 到限不等于完成

- Loop 未提交指引便耗尽预算时，明确显示预算到限。若有最后的自然文本，仍沿用部分指引回退，但不缓存成成功结果。
- Agenda 达到规划或派工上限后可汇总已有工作；运行面板仍列出到限原因和未完成任务。
- Spec 审查回跑到限仍是失败，不会被视为审查通过。
- Director 沿用原有停止和草稿丢弃策略；停止或切换模式不会暗中启动另一种模式。

同一用户楼层切换模式、有效编排预设或模型绑定后，不再复用不匹配的指引。旧历史仍可查看；没有配置指纹的旧结果需要重新运行一次。没有 Web Crypto 的环境跳过结果复用，仍可正常执行。

Director 支持普通生成、重新生成、swipe 和继续；不要把辅助模式的触发类型直接套用到 Director。
