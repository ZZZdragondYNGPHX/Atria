# 为角色卡定制写作指导

导入并选择角色卡后，在 **Extensions → Skills** 创建可复用的写作指导。为 Skill 写清描述、具体例子和简短自查。角色卡预设、世界信息及 Skill 仍是各自的资产；导入角色卡不会发布可执行的 Agent Plan。

## 构建并发布实际 Plan

在 **Agents → Plans** 编辑图、typed 输入和精确资源 pin。绑定不授予能力，也不启动付费工作。使用支持该图的领域消费者及其显式启动或调度操作。

旧 Director 编辑器、自动 profile 改写和 Browser 自定义工具注册表已不可用。Skill 或提示词中的 JavaScript 片段不会创建可执行工具。只使用 Host 实际准入的能力与工具。

## 改进写作指导

在同样合法的上下文下比较输出。寻找反复出现的模式，而不是逐词打补丁。例如，反复使用数词加量词，可能把感受写成舞台计数：

| 片段 | 反馈 |
|---|---|
| 「连闪了五下」 | 当精确次数没有叙事作用时，描述警报带来的视觉变化。 |

把一般规则和反例写进相关 Skill，保存后更新消费者选择或精确 pin。安装 Skill 不代表所有 Agent 都会消费它。共享标注和反馈只在实际提供它们的编辑界面中使用，不代表存在原生模拟或自动修改提示词的入口。

## 保留输出要求

以 Run 的真实费用和结果为准。取消不会撤销付费发送或退还未知用量，修改 Skill 也不授权重放。

参见[原生 Plan 与 Run](/zh-CN/features/native-orchestration)、[Skill 管理](/zh-CN/features/skills/management)和[创作 Skill](/zh-CN/features/skills/authoring)。
