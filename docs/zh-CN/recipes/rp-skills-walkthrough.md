# 用 Skill 调整 RP 输出

打开 **Extensions → Skills**，选择 **Create new**，编写带名称、描述和明确写作指导的 `SKILL.md`。例如描述角色口吻规则，并附一个符合要求的简短例子。可参考现有内置写作 Skill 的文件格式。

保存后为目标路径设置调用方式。原生 RP 为 Narrator 捕获所选始终纳入指导的精确安装版本。独立 Actor 保持自己的角色上下文，安装 Skill 不意味着所有 Agent 都会消费它。

实际图、资源 pin、验证和发布通过 **Agents → Plans** 完成。Skill 指导模型输出，不能授予 Source 访问权、工具或正式输出权限。修改内容后，应在开始新工作前更新相关选择或 pin。

参见 [Skill 管理](/zh-CN/features/skills/management)、[创作 Skill](/zh-CN/features/skills/authoring)和[原生 Plan 与 Run](/zh-CN/features/native-orchestration)。
