# Shaping RP output with Skills

Open **Extensions → Skills**, choose **Create new**, and write a named `SKILL.md` with a description and clear writing instructions. For example, describe a character voice rule and give a short example of the desired prose. Existing bundled writing Skills are useful format references.

Save the Skill and configure its invocation for the intended path. Native RP captures selected always-included guidance for the Narrator at an exact installed version. Independent Actors retain their own role context; installing a Skill does not make every Agent consume it.

Use **Agents → Plans** for the actual graph, resource pins, validation and publication. Skills guide model output; they cannot grant Source access, tools or formal output permission. After changing content, refresh the relevant selection or pins before starting new work.

See [Skill management](/features/skills/management), [Authoring skills](/features/skills/authoring) and [Native Plans and Runs](/features/native-orchestration).
