- 本地 `custom-release`：`38a8a2dc055dbda1406e71d43838c07de7e6c559`；本次 fetch 的远端 HEAD：`112baa3b5f2ad1109a0b143bcffa3d39ec8dc470`。本地基线完整包含于功能分支，没有新提交需要同步。
- 仍使用每聊天 `memory_graph__provenance`、来源版本、受保护事务及原有模型/向量服务；没有新增数据库、持久化缓存或迁移。普通文字卡无外部依赖；MVU/LoreState 的可选提供者仍只读。
- 热点是同步投影中反复扫描聊天来源、关系查找事实与排他槽冲突的二次扫描，不是 Cytoscape 本身。投影和语料构建即使没有模型请求也曾耗时数秒。

## 实现

1. `source-provenance.js` 增加一次同步计算内的来源索引和 Episode 校验缓存；事实、关系、名称和合并投影复用。缓存不能跨 await 或状态修改保存。重复来源 ID、失效 Episode、跨 scope 与手工来源校验保持原有规则。
2. 图谱投影缓存实体合并路径，按排他槽分组查冲突。修复同端点重复边可能漏过冲突的问题：一个槽存在不同端点组合时，全部相关活动边标为 disputed。
3. 召回构建使用事实索引、词频 Map、预分词查询；向量指纹每 64 条计算一次，中间让出事件循环并检查取消。普通只读事务在账本未变时省去重复状态投影。
4. 图谱检查、诊断和历史批次校验/暂存由模块 Web Worker 执行。Worker 不持久化、不访问外部状态运行时。返回前仍检查来源/作用域；取消、关闭、错误、超时均销毁 Worker。历史发布仍由原生命周期事务负责。
5. Worker 输入排除聊天变量表与回滚备份；图谱模式进一步省去原文副本及证据详情，保留来源校验所需字段。检查器打开详情时从已持有且受保护的快照补回证据。调整来源字段时必须同时更新 payload 合约与等价性测试。
6. 无 Worker 时仅对不超过 1000 个 Fact/Entity/Relation 的账本同步降级；更大的计算明确报错。已有 250 实体 / 600 关系画布上限保留，选择器最多生成 500 项并保留当前选中记录。审计与提供者预览最多 32000 字符；完整账本未截断。
7. 图谱工具栏新增“记忆诊断”：只读显示状态数量、提供者状态、历史进度、查询意图、权重/上限、候选来源和各步骤耗时。它只跑本地词法与图遍历，不请求模型或向量、不增加访问计数。生产 recall trace 另外记录语料数、候选数、入选数和耗时。

## 性能与质量证据

`node tests/memory-graph/benchmark.mjs` 使用确定性有效来源账本。每条关系有独立事实、人物和消息来源，共享 Castle 端点。下表为同机 Node 24.16.0 单次运行，单位毫秒，不代表分位数或设备保证：

| 关系数量 | 原投影 | 当前投影 | 原语料构建 | 当前语料构建 | 当前排序 |
| --- | ---: | ---: | ---: | ---: | ---: |
| 500 | 102.9 | 28.7 | 170.7 | 37.9 | 29.7 |
| 1500 | 734.9 | 72.2 | 1514.8 | 108.3 | 30.4 |
| 3000 | 3054.3 | 135.8 | 6386.8 | 189.0 | 53.9 |

三个规模的首位结果均为 Person 42 的 located_in 关系。新增七组中英文名称/别名、词边界、无关查询、空查询回放通过；保留原检索权重，没有仅凭少量合成数据调整默认权重。原有事实抽取证据、否定/失效、冲突、时序、提供者覆盖与重建校验继续回归。

这证明确定性语义规则与排序回放通过，不证明真实模型抽取准确率；本阶段没有向外部模型、embedding 或 rerank 服务发送评测请求。

## 实际验证

- Jest：`node --experimental-vm-modules node_modules/jest/bin/jest.js --config jest.config.json --runInBand --silent --verbose=false memory-graph orchestrator floor-state luker-android-debug-trail debug-export-android-bridge`（在 tests 目录）。160 套件、1958 用例全部通过。
- 新增优化回归覆盖来源读取次数、修改后失效、冲突分组、只读诊断、Worker payload 等价性、作用域切换、取消/迟到响应、无 Worker 降级和向量分批取消。
- 隔离数据目录的真实 Edge 153 浏览器：图谱 9 项、历史构建 7 项、来源/提供者 22 项；模型响应使用固定测试数据。历史用例通过生产 dispatcher、真实模块 Worker 和持久化路径。
- 新增性能浏览器测试 8 项：390×844、4 倍 CPU 降速、3000 条关系真实 Worker、主线程心跳、画布上限、排序、取消、诊断查询和无横向溢出。投影约 1035.7ms，期间 11 次心跳；这不是帧率或最长阻塞时间保证。星形 fixture 的全局首屏截取 250 个叶节点，没有绘制越界端点的边；实际小图语义边由图谱 smoke 检查。
- 图谱首次移动视口检查遇到 ResizeObserver 时序失败，复跑通过；测试改为等待画布尺寸调整后断言。诊断截图已查看，文本改为左对齐。
- 16 个新增/修改 JS 文件语法通过，diff 检查通过；除 main.js 外 ESLint 为 0 错误、1 条测试条件分支提醒。`main.js` 仍有已有的 202 个 ESLint 错误，不声称全仓 lint 通过。
- 执行 `android-app/gradlew.bat --version`，缺少 `java.exe`；环境亦未找到 adb。未执行原生 Android 构建/设备用例；JavaScript Android 调试桥回归已包含在 Jest 中。移动 Edge 模拟不等于 Android 真机。
