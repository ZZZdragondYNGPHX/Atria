# 儲存管理

從 Atria 工作區開啟儲存中心，切換 **伺服器帳戶**或**目前瀏覽器**，分別查看兩處用量。

- **總覽**按資源歸屬顯示用量。
- **清理建議**列出相應資源管理器確認可清理的資料。
- **備份與資源回收筒**顯示可還原項目及其操作。
- **操作記錄**顯示清理和還原工作。
- **進階工具**提供原始儲存檢查，用於查看舊版或未分類檔案。

可執行的操作取決於資源及其參照。清理前請查看預覽；正在使用或還原所需的資源可能受到保護。

原始檢查器的**其他**類別包含 `assets` 目錄，其中可能有正在使用的 Native 作品包和媒體。用量本身不能說明檔案已經過期或可以刪除；作品及其依賴應透過資料庫或儲存中心提供的操作管理。

帳戶封存和遷移見[備份與遷移](/zh-TW/guide/migration)。
