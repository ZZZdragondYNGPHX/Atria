# 儲存管理

從 Atria 工作區開啟儲存中心，切換 **伺服器帳戶**或**目前瀏覽器**，分別查看兩處用量。

- **總覽**按資源歸屬顯示用量，包括已安裝作品及其套件資料。未分類的資料以唯讀方式顯示在**其他資料**中。
- **清理建議**列出相應資源管理器確認可清理的資料。
- **備份與資源回收筒**顯示可還原項目及其操作；早期還原點在此單獨列出，僅在原路徑空閒時還原。
- **操作記錄**顯示清理和還原工作。

可執行的操作取決於資源及其參照。清理前請查看預覽；正在使用或還原所需的資源可能受到保護。

瀏覽器儲存與伺服器儲存分別統計。瀏覽器的網站估算和已知小計採用不同方式，不會相加；部分資料庫和快取無法提供單項大小。

更新後首次開啟 Atria 時，舊版瀏覽器資料會遷移到 Atria 命名的儲存空間，確認一致後才清理舊資料庫。請關閉仍在使用舊版的同網址分頁，避免它們繼續寫入舊資料庫。如果使用了瀏覽器的舊版後備儲存，Atria 會先提示你關閉其他分頁；取消時舊資料會留在原處。

若新舊資料衝突，Atria 會保留兩份資料並暫停遷移。請先備份並檢查衝突，再重新整理重試。極少數仍使用 WebSQL 的舊瀏覽器無法安全自動檢查舊資料庫；此時請保留瀏覽器資料，不要清理儲存空間。
