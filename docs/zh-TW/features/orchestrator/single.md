# 快捷指引與 Single 相容入口

Single 仍可從執行模式的「相容入口」使用。它以原有全域提示詞組成單節點 Spec，不參與角色模式預設庫。

新設定可用「新增快捷指引工作流程」建立全域或角色級 Spec 預設。新範本關閉探索工具，提供兩個簡化提示詞欄位；複雜流程則使用完整 Spec 編輯器及迭代工作台。

選擇 Single 後，按「複製為固定流程預設」，核對提示詞、填寫名稱、選擇儲存範圍，再決定是否勾選儲存後啟用。副本永遠使用獨立 ID，不覆蓋同名預設，也不刪除舊提示詞。普通模式切換不會同步 Single 與 Spec。

複製保留繼承工具與模型綁定；全域注入設定仍共用。Skill 的預設作用域按新名稱解析，請核對名稱專屬的綁定。

四個主模式為自主調研（Loop）、固定流程（Spec）、動態分工（Agenda）、導演創作（Director）。前三者提供正文指引；Director 直接編輯及提交回覆。Spec 與 Agenda 的工作代理也能使用工具；單節點不保證只有一次網路請求。

面板分別顯示實際生效來源與正在編輯的範圍。Loop、Agenda 達到預算上限時，即使已有部分指引，也會明確顯示未完成。舊快照仍可閱讀，但重用需符合執行設定指紋。
