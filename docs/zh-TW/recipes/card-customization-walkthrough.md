# 為角色卡定製寫作指引

匯入並選擇角色卡後，在 **Extensions → Skills** 建立可重用的寫作指引。為 Skill 寫清描述、具體範例和簡短自查。角色卡預設、世界資訊及 Skill 仍是各自的資產；匯入角色卡不會發布可執行的 Agent Plan。

## 建構並發布實際 Plan

在 **Agents → Plans** 編輯圖、typed 輸入和精確資源 pin。綁定不授予能力，也不啟動付費工作。使用支援該圖的領域消費者及其明確啟動或調度操作。

舊 Director 編輯器、自動 profile 改寫和 Browser 自訂工具註冊表已不可用。Skill 或提示詞中的 JavaScript 片段不會建立可執行工具。只使用 Host 實際准入的能力與工具。

## 改進寫作指引

在同樣合法的上下文下比較輸出。尋找反覆出現的模式，而非逐詞打補丁。例如，反覆使用數詞加量詞，可能把感受寫成舞台計數：

| 片段 | 回饋 |
|---|---|
| 「連閃了五下」 | 當精確次數沒有敘事作用時，描述警報帶來的視覺變化。 |

把一般規則和反例寫進相關 Skill，儲存後更新消費者選擇或精確 pin。安裝 Skill 不代表所有 Agent 都會消費它。共享標註和回饋只在實際提供它們的編輯介面中使用，不代表存在原生模擬或自動修改提示詞的入口。

## 保留輸出要求

以 Run 的真實費用和結果為準。取消不會撤銷付費傳送或退還未知用量，修改 Skill 也不授權重播。
