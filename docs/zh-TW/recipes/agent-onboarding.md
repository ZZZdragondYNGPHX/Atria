# 設定 Native Agents

1. 在執行階段中建立連線，依需要引用已儲存的 Secret。建立模型、生成設定和提示詞資源，再用這些精確修訂建立執行階段路由。
2. 開啟 Agents → 編排，選擇 Spec、Loop、Agenda 或 Director，為所需角色選擇執行階段路由並儲存編排設定。
3. 如需語意記憶檢索，在執行階段 → 檢索中建立嵌入資源，依需要設定重排，再在 Agents → Memory 中選擇精確修訂。
4. 開啟 Native 工作階段並執行工作流程。在執行記錄和診斷中查看失敗原因，返回對應的執行階段資源修正設定。

Secret 和執行階段設定歸玩家所有，不隨作品分發。已安裝作品內容不可直接修改；專案修改透過 Studio → ChangeSet → Review → Apply 完成。

可選全域外掛只有 Regex 和 Search Tools。編排與記憶屬於 Agents，無需安裝擴充。
