# 用 Skill 調整 RP 輸出

開啟 **Extensions → Skills**，選擇 **Create new**，編寫帶名稱、描述和明確寫作指引的 `SKILL.md`。例如描述角色口吻規則，並附一個符合要求的簡短範例。可參考現有內建寫作 Skill 的檔案格式。

儲存後為目標路徑設定呼叫方式。原生 RP 為 Narrator 捕獲所選始終納入指引的精確安裝版本。獨立 Actor 保持自己的角色上下文，安裝 Skill 不代表所有 Agent 都會消費它。

實際圖、資源 pin、驗證和發布透過 **Agents → Plans** 完成。Skill 指引模型輸出，不能授予 Source 存取權、工具或正式輸出權限。修改內容後，應在開始新工作前更新相關選擇或 pin。

參見 [Skill 管理](/zh-TW/features/skills/management)、[創作 Skill](/zh-TW/features/skills/authoring)和[原生 Plan 與 Run](/zh-TW/features/native-orchestration)。
