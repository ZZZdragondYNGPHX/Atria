# Android 應用程式

Atria Android 應用程式可以在本機執行內建服務，也可以連線至已設定的遠端服務。使用本機模式時，應用程式啟動服務並在 WebView 中開啟介面。

可以從此儲存庫在本機建置 APK。建置依賴、簽署與輸出路徑見 [Android 建置指南](https://github.com/ZZZdragondYNGPHX/Atria/blob/main/android-app/README.md)；是否提供現成 APK 取決於實際發布情況。

首選資料目錄為 `Android/data/com.atria.app/files/atria-data`；外部應用程式儲存空間不可用時使用內部儲存空間。更換建置或解除安裝前，請另行保存[備份](/zh-TW/guide/migration)。
