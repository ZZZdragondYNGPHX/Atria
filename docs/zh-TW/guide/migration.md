# 備份與遷移

在 Atria 的 **備份與同步 → 封存與還原** 中，可以將帳戶資料遷移到另一套 Atria。先在來源裝置選擇資料範圍並建立 ZIP 備份，再在目標裝置選擇檔案，檢查預檢報告和還原模式後開始還原。確認結果前，請保留原始備份。

Native 備份包含作品、工作階段、資料庫、執行環境、專案原始碼及其所需的資源檔案。設定、金鑰、資源檔案和向量索引有各自的選項；請核對兩側的選擇，還原 API 金鑰需要選擇「金鑰」。

需要在 Atria 裝置之間反覆同步選定檔案時，可使用[區域網路同步](/zh-TW/improvements/lan-sync)。作品、工作階段、資料庫、執行環境和專案的遷移仍使用 Native 封存。

Atria 可以匯入支援的角色卡檔案，但不保證整個 SillyTavern 資料目錄、設定或擴充都能遷移或無損遷回。請獨立保留來源資料，並在使用前核對匯入結果。
