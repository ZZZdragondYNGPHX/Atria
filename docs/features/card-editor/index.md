# Character Card Editor Assistant

The Character Card Editor Assistant (CEA) is Atria's AI-assisted editor for SillyTavern-compatible character cards and World Info. It accepts natural-language edit requests, previews diffs, and applies only changes the user approves.

CEA remains a compatibility-side authoring utility for character-card content. Native game/project authoring lives in **Build → Atria Studio**, where A7 Studio and the A8 Project Agent operate on ProjectStore, Authoring Operations, Workspaces and ChangeSets.

## Entry point

Open **Extensions → Character Card Editor Assistant → Open Editor**.

The editor supports:

- character-card field editing;
- World Info inspection and editing;
- diff review before application;
- iteration history;
- prompt/API preset selection for its editing assistant.

CEA no longer exposes CardApp runtime or CardApp Studio project authoring.
