# 人物外观池

本目录保存实际图片与制作来源。可抽取条目、年龄/性别条件、Native素材ID的唯一权威是 `source/pools/appearances.js`；通用查询/抽取归 `source/rules/pools.js`，本目录不维护第二套随机表。

当前20个配对身份、40张WebP：

- `key-characters/`：萧炎、萧战、萧薰儿、苏晚禾、何照川、陆青、宁素、苏守义。8张本轮专属Q版；8张既有半身对话参考图按原字节复用，不能称为透明全身图。
- `ordinary/`：12组普通NPC专用立绘/Q版，覆盖男女婴幼、少年儿童、成年、中年和老年；成年各两种骨相/体态。立绘与Q版按同一个视觉身份配对，实际人物姓名、职业和关系仍由规则决定。
- `manifest.json`：逐图尺寸、哈希、alpha、可见边界、提示词、参考图哈希与来源。新PNG无损转WebP保留alpha，原生成文件保留在工具缓存；缓存路径不进入包。

Q版为静态站姿（婴幼为坐姿），没有多方向或行走动画。地图只消费玩家投影中的 `chibiAsset`，详情/对话消费同一profile的 `portraitAsset`。前端以可见人物脚底/坐姿底部对齐网格，不能将整张对话图缩成地图小人。`visibleBounds` 是alpha阈值32的像素边界，可用于集成时的留白核对，不代表行走碰撞框。

年龄采用池中声明的阶段分组，不逐岁重绘。重要角色超出已制作时期时明确返回素材缺失；普通人物阶段转换在规则更新时保存，不在渲染或翻页时重抽。当前普通池有限，兼容候选用完后会复用配对形象，Native Subject仍区分人物。

构建把所有ready图片作为Native assets声明、校验哈希并装入归档；`integration/pools.json`提供作者目录和资源引用，不能作为玩家全知查询口。详细设计与当前前后端字段分别见docs分支的 `content-pools.md` 和 `frontend-contract.md`。
