### 1.2 层栈、导航与返回规则

- **单一层栈（Single Layer Stack）**：所有打开的工作区抽屉、确认弹窗（如读档分支确认、大额共同财产支取、长时闭关中断提示）与宿主门诊断面板共用同一层栈。
- **Escape 与返回键行为**：每次按 `Escape` 或点击层右上角「返回场景」，仅关闭最顶层浮层，并将键盘焦点归还给打开该层的触发按钮；在主场景无浮层时按 `Escape` 呼出「宿主门快捷条（保存/读档/暂停说明/退出）」。
- **查看与编辑零时间成本**：打开 F01–F12 任意工作区查阅资料、筛选见闻、对比存档或编写草稿，世界时钟均保持 `暂停（0 耗时）`；只有点击明确标有耗时或规则后果的提交动作时，才进入权威结算。

## 3. 五条核心端到端操作链（Interactive Walkthroughs）

以下五条操作链已在 [`doupo-visual-direction.html`](doupo-visual-direction.html) 顶部的「五大核心验收集」工具栏中做成一键可切换、也可逐步手动操作的完整交互流程：

### 3.1 操作链一：选中人物 → 自动接近 → 明确绑定目标后输入 → 等待 → 结算回执与叙事分离（F02 + F03 + F12）

```text
[1. 场景点选/列表选择] 玩家在乌坦城东坊画布（或左侧等价列表）选中「百草堂掌柜·韩石（距主角 4.2 丈）」
       ↓ （0 耗时：画布绘出古金虚线预览步径，标注「预计接近耗时 +1 刻」，右栏显示韩石半身像与可见状态）
[2. 自动接近] 点击「接近至交谈距离」→ 状态变为「移动接近中」→ 抵达柜台前（距离 1.4 丈 ≤ 2.0 丈交互圈）
       ↓ （接近仅建立空间可达性，不自动触发买卖或泄露秘密；底部输入栏自动绑定目标：[对：掌柜·韩石 · 1.4丈]）
[3. 自由输入] 玩家在底部输入框键入：「韩掌柜，我愿先押十五枚金币借用店里的采药鹤嘴锄，三日内从青山镇采回药材归还。」
       ↓ （编辑与拼音 IME 选词期间世界时钟严格暂停；若此时误点旁人，触发「目标漂移防误发护栏」拦截）
[4. 提交与双阶段等待] 点击「执行行动」：
       ├─ 阶段 A（规则校验与权威结算）：锁定冲突行动按钮，校验随身金币 ≥ 15 且韩石在场
       └─ 阶段 B（权威结果已生效 + 模型叙事生成）：
             · 立即生成不可逆回执章：[印·已结算：金币 -15 · 获得『百草堂鹤嘴锄(借)』 · 新增3日归还约定 · 耗时 1 刻]
             · 若此时模型叙事生成成功 → 追加韩石叮嘱对白；
             · 若模型叙事超时/失败 → 保留已生效回执与入袋物品，仅显示 `[重试叙事表达（不重复扣取金币）]` 按钮。
```

### 3.2 操作链二：目标改道/切人与草稿防误发保护（F02 + F03）

1. **前置状态**：玩家已接近「掌柜·韩石」，并在底部输入框写了一半草稿：`「韩掌柜，关于柳狰昨日买走的那株凝血草……」`（此时草稿快照绑定 `targetId = npc_hanshi`）。
2. **触发变化**：
   - **情形 A（玩家手动切人）**：玩家在 2D 场景中点击了站在街口的竞争者「采药客·柳狰（`npc_liuzheng`）」，右侧详情面板切换为柳狰。
   - **情形 B（NPC 自主改道离场）**：世界时间在此前一步推进后，韩石按自身日程前往后院库房清点药材，脱离当面交谈距离。
3. **防误发护栏响应**：
   - 底部输入栏上方立即展开琥珀色警示护栏：**「目标变更保护：当前草稿原本指向【掌柜·韩石】，但当前选中对象已变为【采药客·柳狰】（或韩石已移步后院）。为防误发泄密，草稿已锁定。」**
   - 提供三个显式出口：
     1. `[追上韩石并继续发送]`（先自动计算前往后院的路径与耗时）；
     2. `[确认将此草稿改发给柳狰]`（显式更新 `targetId = npc_liuzheng`）；
     3. `[暂存韩石专属草稿，清空当前输入对柳狰说话]`（按对象 ID 独立缓存草稿，切回韩石时自动恢复原草稿）。

### 3.3 操作链三：探索争夺改变线索/机缘归属与分段战术交锋（F04 + F09 + F07）

1. **线索核实与认识论区分（F09）**：
   - 玩家在见闻册看到两条关于「百年凝血草」的记录：
     - `[坊间传闻·三日前]`：茶客称幽涧药谷深处石壁有一株百年凝血草将熟；

## 4. 目标、时间与知识（认识论）三大硬边界规约

## 6. 键盘、IME、焦点与桌面缩放规约

1. **快捷键总表（仅在焦点不在输入框且非 IME 组合输入时生效）**：
   - `1`–`8`：切换底部八大功能工作区抽屉（再次按同一数字或按 `Escape` 收起回主场景）；
   - `[` / `]`：折叠或展开左侧（地点与对象列表）/ 右侧（当前选中对象详情）侧栏；
   - `Alt + L`：直接将键盘焦点移入左侧「2D 场景对象等价列表」第一项；
   - `Alt + V`：切换 2D 场景屋檐/树冠遮挡透视淡化；
   - `/`：直接聚焦底部贯穿式自由输入框。

   - 在底部 `<textarea>` 中监听 `compositionstart`、`compositionupdate`、`compositionend` 及 `KeyboardEvent.isComposing`；
   - 处于拼音/五笔候选词输入态时，按 `Enter` 或数字键 `1–9` 仅由输入法选词上屏，**绝不触发行动提交或工作区切换**；
   - 非组合态下：`Enter` 提交当前自由文字行动，`Shift + Enter` 换行。
3. **2D 场景无鼠标完整可达**：
   - 左侧「场景对象等价列表」实时同步当前场所内的全部人物、设施、采集点与出入口，每行显示 `[类型图标] 名称 · 距离 · 状态`，支持 `Tab` / `↑` / `↓` 导航，`Enter` 选中并预览路线，再次按 `Enter` 或点击行内「接近」按钮即可自动接近。
4. **桌面分辨率与 200% 缩放保底**：
   - 在 `1920×1080` 与 `1440×900` 下完整展示「顶栏 + 左栏 + 2D 场景 + 右栏 + 底部交流与输入台」；
   - 在 `1280×720` 与 `200%` 缩放下，自动收起次要侧栏为顶边/侧边抽屉开关，保证 **2D 场景核心区 + 当前选中目标胶囊 + 自由输入框 + 执行/停止按钮 + 宿主门** 始终在首屏可视区内可操作，不出现内容被截断且无法滚动的死区。

## 9. 仍为设计提案的细化项（FE Proposals）

以下为本轮前端设计在不改变 D01–D26 已确认决定的前提下，为强化游戏操作体验而提出的设计细化建议，供用户审阅：

| 提案编号 | 提案内容 | 解决的问题 | 若用户调整的备选方案 |
| --- | --- | --- | --- |
| **FP-01** | **输入框「目标漂移防误发护栏」与按对象暂存草稿** | 防止玩家在写私密话语或战术时因点选画布其他 NPC 查看资料而把话误发给别人 | 若不按对象分别暂存，则仅锁定发送按钮并提示用户手动确认是否改绑 |
| **FP-02** | **四色认识论印记形状系统（`[亲见]` / `[传闻]` / `[原著记忆]` / `[未知]`）** | 让玩家一眼区分本局事实、可能过时的传闻与穿越者原著记忆，满足色觉无障碍 | 可简化为纯文字前缀标签，保持相同的信息隔离边界 |
| **FP-03** | **2D 场景左侧「键盘等价对象列表」与 `Alt+V` 遮挡透视开关** | 解决手绘俯视场景中人物重叠、树冠屋檐遮挡及纯键盘/高倍缩放下的点选难题 | 可将等价列表合并在底部或顶栏下拉抽屉中 |
| **FP-04** | **读档前「当前分支 vs 目标存档快照」8 项差异并列核对卡** | 直观传达 D18「恢复整个世界（而非仅恢复主角）」的后果，防止误覆盖长线进度 | 可简化为紧凑摘要弹窗，展开查看详细 8 项对比 |
| **FP-05** | **规则结算回执印章 `[印]` 与「仅重试叙事表达」按钮分离** | 彻底杜绝世界状态已扣款/已成交但因模型文本生成超时而导致玩家重复点击扣费 | 保持该分离机制为集成硬约束 |
