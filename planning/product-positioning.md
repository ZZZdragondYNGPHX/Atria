# Product Positioning

## Atria

Atria is a SillyTavern-based modified role-playing product.

The project does **not** aim to detach from or rewrite SillyTavern. Instead, SillyTavern remains the upstream foundation while Atria develops its own product experience, memory system, agent orchestration, workspace, runtime behavior, UI and other extensions.

## Relationship to Luker

Luker is the migration source and legacy reference implementation. Atria is the active product line.

New development targets Atria `main`. The `luker` branch is reference-only and should not be treated as the day-to-day development base.

## Relationship to SillyTavern

The `vanilla` branch tracks a selected SillyTavern upstream snapshot. It exists to make future upstream comparison and selective synchronization explicit and auditable.
