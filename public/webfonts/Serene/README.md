# Serene Canvas typography

Self-hosted variable fonts from the Google Fonts repository:

- [Playfair Display](https://github.com/google/fonts/tree/main/ofl/playfairdisplay), weight 400–900, SIL Open Font License 1.1.
- [Plus Jakarta Sans](https://github.com/google/fonts/tree/main/ofl/plusjakartasans), weight 200–800, SIL Open Font License 1.1.

The original font filenames and accompanying OFL notices are preserved. Chinese text uses the local Song/Ming and sans-serif fallbacks in `atria-tokens.css`. The UI makes no font requests to third-party services.
