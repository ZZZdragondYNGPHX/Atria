# 事件摘要

把一段已经发生的故事，写成后来仍能接得上的记忆。读者应该知道谁做了什么、为何作出选择、结果怎样、还有什么悬着；不需要重看全部动作和对白。

这里讨论事件摘要的写法。具体字段、输出结构和本次抽取范围沿用当前任务约定，不把摘要的压缩方式套到小说正文，也不替换运行时的抽取或压缩请求。

## 叶事件：保留完整的因果

同一件事写在一起，用自然的句子连接起因、选择和后果。简单过场可以很短，真正的转折则给它足够空间，不按原文字数分配摘要篇幅。

优先保留：
- 人物的行动与结果，尤其是改变后续处境的决定。
- 承诺的具体内容、条件、期限、代价与接受方。
- 关系、身份、能力、控制权和关键物品的变化。
- 未解问题的具体指向，以及已经取得的线索和进展。
- 决定性的信息传递：谁知道了什么，谁仍被蒙在鼓里。

战斗概括关键战法与战果；调查概括发现、推断和证据的关系；协商保留最后的条件。亲密或情绪强烈的场景同样侧重发生了什么及其关系后果，不逐项回放身体反应。

“原文写得很长”不等于“摘要也要很长”。但为了短，把谈判写成“双方达成协议”，漏掉交换条件，也失去了记忆价值。

## 事实、人物理解与情感

已经明确的内心活动、人物自己表达的想法和持续的情感变化，可以按其来源记下。说“她担心弟弟失踪与城外的军队有关”，保留了她的担心；写成“军队带走了弟弟”，则把猜测变成了事实。

人物的言语不总是实话，沉默也不等于同意。只见到动作时可以记动作，不必替它决定唯一心理解释。原文确实确立了情感变化，也不必为了“客观”把它删得只剩流水账。

有用的细节取决于后文需要：一封信上的错字可能是关键线索，一连串相似的表情通常可以省略。按剧情作用取舍，不按词表或词性剪裁。

## 时间、地点与可选索引

采用默认记忆图的叶事件写法时，可按以下形式组织；任务已有指定格式时沿用它：

    时间: <已知的故事时间或相对时间>
    地点: <已知的地点>

    <自然段，写清事件、关键选择和后果。>

    不可逆:
    - <会持续影响后文的重要变化>

    未结:
    - <具体事项及其已存在或本次产出的 thread 引用>

    原文摘录:
    - <载体或用途>: “<准确原文>”

三个索引段按需要出现，没有对应内容就不写。它们帮助快速找到重要信息，不是另一份重复摘要。

- **不可逆**：死亡、重要身份转变、关键物损毁等持续后果。关系和能力是否可逆以故事设定为准，不把一时情绪写成永久状态。
- **未结**：尚待兑现的承诺、待查明的疑点或仍在推进的任务。指向真实 thread 时使用其现有标题或 ID；没有 thread 记录的上下文，可以在正文保留未完成事项，不编造节点。
- **原文摘录**：需要保留措辞的信件、暗号、题词、仪式语言等。普通对白通常概括其行动意义；一句话的原样措辞若就是线索，则保留它。

时间精度跟着来源走。原文只有“入冬以后”就这样写，不补造年月日时分。故事时间、消息序号和记忆批次是不同概念。

## 新信息如何落位

人物的长期背景、别名和稳定能力，适合进入任务所支持的人物记录；地点的长期用途、资源和控制者适合地点记录。事件仍要记下这条信息何时被谁获知、为何改变当下局面。

例如，某人原本属于敌方是背景；他在会谈中坦白身份、导致谈判中断，是本次事件。只把背景挪进人物卡而删掉这次揭露，就断了因果。

引用正式契约、称号、物件名和数量时保留准确内容。需要删的是摘要自行加上的“关系全面升级”“命运从此锚定”等空泛评价，而不是这些词可能承载的真实事实。

## 高层概括：换一个观察尺度

压缩多条叶事件时，按同一行动线、关系演进或阶段目标归并，不逐条缩短后拼接。输入中重复记录的同一事件只记一次，仍保留它的结果与时间关系。

默认记忆图的 rollup 使用时间区间和简洁编号条目。依据提供的 rollup_depth 或实际层级调整尺度：近层概括保留重要决定和未结线索；更高层聚焦长期变化、阶段转折与结束时的状态。不要仅凭摘要长短猜层级。

更高层可以省去日常过程，却不能把重要后果、关键条件或仍未解决的问题压没。时间区间覆盖本组来源，不只概括最后一个场景；来源只有相对时间时沿用其精度。

## 交付前顺读

看摘要能否回答“事情为什么走到这里，下一段从什么状态接起”。去掉重复描写，保留承诺内容、因果转折和未解事项；确认没有把 prior context 当成本批新事件再记一次。

交付最终摘要或当前请求规定的结构化结果即可，不附逐句判断表、初稿或完整思考过程。
