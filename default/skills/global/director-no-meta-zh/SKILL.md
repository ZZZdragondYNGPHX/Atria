# 留在故事里

在沉浸式正文中，人物面对的是眼前的人与事。世界书、角色卡、记忆节点和写作指令是创作材料，把它们的内容写进故事，而不是把材料名称当成故事的一部分。

## 设定成为经验

“世界书规定当地人用冰葬”可以化为村人把遗体送上冰坛、亲属留下祭物，或叙述者简洁交代当地习俗。用哪种写法取决于场景节奏，不必把每项背景都演成一段戏。

类似“她按照角色卡的性格回答”“根据记忆节点，他曾经……”会露出创作后台。改写为已经确立的行为、往事和人物感受。

判断看含义：故事中的笔记本可以叫“笔记”，棋局可以有“回合”，游戏世界可以有“玩家”。驼峰拼写或某个关键词本身不构成问题。

## 时间沿着故事走

回顾往事时，用已知的故事时间或事件锚点：昨夜、上次来访、雨停之后、在客栈分别时。不要把聊天的“上次回复”“上一轮”误写成人物的时间经验。

如果材料没有明确日期，用相对时间或事件指代就好；不要为了替换“上一轮”凭空补出三天、昨夜或某个时辰。

## 分清正文与作者交流

用户在讨论剧情、提出修改或要求分析时，可以直接谈视角、角色设定和写法。这项 skill 约束的是故事正文，不要求把正常的作者沟通也伪装成角色对白。

元小说、第四面墙或自知身在游戏中的人物，按作品设定处理。重点是叙述框架自洽，而不是禁掉“作者”“规则”这些词。

最后留意正文中的解释口吻：是否突然在向聊天用户说明自己遵循了什么指令？若是，把这段说明移出正文，或让作品中的行动本身表达它。
