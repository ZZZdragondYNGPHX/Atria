# 摆脱套话

套话的问题在于它替读者完成了感受，却没让事情真正发生。先看这句话在场景里有没有独特作用，再决定留下、缩短或重写；熟悉的词也能用得准确。

## 让关系落在事情上

“二人的关系从此进入新阶段”通常不如写清发生了什么：她交出了备用钥匙，他第一次没有在天亮前离开。需要过场时，一句“此后他常来吃晚饭”也很好。

不要把普通相处自动封成“灵魂契约”“专属模式”“永久归属”。若故事里确实签了契约、交换了誓言，照实写出内容和代价；若只是一次答应，就让它保有当时的轻重。

临时命名可以有趣，尤其在人物玩笑里。只有当叙述者反复给行为加新标签、使场景变成概念说明时，才把标签还原为动作。

## 让情绪有个人的形状

“瞳孔骤缩”“呼吸一滞”“嘴角勾起”“心底泛起涟漪”单独出现并无原罪；一段里排队出现，或人人都这样反应，就失去了人物。

挑那个真正属于此人的反应：本想反驳，却先把快掉下来的盘子接住；话说得轻松，离开时忘了拿伞。也可以直接命名情绪，尤其当继续描摹只会拖慢叙事。

分析型人物可以分析，机器人可以读数，寡言者可以真的平静。让这些特征参与他的选择，而不是强行给所有人装上相同的羞怯、失控和热烈内心。

## 留意重复的句法

同一批句子若反复用“不是 X，而是 Y”“仿佛 X，又像 Y”“一寸寸、一点点”推进，换掉其中没有新信息的部分。反问、排比、破折号和省略号都可以有力量，重复过密才会变成程式。

数量词、时间、对白引出词和因果连接词按表达需要使用。“他退了半步”能说清距离，“她说”能让对白清楚，不必为了避套话绕成更僵硬的表达。

## 改写时留下什么

- 留下事实与因果：谁做了什么，为什么此刻这样做。
- 留下人物分寸：他愿意说到哪里，哪些话只会对这个人说。
- 留下真正有用的感官：它让场景具体，或改变人物的注意力。
- 留下余味：动作和对白已经表达的东西，不必再补一段意义总结。

例如，“她用冷静的语气宣告两人的关系彻底终结”可以写成“她把钥匙放在桌上。‘衣服周末来拿。’”若场景需要概括而非特写，“她提出分手，约他周末取走衣物”同样准确。改写跟随叙事距离，不追求固定答案。
